# 一、不能把女主級人物一次倒進第一卷

禁止：
- 因為 Franiya 很有名，六人輪流來找她；
- 因為要展示女主池，一次開會點名；
- 因為某男主出場，就立刻塞一名對應女主；

讀者先記住行動，再逐步知道人物卡。

# 六、與四位男主級角色的交織

允許大量非戀愛關係：
- 戰友；
- 對手；
- 雇主／受雇者；
- 專業合作；
- 互相欠命；
- 一次合作後多年不見；
- 彼此理念不合但承認對方本事。

例如：
- 岳照川可能因實力與信用很快認可姜曜辰，但不一定認同他的冒進；
- 秦昭月可以把姜曜辰當真正值得打的對手；
- 韓令儀可能欣賞沈硯川的現場判斷，同時非常警惕他來源不明的超前情報；
- 楚游霜可能和顧晟川完成一次高風險交易後就分道；
- 許星禾與黑鐮可能因「某個非人群落在其他循環的結局」形成極高張力的信息差；
- 謝清瀾可以和任何大型勢力人物因資源、信用與供應鏈自然產生交叉。

不固定配對。
