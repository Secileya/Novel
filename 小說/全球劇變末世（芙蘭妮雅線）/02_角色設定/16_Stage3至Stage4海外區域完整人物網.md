# Stage 3～Stage 4｜海外區域完整人物網

> 建立日期：2026-10-02  
> 狀態：**WORKING_CAST / 海外長期群像基準**  
> 核心要求：海外地區不得再由一名「國家代表」代替整個社會。每個長期停留區域都要有政府、公共部門、產業、地下／灰色網、散人、文化娛樂與普通生活人物。

---

# 一、東灣港鏈｜東亞島國港鐵共同體

既有人物：**九條真澄**｜鐵路調度工程師。

### 1. 高瀨玲子｜港鏈行政協調官
- 44歲
- 末日前地方政府交通政策出身
- 性格禮貌、效率極高，不喜歡用「緊急」掩蓋規劃失敗
- 負責港口、鐵路、避難區之間的公共協調
- 對九條真澄很信任，但兩人常因「先修哪條線」爭論

### 2. 森川修司｜海防與港區警備指揮
- 39歲
- 性格沉著、保守、對未知海洋生命極度警惕
- 不反對國際合作，但堅持入港檢疫與武裝申報
- 不會因 Franiya 到訪就放棄程序，只會把程序做得更謹慎

### 3. 白石綾｜界材列車工程師
- 31歲
- 原高速鐵路車輛工程師
- 喜歡把所有問題畫成圖
- Stage 3 後主導界性材料減震、列車防護與高風險線路改造

### 4. 羽鳥陸｜港口裝卸工頭
- 47歲
- 大嗓門，愛講冷笑話
- 非高階職業者，但非常懂碼頭實際怎麼活
- 認為很多高層會議只是在重新命名「誰先卸貨」

### 5. 水城葵｜公開論壇主持／地方主播
- 24歲
- 末日前做地方旅遊與生活節目
- 末日後變成港鏈公共直播熟面孔
- 很會把警報、物資、交通資訊講得不令人窒息
- 私下怕昆蟲，遇到鐵殼蟑群會直接失去主播專業感

### 6. 黑田誠一｜灰色貨運中介
- 36歲
- 不做純黑幫，更像「不方便走官方程序的東西找他」
- 有自己的碼頭人脈、船員與倉庫關係
- 會賣情報，也會拒絕太髒的生意

### 7. 矢野千尋｜獨立危區測繪者
- 28歲
- 喜歡獨自行動，話少但不冷
- 擅長海岸、山地與廢線勘查
- 不喜歡被勢力綁定，是東灣散人圈的重要名字

### 8. 佐伯悠斗｜夜間料理攤主
- 33歲
- 末日前居酒屋廚師
- 港鏈最早重新開夜食攤的人之一
- 非戰鬥者
- 會研究新海產到底怎麼去腥，而不是怎麼煉成裝備

# 二、北海聯線｜北歐海事救援與島港網

既有人物：**伊蓮娜・沃斯**｜海事救援主管。

### 1. 馬提亞斯・林德｜海港市議會緊急委員
- 51歲
- 末日前地方政治人物
- 性格溫和，但談預算會變得很難纏
- 主張救援能力與港口公共性不能完全私有化

### 2. 卡琳・霍姆｜破冰船船長
- 42歲
- 對極端海況有近乎本能的判斷
- 不浪漫化海洋
- 常說：「海不恨你，它只是沒在乎你。」

### 3. 約納斯・艾克｜海洋界能研究員
- 34歲
- 興奮型研究者
- 看見新物種容易講太快
- 與伊蓮娜最大矛盾是研究價值與救援風險的邊界

### 4. 艾達・尼爾森｜港區醫師
- 38歲
- 急救與低溫損傷專長
- 性格乾脆，討厭英雄式硬撐
- 後期可能走海事生命維持方向

### 5. 盧卡斯・布倫｜自由獵人／獸群觀察者
- 30歲
- 對新生獸群有高度興趣
- 不以「看到變異獸就殺」為原則
- 在部分保守社群中名聲褒貶兩極

### 6. 莎拉・維克｜地下電台主持
- 27歲
- 末日前喜劇演員兼播客主持
- 世界變了之後仍然很會嘴
- 節目裡會嘲諷政府、領主和天氣，但有明確不曝光救援位置的底線

### 7. 埃里克・索恩｜船舶零件商
- 45歲
- 能從一堆鏽蝕倉庫找出全港口唯一還能用的軸承
- 不強，但一缺他大家都頭痛

### 8. 米婭・羅森｜青年救援志工
- 20歲
- 怕死，真的怕
- 但每次輪到自己值班仍然會去
- 不把勇敢寫成沒有恐懼

# 三、紅沙水鏈｜中東乾旱都市與水務共同網

### 1. 蕾拉・納賽爾｜城市水務總協調
- 40歲
- 與馬利克長期合作也長期爭吵
- 最大原則：水不是戰利品
- 但也知道沒有武裝就守不住水

### 2. 奧馬爾・法魯克｜沙地護運隊長
- 37歲
- 末日前物流與安保
- 嘴很毒，對雇主沒耐性
- 對隊員極護短

### 3. 薩米拉・阿迪勒｜地下水與地質學家
- 32歲
- 對乾旱區界能改變地下水系極度敏感
- 是少數會因「一口井」改變一整座聚落命運的人

### 4. 哈立德・優素福｜大型太陽能場維護主管
- 48歲
- 不喜歡把新世界技術神化
- 堅持最好的界能設備也需要有人清沙、換軸承、檢電纜

### 5. 娜迪雅・薩利姆｜地方市場經營者
- 35歲
- 管糧、水、香料、日用品與交易信用
- 能笑著把三個吵架商隊一起趕出去

### 6. 法迪・卡里姆｜灰市路線掮客
- 29歲
- 熟悉荒野小路、水點與非官方交易
- 愛錢，但不賣會直接導致聚落斷水的情報

### 7. 瑪雅・拉希德｜歌手／現場演出組織者
- 26歲
- 認為「大家都快死了所以不能唱歌」是最荒謬的邏輯
- 會在水配給恢復後第一個重新辦小型演出

### 8. 亞辛・穆拉德｜年輕界材修理師
- 22歲
- 迷戀新世界機械
- 說話很快，喜歡炫新工具
- 戰鬥能力普通，但修設備效率驚人

### 7. 米拉・桑托斯｜喜劇演員／直播主持

# 七、海外人物使用 Gate

1. 一個地區至少要有多個圈層，不用單一角色代表國家。
2. 海外人物不是為了見 Franiya 才存在。
3. 每個區域都要有不戰鬥的重要人物。
4. 娛樂、餐飲、論壇、普通居民同樣屬於人物網。
5. 高階人物也保留私人性格，不變成外交發言機。
6. Franiya 到訪某地，不會讓當地原有矛盾與人際網自動圍著她重組。
7. 一部分人物可以一生都不與 Franiya 正式見面，但仍能成為長期 POV 或世界熟面孔。
