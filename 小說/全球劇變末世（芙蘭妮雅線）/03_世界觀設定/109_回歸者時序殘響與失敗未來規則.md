# 一、世界中確實存在真正的回歸者，但「回歸」不是單一機制

本世界允許真正意義上的回歸者存在。

核心不是：
- 預知夢；
- 人格模擬；
- 系統提前發攻略；
- 死亡後人人可讀檔；
- 可購買的重生券。

而是：
> **某個生命曾真正活過一段未來，之後因世界級回捲、時序接縫事故或特殊自我保存機制，使完整主觀記憶與自我連續性進入更早時間。**

目前正式成立的三名回歸者，其來源並不相同：
1. 裴夜衡【黑鐮】——多次世界回捲中的正式生命側時序錨；
2. 沈硯川——一次世界回捲中的時序接縫搭載事故；
3. 顧晟川——一次性【逆刻印】在世界回捲中保存完整自我。

因此固定：
> **三人都是真回歸者，但不是同一種回歸者。**

Franiya 永遠不是回歸者。

# 二、裴夜衡【黑鐮】｜多輪世界回捲的生命側時序錨

## 2.1 黑鐮不是「死了就重生」

裴夜衡第一次人生原本也只是這個世界中的生命。

在一個極後期世界演化失敗的時代，他抵達與【終末收束】、世界進化門檻或最終資格試煉相關的根源事件，並在世界自救機制中簽下／承接了生命側時序錨定。

其本質可概括為：
> **當世界被判定已進入真正不可挽回的演化終局，世界可將當代時間線回捲至早期錨點；裴夜衡的完整生命記憶、自我連續與人格歷史被指定為可跨回捲保留的生命側觀測資料。**

這不是裴夜衡私人擁有的存檔鍵。

固定規則：
- 黑鐮本人不能主動按下「重開」；
- 黑鐮死亡不等於世界立即回捲；
- 如果他第二天自行送死，他就會真的死亡；
- 只有世界後續真正抵達符合條件的終末失敗，才可能啟動整體回捲；
- 若那一輪世界在他死後仍繼續數年，他沒有中途讀檔權；
- 回捲後保留的是記憶、自我與經驗，不是未來肉體、等級、裝備與世界權限。

因此他的心理不是：
> 「反正死了能重來。」

而更接近：
> **「我得活到足夠後面，才能知道這一輪究竟又在哪裡失敗。」**

## 2.2 黑鐮為何需要作為生命側錨

神序自世界誕生之初便存在，遠早於黑鐮的任何循環。

祂們擁有世界根源、職能、規則災害與跨世界紀元層面的歷史記憶；但祂們本身就是世界根源常設者，與普通生命的生活尺度不同。

黑鐮被保留下來的價值不是「他比神序更懂世界」。

而是：
> **他保留了生命尺度的完整失敗史。**

例如：
- 某個人為何在第七天背叛；
- 某座避難所因哪一扇門沒關好而失守；
- 哪個隊伍其實在任務開始前就已經互不信任；
- 哪條路只差三分鐘就能救下一批人；
- 哪個公會會長在某次事件中做了不同選擇；
- 哪個看似正確的攻略在第三階段會把文明推向另一條死路。

神序記得世界。

黑鐮記得自己真正活過的那些人生。

兩者不是上下替代關係。

## 2.3 回捲次數

裴夜衡已經歷大量循環，具有「數十次至接近百次」的重量。

正式正文揭露前，不必把總數鎖死為正好一百。

每一輪：
- 不一定活到相同年份；
- 不一定由相同事件首先失控；
- 不一定形成相同勢力格局；
- 不一定抵達同一版最終資格試煉；
- 終末時間可能提前或延後；
- 某些人物可能活著、死亡或根本走上另一條人生。

但舊歷史是真實歷史，不是模擬。

# 三、神序知道「世界曾經回捲」

神序的靈魂、本質與世界根源直接綁定。

因此世界發生真正根源級回捲時，祂們不是完全被洗成毫無察覺的新個體。

固定：
> **神序可以保留／恢復與世界根源、職能、重大終末事故、回捲本身相關的根源記憶。**

祂們可以知道：
- 世界曾經抵達過終末；
- 時序曾經被回捲；
- 裴夜衡是跨輪保留完整生命記憶的異常錨定者；
- 某些直接牽涉自身職能的世界級失敗曾發生過；
- 某些曾被證明會導向根源災害的方向需要重新評估。

但神序不必像黑鐮一樣保留每一輪所有日常細節。

例如祂們未必記得：
- 某輪第三天某間便利商店裡誰說過什麼；
- 某個普通人何時第一次加入公會；
- 某條巷子的臨時路障哪天被推倒。

因此固定區分：
> **神序保有根源／世界職能尺度的跨輪記憶；黑鐮保有完整生命人生尺度的跨輪記憶。**

神序從世界存在起便一直都在，黑鐮的循環只是祂們漫長歷史中的後來事件，不得倒寫成黑鐮比神序更古老。

# 四、沈硯川｜一次世界回捲中的時序接縫事故

沈硯川曾真正活過劇變後約五年。

他在一場高階世界領域／時序結構崩壞事件中死亡或進入生命連續即將斷裂的狀態。

恰好同一輪世界之後進入根源級回捲。

正常生命的完整人生記憶應隨回捲被重置，但沈硯川當時的自我連續正卡在：
> **崩壞世界領域與回捲時序之間的接縫。**

結果他沒有成為正式時序錨，卻像被回捲「順手帶上車」一樣，把完整自我記憶帶回早期。

其自我直到：
> **T0 前 43 分鐘**

才在當代身體中完成穩定。

因此：
- 他是真回歸；
- 只回來一次；
- 沒有再次回歸保證；
- 沒有世界級讀檔權；
- 回來時仍是當下普通肉體；
- Franiya 若主動深看，可察覺其自我時序存在一道非常明顯、但只有一次的接縫。

這與黑鐮的多輪錨定痕跡不同。

# 五、顧晟川｜一次性【逆刻印】帶回完整自我

顧晟川的回歸來源不與沈硯川重複。

在他的舊未來中，他曾於一場高風險隱藏事件、特殊試煉或世界側異常中取得極罕見一次性結構：
> **【逆刻印】**

【逆刻印】原始用途不是「死亡後重生」。

其真正作用更接近：
> **當持有者遭遇高階因果、時序、世界領域崩解時，盡可能保存一次完整的自我紀錄與人格連續。**

顧晟川原本甚至可以只把它理解成：
- 防止自我被規則污染改寫；
- 在高階時序災害中保存人格；
- 防止某些因果攻擊把自己變成「從未存在」。

當那一輪世界真正開始回捲時，【逆刻印】判定：
> 整條當前自我歷史正在被覆寫。

於是它把顧晟川完整的記憶、人格、情緒與人生紀錄，一併帶進更早的自己。

完成後【逆刻印】消耗。

所以固定：
- 顧晟川只獲得一次回歸；
- 他不知道自己還有沒有下一次，合理答案是沒有保證；
- 他因此更重視這一世的決斷，不會拿命測試重生；
- 其狠辣與復仇感仍首先來自人格與真實舊人生，不是刻印強迫。

# 六、三人的舊未來不要求來自同一輪

這一點正式固定。

沈硯川與顧晟川可以來自黑鐮不同的歷史循環。

作者層不必立刻公開具體是第幾輪。

例如可以存在：
- 沈硯川經歷的東川基地第三年才陷落；
- 顧晟川經歷的版本第二年冬季便已消失；
- 黑鐮兩種都見過，甚至還見過第一年就崩潰的版本。

三人說出互相矛盾的「未來情報」時，不代表其中有人記錯。

可能只是：
> **他們真正來自不同的已發生歷史。**

具體循環編號在正文需要前保持作者層可調，不鎖死「第61輪／第78輪」等示例數字。

# 七、回歸者帶回的是人生，不是滿裝帳號

三人共同適用：

可帶回：
- 人生記憶；
- 戰鬥經驗；
- 對怪物、生態、城市災難、勢力與人物的認識；
- 已學過的知識與攻略理解；
- 對職業路徑、材料用途、危區規律的經驗；
- 情感、創傷、後悔與私人關係記憶。

原則上不直接帶回：
- 未來等級；
- 未來生命階位；
- 未來裝備；
- 未來領地；
- 未來財產；
- 未來肉體強度；
- 只在未來時間點才成立的行政／世界授權。

黑鐮即使打過同一個 Boss 幾十次，回到 T0 的身體仍需要重新長到能執行那些動作的程度。

# 八、舊未來的可靠度：與 110 號文件共同生效

舊未來是真實發生過的完整歷史。

Franiya 出現不會魔法式使全球五年歷史全部失效。

正式判斷仍遵守：
> **舊未來具有慣性；Franiya 的影響必須沿真實因果鏈擴散。**

因此：

## A. 高可靠
- 地理；
- 建築；
- 災前身份；
- 固定設施；
- 某些世界規則；
- 某些由地形／根源條件決定的世界事件。

## B. 中可靠
- 怪物巢形成；
- 區域任務細節；
- 組織形成時間；
- 某些塔層攻略；
- 某批人物相遇。

## C. 高可變
- 人物最終選擇；
- 背叛；
- 愛恨；
- 死亡；
- 領主與會長人選；
- 政治結果；
- 文明是否通過某次資格試煉。

固定：
> **人格傾向具有慣性，命運沒有保固。**

# 九、Franiya 是所有舊輪都沒有的真正外部變量

Franiya 不屬於這個世界原生時序鏈能完整推演的存在。

在黑鐮大量舊循環、沈硯川舊未來、顧晟川舊未來中，都可以沒有當前這個以 `Franiya` 身分公開介入世界進程的她。

因此當本輪第一次出現：
> 【首個感染生命已被擊殺。】  
> 【完成者：Franiya。】

沈硯川會先視為重大偏差並繼續驗證舊未來。

顧晟川會先把她列為不可測高危變量。

黑鐮則會在多次交叉驗證後逐步形成：
> **她可能是大量世界內答案都無法自行產生的真正外部破局變量。**

不能因這點讓三人自動知道她真正來源、家庭、能力本質或完整存在尺度。

# 十、回歸者可以提前知道本世尚未公開的高階情報

一般角色受到當前世界情報階梯限制。

但回歸者存在一個明確例外：
> **他們可以記得自己舊未來確實接觸過的高階情報。**

因此若某人在舊未來曾真正確認：
- 神序存在；
- 高塔某層規則；
- 世界級代理者特徵；
- 某件超規格遺物；
- 某次終末資格試煉

他在本輪可以提前知道。

但：
- 知道「神序存在」不等於知道五人全部私人資訊；
- 看過某輪終末不等於知道世界所有根源真相；
- 黑鐮輪數最多，知道得最多，但仍不是全知；
- 本輪 Franiya 造成的全新分支沒有舊攻略可用。

# 十一、作者 Gate

1. Franiya 永遠不是回歸者。
2. 回歸不是普遍世界機制，也不是死亡保險。
3. 黑鐮多輪回歸由世界終末級回捲觸發，不由其個人死亡觸發。
4. 神序從世界誕生起即存在，遠早於黑鐮錨定；不得倒置古老程度。
5. 神序知道世界曾回捲，但其跨輪記憶尺度與黑鐮不同。
6. 沈硯川是一次時序接縫事故，顧晟川是一次【逆刻印】保存，兩者不具無限回歸權。
7. 三人舊未來可以來自不同循環，互相矛盾的記憶不必有人說謊。
8. 回歸者不帶回未來等級、裝備、生命階位與完整世界權限。
9. 舊未來是真實歷史，但不等於本輪必然未來。
10. Franiya 是舊循環集合之外的核心外部變量之一。
11. 回歸者可提前知道舊未來曾合法接觸的神序／高階情報，但不得升格為作者全知。
12. 不得因上一世某人曾犯罪，就把本世尚未犯罪者視為已被世界判罪。
