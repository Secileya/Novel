# Stage 3｜高職能代理者與區域級世界執行節點

> 狀態：WORKING_BASELINE / Stage 3 中後段可逐步登場

## 一、核心原則

Stage 3 後，人類開始接觸不只負責「解說／單點執行」的代理者。

但仍須維持：
- 代理者不是世界本身；
- 不同職能權限不同；
- 高職能 ≠ 全知；
- 代理者仍能受傷、失誤、被世界撤換或死亡。

## 二、新增職能候選

### 1. 【區域審核使】
- 審核大型領地、跨區事件與特殊節點資格；
- 不直接替人類治理領地；
- 能讀取比引導使更高層的區域資料。

### 2. 【調停使】
- 用於多領地、代理者、特殊世界節點之間的規則衝突；
- 調停的是世界規則接口，不是人類政治仲裁庭。

### 3. 【監察使】
- 追蹤世界節點異常、代理者失誤、特殊規則偏移；
- 瑟列事件之後，這類職能在例外生命與高風險事件中更重要。

### 4. 【商律使】
- 管理特殊世界商店、拍賣、跨區支付與世界認證交易規則；
- 不能隨意定價，主要維護節點規則與資格。

## 三、人格仍然存在

高職能代理者可有：
- 極端程序派；
- 對例外保持謹慎；
- 對人類文明產生研究興趣；
- 討厭低效流程；
- 對其他代理者文化有不同看法。

不能變成同一個客服聲線換制服。

## 四、Franiya 與高職能代理者

瑟列死亡後，高職能代理者面對 Franiya 通常會：
- 先確認權限邊界；
- 避免把本地生命綁定條款直接套到她身上；
- 將「無法分類」與「違規」分開；
- 必要時上報更高層判定，而不是一路加碼暴力。

這表示世界在學會處理例外，但不是變得能理解她全部。

## 五、代理者與世界政治

人類會試圖：
- 建立代理者聯絡窗口；
- 記錄不同職能說法；
- 比對權限；
- 尋找可申訴、可審核、可交易的接口。

代理者因此逐漸從「神秘存在」變成新世界制度環境的一部分。

## 六、Gate

1. 高職能代理者不能變成萬能 NPC。
2. 不讓代理者取代人類政府、法院、商會與外交。
3. 不因 Franiya 殺過瑟列就讓所有代理者恐懼屈服。
4. 世界的制度學習應體現在接口改進，而不是突然獲得全知。
