# 一、總原則：殺死代理者不是沒有回報，但也不是普通怪物掉寶

代理者是由世界接口、節點、職能與規則授權共同形成的世界側個體。

當代理者真正死亡時，可能同時產生三類結果：

1. **世界紀錄／成就／稱號**；
2. **代理者自身攜帶或構成的世界側遺留物**；
3. **因其職能、核心、節點與死亡方式形成的特殊材料／道具。**

但禁止寫成：
> 殺死代理者 → 地上固定噴出金幣、裝備、藥水。

更準確的機制是：
> **代理者死亡後，世界會優先嘗試回收其職能、權限與核心結構；未被完整回收、被殺手截留、因死亡方式破碎、或因世界承認特殊擊殺而凝成實體的部分，才可能形成世界側特殊遺留物。**

因此「殺了代理者有沒有東西」的答案是：
> **有可能，而且高階代理者的遺留物可以極其珍貴；但不是固定掉落表。**

# 二、Franiya 的全球首個代理者擊殺維持唯一級重量

Franiya 擊殺瑟列的既有事件固定保留。

當時世界首次確認：
> 世界側正式代理者可以被原生紀錄中的單一個體真正殺死。

因此世界建立唯一紀錄：

> 【全球首次代理者擊殺紀錄已成立。】  
> 完成者：Franiya。

並授予既定唯一稱號：

> **【弒使者】**

【弒使者】不是「對代理者傷害 +10%」這種普通數值稱號。

其核心重量為：
- 世界正式承認持有者曾真正終止一名世界側代理者的個體連續；
- 普通代理者在辨識該稱號時會知道這不是普通居民；
- 對世界側事件具有極高歷史辨識度；
- 某些代理者、世界接口與高階任務會因該紀錄調整風險判斷；
- 後續世界側研究、黑市情報、國家安全機構都可能把【弒使者】視為重大身份標籤。

這個稱號的首創權固定屬於 Franiya，不因後來更多人成功殺死代理者而被稀釋。

# 三、後續擊殺代理者仍可獲得成就與稱號，但不機械重複

世界不會每殺一名代理者就發一個完全相同的【弒使者】。

後續更常依「第一次完成某類高重量條件」建立成就。

可成立的例子：

## 3.1 【斷令者】
條件方向：
> 首次在沒有其他世界側高位存在協助的情況下，獨立切斷一名高職能代理者的完整執行鏈並將其擊殺。

可帶來：
- 對世界側權限連線、節點依附、職能運作的感知／辨識提高；
- 某些特殊道具與遺留物更容易被本人穩定持有；
- 不是直接獲得行政權限。

## 3.2 【獵使者】／【世界側獵手】類長期成就
不是殺一隻就得到。

需要：
- 多次真實擊殺；
- 對不同職能代理者建立穩定作戰能力；
- 世界確認其已形成可重複的「代理者獵殺能力」。

這類更適合黑鐮在某些後期循環中取得。

其效果可偏向：
- 更快辨識代理者核心與世界連線；
- 對代理者威壓、權限干擾、世界側精神壓力提高耐受；
- 擊殺後更容易截留完整遺留物；
- 部分低階代理者會因其紀錄提高初始警戒。

但不得寫成：
> 代理者看到稱號自動掉血。

## 3.3 高職能／世界級代理者首殺
若某一類代理者在當代從未被世界內生命擊殺過，首次成功者可以建立新的唯一／稀有紀錄。

例如：
- 首名世界級代理者擊殺；
- 首次單人擊殺世界級代理者；
- 首次在無特殊世界遺物輔助下擊殺高職能代理者；
- 首次以原生職業者身份完成世界側核心破壞。

稱號與成就應依事件實際重量決定，不預先把所有名字鎖死。

# 四、代理者死亡後的世界側遺留物

代理者不是普通血肉生命。

因此真正有價值的「掉落」通常不是屍體，而是其死亡後留下的規則結構。

正式統稱可使用：
> **【世界側遺留物】**

常見大類如下。

## 4.1 【執行殘核】
來源：代理者核心在死亡時未被世界完整回收。

性質：
- 高密度界能與世界規則結構混合物；
- 保留部分原職能的「作用方式」；
- 可用於高階裝備、職業晉升、塔／特殊區域機關、規則研究；
- 無法直接等同原代理者完整權限。

執行型代理者的殘核，可能偏向：
- 中斷；
- 鎖定；
- 強制終止；
- 目標確認。

導引型則可能偏向：
- 路徑；
- 導航；
- 節點識別；
- 安全通道。

## 4.2 【權限碎片】
代理者世界授權在死亡瞬間破碎後形成的有限規則殘片。

極其稀有且危險。

可以做到的不是「變成 GM」，而是例如：
- 在特定世界側門禁中提供一次性合法性；
- 暫時開啟一個低位封鎖節點；
- 讓某件世界側設備承認使用者一次；
- 作為特殊職業／裝備的高階材料；
- 抵銷一次同源低階權限效果。

通常有：
- 職能限制；
- 次數限制；
- 節點限制；
- 有效期；
- 使用風險。

禁止用一片碎片永久取得原代理者全權。

## 4.3 【界令刻印】
某名代理者長期執行某一職能後，在自身存在上形成的世界命令紋理。

可被：
- 裝備鍛造；
- 特殊符文；
- 職業進階；
- 結界；
- 高塔／界門鑰匙

利用。

它更接近「一段已被世界驗證過的規則格式」。

## 4.4 【斷鏈核心】
只有當代理者與其原世界節點的連線被完整切斷、死亡又沒有立刻被世界接管時，才可能形成。

極其稀有。

用途可能包括：
- 製作反世界側拘束道具；
- 臨時隔絕低階代理者追蹤；
- 在塔／規則區域製造數秒至數分鐘的「非授權盲區」；
- 對高職能代理者造成真正可利用的弱點窗口。

這類道具非常符合黑鐮式高階攻略物。

## 4.5 【職能遺物】
部分代理者本來就持有實體化裝備、武器、印章、書卷、鑰匙、鎖鏈、法器、指針、裁定器等世界側工具。

代理者死亡後，這些物件若沒有隨其回收，就可以直接成為戰利品。

其價值可能高於普通同 Stage 裝備數個層級，但常有非常苛刻的適配條件。

# 五、不同職能代理者可以留下真正有辨識度的特殊道具

後續可依職能設計類似韓漫式「只會從這類存在身上得到」的特殊物。

例如：

### 導引使系
可能形成：
> 【失路指針】

作用方向：
- 指向某個已被世界承認但尚未公開的出口／節點；
- 次數有限；
- 不能直接告訴使用者裡面有什麼。

### 執行使系
可能形成：
> 【終止楔】

作用方向：
- 對一個已成立的低階持續型規則效果進行一次強制中斷；
- 對神序無效；
- 對高於其原代理者權限層級的規則成功率顯著下降。

### 封鎖／隔離系
可能形成：
> 【封域釘】

作用方向：
- 暫時釘住一段空間／區域邊界；
- 可用於防止怪物、污染或低階規則越界；
- 也可以被灰黑勢力拿去做很危險的事。

### 裁定／審核系
可能形成：
> 【空白裁定印】

不是隨便判別人有罪。

而是允許持有者在某次世界事件中向世界提交一個高優先級「重新判定請求」。

是否成立仍由世界判定。

### 世界級代理者
有機率留下真正接近「唯一級／傳說級」的：
> 【世界權柄遺片】

這是世界側高階職能破碎後形成的極少量具現。

可以成為：
- 黑鐮某些循環裡的核心破局道具；
- 高塔後期隱藏層鑰匙；
- 極高階職業突破材料；
- 能重創／暫時封印神序顯現的超規格道具組件之一。

但一枚世界權柄遺片本身仍不能讓普通人直接對神序造成永久死亡。

# 六、掉落品質受「死亡方式」影響

同一名代理者死亡，不同殺法留下的東西可以不同。

可能影響因素：
- 核心是否完整；
- 世界連線是否先被切斷；
- 是否在本職能節點內死亡；
- 是否被世界立即回收；
- 是否使用反世界側武器；
- 是否摧毀了全部規則結構；
- 殺手是否能在回收完成前取得殘留物。

例如：
> 把代理者整個核心炸成規則碎塵，可能殺得很快，但拿不到完整殘核。

反過來，黑鐮這種熟悉代理者結構的人，可能故意：
1. 先切節點；
2. 逼核心顯現；
3. 精準破壞自我連續；
4. 保留職能殘核。

因此他的多輪情報可以直接轉化成更高品質的世界側戰利品。

# 七、世界會搶著回收

代理者一死，世界不是站著看玩家摸屍。

正常流程可能是：
> 死亡確認 → 世界連線斷裂 → 權限回收 → 核心回收／解體 → 遺留物穩定化。

因此高階代理者死亡後往往存在極短的「回收窗口」。

普通人可能連發生什麼都看不懂。

真正懂行的人會知道：
> **最值錢的東西不是屍體，而是世界還沒收回去的那幾秒。**

這能成為黑鐮非常有辨識度的戰鬥後動作。

別人剛打贏還在喘。

黑鐮已經伸手把某個正在消失的光核扣了下來。

旁人：
> 「那是什麼？」

他：
> 「三秒後就沒有了。」

# 八、非法持有世界側遺留物會有後果

世界側遺留物不是普通戰利品。

部分物品可能：
- 被其他代理者感知；
- 具備原世界節點追蹤性；
- 被國家／大型勢力列為最高級戰略物資；
- 在世界商店無法正常交易；
- 黑市價格極端誇張；
- 對持有者造成規則污染／精神負荷；
- 需要特殊容器或封印。

所以「殺代理者拿裝」天然會形成一整條：
> 獵殺 → 截留 → 封存 → 洗來源 → 黑市 → 研究 → 鍛造

的高階地下產業鏈。

# 九、四位男主級人物的差異化收益

## 沈硯川
傾向：
- 不主動獵殺；
- 如果不得不殺，優先保留能用於危區處理、封鎖解除、救援與路徑判定的遺留物；
- 舊未來情報讓他知道某些物品真正用途。

## 顧晟川
傾向：
- 更願意把世界側遺留物當成生存籌碼；
- 會交易、藏匿、交換；
- 可能用一件高職能代理者遺物反殺另一名世界側敵人；
- 非常清楚哪些東西不能公開拿出來。

## 裴夜衡【黑鐮】
正式固定：
> **代理者特殊遺留物是黑鐮多輪破局體系的重要組成。**

他不只知道怎麼殺代理者，也知道：
- 哪種代理者值得殺；
- 哪種殺法能保留核心；
- 哪輪需要哪件遺物；
- 哪件世界側遺留物能組合成更高階反規則道具；
- 哪些看似垃圾的碎片其實是高塔隱藏層鑰匙。

在部分舊循環中，他可以建立一套由多種世界側遺留物組成的高階裝備／道具鏈。

這非常接近「百次回歸」式獨狼攻略感，但仍由本世界規則自然成立。

## 姜曜辰
他沒有攻略。

但他可能第一次殺死代理者後，靠自己的戰鬥直覺發現：
> 「核心在消失。」

直接伸手搶下來。

後來才知道自己拿到的是別人求都求不到的高階遺留物。

這能保留他的原生天才感。

# 十、Franiya 的特殊情況

Franiya 不需要靠代理者掉落變強。

但她可以：
- 因好奇留下某個世界側核心；
- 把東西送人；
- 拆開研究；
- 看完覺得普通再放回去；
- 因為外觀好看而留著；
- 用自己的方式穩定原本即將被世界回收的遺留物。

瑟列事件後可以成立一件非常特殊的首殺遺留物。

它不必是立即提升 Franiya 戰力的神器，而可以是：
> **全球第一枚被完整保留下來的代理者執行核心／職能殘核。**

世界、各國、高階研究者與未來黑市會認為其價值不可估量。

Franiya 本人則可能只是：
> 「先留著。」

這種價值認知差非常符合她。

# 十一、神序死亡不適用普通「代理者掉落表」

神序不是代理者的更高階版本。

正常情況下祂們的根源靈魂與世界綁定，也不存在普通意義上的可刷掉落。

Franiya 真正殺死薩維爾後，若有遺留物，也必須是世界史唯一等級的事件產物。

例如：
- 【終斷之痕】；
- 一段本來屬於薩維爾與世界根源連線的位置空缺；
- 世界自行凝成的死亡證明／根源紀念物；
- 與【神序可斷】成就關聯的唯一規則物。

這類內容不得提前當普通裝備使用，並應與薩維爾後續復歸、四神序反應、Franiya 對世界側關係共同處理。

# 十二、作者 Gate

1. 代理者可掉特殊物，但不是固定 loot table。
2. 普通代理者也可能什麼都沒留下，尤其世界回收完整時。
3. 高職能／世界級代理者更容易形成高價值世界側遺留物。
4. 世界側遺留物的功能應高度對應原代理者職能。
5. 權限碎片不能直接讓普通人變世界管理員。
6. 世界會主動回收代理者結構，形成「回收窗口」。
7. 黑鐮可因多輪經驗成為最懂截留世界側戰利品的人之一。
8. 沈硯川、顧晟川、姜曜辰是否取物、怎麼用，先由人格推導。
9. Franiya 不靠掉落提升本體，但可以取得、保留、研究、轉贈。
10. 【弒使者】仍固定為 Franiya 全球首個代理者擊殺的唯一稱號／紀錄。
11. 神序不適用普通代理者掉落規則；薩維爾真正死亡若產生遺留物，必須是世界史唯一級。
12. 代理者遺留物應成為高階黑市、研究、職業、裝備與高塔攻略的一條長期經濟／劇情線，而不是一次性爽點。
