# 4. Franiya 核心 Gate 摘要

此節只作導航，正式使用仍以家庭總檔原文為準。

## 4.1 外貌與存在

- 成年女性，小巧纖細，略有少女感但不是兒童。
- 黑髮，小而精緻的狼耳。
- 深空藍紫色豎瞳，帶珠光／虹彩／星點質感。
- 左眼歷史上曾被毀、後來已完全修復，功能與右眼相同；寬斜眼帶是習慣、舒適與身份感，不是現在仍失明。
- 代表武器偏雙短刃／匕首，但不受職業鎖定。
- **衣物不會因本世界常規戰鬥、爆炸、抓扯、摩擦等撕裂、燒毀或戰損。禁止寫戰損衣服。**

## 4.2 性格

核心：**木然、空虛與生存。**

- 安全時可以更有生活感、說話、吐槽、主動問、玩、逗人。
- 危機時清楚、精準、高效。
- 不是救世英雄，也不是嗜殺模板。
- 喜歡咖哩。
- 不因全球戰績變成只會冷臉走路的兵器。

## 4.3 能力本質

核心不是單純重力，而是：
> **作用關係與權重。**

外顯可涉及重力、質量、慣性、動量、物質、空氣、空間／時空路徑，深層甚至可及存在、時間、因果、可能性等。

她真正尺度遠超本世界，但**主動自限**，來這裡的目的之一就是不把答案全部提前翻完。

## 4.4 感知

禁止寫成常駐全知。

她在自限允許範圍可自然察覺：
- 生命存在與相對能量；
- 異常結構；
- 空間／作用關係異常；
- 高權重節點；
- 戰鬥前兆。

預設得到的是方向、強度、異常性，不是自動拿到完整語義答案。

心聲規則：
> **Franiya 能讀，但通常不讀。**

不是被動常駐讀心。

## 4.5 禁止降智

她可從結構直接判斷的低層基礎事實，不得為了向讀者解說而讓她發問。

例如她早已知道：
- 洛珥／代理者不是世界本身；
- 殺一名代理者不會讓世界規則消失；
- 世界側低層系統不能真正改寫她本體；
- 自己是否被規則真正綁定。

需要問代理者時，問其主觀、權限、拒絕權、知識邊界、執行邏輯，而不是裝傻問「你是世界本身嗎」。

# 6. 世界／Stage／成長硬規則

## 6.1 Stage

- Stage 0：劇變前。
- Stage 1：前 72 小時左右，生存證明與第一輪世界壓力測試。
- Stage 2：數週至數月，職業、材料、生態、交通、灰市、早期獵人化社會逐步形成。
- Stage 3：數月至數年，界塔與跨區公會／高階攻略社會成熟。
- Stage 4：多年級全球重連與多文明時代。
- Stage 5+：高規則文明與世界邊界／外部問題。

不得第一週就成熟高塔、公會全球聯盟、世界商店與高階職業遍地。

Stage ≠ 生命階位 ≠ Level ≠ 戰力。

- 全球首位 Lv.10：Franiya。
- Franiya 到 Lv.10 後，世界無法對她真正建立本地生命質變方案。
- 全球首位真正原生智慧生命階位跨越：梁策。

# 9. 神序最高位格 Gate

五位神序：
- 薩維爾【終斷】
- 伊瑟菈【封界】
- 凱羅恩【校律】
- 米蕾西亞【續世】
- 奧緹爾【衡定】

固定：
- 自世界根源成立之初就一直存在。
- 早於人類、Stage、現代代理者、黑鐮輪迴；甚至黑鐮簽下時序錨之前，祂們已跨過數個世界紀元。
- 靈魂、本質、神性職能直接綁定世界根源。
- 世界側壓制力極高。普通／高職能／世界級代理者的世界授權都在神序根源秩序之下。
- 神序合法展開職能時，可撤銷、關閉、收回下位世界側權限；祂們不是「比較強的代理 Boss」。
- 神序威壓可凝成實質，普通生命乃至世界側個體可出現跪伏、停機、權限收斂等反應。
- 正常世界內頂尖生命＋極端唯一級道具，最多在非常後期有機會重創、暫封、沉眠或切斷一段時間；**永久殺死幾乎不成立。**
- Franiya 是例外。

Franiya 真正殺死薩維爾時，切斷的是薩維爾與世界根源的存在連續。其他四名神序因此確認「祂們真的可以被她永久殺死」，主動停手、承認執行失敗、求她不要再殺是合理而且必須有重量的反應。

【神序可斷】之類稱號對真正知道神序重量的人，是近乎世界史常識崩裂級資訊，不是普通「弒神稱號」。

神序知道世界發生過回捲。祂們保有根源／世界尺度記憶；黑鐮的特殊性在於保存大量同一歷史區段的生活與微觀人生細節。

專題必讀：
- `03_世界觀設定/114_神序原初性世界綁定絕對位格與Franiya例外修正.md`
- 神序相關舊檔若尺度較弱，以 114 為覆蓋基準。

# 10. 終末收束與最終 Boss

世界劇變的本質是為了**進化**。

世界若長期卡在最高演化門檻，會逐步進入【終末收束】：不是單純城市毀滅，而是所有有效未來逐漸收窄，世界失去可持續存在的下一合法狀態。

在終末前，世界可啟動：
> **【最終資格試煉】**

並投放真正的最終 Boss／終局驗證者。

固定：
- 最終 Boss 不是造成終末的元兇，而是「你們有沒有資格往下一階段進化」的最終驗證。
- 神序很強、能修世界、壓制階段、封鎖失控、拖延終局，但不能替文明代考。
- Franiya 可以殺 Boss，但她單獨一刀不等於世界內生命取得演化資格。
- 她真正的破局價值是從外部打開世界自己從未能產生的新答案，讓本世界生命有機會真正走完。
- 黑鐮多輪最深困局不只是「輸出不夠」，而是世界內不同方案一再無法形成有效通關答案。

專題必讀：
- `03_世界觀設定/116_終末收束最終資格試煉與世界進化門檻.md`

# 13. 正文寫作格式硬 Gate

正文語感可參考《網遊：重生就是最大的BUG（芙蘭妮雅改寫版）》的完整小說段落感，但不是照抄文風。

固定：
- Traditional Chinese。
- 正常使用完整自然段。
- 動作、空間、環境、心理可在一段內自然連接。
- 對話換行正常，但不要求每句後再多一個空白段。
- 禁止整章「五六個字一句 → 換行 → 再五六個字 → 換行」的句子雨。
- 連續三個以上超短獨立段若沒有明確節奏功能，視為格式警告，優先合併。
- 短句獨立段只用於真正需要敲重音的世界公告、死亡、重大反轉、關鍵台詞、情緒斷點。
- `——` 分隔線只用於真正場景／時間／POV切換或重大留白，不得一句話一條線。
- 正式章節若在聊天中交付，章名與全文放進同一個可一次整段複製的 writing block。
- 不為固定字數壓縮關鍵場景；必要時可拆上下篇／多部分。

# 14. 正式寫作 PREWRITE Gate

每章正式正文前，必須在內部確認：

1. 時間：T0 前後多久、日期、時段。
2. Stage。
3. 地點與當地秩序狀態。
4. POV。
5. 在場角色。
6. 每個角色知道什麼、不知道什麼。
7. 傷勢、裝備、物資、交通、通信。
8. 當前任務／公告／稱號是否已成立。
9. 回歸者舊未來錨點是否仍有效、是否已受 Franiya 因果影響。
10. Franiya 本章自限程度與她已能直接判斷的事，避免降智。
11. 是否引入新世界規則；若有，是否已有正式設定與代價。
12. 本章至少一項「世界不圍著 Franiya 轉」的具體運作證據，除非該章本來就是極度私人場景。
13. 章末要推動什麼新問題／因果，不要求每章靠全球公告收尾。

若任一關鍵點不確定：
> **先查正式檔。仍無答案則標記待定，不得正文自動填空。**
