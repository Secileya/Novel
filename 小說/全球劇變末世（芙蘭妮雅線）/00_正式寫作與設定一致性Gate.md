# 一、最高原則：不確定就先查，不允許自動腦補

正式寫作時，若涉及以下任一項而無法百分之百確認：
- 角色人格；
- 角色是否知道某情報；
- 時間與 Stage；
- 能力上限／下限；
- 任務條款；
- 世界公告是否已出現；
- 某稱號／成就是否已有持有者；
- 某人物是否已見過另一人；
- 回歸者舊未來是哪一輪、是否曾接觸某事件；
- 神序／代理者位格；
- 界塔／世界任務是否已在該時期開放；
- 某道具、裝備、掉落是否存在；
- 某地區是否仍由政府／軍警／勢力控制；
- Franiya 是否會主動讀取、介入或解除自限

則：
> **先查正式檔，再寫。**

禁止使用：
> 「應該差不多」／「一般韓漫都這樣」／「為了這場戲方便先當作有」

作為正式 canon 的依據。

若仍無正式答案，PREWRITE 中標記：
> `【待定，不得正文自動填空】`

不得在正文中偷偷替作者決定。

# 二、Canon 優先級 Gate

發生衝突時，依下列順序裁定：

1. **使用者最新明確修正／作廢／指定**
2. 本檔 `00_正式寫作與設定一致性Gate.md`
3. Franiya 跨世界核心權威：

   - `小說/家庭總檔/11_芙蘭妮雅資訊觀測與自限補充.md`

5. 已正式發生且未被後修推翻的正文事件

7. 舊 baseline、舊補丁、已被後修覆蓋檔
8. 候選方案、腦暴、聊天範例、未核定名稱

固定：
> **正式正文不能靠「已經寫出來了」反過來偷偷改掉高優先級設定。**

若正文與高位設定衝突，應修正文，不是默認正文變成新 canon。

# 三、正式寫作前最小載入 Gate

每次開始新章／重大場景前，必須先建立當章內部 PREWRITE，至少確認：

## 3.1 時空
- 現在是 T0 後多久；
- 當前 Stage；
- 日期／時段；
- 地點；
- 天候／交通／基礎設施狀態；
- 該地目前屬核心維持區、半失序區、爭奪區、放棄區或無控區中的哪類。

## 3.2 POV 與在場角色
- POV 是誰；
- 誰實際在場；
- 誰只透過通訊／公告／新聞存在；
- 每人當前傷勢、裝備、衣著、物資與任務狀態；
- 角色最後一次有效登場停在哪裡。

## 3.3 情報矩陣
對每位重要角色確認：
- 他知道什麼；
- 他不知道什麼；
- 哪些只是猜測；
- 哪些來自舊未來；
- 哪些已被 Franiya 蝴蝶效應改變；
- 是否有權知道神序、代理者、高塔、世界任務等資訊。

## 3.4 未完成因果
至少列出本章可能碰到的：
- 未回收承諾；
- 尚未完成任務；
- 尚未結算傷亡；
- 已形成但尚未爆發的勢力矛盾；
- 舊未來錨點；
- Franiya 已造成的因果改變；
- 角色私人目標。

以上任一項無法確認時，不得直接開始正式正文。

# 四、Franiya 核心 DNA Gate

每次 Franiya 出場前必檢：

1. 她不是重生者、召喚勇者、系統選中救世主。
2. 真正能力核心是**作用關係與權重**，重力只是外在表現之一。
3. 世界等級、職業、天賦、生命階位只是在本地介面上對她的局部映射，不能真正提升／改寫她本體。
4. 她主動自限，不等於做不到。
5. 她不常駐全知掃描；感知範圍與深度是主動控制。
6. 她能定向讀取心聲，但通常不讀；不得平常自動偷聽所有人。
7. 她不能為了向讀者解說而向低層存在詢問自己本可直接從結構判斷的基礎事實。
8. 她主觀痛覺為 0，但仍精確理解損傷。
9. 戰鬥偏好雙短刃／匕首，但非職業鎖定。
10. **衣物不會因本世界常規戰鬥、爆炸、摩擦、怪物攻擊等撕裂、燒毀或戰損。**
11. 她可以救人、可以不救、可以殺人，不預設救世主道德。
12. 她可以有普通生活、熟人、咖哩、遊戲、娛樂，但不能因日常戲被普通化；公開戰績與社會重量仍存在。
13. 新人對她的反應必須依公開知名度、可辨識度與當地情報來源決定，不能所有人都無感，也不能所有人都一眼認出。

任一條違反：
> **正文 Gate FAIL。**

# 五、人物人格先於劇情功能 Gate

所有核心／次核心人物，尤其沈硯川、顧晟川、裴夜衡【黑鐮】、姜曜辰、公會會長群像，正式行動前必須依序回答：

1. **他現在真正想要什麼？**
2. **他現在最怕／最不想失去什麼？**
3. **他目前知道什麼？**
4. **以他的習慣，他會先做哪一步？**
5. **這個行動是角色自己會做，還是作者只是需要他來推劇情？**

如果答案是後者，重寫。

固定禁止：
- 為了讓角色集合，突然讓四位男主級人物全部趕來同一事件；
- 為了讓 Franiya 展示力量，讓其他角色集體降智；
- 為了製造誤會，讓平時謹慎人物突然不查情報；
- 為了讓某人看起來善良／冷酷，而扭曲其既定價值觀；
- 讓不同公會會長只剩「豪爽／清冷／笑面狐」標籤，忘記其實際利益、責任與生活方式。

# 六、回歸者 Gate

## 沈硯川
- 只有一次回歸；
- 舊未來約五年；
- 回來的是完整人生記憶，不帶等級、裝備、未來身體；
- 性格重實證、因果與救援，不會看到偏差就宣布所有未來失效；
- 必須持續使用「舊未來錨點／偏差表」思路。

## 顧晟川
- 只有一次回歸；
- 因一次性【逆刻印】在世界回捲中保住自我；
- 狠辣來自背叛與代價，不是無差別殺人；
- 不能把上一世罪行自動當成這一世現行犯罪。

## 裴夜衡【黑鐮】
- 多輪回歸／時序錨；
- 死亡不等於自動讀檔；
- 只有世界真正走到終末失敗／回捲條件時才可能進下一輪；
- 他對大量事件熟悉，但不是作者全知；
- Franiya 是所有已知循環不存在的外部變量；
- 他把她視為可能破局關鍵，必須經過驗證，不是見面即認救世主。

## 回歸未來
- 舊未來是真實歷史，不是假夢；
- Franiya 的存在不會無因果讓全世界瞬間洗牌；
- 人格、地理、組織結構需求、資源等仍具有歷史慣性；
- 變化必須沿公告、救援、死亡、物流、情報、任務、勢力、交通等實際因果傳播。

# 七、Stage／時間尺度 Gate

每次加入新機制前必問：
> **這個東西現在真的已經開放了嗎？**

固定大尺度：
- Stage 1：數天，感染／區域任務／引導使／初期黑市／Lv10／先驅榜；
- Stage 2：數週至數月，正式職業、穩定新生種、界塔中後期才開始真正可攻略；
- Stage 3：月年至約 1～3 年或更久，區域生態、公會／領地／跨區產業成熟；
- Stage 4：約 T0+3～5 年視文明成熟度，全球重連、多文明、跨洲政治與昂貴有限航空；
- Stage 5+：更高規則文明；
- 終末資格試煉屬真正後期世界演化門檻。

禁止：
- T0 當天全球遍地高塔；
- 第一週就形成完整跨國獵人經濟；
- 半年內全球航空、跨文明外交、成熟高階社會全部恢復；
- 把後期神序／終末內容拿來當前期普通事件背景板。

# 八、系統、任務與致死規則 Gate

1. 系統是世界新規則的可讀介面，不是遊戲公司客服。
2. 人不是玩家，沒有登出。
3. 一般感染體不爆遊戲式戰利品。
4. 任務必須對應真實危機、演化節點或世界目標。
5. 一般任務失敗優先產生真實後果，不是隨便抹殺。
6. 致死型強制任務可以存在，但必須有明確世界因果／封鎖域／高風險契約／特殊規則基礎。
7. 世界直接死亡結算出現時必須有重量，不能每三章來一次。
8. 世界公告、唯一成就、全球首次都必須先核對是否已有紀錄，禁止重複「第一次」。
9. 任務貢獻可來自戰鬥、醫療、工程、情報、運輸、研究、資源與指揮，不得默認殺怪最高。

# 九、代理者與神序位格 Gate

正式層級主幹：
> **普通代理者 → 高職能／世界級代理者 → 神序五執行者 → 世界本身**

## 代理者
- 可以被極強世界內生命殺死；
- 擊殺可形成稱號、成就、世界紀錄；
- 可能留下執行殘核、權限碎片、界令刻印、斷鏈核心、職能遺物等；
- 世界會主動回收，掉落不是固定爆裝表；
- 黑鐮因多輪經驗可極擅長截留高品質世界側遺留物。

## 神序
- 從世界誕生之初便存在，早於人類文明與黑鐮循環；
- 靈魂／本質／職能直接綁定世界根源；
- 對世界側的位格壓制是根源級，不只是「高級主管」；
- 普通代理者對神序甚至可能連敵對程序、權限、武裝都無法成立；
- 神序展開時威壓可以凝成實質；
- 世界內頂尖存在＋極其超規格道具最多可在特殊條件下重創／封印／逼退神序一段時間；
- 正常世界內生命幾乎不可能永久殺死神序。

## Franiya 例外
- Franiya 真正殺死薩維爾，代表連世界根源綁定都被切斷；
- 其他四位在確認真正永久死亡後停止執行、克制求停是合理反應；
- 【神序可斷】、【神序不及】是世界史／根源秩序級重量，不能寫成普通神話稱號。

若正文把神序寫成可量產高階 Boss：
> **Gate FAIL。**

# 十、力量尺度 Gate

固定禁止 RPG 化：
- Level ≠ 生命階位；
- 生命階位 ≠ Stage；
- Stage ≠ 戰力；
- 稱號 ≠ 戰力；
- 排行榜 ≠ 世界最強榜；
- 界塔最高層 ≠ 世界第一戰力。

每次比較強弱必須考慮：
- 真實能力；
- 經驗；
- 情報；
- 相性；
- 裝備；
- 地形；
- 世界權限；
- 生命階位；
- 職業成熟；
- 是否有準備；
- 是否主動保留力量。

Franiya 更不可被本地數值條機械換算。

# 十二、界塔／高塔 Gate

1. 正式名稱【界塔】。
2. Stage 2 中後才逐步有真正可攻略塔，Stage 3 才成為成熟產業。
3. 不是每城一座。
4. 塔層是真實規則空間，不是副本選單。
5. 不必每層打 Boss；可有工程、生存、談判、護送、文明型任務。
6. 少數層可以致死，但不能每層紅字死亡。
7. 黑鐮有舊攻略優勢，但 Franiya 蝴蝶效應可以產生他沒見過的新分支。
8. 姜曜辰的辨識度是「第一次遇到也能現場學」，不能所有塔戲都被黑鐮攻略表吃掉。
9. Franiya 可察覺隱藏結構，但依自限可選擇正常探索，不直接拆塔讀答案。

---

# 十三、終末收束 Gate

1. 終末不是「最後 Boss 把世界打爛」這麼簡單。
2. 神序可以修復極大範圍世界損傷，普通末日級災害不足以形成真正不可挽回終局。
3. 真正危機是世界演化卡死、有效未來持續收窄、下一合法世界狀態逐步不存在。
4. 世界可以投放【最終資格試煉／終末驗證者】。
5. 最終 Boss 是文明進化資格的驗證者，不是終末元兇。
6. 神序不能替文明代考；祂們可維持、修補、爭取時間，但替代通關不算。
7. Franiya 可以打開原本不存在的路，但完全替世界內生命一刀代考，不必被判為有效文明通過。
8. 黑鐮多輪失敗的核心問題不只是 DPS 不足，而是世界內答案長期無法形成真正有效資格。

# 十四、情報邊界 Gate

每段重要對話前必確認：
> **這個人憑什麼知道？**

情報來源只能來自：
- 親眼見過；
- 公告；
- 新聞／論壇／直播；
- 政府／組織資料；
- 世界節點；
- 他人告知；
- 研究；
- 合理推理；
- 回歸者真實舊未來記憶；
- 神序根源記憶等已成立例外。

禁止：
- 作者知道，所以角色也知道；
- 黑鐮回歸很多次，所以什麼都知道；
- 神序很古老，所以全知；
- Franiya 知道，所以必須主動科普。

固定區分：
> **已知事實／高概率推論／私人猜測／錯誤情報**

正文不得混寫。

# 十五、寫作格式 Gate

正文排版參考《重生就是最大的 BUG（芙蘭妮雅改寫版）》的完整小說閱讀感，固定避免「句子雨」。

## 必須
- 以完整自然段為主；
- 同一連續動作、觀察、環境與心理可在同一段自然流動；
- 對話換說話者時換段即可，不必每句後再空一整行；
- 戰鬥保持空間、因果、節奏與連續動作；
- 場景內加入足夠的人物位置、環境聲、旁人反應與物件狀態。

## 禁止常態化
> 她停下。  
>  
> 看了一眼。  
>  
> 沒說話。  
>  
> 然後走了。

這種五六個字一句、句句獨立、段段空行的排版不得成為主體。

短句獨立段只允許用於：
- 重大世界公告；
- 死亡瞬間；
- 核心反轉；
- 關鍵台詞；
- 高壓節奏斷點。

連續三個以上超短獨立段落若不是刻意特殊節奏，視為**格式警告**，需合併重寫。

同樣禁止：
- 幾乎每句對話後插 `——` 分隔線；
- 用大量分隔線代替真正轉場；
- 為手機閱讀而無意義切碎所有句子。

【Stage】
【地點】
【POV】
