# 第二十五章　誰的廢料

七月八日。

任務第二十二日。

西北舊路再往偏西走，大約一個半小時。

道路重新變窄。

不是周渡和塔恩前幾天修過的那一段。

這裡沒有重新亮起的燈。

也沒有新的路牌。

兩側雜草比車輪高。

幾處舊排水溝完全被土填平。

莫爾一路沒怎麼說話。

領路的是昨天那支拆取隊。

四名本地人。

領頭人叫德諾。

五十歲上下。

左手小指少了一節。

腰間掛著一串拆裝工具。

他的木牌是真東西。

塔恩昨天已經拿去登記屋確認過。

多年以前，這一帶幾座停用維護設施被正式列入可拆取舊料範圍。

德諾不是偷來的。

他每年都要付一筆費用，換取指定區域的拆取權。

這件事讓問題從一開始就很麻煩。

走到地方以後，周渡先看見兩輛平板車。

車上堆著拆下來的金屬框、破碎晶材、幾段黑化導能片。

還有一名地球參與者。

年紀大概二十多。

短髮。

深色護臂。

一把窄刃長刀靠在石墩旁。

他看見周渡時，第一反應也很明顯。

「大夏？」

周渡停了一下。

「嗯。」

男人笑了。

「終於碰到第二個能完整說話的。」

他指自己。

「邵衡。」

「南嶺工業帶。」

周渡：「周渡，臨江。」

邵衡上下看他一眼。

視線在腰間長刀和腕上退出印記停了一下。

「幾級？」

周渡沒有立刻回答。

邵衡自己笑了一聲。

「行，不問。」

這種反應反而讓周渡比較放心。

真正麻煩的人通常不是問。

是覺得你必須回答。

邵衡和德諾不是昨天才合作。

前兩天就已經一起拆過一輪。

他的能力不是讓東西消失。

而是能把接觸到的震動集中到一個很小的面。

切鏽死的金屬扣、鬆老舊接點，非常快。

對拆廢設備來說很好用。

這也是德諾願意拿材料分成和食宿換他幫忙的原因。

邵衡沒有掩飾。

「我還有八天。」

「能拿的材料就拿一點。」

「這邊這種老設備，晶材純度還行。」

他指平板車上一塊灰藍色晶片。

「帶回去應該能過檢疫。」

周渡：「你知道任務可以帶多少？」

「不知道。」

邵衡很坦白。

「所以先拿小的。」

塔恩和德諾已經走到前面。

真正的老節點藏在一片半塌石棚後面。

不像周渡修過的那座舊井。

它露在地面上的部分更多。

四根低矮石柱圍著中央金屬環。

原本應該還有外罩。

早就不見了。

其中兩根石柱的晶石座已經空。

第三根只剩一小段碎晶。

中央金屬環則被切開一道缺口。

切口新。

邵衡昨天做的。

周渡靠近。

沒有直接開到最深感知。

先看表面。

失穩殘餘很多。

比第一座地下設施更亂。

但和那座設施不一樣的是，這裡沒有一個完整、厚重的核心。

至少表面看不到。

德諾把木牌交給莫爾。

又指中央環。

說了一長串。

塔恩中間插話。

邵衡在旁邊翻譯自己聽懂的部分。

「他說這東西二十多年前就不亮了。」

「後來路也廢。」

「塔維爾把這片列成舊料。」

「他家拆這邊不是第一年。」

周渡：「他知道中央環以前做什麼？」

「不知道。」

邵衡看德諾。

「我問過。」

「就說以前能讓附近燈比較穩。」

「後來早就沒用了。」

莫爾顯然不同意最後一句。

老人走到環外一段石面。

腳踩兩下。

又指遠處一條已經塌一半的小路。

他和德諾吵了起來。

不是誰突然拔刀。

就是兩個做了一輩子不同工作的人，都覺得自己知道這堆舊東西是什麼。

對德諾來說，它是登記過的廢料。

拆了能賣。

不拆就繼續爛。

對莫爾來說，前幾天另一座老設施修好後，路、燈和震動確實一起變好。

那代表這些老東西也許還有別的作用。

周渡沒有站隊。

他先走到中央環切口旁。

新能力慢慢往裡。

第一層。

金屬。

第二層。

曾經存在的導能路徑。

第三層。

斷掉。

不是完全死。

中央環底下仍有四條非常微弱的穩定連接。

其中一條已經因昨天的切口變得不完整。

另一條通往西側地下。

再遠，他看不清。

不是距離問題。

是結構太破。

再解析下去只會把一堆殘缺資訊塞進腦子。

周渡停。

他指中央環。

再指遠處。

手指畫線。

邵衡看明白了。

「你是說它還連著東西？」

周渡：「嗯。」

「你能證明？」

「只能證明我看得到連接。」

邵衡搖頭。

「那不叫證明。」

周渡沒有反駁。

確實。

能力感知對他自己可以是判斷依據。

對別人只是他的話。

塔恩這時蹲到切口旁。

他拿出工具，把新切面外的一層鏽刮掉。

下面露出一段很細的舊紋。

和西北那座地下設施的導能紋不完全相同。

但接頭形式很像。

塔恩抬頭看莫爾。

莫爾表情更差。

德諾仍不服。

他指木牌。

再指拆下來的貨。

意思也很合理。

如果塔維爾以前自己說這是廢料，今天不能因為有人說「也許還有用」就直接把合法權利作廢。

邵衡在旁邊說：

「這個我站他。」

「我不知道你們這邊法律怎麼算。」

「但人家有牌。」

周渡：「我也沒說他偷。」

「那就好。」

「我只是想知道再拆會怎樣。」

邵衡看他。

「任務不是連破壞這種東西也算記錄？」

周渡沉默一下。

去年公開規則確實寫過。

世界錨修復。

世界錨破壞。

當時沒人知道那是什麼。

現在周渡仍然不知道這裡是不是同一類設施。

但如果是，邵衡這句話並沒有錯。

任務本身沒有說「破壞一定錯」。

邵衡靠著石柱。

「我就剩幾天。」

「你要留在這裡修二十年，是你的事。」

「我拿點能帶走的東西，也是我的選擇。」

周渡：「如果它會讓附近更不穩呢？」

「有證據我再看。」

這句反而很重要。

至少他不是說有證據也不管。

問題變成怎麼證明。

下午，眾人沒有立刻拆。

莫爾先沿周圍舊路走了一圈。

塔恩去看附近三處完全熄掉的晶石節點。

周渡則只對中央環做最低程度感知。

一個多小時後，他們找出一個可測的地方。

中央環東側有一塊已經切開大半、只剩最後兩個固定點的弧形金屬片。

德諾原本今天就打算拆掉。

它不是核心。

至少看起來不是。

塔恩把附近一盞勉強還能亮的舊節點先接上測試晶石。

很弱。

但能亮。

莫爾則站到三十多公尺外一段會偶爾震的路面。

邵衡抱著手。

「所以現在拆這片？」

周渡：「只拆到最後固定前。」

「你想看流向？」

「嗯。」

邵衡點頭。

他把手放上金屬片。

震動集中。

第一個固定點斷。

第二個還在。

整塊弧片往外鬆了一點。

周渡感知裡，中央環那條原本很弱的東側連接立刻變細。

同時，塔恩旁邊那盞測試燈閃了一下。

不是熄。

只是明顯暗。

遠處莫爾突然抬手。

路面傳來一陣比剛才更清楚的低頻顫動。

所有人都停。

邵衡沒有切第二個。

幾秒後，燈恢復原本亮度。

震動也慢慢降低。

德諾臉色變了。

這一次不是周渡說。

塔恩看見燈變暗。

莫爾站在路上感覺到震。

邵衡自己也看見了。

弧片重新固定回去很難。

但塔恩還是先把臨時扣件裝上。

測試燈穩定。

遠處路面也沒有再立刻震。

邵衡看著中央環。

「行。」

他沒有嘴硬。

「這個先不拆。」

德諾立刻說了很多。

語速很快。

內容不用全懂也知道是錢。

已經請人。

已經運工具。

已經切了一部分。

木牌也還有效。

現在突然說不能拆，誰負損失？

莫爾沒有答案。

塔恩也沒有。

他們是維護人員。

不是能一句話改掉塔維爾舊料規則的人。

最後只能把現場暫停，帶木牌、測試紀錄和拆取清單回城。

邵衡卻還有另一個問題。

他指平板車上已經拆下來的晶材。

「這些呢？」

德諾也看向莫爾。

已經拆下。

已經按舊規則分配。

現在再說要全收回去，和直接搶沒什麼差別。

周渡沒有說「應該還」。

因為他不知道塔維爾規則。

而且那些材料裡，大部分確實早已經徹底脫離原結構。

新能力看得到。

很多只剩穩定晶材本身。

不再連著節點。

拿回去也不能直接把功能補回來。

最後，莫爾只指今天不能再拆的中央環。

至於車上的東西，他沒有攔。

邵衡把自己的分成收進背包。

沒有挑釁。

也沒有炫耀。

「我明天可能往東走。」

他對周渡說。

「這裡後面怎麼判，你們自己處理。」

周渡：「你不等？」

「等什麼？」

「等他們改木牌？」

邵衡笑了一下。

「我只剩七天。」

「你是打算在這裡做到最後？」

周渡看向那條舊路。

「不知道。」

「行。」

邵衡拍了拍背包。

「那各走各的。」

事情原本到這裡應該算暫停。

偏偏傍晚回城前，出了一個小插曲。

德諾隊裡一名年輕工人不知道是不是沒聽懂，還是覺得最後再拆一件沒差。

他趁其他人在裝車，拿撬杆去碰中央環另一側一塊半鬆金屬片。

莫爾看見，立刻喊。

年輕工人停了一瞬。

又撬。

不是惡意要毀。

更像「今天都來了，至少別空手」。

下一秒，石柱底下震了一下。

周渡第一個過去。

沒有用新能力拆東西。

直接一把抓住撬杆。

年輕工人下意識往回扯。

兩人力量僵住。

邵衡從旁邊一步跨過來。

手掌壓住撬杆中段。

沒有發動能力。

只是以更強的身體力量往下一壓。

周渡手臂一沉。

他現在七級。

邵衡的實際階位明顯比他高。

硬比力量，不占優勢。

邵衡卻沒有幫年輕工人撬。

而是把杆子整根從兩人手裡壓回地面。

「停。」

這個中文沒人懂。

動作都懂。

他轉頭看德諾。

再指剛才已經測過的中央環。

搖頭。

這一次，年輕工人沒有再動。

周渡鬆手。

邵衡也鬆。

短促得連架都算不上。

可結果很清楚。

不是因為周渡打贏了誰。

而是證據出現後，有人改了選擇。

七月九日。

任務第二十三日。

塔維爾把那張拆取木牌暫時收回重審。

沒有把德諾抓起來。

沒有把已拆材料全沒收。

更沒有宣布所有舊設施從此禁止碰。

貨運院、登記屋、道路維護者和舊料市場的人花了一上午重新列分類。

周渡只被叫去說自己看到什麼。

他不會本地語完整技術詞。

所以仍然畫圖。

已斷。

仍連。

拆一點。

燈暗。

路震。

就這些。

不需要把新能力吹成什麼神眼。

下午結果出來。

那一處節點暫停核心結構拆取。

已完全脫離結構的舊料仍可照原規則處理。

其他列為「停用廢設施」的地點，今後若要拆中央結構，需要先做一次最低檢查。

不是永久禁止。

也不是突然把舊料全部變成聖物。

只是規則多了一道。

德諾不滿。

但接受。

因為他的木牌沒有被說成非法。

前面幾年的活也沒有被追討。

真正讓他不高興的是以後多一道程序，可能少一些能拆的東西。

這種不高興不需要反派台詞。

他靠這個吃飯。

少料，就是少錢。

邵衡上午已經離開塔維爾。

帶著前幾天合法分到的那一小批晶材。

周渡沒有追。

任務規則允許資源取得。

塔維爾也沒有判定那些東西必須追回。

那就不是他的東西。

傍晚，周渡重新去看那個被停拆的老節點。

中央環仍然很破。

少掉的晶石也不會自己長回來。

它不可能像西北舊井那座設施一樣，很快重新恢復完整循環。

可至少今天以後，它不會在沒人知道後果的情況下繼續被一片一片拆掉。

周渡把這件事寫進紙本記錄。

【不是所有廢料都真的只是廢料。】

想了一下。

又補：

【但被判成廢料的人，也不一定是在偷。】

再下一行：

【先證明後果，再談要不要停。】

這比「誰對誰錯」難記得多。

可也比較接近這兩天真正發生的事。
