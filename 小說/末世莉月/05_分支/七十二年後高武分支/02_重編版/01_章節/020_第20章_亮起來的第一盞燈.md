# 第二十章　亮起來的第一盞燈

六月二十五日。

任務第九日。

塔恩在舊井口多插了三根標記木樁。

紅。

黃。

白。

不是什麼本地技術分類。

只是昨天晚上三個人最後商量出來，今天最容易看懂的方法。

紅色不碰。

黃色先確認。

白色才允許周渡嘗試清理。

語言不夠時，顏色比長句可靠。

莫爾把第一層房間分成五段。

塔恩負責把仍然有明確功能的導能紋、金屬扣和晶石座重新固定。

兩名道路工人清石、補支撐和排水。

周渡只做一件事。

處理已經確定失去穩定結構、又明顯妨礙其他部分的殘餘。

第一段從昨天測過的位置開始。

周渡蹲下。

【餘能汲取】展開。

最外層鬆動殘餘仍在。

比昨天少一點。

旁邊兩條導能紋則都比昨天清楚。

他先指白色標記。

再看塔恩。

塔恩點頭。

周渡開始吸收。

五秒。

停。

重新看。

能量流向往右偏了一點。

但沒有像昨天那樣讓另一側立刻惡化。

再五秒。

停。

莫爾趴在地上感覺震動。

塔恩則盯著一條原本斷斷續續的暗紋。

那條紋沒有亮。

卻不再持續往外漏。

第一段花了四十分鐘。

真正吸收的時間加起來不到一分鐘。

剩下時間全在等。

看。

拆。

固定。

確認。

如果只看「能量處理量」，效率低得不像工作。

但沒有人催。

第二段反而證明這種慢是必要的。

一塊被壓在石板下的舊導能片清出來後，周渡確認外層有一圈鬆動殘餘。

白標。

他吸掉第一小部分。

地面立刻傳來一下很明顯的震動。

不是危險到站不住。

卻讓所有人同時停手。

左後方一條原本黃色的導能紋開始快速失穩。

塔恩幾乎是撲過去。

周渡已經先收能力。

塔恩打開外殼。

裡面的固定片鬆了。

不是周渡吸壞。

更像那一層堵塞少掉後，原本承受不到壓力的位置忽然重新吃到了一點流量。

如果繼續吸，結果只會更差。

塔恩換固定片。

莫爾補支架。

周渡在紙上把那條線從黃改成紅。

整個上午，第二段都沒有再碰。

午飯就在舊石屋吃。

扁餅。

乾肉。

水。

周渡現在已經能認出幾個和工作有關的音。

停。

走。

上。

下。

這個。

那個。

壞。

至於更複雜的「這條流路剛才因為上游殘餘移除而重新加壓」，仍然只能靠圖。

塔恩看著周渡畫箭頭。

忽然拿過炭條。

在其中一條線旁畫了個歪掉的圈。

再往旁邊畫裂口。

周渡一看就懂。

不是只有他能把想法畫出來。

下午，工作開始變成真正的合作。

塔恩先指出哪些結構仍有用途。

莫爾判斷哪裡的石面、排水和支撐需要先處理。

周渡只在他們把「還活著的」和「已經鬆掉的」分開後，處理最後那一層無主失穩殘餘。

第三段沒有出意外。

第四段甚至沒有讓周渡吸。

那裡的問題只是淤泥把一個回流槽堵死。

清掉泥後，原本亂掉的能量自己慢慢穩了一部分。

周渡看著那一幕，反而比吸到能量更在意。

不是所有問題都需要他的能力。

甚至不是所有失穩，都應該由他直接處理。

有時候把物理原因修好，能量自己就會回到原本的位置。

傍晚離開地下設施時，莫爾在入口外停了一會兒。

他用腳踩昨天震得最明顯的石面。

等。

十秒。

二十秒。

那種週期性低鳴還在。

但間隔變長了。

幅度也小了一點。

不是「修好了」。

只是變化第一次能被不靠周渡能力的人感覺到。

六月二十六日。

任務第十日。

舊路外多了兩個人。

不是參與者。

是塔維爾本地道路維護的人。

其中一個昨天傍晚來看過震動變化，今天帶了新的支撐木和兩組舊晶石節點零件。

沒有誰稱周渡為什麼大師。

他們甚至還是只叫「周」。

只是原本三個人的短工，變成六個人的工作。

原因很簡單。

昨天的路確實少震了一點。

這比任何解釋都好用。

上午先處理井外排水。

莫爾堅持。

不是因為地下不重要。

而是昨晚又下過一場小雨。

如果不先把水路疏通，今天下井只會多一層泥。

周渡和另外兩人搬石、挖溝。

整整兩個小時沒有開一次【餘能汲取】。

快中午時，原本積在舊路低處的一灘水終於開始往外走。

莫爾站在水溝旁看著。

表情比昨天第一段成功時還滿意。

下午，塔恩把一盞舊路燈帶到井下。

不是正常拿來照明的。

是昨天從路邊拆下來、已經壞了很多年的那一盞。

燈柱外殼被磨得發白。

底座補過三次。

晶石本體仍在。

卻只能亮幾秒就熄。

塔恩把它接到第一層一個修復過的側槽上。

沒有直接啟動。

先看周渡。

周渡感知一遍。

晶石穩。

接點穩。

側槽仍有少量失穩殘餘。

但比昨天乾淨很多。

他指其中一小段。

白標。

清。

三秒。

停。

塔恩重新固定。

再檢查。

莫爾則在地面那一側等震動。

沒有異常增加。

塔恩這才敲兩下啟動槽。

燈亮了。

淡黃色。

所有人都沒說話。

不是因為多壯觀。

塔維爾每天晚上有很多燈。

真正重要的是這一盞以前也亮過。

只是每次只能撐很短。

十秒。

二十秒。

一分鐘。

塔恩一直沒有伸手關。

五分鐘後，燈還亮著。

莫爾從井外走進來。

第一眼就看見它。

老人停在石階口。

盯了很久。

然後說了一句。

周渡聽不懂。

塔恩卻笑了。

不是大笑。

只是那種一個東西拆了很多次、終於第一次不立刻熄掉的笑。

他把燈關掉。

又重新開。

還亮。

接著把它搬回地面。

重新裝到原本那根舊燈柱上。

下午四點十七分。

舊路外圍第一盞多年無法穩定工作的晶石燈，重新亮起。

白天其實看不太出光。

塔恩還是讓它一直開著。

不是浪費。

是測試。

周渡每隔一段時間去看一次。

晶石穩定。

外圍導能紋沒有重新出現大規模失穩。

天色開始變暗時，路上來了一輛小車。

車上只有一名老婦人和兩箱蔬菜。

拉車的長頸獸走到前幾天那段抗拒區時，腳步明顯慢了。

牠抬頭。

鼻腔低鳴。

駕車人沒有硬拉。

等了一會兒。

長頸獸往前踏一步。

又一步。

最後走過去了。

沒有繞路肩。

沒有人因此歡呼。

駕車的老婦人甚至不知道周渡是誰。

她只回頭看了一眼那盞重新亮著的路燈，和莫爾說了幾句。

然後繼續走。

這一幕比任何「任務完成」提示都更實際。

晚上，塔恩、莫爾和幾名維護工沒有立刻回城。

他們在舊石屋生火。

吃東西。

等那盞燈。

一個小時。

兩個小時。

燈仍然亮。

低頻震動偶爾還有。

但不再像兩天前那樣固定地一陣一陣頂上來。

地下設施深處那個穩定核心也還在。

而且隨著外層逐步清理，周渡現在能更清楚地感覺到它周圍的層次。

不是它突然變強。

是堵在外面的東西少了。

有幾條原本完全斷掉的流路，現在已經重新出現非常微弱的聯繫。

但還不完整。

最深處仍有一圈他不敢碰的失穩區。

那一圈不是最髒。

反而最接近仍然穩定的核心。

只要動它，流向會怎麼變，周渡現在沒有把握。

塔恩問了一句。

他只聽懂「明天」。

周渡沒有點頭立刻下井。

先指自己。

再指深處。

最後做一個停的手勢。

周渡：「薩。」

塔恩看他。

莫爾也看。

周渡拿紙。

畫那個穩定核心。

外面畫一圈。

再把明天畫在旁邊。

然後指眼睛。

先看。

不是先吸。

莫爾最先點頭。

塔恩過幾秒也點。

回城前，那盞舊路燈仍然亮著。

淡黃色的光落在長滿草的路面上。

很小。

離塔維爾的城牆也還很遠。

它沒有把整條舊路救回來。

沒有讓三道交叉線從地圖上消失。

也沒有證明地下那套老設施一定能修。

可至少從今天開始，塔恩和莫爾已經不再只是因為周渡說「下面還有東西」，才願意繼續做。

他們自己也看見了結果。

一條排水溝重新走水。

一段震動變弱。

一頭牲畜願意走過原本抗拒的位置。

還有第一盞燈。

真的亮了起來。

周渡晚上回旅店後，在紙上寫：

【六月二十六日，任務第十日。】

【外層清理有效，但每次清理都可能改變其他流路。必須分段、停、重查。】

【物理維修與能量殘餘清理缺一不可。部分失穩會在堵塞／固定問題修好後自行降低。】

【舊路第一盞長期故障晶石燈已恢復穩定照明，截至離開前未再次熄滅。】

【牲畜抗拒區反應降低。地面低頻震動減弱，但未消失。】

【深處穩定核心外仍有最後一圈高關聯失穩區。】

最後，他加了一句：

【明日不是吸更多。】

【先確認最後那一圈到底連著什麼。】

窗外的塔維爾照常有人走動。

而很遠的西北舊路上，有一盞原本早就該被當成廢物的燈，今晚還亮著。
