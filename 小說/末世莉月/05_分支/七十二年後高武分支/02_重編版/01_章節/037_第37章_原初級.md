# 第三十七章　原初級

七月二十九日。

下午兩點五十一分。

周渡按下【查看鑑定結果】。

頁面沒有動畫。

沒有金光。

也沒有任何「恭喜」。

第一欄只向下展開了四行。

【能力品質】

【原初級】

【當前個體階位：7級】

【能力品質與個體階位不作直接等值換算】

周渡看著第二行。

原初級。

這個詞他從來沒在第七武高課本裡看過。

也沒在人類常用的E、D、C、B、A、S、SS、SSS裡見過。

母親坐在旁邊，同樣看了幾秒。

第一句就問：

「這是不是SSS上面？」

服務人員回答得很快。

「不是這樣換算。」

母親：「那是比SSS強，還是比SSS弱？」

「也不能這樣比較。」

她把結果頁往下拉了一點。

下面果然有附註。

【「原初級」為本服務體系對能力本質／品質的專項分類結果之一。】

【其不等同於現行地球E～SSS潛力序列中的新增上位等級。】

【其不直接表示當前戰力、個體階位、能量總量、成長完成度或對任意其他能力的勝負關係。】

母親讀完。

「所以他現在還是七級？」

服務人員：「對。」

「沒有因為這個名稱變成七十級？」

「沒有。」

「出去跟三十級打？」

「仍然不建議。」

母親點頭。

「那就好。」

周渡看她。

「哪裡好？」

「至少沒花一筆錢，然後告訴我你現在可以去挑戰全球強者。」

服務人員嘴角很輕地動了一下。

可能是在笑。

也可能只是正常表情。

周渡重新看那四個字。

原初級。

如果放在兩週以前，他大概會先想這到底相當於S還是SS。

可這幾天人類側已經把這條路試過了。

沒有答案。

能力品質模型匹配失敗。

功能分類互相衝突。

最後只能填「待定」。

莉月現在沒有把它硬塞回去。

而是直接給了另一個分類。

周渡問：

「為什麼叫原初級？」

服務人員沒有立刻回答一大段理論。

她先確認終端上的服務範圍。

「你購買的鑑定包含結果用詞說明。」

「可以解釋到基本層級。」

周渡：「嗯。」

服務人員：「簡單說，它描述的是能力現在的根本性質，而不是你現在能打多強。」

「這類能力的核心結構不再適合用單一固定功能的成長模板理解。」

「它已經形成自己的完整根基，後續能如何發展，取決於能力本身、使用者承載能力、實際接觸與理解，以及之後真正形成的路。」

母親：「這聽起來還是很大。」

「範圍確實很大。」

服務人員說。

「所以才更不能把它翻譯成『現在很強』。」

她在桌面點出一張很簡單的比較示意。

左邊是一個七級S級能力者。

右邊是一個七級原初級能力者。

沒有戰力箭頭。

也沒有誰壓誰。

下面只寫：

【品質描述不同，不構成戰鬥結果。】

服務人員：「七級就是七級。」

「身體承載、源能總量、反應、經驗、裝備、戰術和能力成熟度都還是現實限制。」

「你今天可以解析一件七級以下的普通材料，不代表你明天就能把五十級生命體拆掉。」

周渡：「如果是無主的五十級材料？」

服務人員看他一眼。

「這就要進能力邊界說明。」

「下一欄會回答一部分。」

「但不會替你保證任何具體高階目標。」

周渡點頭。

這才是他想知道的。

不是一句「你很稀有」。

是這四個字到底會不會把原本的安全判斷全部推翻。

母親則問另一件事。

「這個分類常見嗎？」

服務人員：「不是日常能力鑑定最常出現的結果。」

母親：「有多少？」

「你本次服務不包含統計資料查詢。」

回答平靜得非常莉月。

母親沉默兩秒。

「加錢？」

「如果有公開統計服務，會另外列價。」

「算了。」

她放棄得很快。

周渡差點笑出來。

他自己其實也想知道。

但現在沒有必要。

稀不稀有不會改變明天他還要回學校這件事。

服務人員繼續說：

「另外，你的人類側報告把能力品質暫列為待定。」

「如果你需要，我們可以生成一份可供外部機構閱讀的鑑定證明。」

「內容只包含你選擇公開的欄位。」

「不會自動同步。」

周渡：「可以只公開品質，不公開後面的完整能力說明？」

「可以。」

「可以只給學校和醫療機構？」

「你把文件交給誰，是你的選擇。」

母親在旁邊問：

「未成年呢？」

服務人員：「依法需要監護程序的部分，你已完成。」

「但鑑定結果仍屬於本人資料，不因監護程序自動對學校、企業或研究機構公開。」

母親點頭。

這一點她明顯很滿意。

周渡把「外部證明」先放著。

沒有立刻生成。

他看向下一個尚未展開的欄位。

【能力正式名稱】

再下面還有：

【基本作用邊界】

【已確認風險】

【未確認項目】

這些才是今天真正需要帶回去的東西。

可周渡沒有馬上點第二欄。

他先把「原初級」那頁重新看一次。

不是SSS以上。

不等於戰力。

不等於等級。

不等於現在已經完成成長。

它只是第一次有人用一個正式名稱描述他現在這個能力究竟屬於哪一類。

一年以前。

E級。

【餘能汲取】。

那個結果也是真的。

他就是從只能在一點八公尺內撿別人不要的失穩能量開始。

這一年所有訓練、實習和處理站安全規則，也都不是因為今天出現「原初級」三個字就變成笑話。

如果沒有那些東西，他在世界錨下面第一次感知爆開時，可能連「先停」都不知道。

周渡突然問：

「以前的E級算錯了嗎？」

服務人員：「如果當時的鑑定對象確實是當時的【餘能汲取】，那就不算錯。」

「能力後來發生根性質改變，不會反過來把過去的結果改成假的。」

這句話讓周渡安靜了一下。

很好。

E級是真的。

原初級也是真的。

只是中間隔著一座他當時根本不知道叫世界錨的舊設施。

還有三十天。

母親把水瓶擰好。

「所以這張能拿回去？」

服務人員：「鑑定結束後可以下載。」

「紙本呢？」

「可列印。」

「要錢？」

「本次服務包含一份。」

母親立刻說：

「那印。」

服務人員：「好的。」

周渡看她。

母親：「都付錢了。」

無法反駁。

桌面終端的下一欄仍然收著。

【能力正式名稱】

周渡把手放上去。

這一次停得比剛才短。

原初級已經夠陌生了。

名字反而更直接。

他按下展開。
