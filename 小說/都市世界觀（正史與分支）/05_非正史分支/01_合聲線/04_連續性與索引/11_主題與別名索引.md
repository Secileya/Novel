# 合聲線・主題與別名索引

> 用途：提供 TOPIC_SWEEP_GATE 的動態檢索入口。  
> 本檔不是設定正文；真正內容仍以正式正文、穩定設定、後修／禁用與候選規劃為準。

## 維護規則

- 本索引**持續增長**，不設定固定上限。
- 後續討論只要新增會反覆使用的重要人物、別名、舊譯名、能力名、事件名、組織名、館藏名、代號、伏筆或術語，就應加入。
- **現行有效資料一律改寫成最新正式名。**舊名稱不留在一般設定／規劃內容中，只在本索引（以及必要的最小禁用紀錄）保留作歷史搜尋入口，並標註「舊稱／誤譯／已禁用／勿混用」。
- 若一個舊詞後來拆成多個不同概念，應保留舊詞並標註拆分方向。
- 本索引只幫助「找到資料」，不能單獨決定哪個版本有效。

## 名稱正規化原則

- 本索引負責保存「舊名怎麼對到新名」，不是要求其他文件繼續使用舊名。
- 一旦名稱後修，所有現行正文／設定／狀態／規劃應立即換成最新正式名。
- 新普通對話即使只知道最新正式名，也應能直接搜尋到完整有效資料。
- 舊名只作第二輪補漏搜尋，主要用於 Git 歷史、尚未清理的遺漏與防止舊版本復活。
- 每次名稱後修都執行 `CANONICAL_NAME_MIGRATION`：新名全庫確認 → 舊名全庫清掃 → 更新本索引。
