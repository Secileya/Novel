# 02｜世界的基本構造

- 系統與未知世界：規模、來源、目的與真正上限未知。
- 居住區：長期生活與休整。
- 輪轉場域：探索、事件與各類體驗。
- 特殊節點：臨時商店、休息點、奇遇。
- 跨區公共場域：大型活動、交易與人員交流。

基本世界結構，並不代表所有空間都必須符合這四種分類。

世界不具有單一的固定美術風格。

可以存在現代都市、未來科技設施、奇幻王國、後室式異常空間、海洋、宇宙、遊樂園、古老文明、夢境般的場所，乃至於完全不符合人類正常空間概念的世界。

某些場域可能只是一間房間，某些則可能擁有完整的星球、文明與數百萬居民。

目前不確定這些場域是系統創造的、從其他世界連接而來的，還是原本就存在於某個更龐大的世界結構中。

這部分可以長期保持未知。

# 04｜人口與不同居住區

世界中存在許多居住區。

不同居住區的建立時間、人口、資源、組織、文化與發展程度都可以不同。

示意：第012區（成熟居住區）、第037區（初始故事區域）、第081區（大型居住區）、第119區（新興居住區）分別連向共同場域與公共活動（交流、交易、輪轉、競技）。不同居住區平時獨立運作，特定條件下可以相互接觸。

## 4.1 新人與人口變化

每個居住區可以擁有一批固定的初始參與者，但人口不會永久固定。

系統可以不定期投放新人，也可能建立全新的居住區。

新人加入不需要與死亡人數一一對應。有人死亡不代表立即有人補上，也可能有相當長的時間沒有新人到來。

因此居住區會逐漸形成不同世代的人員。

最初的新人可能在半年後成為資深者，原本的資深者可能成為有名的探索者、強者、商人或組織領導者。

新人與資深者之間的差異可以表現在財富、道具、實力、情報、社交關係與對世界的理解上。

## 4.2 跨區交流

不同居住區的參與者可能透過共同輪轉、大型市集、特殊活動、公共競技場、跨區商店及其他特殊渠道相遇。

某些場合可能只有兩個居住區接觸，某些場合可能同時出現數萬人。

也可以存在移居、長期訪問、跨區組隊與特殊居住資格，但具體取得條件尚未鎖定。

這讓人物既能保有固定生活圈，也能持續認識新的人。

# 05｜輪轉的核心機制

輪轉是參與者無法永久逃避的週期性現象。

它是世界最主要的變化來源，也是重要的生存壓力來源。

但是輪轉不等於死亡遊戲，也不等於每次都需要完成任務。

## 5.1 個人輪轉排程

採用個人排程為主要架構，不再要求所有居住區居民同時出發、同時返回。

每名參與者具有自己的輪轉倒數。

| 人物 | 目前狀態 | 倒數／預計返回 |
|---|---|---|
| 林夏 | 居住區・自由活動中 | 下次27:14:06 |
| 周宇 | 居住區・準備出發 | 下次00:08:32 |
| 居民 C | 輪轉中・海濱度假區 | 3天後返回 |
| 居民 D | 輪轉中・未登錄場域 | 未知 |

每次輪轉結束後，系統會重新安排下一次輪轉時間。

休整期可能只有數小時，也可能持續數天或數週，特殊情況下甚至可以更長。

參與者可以自由安排這段時間，但正常情況下不能藉由拒絕、睡覺、躲藏或單純支付普通積分，永久避免強制輪轉。

## 5.2 輪轉規模

| 規模 | 參與人數示例 |
|---|---:|
| 個人遭遇 | 1人 |
| 雙人場域 | 2人 |
| 小隊場域 | 3～8人 |
| 小型輪轉 | 10～30人 |
| 中型輪轉 | 50～150人 |
| 大型輪轉 | 數百至數千人 |
| 跨區大型事件 | 數萬人以上 |
| 特殊世界級輪轉 | 未設定上限 |

上述只是可能出現的規模，不是正式階級。

單人輪轉可能極度危險，萬人輪轉也可能只是盛大的節日。

人數、危險程度、獎勵、時間與規模不存在必然的正比關係。

## 5.3 組隊機制

參與者可以透過系統建立臨時隊伍或長期隊伍，並申請共同參與下一次輪轉。

暫定採取自願同步機制，避免不同朋友的輪轉倒數永遠無法配合。

但組隊不應成為無限推遲輪轉的漏洞。同步安排必須符合系統允許的時間範圍。

部分場域可以接納完整隊伍，部分則可能限制人數、禁止預組隊伍，或者在進入後重新分配身分與陣營。

同一隊伍甚至可能在某次智鬥場域中成為對手。

隊伍關係也可以跨越多次輪轉持續存在。

## 5.4 特殊輪轉安排

除了個人排程之外，可以存在全區輪轉、指定人物輪轉、跨區共同輪轉、活動型輪轉，以及由特殊道具觸發的額外輪轉。

正在其他場域內的參與者，原則上不會因居住區開啟新輪轉而被任意抽離。

特殊例外必須有對應規則或真正的異常原因。

## 5.5 場域時間

每次輪轉的持續時間不固定。

可能只需要十秒鐘，也可能持續數小時、數天、數月，甚至數年。

有些場域具有明確倒數，有些必須找到出口，有些可以自行決定何時離開，有些則存在完全未知的返回條件。

暫時以場域時間和外界時間正常同步流逝為常態，特殊時間差則可作為特定場域的獨立性質。

因此，當某個人經歷了三個月的漫長輪轉時，他原本居住區內的朋友也可能已經度過了三個月。

世界不會停下來等待任何人。

# 08｜場域內的次級輪轉與長途旅程

輪轉不需要永遠採用出發、完成事件、返回居住區的單層結構。

某些大型輪轉內部可以擁有自己的旅程、輪次、停靠點與安全區。

例如某次輪轉將數百人送往一艘巨型輪船。

船上擁有私人房間、餐廳、商店、游泳池、娛樂設施與公共大廳。

整趟航行可能持續三十天。

期間會經歷不同性質的停靠點。

1. 第一站・珊瑚島：自由遊玩、潛水、特殊食品與紀念品。
2. 第二站・失聯港口：危險探索，可能取得船艦零件與未知物品。
3. 航行期間・船上生活：休息、娛樂、交易、私人事件。
4. 第三站・海上商業都市：其他旅人、臨時商店、特殊貨幣與競技活動。
5. 第四站・未知海域：沒有完整提示，船艦與乘客可能遭遇重大事件。
6. 最終返回：結束整趟大型輪轉，返回各自居住區。

也可以出現具有類似結構的電梯、列車、移動都市、太空船、會不斷改變內部結構的設施，或由許多特殊空間組成的巨大建築。

但不會因為喜歡 Regretevator 的輪次感，就將所有場域限制成電梯或載具。

## 早期機制與後修辨識
早期四種人口方案：固定群體永無新人（適合終局死亡遊戲但易枯竭）；不定期投放新人；多個獨立區偶爾接通；可移居和流動人口。後續偏好混合第二、第三、第四種，並未鎖死人口上限。

### 分配與返回時間示例
300人週一10:00一同出發亦不必同場：
| 場域 | 人數 | 時間 |
|---|---:|---:|
| 廢棄都市 | 120 | 48小時 |
| 異常列車 | 60 | 12小時 |
| 競技樂園 | 100 | 6小時 |
| 神祕旅館 | 20 | 72小時 |

樂園的人下午就回家、列車的人晚上回家、都市的人兩天後、旅館的人三天後；次次不必等全員返還。不同個人可有42:18:09、02:36:41等不同倒數，正在輪轉者可能剩18:04:32或返回時間未知。

### 可存在的壓力
生存（不可提前撤離）、輪轉（場域關閉／下一次出發）、經濟（醫療裝備）、競爭（資源獎勵）、人際（恩怨／失去）、未知（下一次內容）。不需要同時存在，也不以固定周期、飢餓或系統抹殺為唯一壓力。
