# 06｜輪轉場域的設計自由

這是整部作品最需要保有創造力的部分。

場域不採固定的類型限制，也不使用簡單的低級、中級、高級副本排列。

每個場域都可以獨立決定以下性質。

| 性質 | 範圍示意 |
|---|---|
| 美術與氣氛 | 清新、明亮至陰暗、恐怖 |
| 實際危險 | 完全安全至極度致命 |
| 規則複雜度 | 幾乎沒有至高度複雜 |
| 活動自由度 | 指定行動至完整開放世界 |
| 參與人數 | 單人至無數人 |
| 停留時間 | 數秒至數年 |
| 人際結構 | 完全合作至致命敵對 |
| 空間性質 | 一間房間至完整文明 |
| 情報透明度 | 完全公開至完全未知 |
| 場域存續 | 一次性出現至永久持續存在 |

這些性質彼此獨立。

不能因為場景鮮豔就判斷安全，也不能因為場景恐怖就認定有危險。

- 看起來安全，實際安全：真正的休假、遊樂與生活體驗。
- 看起來安全，實際危險：歡樂舞廳中的致命遊戲。
- 看起來危險，實際安全：以恐怖為主題的正常娛樂設施。
- 看起來危險，實際危險：真正存在致命實體與異常現象的場所。

上述四種只是最容易理解的例子。

還可能存在最初安全但因人為衝突而變得危險的地方，或者原本非常危險，但經過探索者長期經營後建立了安全據點的場域。

# 07｜場域內容素材庫

以下不是固定分類，而是目前可以納入世界的部分內容方向。未來可以不斷增加。

| 內容方向 | 可能的場域或事件 |
|---|---|
| 大型探索 | 廢棄都市、未知星球、地下文明 |
| 後室式探索 | 無限走廊、泳池空間、異常商場 |
| 規則怪談 | 特殊旅館、夜間學校、異常住宅 |
| 智鬥 | 狼人殺、身分推理、欺騙與博弈 |
| 死亡遊戲 | 彩色舞池、致命競技、淘汰規則 |
| 普通遊戲 | 捉迷藏、障礙賽、桌遊、團體競賽 |
| 戰鬥 | 競技場、陣營戰爭、怪物狩獵 |
| 大型生存 | 災害都市、未知荒野、深海設施 |
| 合作 | 多人建設、救援、共同解謎 |
| 生活體驗 | 特殊公寓、海濱小鎮、異界旅館 |
| 商業 | 拍賣會、特殊市集、商店經營 |
| 經營與發展 | 經營餐廳、建立聚落、管理領地 |
| 載具旅程 | 列車、輪船、太空船、移動城市 |
| 文明與政治 | 完整王國、國家衝突、異界社會 |
| 角色扮演 | 身分分配、特殊職業、情境體驗 |
| 娛樂享受 | 水上樂園、度假村、音樂節 |
| 奇遇 | 特殊NPC、未知生物、私人遭遇 |
| 荒誕事件 | 玩具世界、巨大化、重力顛倒 |
| 異常現象 | 空間循環、時間異常、認知改變 |
| 純粹景觀 | 星空海洋、雲端花園、永恆黃昏 |
| 未知場域 | 沒有明確任務、規則、目的或解釋 |

場域也不必只擁有一種內容。

例如一座巨大都市內可以同時存在戰鬥、商業、奇遇、規則怪談、特殊居民、政治衝突與普通生活。

某些事件可以短到一段正文就結束，某些場域則足以成為數十章乃至更長的大型篇章。

## 7.1 部分具體場域示例

### DISCO! DISCO!
參與者按照螢幕指示站上指定顏色的方格。某些版本的失敗可能只是淘汰，某些則是真正死亡。
不預設主持人一定存在，也不預設系統會提前完整告知風險。

### 十三人的晚宴
參與者具有不同的身分、目標與私人情報。白天可以正常生活、聊天與享用餐點，夜間則可能發生與身分規則相關的事件。
合作、欺騙、信任與智鬥會直接影響結局。

### 未登錄場域0067
多座泳池、商場、走廊、地下空間與未知區域彼此連接。不同批次的探索者可能在此相遇。
沒有完整地圖，也沒有固定離開時間。可能出現臨時補給店、其他居民建立的據點及未知出口。

### 玩具戰爭
參與者縮小至玩具尺寸，普通房間成為龐大的探索空間。玩具、家具與日常用品具有截然不同的用途。
可以是競技，也可以是陣營戰爭或合作探索。

### 藍灣度假村
可以自由使用度假設施、購物、游泳、參與活動、尋找限定紀念品，並認識其他居住區的人。
場域本身可以真正安全，沒有需要被揭露的恐怖真相。

### 永雨小鎮
一座持續下雨的小鎮，擁有住宅、餐廳、商店及自己的居民。參與者可以正常生活，也可以探索小鎮更深處的特殊現象。
不同區域可能具有不同的危險程度。

### 無限購物中心
商場內部的空間規模未知，有些店舖正常營業，有些店舖則具有特殊的商品與規則。
人們可能在這裡經營據點、探索數月，也可能找到返回通道後立即離開。

# 17｜場域的持續性與世界歷史

並非所有場域都會在參與者離開後消失。

有些是一次性的事件空間，有些則是真正長期存在的場所。

不同批次的人可以在不同時間進入同一個世界，看到先前參與者留下的痕跡。

曾經存在的據點可能發展成聚落，已經被發現的商店可能歇業，某個原本安全的地區可能因戰爭而改變。

也可能有人在半年後再次進入自己曾經造訪過的城市，發現當初認識的居民已經過著不同的人生。

場域具有自己的時間、歷史與因果。

不需要在每次輪轉後自動恢復初始狀態。

同時也允許某些場域確實具有重置、週期循環、不同版本或特殊時間現象，但這些是個別場域的性質。

## 較早的具體候選保全
- 室內水上樂園：無敵人、無任務，眾人玩一下午；失聯設施：真正致命；凌晨便利商店：八小時休息；超大型超市：購物車自己逃跑，抓到可免費取得內部商品；競技場：觀戰、下注、切磋、致命競技皆可；雨夜旅館：離開時間未知、不同房價與設施。
- 廢棄購物中心：48小時自由搜尋，夜間實體與爭奪。浮空遊樂場：6小時、搞怪競技、積分。永雨小鎮：7天、居民及特定規則。競技都市：3天跨區，安全與致命區並存。海濱度假區：5天純享受。第零號地下設施：時間未知、找出口。
- 深夜廣播電臺：不同房間，透過廣播交流，指令可能不同。無限家具城：探索、搭建據點、自有晝夜與未知居民。千人夏日祭：真正安全、煙火、攤販、限定商品。雙人公寓：陌生人同住豪華公寓一週，無特殊任務。第九收容設施：明確告知致命風險。午夜拍賣會：跨區富有者及商人。無盡高速公路：各種載具、加油站、汽車旅館、其他旅人。空白房間：無提示、出口或敵人。海上漂流都市：不同船艦、外交、貿易及戰爭。
- 早期彩燈舞廳候選：24人、四輪、17人生還，與後來36人、九輪、29人生還的試寫不同。兩版本均非正史，不合併。舞廳可以有主持人（坦承、誤導、禮貌播報或黑色幽默）也可以沒有（設備自己運作）。看似輕鬆的遊戲可真致死，但不能視為世界所有派對的隱藏真相。
