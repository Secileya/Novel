# 20｜仍然開放的世界觀問題

以下部分目前不急著確定，因為它們具有很大的後續創作潛力。

| 項目 | 目前狀態 |
|---|---|
| 系統的創造者 | 未知 |
| 系統運作的真正目的 | 未知 |
| 參與者被選中的原因 | 未確定 |
| 是否能回到原世界 | 未確定 |
| 居住區的總數與總人口 | 不設上限 |
| 場域的真正來源 | 未知 |
| NPC的本質 | 依個體與場域而定 |
| 力量的最終上限 | 未確定 |
| 系統是否全知全能 | 未確定 |
| 系統之外是否有更龐大的世界 | 保留可能性 |
| 是否存在特殊管理者 | 保留可能性 |
| 是否存在永久退出輪轉的方法 | 未確定 |
| 最初參與者進入至今的歷史 | 未確定 |

這些不一定都要成為主線謎團。

某些真相可以很晚才揭露，某些甚至可以始終保持未知。世界的吸引力不必完全依靠最後揭曉系統的秘密。

## 實作前仍需核定的具體問題（OPEN）
| 主題 | 待決內容 |
|---|---|
| 人口 | 新人來源、投放頻率、居住區容量、是否可跨區移居、跨區交通權限 |
| 排程 | 倒數發放規則、最短休整、組隊同步窗口、未完成輪轉、拒絕與延期的例外 |
| 資訊 | 通訊範圍、場域名稱公布時機、存活狀態是否公開、論壇可見範圍、物品鑑定與資訊可靠性 |
| 安全 | 正式居住區安全機制細則、不同安全場域的邊界、競技傷害和醫療服務 |
| 經濟 | 初始積分與正常收入、日常物價、失去裝備／醫療的成本、特殊貨幣流通 |
| 物品 | 儲物容量與限制、道具疊加、副作用、適性、綁定及交易、遺物繼承 |
| 長篇 | 正式主角與其他核心視角、首批人物、首場正式輪轉及是否有更長遠劇情 |
| 世界 | 系統目的及真正能力、場域來源與時間、永久退出、回原世界、NPC 本質、力量上限 |

以上是整理者新增的待決清單，不代表必須一次全定、每個都變成主線謎團。已提出的候選規則保留於00與01–12。作者最新修正優先；不因收錄、分類、GitHub提交或試寫自動成為 Canon。
