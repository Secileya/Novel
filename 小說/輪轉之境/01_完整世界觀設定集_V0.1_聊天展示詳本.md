# 01｜核心世界觀與創作基調

這是一個由無數特殊場域、居住區、異常存在、未知文明與系統機制共同構成的世界。

來自不同地方的人被轉移至此，在獲得基本生活保障與個人系統後，必須持續參與名為「輪轉」的特殊現象。

輪轉可能將參與者送往任何性質的場所。

有些地方存在真正的死亡危險，有些需要智鬥、合作、探索或戰鬥，有些則只是讓人享受娛樂、購物、度假與其他不可思議的體驗。

整個世界可以同時容納以下氛圍。

| 氛圍 | 內容 | 原畫面參考的文字描述 |
|---|---|---|
| 舒適 Cozy | 清涼、乾淨、物資充足、自由享受生活。 | 午夜現代便利商店、乾淨白光、零食冷飲、藍色調 |
| 未知 Wonder | 奇妙、異常、探索慾與從未見過的景象。 | 無盡室內泳池、藍色水面與閾限空間 |
| 遊戲感 Playfulness | 搞怪、競技、奇遇、特殊玩法與人際互動。 | 鮮豔超現實多人競技節目 |
| 危險 Peril | 真實死亡、生存壓力、衝突、恐怖與不可逆的後果。 | 陰暗廢棄地下科技設施、緊急照明 |
| 群像 Social | 朋友、戀人、宿敵、陌生人、組織與持續發展的人際關係。 | 午夜冷氣電玩休息室、朋友與零食 |
| 期待 Anticipation | 下一次輪轉、新商品、稀有物品、未知人物與特殊事件。 | 神祕流動商店、色彩繽紛的奇異物品 |

上述氛圍沒有固定比例，也沒有必要彼此對立。

舒適可以真的舒適，恐怖可以真的恐怖，荒唐的事情也可以單純只是荒唐。

世界不需要永遠壓抑，也不需要透過反轉證明每一處安全場所都暗藏危機。

**最重要的核心是：參與者擁有持續的人生，而輪轉不斷為這些人生帶來新的經歷。**

# 02｜世界的基本構造

- 系統與未知世界：規模、來源、目的與真正上限未知。
- 居住區：長期生活與休整。
- 輪轉場域：探索、事件與各類體驗。
- 特殊節點：臨時商店、休息點、奇遇。
- 跨區公共場域：大型活動、交易與人員交流。

基本世界結構，並不代表所有空間都必須符合這四種分類。

世界不具有單一的固定美術風格。

可以存在現代都市、未來科技設施、奇幻王國、後室式異常空間、海洋、宇宙、遊樂園、古老文明、夢境般的場所，乃至於完全不符合人類正常空間概念的世界。

某些場域可能只是一間房間，某些則可能擁有完整的星球、文明與數百萬居民。

目前不確定這些場域是系統創造的、從其他世界連接而來的，還是原本就存在於某個更龐大的世界結構中。

這部分可以長期保持未知。

# 03｜居住區

居住區是參與者長期生活、休息與建立人際關係的主要場所。

每個參與者最初都會被分配至某個居住區。暫時以第037居住區、初始人口300人作為故事設計示例。

居住區不應只是簡陋的主神廣場或副本等待室，而是一個真正值得生活的地方。

畫面：現代未來感住宅中庭、室內植物、白藍建築、冷藏櫃裝滿零食的便利商店、舒適電玩沙發及私人公寓。

## 3.1 基本設施

| 設施 | 內容 |
|---|---|
| 中央大廳 | 公共休息、公告、輪轉出發與返回 |
| 私人住宅 | 免費基礎房間、套房、高級住所 |
| 便利商店 | 普通食品、特殊食品、日用品 |
| 商業街 | 餐廳、服飾、家具、專門商店 |
| 系統商城 | 裝備、道具、能力、特殊服務 |
| 娛樂區 | 電玩、桌遊、電影院、卡拉OK |
| 運動設施 | 游泳池、健身房、各類球場 |
| 訓練區 | 武器測試、能力測試、安全切磋 |
| 醫療區 | 傷勢治療、異常狀態處理 |
| 交易區 | 私人店鋪、物品交換、拍賣 |
| 公共浴場 | 淋浴、浴池、休息設施 |
| 特殊展區 | 不定期活動、展示、臨時商店 |
| 未開放區域 | 日後可能開啟的未知設施 |

居住區可以有自然光模擬、空調、乾淨的飲用水、完善的供電、自動清潔，以及便利的現代化設備。

不需要刻意讓正常生活變得艱難。

## 3.2 私人住所

所有新參與者可以獲得免費的基礎私人房間。房間具有基本床鋪、衛浴、照明、空調與儲物設備。

之後可以透過積分購買更大的空間、家具與特殊設施。

畫面示例：基礎單人房間；個人遊戲與娛樂室（多螢幕、電玩椅、藍色照明）；多人共同住宅（寬敞客廳、沙發）；特殊景觀住宅（巨窗俯瞰雲海或海洋）。

居民可以按照自己的喜好生活。

有人將房間改造成武器庫，有人擺滿稀有收藏，有人購買大量電玩設備，有人弄了一間私人電影院，也有人只是喜歡一張大床和非常舒服的空調。

朋友、戀人、隊伍成員可以共同生活，也可以保有各自的私人空間。

某些特殊家具、房間功能與景觀甚至可能只能在輪轉中取得。

## 3.3 安全機制

正式居住區內具有可靠的系統安全保障。

原則上禁止真正的殺人行為、致命傷害、強行侵入私人住宅，以及其他直接破壞基礎安全的行為。

訓練與競技則可以透過特殊設施進行，按照參與者同意的規則限制傷害。

但安全不代表所有居民都會友善。

居住區仍然存在欺騙、利益衝突、商業競爭、情感糾紛、團體排斥、情報交易與私人恩怨。

也可以存在非常討厭彼此的人，卻因為安全機制而無法直接殺死對方。

真正的致命衝突可能延續至下一次沒有安全保護的輪轉。

## 3.4 居民自行發展

系統提供基礎設施，但不會包辦所有生活內容。

居民可以自行開設餐廳、經營商店、成立組織、舉辦活動、出租設備、研究道具、提供情報與其他服務。

經過長時間發展，不同居住區可能形成截然不同的文化與社會秩序。

居住區本身也具有歷史。

# 04｜人口與不同居住區

世界中存在許多居住區。

不同居住區的建立時間、人口、資源、組織、文化與發展程度都可以不同。

示意：第012區（成熟居住區）、第037區（初始故事區域）、第081區（大型居住區）、第119區（新興居住區）分別連向共同場域與公共活動（交流、交易、輪轉、競技）。不同居住區平時獨立運作，特定條件下可以相互接觸。

## 4.1 新人與人口變化

每個居住區可以擁有一批固定的初始參與者，但人口不會永久固定。

系統可以不定期投放新人，也可能建立全新的居住區。

新人加入不需要與死亡人數一一對應。有人死亡不代表立即有人補上，也可能有相當長的時間沒有新人到來。

因此居住區會逐漸形成不同世代的人員。

最初的新人可能在半年後成為資深者，原本的資深者可能成為有名的探索者、強者、商人或組織領導者。

新人與資深者之間的差異可以表現在財富、道具、實力、情報、社交關係與對世界的理解上。

## 4.2 跨區交流

不同居住區的參與者可能透過共同輪轉、大型市集、特殊活動、公共競技場、跨區商店及其他特殊渠道相遇。

某些場合可能只有兩個居住區接觸，某些場合可能同時出現數萬人。

也可以存在移居、長期訪問、跨區組隊與特殊居住資格，但具體取得條件尚未鎖定。

這讓人物既能保有固定生活圈，也能持續認識新的人。

# 05｜輪轉的核心機制

輪轉是參與者無法永久逃避的週期性現象。

它是世界最主要的變化來源，也是重要的生存壓力來源。

但是輪轉不等於死亡遊戲，也不等於每次都需要完成任務。

## 5.1 個人輪轉排程

採用個人排程為主要架構，不再要求所有居住區居民同時出發、同時返回。

每名參與者具有自己的輪轉倒數。

| 人物 | 目前狀態 | 倒數／預計返回 |
|---|---|---|
| 林夏 | 居住區・自由活動中 | 下次27:14:06 |
| 周宇 | 居住區・準備出發 | 下次00:08:32 |
| 居民 C | 輪轉中・海濱度假區 | 3天後返回 |
| 居民 D | 輪轉中・未登錄場域 | 未知 |

每次輪轉結束後，系統會重新安排下一次輪轉時間。

休整期可能只有數小時，也可能持續數天或數週，特殊情況下甚至可以更長。

參與者可以自由安排這段時間，但正常情況下不能藉由拒絕、睡覺、躲藏或單純支付普通積分，永久避免強制輪轉。

## 5.2 輪轉規模

| 規模 | 參與人數示例 |
|---|---:|
| 個人遭遇 | 1人 |
| 雙人場域 | 2人 |
| 小隊場域 | 3～8人 |
| 小型輪轉 | 10～30人 |
| 中型輪轉 | 50～150人 |
| 大型輪轉 | 數百至數千人 |
| 跨區大型事件 | 數萬人以上 |
| 特殊世界級輪轉 | 未設定上限 |

上述只是可能出現的規模，不是正式階級。

單人輪轉可能極度危險，萬人輪轉也可能只是盛大的節日。

人數、危險程度、獎勵、時間與規模不存在必然的正比關係。

## 5.3 組隊機制

參與者可以透過系統建立臨時隊伍或長期隊伍，並申請共同參與下一次輪轉。

暫定採取自願同步機制，避免不同朋友的輪轉倒數永遠無法配合。

但組隊不應成為無限推遲輪轉的漏洞。同步安排必須符合系統允許的時間範圍。

部分場域可以接納完整隊伍，部分則可能限制人數、禁止預組隊伍，或者在進入後重新分配身分與陣營。

同一隊伍甚至可能在某次智鬥場域中成為對手。

隊伍關係也可以跨越多次輪轉持續存在。

## 5.4 特殊輪轉安排

除了個人排程之外，可以存在全區輪轉、指定人物輪轉、跨區共同輪轉、活動型輪轉，以及由特殊道具觸發的額外輪轉。

正在其他場域內的參與者，原則上不會因居住區開啟新輪轉而被任意抽離。

特殊例外必須有對應規則或真正的異常原因。

## 5.5 場域時間

每次輪轉的持續時間不固定。

可能只需要十秒鐘，也可能持續數小時、數天、數月，甚至數年。

有些場域具有明確倒數，有些必須找到出口，有些可以自行決定何時離開，有些則存在完全未知的返回條件。

暫時以場域時間和外界時間正常同步流逝為常態，特殊時間差則可作為特定場域的獨立性質。

因此，當某個人經歷了三個月的漫長輪轉時，他原本居住區內的朋友也可能已經度過了三個月。

世界不會停下來等待任何人。

# 06｜輪轉場域的設計自由

這是整部作品最需要保有創造力的部分。

場域不採固定的類型限制，也不使用簡單的低級、中級、高級副本排列。

每個場域都可以獨立決定以下性質。

| 性質 | 範圍示意 |
|---|---|
| 美術與氣氛 | 清新、明亮至陰暗、恐怖 |
| 實際危險 | 完全安全至極度致命 |
| 規則複雜度 | 幾乎沒有至高度複雜 |
| 活動自由度 | 指定行動至完整開放世界 |
| 參與人數 | 單人至無數人 |
| 停留時間 | 數秒至數年 |
| 人際結構 | 完全合作至致命敵對 |
| 空間性質 | 一間房間至完整文明 |
| 情報透明度 | 完全公開至完全未知 |
| 場域存續 | 一次性出現至永久持續存在 |

這些性質彼此獨立。

不能因為場景鮮豔就判斷安全，也不能因為場景恐怖就認定有危險。

- 看起來安全，實際安全：真正的休假、遊樂與生活體驗。
- 看起來安全，實際危險：歡樂舞廳中的致命遊戲。
- 看起來危險，實際安全：以恐怖為主題的正常娛樂設施。
- 看起來危險，實際危險：真正存在致命實體與異常現象的場所。

上述四種只是最容易理解的例子。

還可能存在最初安全但因人為衝突而變得危險的地方，或者原本非常危險，但經過探索者長期經營後建立了安全據點的場域。

# 07｜場域內容素材庫

以下不是固定分類，而是目前可以納入世界的部分內容方向。未來可以不斷增加。

| 內容方向 | 可能的場域或事件 |
|---|---|
| 大型探索 | 廢棄都市、未知星球、地下文明 |
| 後室式探索 | 無限走廊、泳池空間、異常商場 |
| 規則怪談 | 特殊旅館、夜間學校、異常住宅 |
| 智鬥 | 狼人殺、身分推理、欺騙與博弈 |
| 死亡遊戲 | 彩色舞池、致命競技、淘汰規則 |
| 普通遊戲 | 捉迷藏、障礙賽、桌遊、團體競賽 |
| 戰鬥 | 競技場、陣營戰爭、怪物狩獵 |
| 大型生存 | 災害都市、未知荒野、深海設施 |
| 合作 | 多人建設、救援、共同解謎 |
| 生活體驗 | 特殊公寓、海濱小鎮、異界旅館 |
| 商業 | 拍賣會、特殊市集、商店經營 |
| 經營與發展 | 經營餐廳、建立聚落、管理領地 |
| 載具旅程 | 列車、輪船、太空船、移動城市 |
| 文明與政治 | 完整王國、國家衝突、異界社會 |
| 角色扮演 | 身分分配、特殊職業、情境體驗 |
| 娛樂享受 | 水上樂園、度假村、音樂節 |
| 奇遇 | 特殊NPC、未知生物、私人遭遇 |
| 荒誕事件 | 玩具世界、巨大化、重力顛倒 |
| 異常現象 | 空間循環、時間異常、認知改變 |
| 純粹景觀 | 星空海洋、雲端花園、永恆黃昏 |
| 未知場域 | 沒有明確任務、規則、目的或解釋 |

場域也不必只擁有一種內容。

例如一座巨大都市內可以同時存在戰鬥、商業、奇遇、規則怪談、特殊居民、政治衝突與普通生活。

某些事件可以短到一段正文就結束，某些場域則足以成為數十章乃至更長的大型篇章。

## 7.1 部分具體場域示例

### DISCO! DISCO!
參與者按照螢幕指示站上指定顏色的方格。某些版本的失敗可能只是淘汰，某些則是真正死亡。
不預設主持人一定存在，也不預設系統會提前完整告知風險。

### 十三人的晚宴
參與者具有不同的身分、目標與私人情報。白天可以正常生活、聊天與享用餐點，夜間則可能發生與身分規則相關的事件。
合作、欺騙、信任與智鬥會直接影響結局。

### 未登錄場域0067
多座泳池、商場、走廊、地下空間與未知區域彼此連接。不同批次的探索者可能在此相遇。
沒有完整地圖，也沒有固定離開時間。可能出現臨時補給店、其他居民建立的據點及未知出口。

### 玩具戰爭
參與者縮小至玩具尺寸，普通房間成為龐大的探索空間。玩具、家具與日常用品具有截然不同的用途。
可以是競技，也可以是陣營戰爭或合作探索。

### 藍灣度假村
可以自由使用度假設施、購物、游泳、參與活動、尋找限定紀念品，並認識其他居住區的人。
場域本身可以真正安全，沒有需要被揭露的恐怖真相。

### 永雨小鎮
一座持續下雨的小鎮，擁有住宅、餐廳、商店及自己的居民。參與者可以正常生活，也可以探索小鎮更深處的特殊現象。
不同區域可能具有不同的危險程度。

### 無限購物中心
商場內部的空間規模未知，有些店舖正常營業，有些店舖則具有特殊的商品與規則。
人們可能在這裡經營據點、探索數月，也可能找到返回通道後立即離開。

# 08｜場域內的次級輪轉與長途旅程

輪轉不需要永遠採用出發、完成事件、返回居住區的單層結構。

某些大型輪轉內部可以擁有自己的旅程、輪次、停靠點與安全區。

例如某次輪轉將數百人送往一艘巨型輪船。

船上擁有私人房間、餐廳、商店、游泳池、娛樂設施與公共大廳。

整趟航行可能持續三十天。

期間會經歷不同性質的停靠點。

1. 第一站・珊瑚島：自由遊玩、潛水、特殊食品與紀念品。
2. 第二站・失聯港口：危險探索，可能取得船艦零件與未知物品。
3. 航行期間・船上生活：休息、娛樂、交易、私人事件。
4. 第三站・海上商業都市：其他旅人、臨時商店、特殊貨幣與競技活動。
5. 第四站・未知海域：沒有完整提示，船艦與乘客可能遭遇重大事件。
6. 最終返回：結束整趟大型輪轉，返回各自居住區。

也可以出現具有類似結構的電梯、列車、移動都市、太空船、會不斷改變內部結構的設施，或由許多特殊空間組成的巨大建築。

但不會因為喜歡 Regretevator 的輪次感，就將所有場域限制成電梯或載具。

# 09｜特殊節點與臨時商店

特殊節點可以出現在居住區、輪轉場域、旅程途中及其他未知空間。

其性質不一：臨時補給商店、特殊商品店舖、中途休息站、期間限定市集。

臨時商店不只是用來購買戰鬥道具的地方。

它可以提供食物、飲料、家具、醫療、淋浴、休息、情報、遊戲、特殊活動、稀有商品及與NPC交流的機會。

有些商店具有明確的營業時間，有些何時離開完全未知。有些商店會重複出現，有些可能只存在一次。

同一家商店也可能在不同場域出現。

一名參與者甚至可能在非常危險的地下世界探索了十幾天後，意外發現自己幾個月前曾經去過的那間便利商店。

店員還記得他。

## 9.1 商店本身也有不同的性質

系統直營的商店可以具有可靠的交易與安全保障。

其他商店可能由參與者、場域居民、特殊NPC或異常存在經營，其規則與商品品質則各不相同。

並非所有商店都必須安全，也不是每個商人都會欺騙顧客。

有些店舖只是普通商店，有些則可能擁有非常奇怪的支付規則。

例如只收特定場域的舊硬幣、只接受以物易物，或只向某些受到店主認可的人出售商品。

# 10｜個人系統與資訊機制

系統是這個世界重要的基礎設施，但不需要時刻干涉參與者。

介面示意：
- 個人系統・第037居住區；18,420 P；休整中。
- 距離下一次輪轉：42:16:08。
- 商城、儲物空間、聯絡人、公共論壇、場域紀錄、物品資訊、住宅管理、特殊商店、活動資訊、組隊、交易、個人狀態。

系統功能介面示意，實際功能可能因環境與權限而改變。

系統可以提供基本身分、積分、物品資料、儲物、好友、交易、輪轉紀錄、公告及其他便利功能。

但不預設所有問題都能透過系統解答。

部分場域可能限制通訊、儲物空間、交易或其他系統功能。部分物品可能只有基礎資料，甚至完全沒有系統辨識結果。

也不需要讓所有參與者都具有公開的攻擊力、生命值、等級及固定數值面板。

某些道具或能力可以具有明確數值，某些則只能透過實際使用理解。

# 11｜積分與經濟

積分是居住區及多數系統設施內的主要通用貨幣。

暫時以初始積分1,000 P作為經濟設計參考，並非正式固定數值。

積分可以來自輪轉獎勵、探索成果、競技、出售物品、交易、特殊事件、情報與居民自行經營的事業。

不需要每次輪轉都發放積分，也不要求所有獎勵都必須經過系統結算。

## 11.1 基礎生活應當相對便宜

| 日常商品價目示例 | 價格 |
|---|---:|
| 礦泉水 | 1 P |
| 普通汽水 | 3 P |

| 家庭號洋芋片 | 5 P |

## 11.2 非積分經濟

部分商品不接受積分。

世界可以存在場域專屬貨幣、特殊活動代幣、紀念硬幣、交換材料、會員資格、特殊票券及其他無法直接使用積分兌換的東西。

- 積分 P：最普遍的系統貨幣，但不能購買所有事物。
- 特殊票券與活動代幣：具有特定來源、用途及適用範圍。
- 交換物與特殊材料：價值取決於持有者、需求、來源及特殊用途。
- 資格與私人認可：可能來自經歷、成就、特定事件或NPC的個人決定。

積分無法直接購買的物品，不代表完全不能透過參與者之間的交易取得。

只有在物品本身具有特殊限制、不可轉移性或其他條件時，才會真正無法以普通交易取得。

# 12｜道具與物品系統

道具是整個世界的重要探索與收藏樂趣來源。

任何具有足夠創意與內在合理性的物品，都可以存在。

**道具的價格、稀有度、強度、用途、取得難度、趣味性與情感價值，彼此獨立。**

不採所有物品都必須遵循同一套白、綠、藍、紫、金的強度階梯。

特定商店、場域或研究組織可以有自己的物品分類方式，但不需要成為整個世界的唯一標準。

## 12.1 道具的價值維度

| 維度 | 意義 |
|---|---|
| 價格 | 商店或交易市場的售價 |
| 稀有度 | 物品出現與取得的頻率 |
| 強度 | 所具有的實際力量或效果 |
| 實用性 | 在特定情境中的用途 |
| 泛用性 | 能夠適用多少不同環境 |
| 收藏價值 | 外觀、歷史、限定性或特殊意義 |
| 情感價值 | 對某個人而言的重要程度 |
| 趣味性 | 是否好玩、可愛、荒唐或有趣 |
| 取得條件 | 金錢、事件、資格、關係或其他要求 |

高價物品可以真的非常強。

低價物品也可以非常實用。

稀有物品可能具有極高的收藏價值，卻完全沒有戰鬥能力。

有些東西則可能同時昂貴、稀有、實用且極度強大。沒有必要為了追求平衡，刻意削弱所有頂級物品。

- 私人贈禮「給你的那顆星星」：「如果晚上睡不著，就把它放在床邊吧！」附有贈送者的手寫紙條。

部分資訊可以透過鑑定、研究、實驗、NPC詢問或特殊場域發現。

但不要讓每件不起眼的物品最後都變成神器。

未知可以帶來驚喜，也可以永遠只是未知。

## 12.6 道具組合與非預期用途

不同物品可以彼此配合，甚至形成設計者未曾想到的用途。

例如普通防滑拖鞋在特殊冰面競技中具有巨大優勢；可以拍下異常現象的相機可能協助探索不可見實體；某種糖果可能剛好受到特定NPC喜愛。

部分道具的組合可能增強效果，部分可能互相抵銷，也可能產生新的特殊反應。

因此世界可以自然形成專門研究物品、開發裝備、測試奇怪組合、整理攻略與收集情報的人。

# 13｜NPC、場域居民與異常存在

世界可以存在大量不同性質的非參與者角色。

暫時使用NPC作為方便討論的稱呼，但不預設他們都是系統生成的程式或沒有真正人格的存在。

他們可能是場域原住民、異界生物、特殊商人、主持人、工作人員、異常實體，或某種完全未知的存在。

人物示例：米露（喜歡甜食的特殊商店常客、兔耳少女）、售貨機先生（會聊天、移動與販售飲料的販賣機）、尼克斯（喜歡收集鑰匙圈的黑色異常生物）。

## 13.1 NPC的特殊互動

NPC可以有自己的喜好、習慣、私人生活、能力、物品與人際關係。

參與者可以和他們聊天、玩遊戲、購物、交換物品、贈送禮物、合作、戰鬥或建立長期關係。

例如米露喜歡草莓牛奶，收到時可能很開心。售貨機先生可能送給熟悉的顧客一張特殊會員卡。尼克斯則可能把自己的雨傘送給某個真正熟識的人。

但不存在送滿十次禮物就必定掉落指定道具的普遍規則。

個別NPC可以有非常遊戲化的互動條件，也可以完全按照自身人格作出決定。

有些特殊互動可以非常簡單，有些則可能需要經過很長時間的相處。

## 13.2 NPC的立場與危險性

NPC可以友善、中立、危險、殘酷、幽默、善良、冷漠，或者具有完全不符合人類價值觀的行為邏輯。

外表恐怖的存在可能相當友善，外表可愛的存在也可能極度危險。

有些NPC會主動幫助參與者，有些只在乎自己的生意，有些會根據特定規則行動，有些則可能將參與者視為真正的敵人。

## 13.3 重複相遇

部分NPC可能在不同場域、不同輪轉及不同居住區再次出現。

他們可以記得曾經見過的人，也可能因為此前事件改變對某人的態度。

某個參與者幾個月後再次遇見一名特殊NPC時，對方可能記得他的名字、喜歡的飲料，以及上次沒有說完的事情。

也可以存在只在某個場域出現一次，之後再也無法找到的特殊人物。

NPC的故事同樣可以具有延續性。

# 14｜戰鬥、力量與死亡

參與者可以透過訓練、特殊物品、商城、能力、研究、科技、場域探索及其他方式獲得力量。

世界可以同時存在現代武器、超自然能力、異常科技、規則型能力、特殊身體變化及其他力量形式。

不需要設立所有人共用的職業系統與固定升級路線。

## 14.1 戰力差距

資深參與者可以真正強大，擁有比普通人高出非常多的力量、經驗與資源。

這些優勢應該能實際影響生存能力。

不需要強制讓每次輪轉的難度永遠跟著個人戰力增長，否則成長會失去意義。

強者可以輕鬆解決部分普通危險，甚至能在某些場域中舒舒服服地度過整次輪轉。

同時，未知規則、智鬥、能力相性、特殊環境與限制仍然可能帶來不同類型的挑戰。

但不應為了讓弱者獲勝，就讓高階力量毫無合理性地失效。

## 14.2 戰鬥的不同性質

世界可以存在安全切磋、娛樂競技、認真決鬥、陣營對抗、生存戰鬥、規則限制下的對戰，以及真正的致命衝突。

兩個關係很好的人可以經常互相對戰與玩鬧。

兩個真正有仇的人也可能在沒有安全保障的場域中交手。

場域規則可以允許殺人、禁止殺人、限制特定行為，或者完全沒有額外限制。

## 14.3 真實死亡

正常情況下，死亡永久有效。

系統不會為了維持參與人數而要求每次輪轉必須死亡多少人，也不會因為某人是重要角色而自動提供復活機會。

危險場域完全可以因為準備充分、合作良好或力量足夠而全員生還。

受傷、損失、死亡與失敗應該留下真實後果。

如果未來確實設計涉及復活、時間逆轉或特殊生命保障的異常物品，必須重新審視其限制與整體死亡重量，不能將其變成廉價的常規重來機制。

# 15｜人際關係、組織與居住區文化

居住區長期發展後會出現許多不同的人與組織。

有些人專注於戰鬥，有些人熱衷探索，有些人經營生意，有些人研究道具，有些人喜歡收藏，有些人只想努力活下來，然後好好享受每次休息。

可能形成固定隊伍、商會、情報商、探索團、研究組織、互助團體、競技團體及其他具有不同目的的組織。

也可以存在完全沒有加入任何組織，卻極具名氣的獨行者。

## 15.1 社會重量

長期累積的實力、財富、名聲、組織背景與特殊經歷，會影響人物之間的相處方式。

某個頂尖探索者出現在居住區時，可能引起新人的注意。

某個知名道具研究者走進臨時商店，其他人可能好奇他會選擇什麼。

某名經常幫助新人的資深者，也可能比某些實力更強的人受到更多尊敬。

名氣不需要完全由戰力決定。

## 15.2 公共論壇與交流文化

輪轉交流網・公共討論區・當前熱門內容：

| 分版 | 標題 | 回覆 |
|---|---|---:|
| 場域情報 | 【警告】DISCO! DISCO! 的掉落淘汰可能是真的死亡。 | 147 |
| 日常閒聊 | 連續抽到三次恐怖場域，我是不是得罪系統了？ | 382 |
| 美食交流 | 有人知道藍灣度假村的芒果冰沙在哪裡還能買到嗎？ | 82 |
| 道具研究 | 我發現彩虹泡泡糖可以用來測試異常氣流。 | 216 |
| 尋人 | 找昨天在無限超市幫我推購物車的白髮女生。 | 23 |
| 物品交易 | 高價收購星期八的門票，價格可以談。 | 96 |
| 奇怪經歷 | 我在某個場域當了三個月國王，現在非常想睡覺。 | 713 |
| 娛樂分享 | 有誰也抽到夏日限定水上樂園？ | 164 |

論壇可以有攻略、錯誤情報、黑話、傳聞、迷因、美食交流、道具交易、私人恩怨、跨區認識及各種日常內容。

不是所有人都需要時刻嚴肅地研究生存。

有些居民甚至可能因為搞笑影片、特殊收藏、料理或個人魅力而成為知名人物。

# 16｜物品、收藏與經歷的延續

物品除了能力之外，也可以承載一段真正發生過的經歷。

一個資深參與者的房間裡可能擺著自己參與過的競技活動獎盃、不同場域限定的飲料、異界王國的照片、NPC贈送的飾品，以及早已死亡的朋友留下的東西。

某些物品可能價值極高，某些東西則完全沒有市場價值。

參與者死亡後，其物品不需要全部自動消失。

身上的物品可能留在死亡場域，被其他人拾取、破壞或長期保存。居住區內的財產則可存在指定繼承人、遺物處理及其他制度。

具體繼承機制待之後確定。

幾個月後，完全不認識死者的人可能在未知場域裡發現他留下的日記。

數年後，某個收藏家也可能在二手商店裡買到一件具有漫長歷史的特殊物品。

物品可以跨越人物、故事與時間持續存在。

# 17｜場域的持續性與世界歷史

並非所有場域都會在參與者離開後消失。

有些是一次性的事件空間，有些則是真正長期存在的場所。

不同批次的人可以在不同時間進入同一個世界，看到先前參與者留下的痕跡。

曾經存在的據點可能發展成聚落，已經被發現的商店可能歇業，某個原本安全的地區可能因戰爭而改變。

也可能有人在半年後再次進入自己曾經造訪過的城市，發現當初認識的居民已經過著不同的人生。

場域具有自己的時間、歷史與因果。

不需要在每次輪轉後自動恢復初始狀態。

同時也允許某些場域確實具有重置、週期循環、不同版本或特殊時間現象，但這些是個別場域的性質。

# 18｜多核心群像與非同步敘事

這是我認為前面討論中非常有潛力的一項核心設定。

由於參與者的輪轉時間、場域與返回時間不同，因此同一個居住區內，可以同時存在完全不同的故事與情緒。

第037居住區・凌晨02:00：
- DISCO! DISCO!：舞廳倖存者剛剛返回。
- 藍灣水上樂園：居民正在便利商店吃冰棒、分享照片。
- 十三人的晚宴：兩名參與者仍在討論此前的欺騙與推理。
- 未登錄場域：有探索者已經失聯十七天。
- 私人住宅區：一群人正在連線打遊戲。
- 中央商業街：新的臨時商店即將開始營業。

剛從致命舞廳返回的人，可能看到朋友穿著拖鞋、拿著冰棒，開心地詢問那場派對好不好玩。

某個人剛從異界王國結束數月的政治鬥爭，回到住所後只想打一場電動。

另一個人正在非常危險的地方掙扎求生，而他的朋友可能正在參加一場普通的料理大賽。

這些不同的故事可以各自成立，也可以自然交會。

不需要所有人物共享相同的情緒節奏，也不需要所有人物永遠跟隨同一條主線。

角色離開視角後，自己的經歷仍然持續發展。

等他再次出現時，這段期間經歷的事情、關係、傷勢、物品、財富與心理變化都可以成為後續故事的一部分。

# 19｜長篇故事的節奏

故事不需要遵循固定的戰鬥、購物、休息、戰鬥公式。

圖示轉錄：生活（低張力）、奇遇（略升）、死亡遊戲（高張力）、休假（回落）、智鬥（再升）、大型危機（高峰）、回家（放鬆）。不規律的故事張力示意，並非固定篇章安排。

可以有連續十幾章的恐怖、生存與智鬥。

也可以有連續數章真正舒服的生活、購物、遊戲、探索與人際互動。

場域內部也可以突然轉換氛圍，或一直保持相同的性質。

故事的目標不是永遠讓人緊張，而是讓人對這個世界產生持續的興趣、期待、留戀與探索慾。

# 20｜仍然開放的世界觀問題

以下部分目前不急著確定，因為它們具有很大的後續創作潛力。

| 項目 | 目前狀態 |
|---|---|
| 系統的創造者 | 未知 |
| 系統運作的真正目的 | 未知 |
| 參與者被選中的原因 | 未確定 |
| 是否能回到原世界 | 未確定 |
| 居住區的總數與總人口 | 不設上限 |
| 場域的真正來源 | 未知 |
| NPC的本質 | 依個體與場域而定 |
| 力量的最終上限 | 未確定 |
| 系統是否全知全能 | 未確定 |
| 系統之外是否有更龐大的世界 | 保留可能性 |
| 是否存在特殊管理者 | 保留可能性 |
| 是否存在永久退出輪轉的方法 | 未確定 |
| 最初參與者進入至今的歷史 | 未確定 |

這些不一定都要成為主線謎團。

某些真相可以很晚才揭露，某些甚至可以始終保持未知。世界的吸引力不必完全依靠最後揭曉系統的秘密。

# 21｜目前應優先保留的核心創作原則

這部分我認為比具體人數、價格與場域名稱更加重要。

- **死亡與危險具有真實重量，但舒適、安全與快樂也是真實的。**
- 場域不受單一類型限制，不需要每次都有反轉、主持人、任務、敵人或通關方式。
- 輪轉具有持續性與壓力，但每次輪轉的內容、規模、時間與性質都可以完全不同。
- 居住區是真正的生活空間，而非單純的副本等待室。
- 參與者可以享受生活、購物、收集、玩鬧、競爭、探索與發展私人關係。
- 物品的價格、強度、稀有度及特殊價值不具有必然關係。
- NPC可以具有自己的性格、歷史、情感、規則與特殊互動。
- 世界可以容納真正強大的角色，不必永遠透過強制平衡維持危險。
- 不同人物可以同時經歷完全不同的故事，之後重新在同一個世界交會。
- 人物、場域、物品、組織、財富與關係都應具有持續的歷史與因果。
- 普通事物可以真的普通，不需要所有食物、物品、場所與人物都有隱藏秘密。
- 未來的新概念可以持續加入，不受目前示例與分類限制。

# 22｜整體世界應該具有的感覺

畫面組：凌晨清涼便利商店、超現實鮮豔遊樂設施、危險地下探索、夜間朋友電玩零食、神祕臨時商店、海濱度假設施。

我希望寫到後期，讀者不只是期待下一次大型戰鬥，也會期待下一次輪轉、下一家商店、下一名NPC、下一件特殊道具，以及角色回到家以後會做什麼。

甚至某一章完全沒有任何主線事件。

只是幾名已經認識很久的人，晚上跑去便利商店，買了一大堆冰飲與零食，回到公共休息室打遊戲，順便討論彼此從不同場域帶回來的奇怪物品。

其中一人還有三小時就必須開始下一次輪轉。

另一個人已經休息了四天。

有人從危險的地方撿到一件強大的裝備，有人花了大量積分買到一個會自己跳舞的玩偶。

大家都對下一次會發生什麼抱有不同程度的期待與不安。

他們的人生仍然在繼續。
