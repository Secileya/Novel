# 01｜核心世界觀與創作基調

這是一個由無數特殊場域、居住區、異常存在、未知文明與系統機制共同構成的世界。

來自不同地方的人被轉移至此，在獲得基本生活保障與個人系統後，必須持續參與名為「輪轉」的特殊現象。

輪轉可能將參與者送往任何性質的場所。

有些地方存在真正的死亡危險，有些需要智鬥、合作、探索或戰鬥，有些則只是讓人享受娛樂、購物、度假與其他不可思議的體驗。

整個世界可以同時容納以下氛圍。

| 氛圍 | 內容 | 原畫面參考的文字描述 |
|---|---|---|
| 舒適 Cozy | 清涼、乾淨、物資充足、自由享受生活。 | 午夜現代便利商店、乾淨白光、零食冷飲、藍色調 |
| 未知 Wonder | 奇妙、異常、探索慾與從未見過的景象。 | 無盡室內泳池、藍色水面與閾限空間 |
| 遊戲感 Playfulness | 搞怪、競技、奇遇、特殊玩法與人際互動。 | 鮮豔超現實多人競技節目 |
| 危險 Peril | 真實死亡、生存壓力、衝突、恐怖與不可逆的後果。 | 陰暗廢棄地下科技設施、緊急照明 |
| 群像 Social | 朋友、戀人、宿敵、陌生人、組織與持續發展的人際關係。 | 午夜冷氣電玩休息室、朋友與零食 |
| 期待 Anticipation | 下一次輪轉、新商品、稀有物品、未知人物與特殊事件。 | 神祕流動商店、色彩繽紛的奇異物品 |

上述氛圍沒有固定比例，也沒有必要彼此對立。

舒適可以真的舒適，恐怖可以真的恐怖，荒唐的事情也可以單純只是荒唐。

世界不需要永遠壓抑，也不需要透過反轉證明每一處安全場所都暗藏危機。

**最重要的核心是：參與者擁有持續的人生，而輪轉不斷為這些人生帶來新的經歷。**

# 03｜居住區

居住區是參與者長期生活、休息與建立人際關係的主要場所。

每個參與者最初都會被分配至某個居住區。暫時以第037居住區、初始人口300人作為故事設計示例。

居住區不應只是簡陋的主神廣場或副本等待室，而是一個真正值得生活的地方。

畫面：現代未來感住宅中庭、室內植物、白藍建築、冷藏櫃裝滿零食的便利商店、舒適電玩沙發及私人公寓。

## 3.1 基本設施

| 設施 | 內容 |
|---|---|
| 中央大廳 | 公共休息、公告、輪轉出發與返回 |
| 私人住宅 | 免費基礎房間、套房、高級住所 |
| 便利商店 | 普通食品、特殊食品、日用品 |
| 商業街 | 餐廳、服飾、家具、專門商店 |
| 系統商城 | 裝備、道具、能力、特殊服務 |
| 娛樂區 | 電玩、桌遊、電影院、卡拉OK |
| 運動設施 | 游泳池、健身房、各類球場 |
| 訓練區 | 武器測試、能力測試、安全切磋 |
| 醫療區 | 傷勢治療、異常狀態處理 |
| 交易區 | 私人店鋪、物品交換、拍賣 |
| 公共浴場 | 淋浴、浴池、休息設施 |
| 特殊展區 | 不定期活動、展示、臨時商店 |
| 未開放區域 | 日後可能開啟的未知設施 |

居住區可以有自然光模擬、空調、乾淨的飲用水、完善的供電、自動清潔，以及便利的現代化設備。

不需要刻意讓正常生活變得艱難。

## 3.2 私人住所

所有新參與者可以獲得免費的基礎私人房間。房間具有基本床鋪、衛浴、照明、空調與儲物設備。

之後可以透過積分購買更大的空間、家具與特殊設施。

畫面示例：基礎單人房間；個人遊戲與娛樂室（多螢幕、電玩椅、藍色照明）；多人共同住宅（寬敞客廳、沙發）；特殊景觀住宅（巨窗俯瞰雲海或海洋）。

居民可以按照自己的喜好生活。

有人將房間改造成武器庫，有人擺滿稀有收藏，有人購買大量電玩設備，有人弄了一間私人電影院，也有人只是喜歡一張大床和非常舒服的空調。

朋友、戀人、隊伍成員可以共同生活，也可以保有各自的私人空間。

某些特殊家具、房間功能與景觀甚至可能只能在輪轉中取得。

## 3.3 安全機制

正式居住區內具有可靠的系統安全保障。

原則上禁止真正的殺人行為、致命傷害、強行侵入私人住宅，以及其他直接破壞基礎安全的行為。

訓練與競技則可以透過特殊設施進行，按照參與者同意的規則限制傷害。

但安全不代表所有居民都會友善。

居住區仍然存在欺騙、利益衝突、商業競爭、情感糾紛、團體排斥、情報交易與私人恩怨。

也可以存在非常討厭彼此的人，卻因為安全機制而無法直接殺死對方。

真正的致命衝突可能延續至下一次沒有安全保護的輪轉。

## 3.4 居民自行發展

系統提供基礎設施，但不會包辦所有生活內容。

居民可以自行開設餐廳、經營商店、成立組織、舉辦活動、出租設備、研究道具、提供情報與其他服務。

經過長時間發展，不同居住區可能形成截然不同的文化與社會秩序。

居住區本身也具有歷史。

# 22｜整體世界應該具有的感覺

畫面組：凌晨清涼便利商店、超現實鮮豔遊樂設施、危險地下探索、夜間朋友電玩零食、神祕臨時商店、海濱度假設施。

我希望寫到後期，讀者不只是期待下一次大型戰鬥，也會期待下一次輪轉、下一家商店、下一名NPC、下一件特殊道具，以及角色回到家以後會做什麼。

甚至某一章完全沒有任何主線事件。

只是幾名已經認識很久的人，晚上跑去便利商店，買了一大堆冰飲與零食，回到公共休息室打遊戲，順便討論彼此從不同場域帶回來的奇怪物品。

其中一人還有三小時就必須開始下一次輪轉。

另一個人已經休息了四天。

有人從危險的地方撿到一件強大的裝備，有人花了大量積分買到一個會自己跳舞的玩偶。

大家都對下一次會發生什麼抱有不同程度的期待與不安。

他們的人生仍然在繼續。

## 關於這一版

我主動補充了組隊同步限制、場域時間與外界時間的基本關係、特殊貨幣的交易邏輯、居住區的安全邊界、道具研究、NPC的記憶延續、物品繼承與場域持續性等機制。

這些是新增的暫定提案，還不是你已經確認的硬設定。

我也刻意保留了大量創作空間。尤其是場域、道具與NPC，這三個部分應該可以無限擴充。現在列出的內容只是一小部分素材，絕對不應變成未來生成內容的上限。

**目前最重要的成果，是這個世界已經有了能夠持續運作的底座，而不是只有一堆彼此獨立的有趣場景。**

## 早期氛圍補存
- 原本的 Cozy 不只有壁爐、木屋、暖黃光，也有凌晨兩點空調、白光、乾淨地板、冷藏櫃、冰飲、零食、拖鞋。兩種可以同時存在，不以現代科技統一世界。
- 永久安全區可長住、開店；輪轉中的安全區可能有限時；偶遇型安全區可在探索途中購物睡覺療傷；相對安全區可能無怪物但仍有人的衝突。這是早期候選分法，不應把所有標為安全的正式居住區寫成隨時遇害。
- 旅館、咖啡廳、車站、夜間列車、無盡雪原便利店、特定夜晚市集、深海旅館皆可成為「存在的理由就是讓人想去」的場所。房間能慢慢放入家具、紀念品、照片；強者也可能每次回到熟悉座位。
- 真正的安全區可卸下防備；舒適不是必然的恐怖前奏。角色不必時刻研究如何活命，也不用因購買低價零食被作者處罰。
