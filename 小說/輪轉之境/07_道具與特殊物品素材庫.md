# 12｜道具與物品系統

道具是整個世界的重要探索與收藏樂趣來源。

任何具有足夠創意與內在合理性的物品，都可以存在。

**道具的價格、稀有度、強度、用途、取得難度、趣味性與情感價值，彼此獨立。**

不採所有物品都必須遵循同一套白、綠、藍、紫、金的強度階梯。

特定商店、場域或研究組織可以有自己的物品分類方式，但不需要成為整個世界的唯一標準。

## 12.1 道具的價值維度

| 維度 | 意義 |
|---|---|
| 價格 | 商店或交易市場的售價 |
| 稀有度 | 物品出現與取得的頻率 |
| 強度 | 所具有的實際力量或效果 |
| 實用性 | 在特定情境中的用途 |
| 泛用性 | 能夠適用多少不同環境 |
| 收藏價值 | 外觀、歷史、限定性或特殊意義 |
| 情感價值 | 對某個人而言的重要程度 |
| 趣味性 | 是否好玩、可愛、荒唐或有趣 |
| 取得條件 | 金錢、事件、資格、關係或其他要求 |

高價物品可以真的非常強。

低價物品也可以非常實用。

稀有物品可能具有極高的收藏價值，卻完全沒有戰鬥能力。

有些東西則可能同時昂貴、稀有、實用且極度強大。沒有必要為了追求平衡，刻意削弱所有頂級物品。

## 12.3 特殊道具示例

**壞掉的方向標**（場域探索取得・無固定系統售價）
指向附近正在營業的商店，而不是北方。附近沒有有效商店時，指針會不停旋轉。

**不會融化的冰棒**（常駐商城・6 P）
永遠保持適合食用的冰涼溫度，直到被吃完。沒有特殊戰鬥加成。

**星期八的門票**（特殊事件取得）
有效日期為星期八，目的地未知。系統只能辨識出基本資料。

**黃色塑膠鴨**（無限泳池場域・拾取）
具有浮力，捏下去會發出聲音。目前沒有發現任何特殊能力。也許真的只是一隻鴨子。

**尼克斯的黑色雨傘**（NPC私人贈禮）
部分異常降雨會將持有者視為環境的一部分。其餘時間則是一把品質優秀的雨傘。

**空間錨定裝置**（高級商城・36,000 P）
穩定有限範圍內的空間結構，抵抗部分異常位移與空間干擾。

**永遠盛開的藍色小花**（未知場域・無系統售價）
永遠不會凋謝，夜間會散發淡淡的藍色光芒。其他性質未知。

**一次性請假單**（特殊辦公室事件取得）
可推遲一次個人輪轉，最多二十四小時。屬於少數能直接影響排程的特殊道具。

以上物品可以成為未來正式素材，但價格、效果及來源目前都還是示例。

## 12.4 道具取得途徑

| 來源 | 可能取得的內容 |
|---|---|
| 常駐商城 | 標準裝備、食品、生活用品、特殊能力 |
| 臨時商店 | 限定商品、未知物品、特殊服務 |
| 自由探索 | 拾取物、遺物、場域特有物品 |
| 隱藏區域 | 未知裝備、秘密收藏、特殊材料 |
| NPC互動 | 贈禮、交換、個人製作品 |
| 競技與活動 | 獎品、獎盃、限定道具 |
| 特殊事件 | 具有獨特來源的物品 |
| 研究與製造 | 自製裝備、道具改造 |
| 生物與異常現象 | 特殊材料、異常物品 |
| 人際交易 | 購買、交換、拍賣、贈送 |
| 特殊經歷 | 紀念物、私人收藏、身分證明 |

有些物品可以大量取得，有些只能在特定時間取得，有些具有唯一性，有些則可能在多年後再次出現。

## 12.5 道具的說明與未知性

系統不需要完整公開每件物品的所有性質。

- 標準商品「緊急治療針劑」：快速穩定傷勢，促進傷口修復。使用次數1，280 P。
- 未登錄物品「白色立方體」：無論如何轉動，始終有一面朝向目前持有者。其他性質未知。
- 私人贈禮「給你的那顆星星」：「如果晚上睡不著，就把它放在床邊吧！」附有贈送者的手寫紙條。
- 特殊活動商品「藍灣夏日紀念章」：藍灣度假村夏日活動期間販售的紀念物。未發現特殊能力。

部分資訊可以透過鑑定、研究、實驗、NPC詢問或特殊場域發現。

但不要讓每件不起眼的物品最後都變成神器。

未知可以帶來驚喜，也可以永遠只是未知。

## 12.6 道具組合與非預期用途

不同物品可以彼此配合，甚至形成設計者未曾想到的用途。

例如普通防滑拖鞋在特殊冰面競技中具有巨大優勢；可以拍下異常現象的相機可能協助探索不可見實體；某種糖果可能剛好受到特定NPC喜愛。

部分道具的組合可能增強效果，部分可能互相抵銷，也可能產生新的特殊反應。

因此世界可以自然形成專門研究物品、開發裝備、測試奇怪組合、整理攻略與收集情報的人。

# 16｜物品、收藏與經歷的延續

物品除了能力之外，也可以承載一段真正發生過的經歷。

一個資深參與者的房間裡可能擺著自己參與過的競技活動獎盃、不同場域限定的飲料、異界王國的照片、NPC贈送的飾品，以及早已死亡的朋友留下的東西。

某些物品可能價值極高，某些東西則完全沒有市場價值。

參與者死亡後，其物品不需要全部自動消失。

身上的物品可能留在死亡場域，被其他人拾取、破壞或長期保存。居住區內的財產則可存在指定繼承人、遺物處理及其他制度。

具體繼承機制待之後確定。

幾個月後，完全不認識死者的人可能在未知場域裡發現他留下的日記。

數年後，某個收藏家也可能在二手商店裡買到一件具有漫長歷史的特殊物品。

物品可以跨越人物、故事與時間持續存在。
