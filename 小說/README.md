## 分類方式
每部作品依實際已有資料使用以下分類：
- 01_章節／正史章節
- 02_角色設定
- 03_世界觀設定
- 04_連續性與索引
- 05_分支／非正史
- 06_參考資料
- 07_草稿
- 08_劇情規劃

沒有對應資料的分類不建立空資料夾，避免目錄看起來複雜。
