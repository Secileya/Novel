## 一、原版 Trench Trooper：Hades 霰彈槍的刺刀有兩種動作

**來源：** [Fandom｜Shock Trooper，The Trench Trooper／Synergy Exclusive](https://gravedigger.fandom.com/wiki/Shock_Trooper) 整理官方 Trello 與社群數據；[官方 Trello 相關卡](https://trello.com/c/aZk989AW/255-assault-trooper-lancer) 可另作一手查核，**本文沒有親登入 2026-11 伺服器實測**。

| 動作／配備 | 普通 Trench Trooper（不限原班底） | **原 Lancer→Trench Synergy** 額外結果 |
|---|---|---|
| **Hades Trench Shotgun** | 幫浦式霰彈槍；固定**長刺刀**，可開火又可近戰；近距適用、遠距霰彈衰減 | **裝填速度約 +20%**，彈藥資訊更清楚；不等於所有其他兵種的 Trench 沒有 Hades |
| **普通 Bayonet Melee** | 刺刀每次揮擊約 **199 damage**；前搖約 **0.2 s**、兩次之間的 Swing Rate 約 **0.9 s**；**大範圍橫掃 AOE 能擊中複數敵人**，不是細小精準的 Heavy Lance 窄刺 | 每次橫掃約 **450 damage**（對一般 200／Shock 300 HP 士兵極有威脅，Dread 例外），**AOE 型態不變**；不等於只會點刺 |
| **全速奔跑＋Q Bayonet Charge** | 突進刺中第一名敵人可觸發近戰處決動畫；撞障礙、Vanguard 盾可倒地，失敗有短暫僵直；距敵太近可能只觸發普通刺擊 | **可串穿多個敵人**、突進時間更長、冷卻更短（類似 Veteran 的衝鋒改善）；不是一般 Trench 都天生連刺多人 |
| **Flagbearer 與頭盔** | 背負軍旗對附近友軍 Morale 有影響，使用較強 Lancer 風格頭盔 | 不把軍旗當成同職才存在；具體加成與 Synergy 分清 |

**小說轉譯〔ADOPTED-WORKING〕**：區分霰彈交火、持槍大幅度橫掃、長刺刀突進、多名敵人密集站位時衝鋒貫穿；別把槍尾一晃直接改成刺中任何角度的敵人，也別讓 AOE 變無視視線與友軍安全的魔法。Lancer 原職對長柄衝鋒、軍旗、重裝、步法與衝刺力量已有更熟練訓練，Synergy 可轉為**特化裝備調校、適合個人的刺刀結構、協同步法、力量與維修／裝填技術**。普通 Soldat／Officer 換 Trench 也仍能使用刺刀、霰彈與 Charge；只是**沒有 Lancer 對應的 450 與連續衝鋒加成**，除非本小說另有獨立真實能力／裝備特殊條件。

**另一容易漏的遊戲事實：** [Fandom｜Cavalry Sword](https://gravedigger.fandom.com/wiki/Cavalry_Sword)、[Special weapon skins](https://gravedigger.fandom.com/wiki/Special_weapon_skins) 記載以 Trench Trooper 取得 **10 次擊殺**可解鎖 **Cavalry Sword 的「Trench」skin**，外形即拆下來的 **Hades 刺刀**。在小說裡可以是可拆卸的特殊戰場刺刀／軍械工藝，而非「必須殺十人才能憑空長出一把刀」的世界規則。

## 二、Shock 兵種搭配／Synergy 七類（遊戲對照，非絕對小說數值）

**核心〔USER-FIXED＋SOURCE-CHECKED〕** [Fandom Shock Trooper](https://gravedigger.fandom.com/wiki/Shock_Trooper) 允許選**七種常規 Shock Kit**（部分新手／自動配對設定會自動挑原兵種對應型）；**不限只有對應 class 才能獲得該 Shock 基本武器與能力**。原職與 Shock 相同，才多得**Synergy Exclusive**。不可將「自動挑裝備」「軍需授權」「專屬加成資格」誤混成「跨職業禁止取得」。

| 原兵種 → Shock | 同兵種專屬 Synergy（社群記載，版本敏感） | 跨兵種時仍要保留的重點 |
|---|---|---|
| **Soldat → Storm** | 裝填約 **+30%**、可看精確彈數、加速衝刺、操槍與移動射擊更穩；原 Soldat 操槍約 +20% 可並存 | Rook／Officer 也可拿 Storm 基本強槍，但不自動取得 Soldat 專屬附加加成 |
| **Rook → Anti-Material** | **+20% 裝填、約 +7.5% 射速**、抗震／抗倒地，彈數資訊；Grace 支援的部分 Veteran 效果 | 其他職業可用 Remover 的基本高穿透，**但不自動有 Rook 的抗震裝填優勢** |
| **Mortician → Flame** | **+20% 裝填**、Medical Syrette 對友軍恢復至約 **200 HP**；Grace 有部分 Veteran 效果 | 非醫護也可用火焰噴射器，但**不憑空學會專業針劑醫療與 Mortician 加成** |
| **Officer → Radio** | **+20% 裝填**、Recon Kit 標記轉為 **Radio marks**、移動速度和彈數資訊改善 | 其他職業的 Radio 仍有基本電台、Glory 和團隊範圍增益；只是不自動獲得 Officer Recon 套件的專屬整合 |
| **Jaeger → Geist** | 保留／結合 Hunter Kit、煙霧工具；額外 **+15% 裝填**、毒性彈、陷阱絆線更不易察覺，彈數資訊 | 非 Jaeger 也能選 Geist 並有 Ghost、Hunt 等基本能力；其**原兵種裝備可能有個別保留**，不可無證據說所有非 Jaeger 都一樣有 Hunter Kit |
| **Lancer → Trench** | **+20% 裝填**、刺刀 **199→450**、可串穿複數目標、Charge 延長／更快再次發動、彈數資訊 | 別的職業也能用 Hades 基本霰彈／刺刀／單人衝鋒；沒有此專屬威力疊加 |
| **Vanguard → Bulwark** | **+20% 裝填**、Bulwark's Hope 可使用、頭盔強度提升 **1 級**（Powerful／Devastating 等例外）、在特定彈數下顯示精確彈量 | 非 Vanguard 也可用 Guardian 機槍和部署盾基本功能，但不會自動得到 Vanguard 專屬護盾鼓舞 |
| **Ocelot** | **沒有 class Synergy**，隱藏特殊解鎖流程 | 原職基礎與遊戲彩蛋機制另論，不製造不存在的專屬同步加成 |

**不要把「非同職只能拿槍」當成結論**：一般 Shock Kit 自身仍有頭盔、主武器、特定被動／配備；**與原職的選擇組合**可能保留不同工具。原版 [Shock Trooper Wiki](https://gravedigger.fandom.com/wiki/Shock_Trooper) 甚至舉 **Lancer→Geist** 可能保留投斧等舊職器材的例子；同理也不能說所有跨職配裝無限繼承全部工具。任何組合實際裝備槽、特殊頭盔與 Perk 取代規則以當版為準。

**小說化〔ADOPTED-WORKING〕**：Synergy 不是數位權限辨識或一聲系統提示就使人體變強，而是個人長期專業訓練、武器搭配適性、班底協作、特殊配發、知識與熟練度帶來的更強實際表現；跨職專精者也可以很厲害，但不會機械獲得特定裝備整合與同職加成。瑟薇媞雅有長期跨職實戰、AT／Geist／Radio／Flame／Ocelot 等經驗，**不因她本次穿哪一類套裝就重新定義她所有人格、軍階或長年技藝**。

## 四、「帝國之刃」Sevithia：是真的頂級刀術高手，不是只有槍法的人

**〔USER-FIXED〕** 刀劍也是瑟薇媞雅長期深度磨練的核心戰力，**她與普通劍士／多數所謂頂尖刀戰好手的相對差距**，可借用《鬼滅之刃》**繼國緣壹相對於其他劍士**的感覺來理解：看到的是步伐、距離、架勢、預判、臂力、轉腕、刀尖角度、出刀時機、收式、反擊與節奏全方位地高出一般認知；**在正常可有效施展刀術的場景，她與多數敵軍劍士一對一，可以是清楚的壓倒性差距**，不必為了「比較合理」把每場都寫成五五開。

- **武器**：Cavalry Sword、Combat Knife／Army Machete 等實際攜刀、戰場拾取與 Judgement／Trench Bayonet，依槍身／刀身差別運用。她對刀劍重心、刃長、握柄、角度與對手武裝的理解遠超一般人；**不需要所有場景都把刀和多把招牌槍同時背在身上**。
- **物理與技術**：她原本極強臂力、核心穩定、爆發與雙手控制，與閱讀對手動作和預測下一步形成高度可怕的刀術。她可以在短暫接觸中斷開對手的進攻節奏、找出防護與重心破綻、以極低多餘動作迅速勝過對方。
- **呈現差距**：不必每個接戰都設計長篇華麗對刀，真正巨大差距可能表現為「對手以為還在試招，她已判定進退」「高手才看得出原本那一步為何已輸」。遇數人、盾牌、槍火、狹窄地形時，她也有足夠戰場經驗主動選路線、取捨風險，而非只會盲目衝刀。
- **比喻不等於能力照搬**：不能未經獨立設定把《鬼滅之刃》的日之呼吸、通透世界、超自然視覺、斑紋、無視槍火和不可能技術直接授予她。**角色的絕強刀術應該是真正且可反覆證明，不只是敵人口頭吹捧**。
- **仍保留對抗與後果**：她強不等於世上再無任何能對她造成威脅的對手，尤其極端能力、準備充足的高階人物、火力包圍與地形；**但不無故把她的刀術降格成對普通高手還需要苦戰**。戰鬥有實際防護、裝備、後勤與代價。
