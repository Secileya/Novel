### B. 只供創作的可擴展擬聲家族〔新造候選，非 Gemini 已用清單〕

這些不是既定口癖，也不是每篇要塞的清單；使用時先決定**聲源／距離／材質／人物反應**：

| 地下世界聲源 | 可試詞材 | 最有可能帶來的小說效果 |
|---|---|---|
| 槍機與零件 | 喀、鏘、喀啦、咔、金屬輕碰的脆響 | 讓裝填和保養變成手上的實際工作 |
| 軌道與機車 | 匡啷、鏗鏘、隆隆、轆轆 | 從聲音辨別遠處重量、交通是否異常 |
| 木樑與地層 | 喀嚓、嘎吱、吱呀、細碎剝落聲 | 先讓人聽見危險，不急著宣布「坍方」 |
| 水與蒸氣 | 滴答、滴滴答答、嘶——、咕嚕 | 由廚房、淋浴、漏水到封閉坑道的水壓 |
| 軍靴與裝備 | 咚、踏、擦、金屬扣環輕撞 | 軍階、腳步個性、慌亂與克制 |
| 高壓戰鬥 | 砰！、轟——、鏗！、一陣震耳的嗡聲 | 當下的方向、節奏與物理衝擊，不必每槍都同一音 |
| 低聲私語與小動作 | 吸氣聲、衣料窸窣、杯底輕碰桌面 | 表現關心、心虛、偷笑或難以開口 |

這一欄的詞只是**起點，不是需要照字典選詞的成品**。最有辨識力的通常不是「砰」，而是槍響之後哪個人的手停住、哪張椅子滑動、誰第一時間去護住別人。

## 四、嘆詞和語氣詞：意圖比字本身重要〔見證／衍生分析〕

聲音類別分開理解：

- **嘆詞／呼聲**如「哎呀！」「嗯」「喔」「哈」「喂」「噓」，可以單獨成句，代表瞬間反應。
- **句尾語氣詞**如「呀」「啦」「嘛」「喔」「呢」，會改變一整句話對聽者的態度。
- **擬聲詞**如「啪嗒」「咕咚」「咕嘟咕嘟」模擬事物或身體聲響；不是同一類。
- **動作與嗓音敘述**如「笑吟吟地」「咬牙」「聲音劈了」「慢吞吞」「低聲」，可讓相同台詞聽起來完全不同；不必每句再加一個「欸」。

| 實際引句／短句 | 角色／場景 | 不是「一個感嘆詞」而已 |
|---|---|---|
| 「**喔，我看見了。**」 | 瑟薇媞雅回泰奧，元帥進門 | 平靜、故意不急；恰好讓泰奧更崩潰 |
| 「**哎呀，阿爾德里克！**」 | 她看見同階好友來找人 | 朋友式歡喜，不是軍中制式口令 |
| 「**嗯，有道理。**」 | 她假裝接受泰奧說她會掉下長椅的警告 | 先給對方「說通了」的錯覺，再以挪到裡面迴避問題 |
| 「**……哈。**」 | 她喝酒後滿足嘆息 | 單聲、停頓、身體放鬆；與前面的咕咚配合 |
| 「**喂，你叫什麼名字？**」 | 她開始真正認識泰奧 | 一個不拘禮節卻自然親近的主動開口 |
| 「**噓。**」 | 軍階曝光後阻止泰奧喊得太大聲 | 很少字，靠手指與現場等級落差有力量 |
| 「**……要你管。**」 | 38 版她收下滷肉、阿爾德里克調正叉子 | 低聲嘴硬可以是親近與被照顧，不是拒絕友誼 |
| 「**加油喔，審判官。**」 | 34 版她安排尤里烏斯搬木料 | 溫柔字面搭配權力反轉，明顯的戲謔 |
| 「**好玩個屁！**」 | 34 馬庫斯打斷八卦 | 只屬於軍士長在此場合的粗魯脾氣，不能廣泛複製到其他人身上 |
| 「**閉嘴。**」 | 33 支道佩恩打斷因爭方向的吵鬧 | 無須更難聽的罵法；他沉默已久、撐樑吃力，使這兩字極有重量 |

### 同一個字如何變成完全不同的情緒〔新造候選，非原稿逐字引句〕

| 句子 | 聲線與心理 |
|---|---|
| 「喔。」 | 確實收到資訊、也可能故意不給期待的反應 |
| 「喔？」 | 意外、察覺破綻、準備調戲 |
| 「喔——？」 | 拉長聲音，逗弄、半信半疑；不必加♡才能成立 |
| 「喔……」 | 失落、懂了卻暫時說不出話 |
| 「喔！」 | 突然想通或真的驚喜 |
| 「……喔。」 | 心裡先承受了什麼，再輕聲接下這件事 |

同樣地，「哼」可以是生氣、傲嬌、輕蔑、虛張聲勢或疼痛時的一聲悶哼；**不能看見「哼」就把每個人寫成嬌嗔角色**。「喂」可以帶友情、命令、焦急或怒意；要看動作、語速、關係與上下文。

## 五、標點庫：情緒的速度，不是裝飾密度

| 標點 | 原稿中的典型功能 | 例子／留意 |
|---|---|---|
| **！** | 下令、慌張否認、驚喜、軍士長斥責、震撼後反應 | 37「起床！」、34「元帥閣下！」；可用，但**不是所有角色每句都要喊** |
| **？** | 不解、反問、接話、擠出對方破綻 | 38「你今天是奉命來調查我的晚餐嗎？」；問句本身即是人物性格 |
| **？！** | 訝異與質疑同時爆出 | 33／34 有出現；用於真被驚動之處而非每句慣例 |
| **……** | 猶豫、語塞、醉後含糊、無語、情緒剛沉下來 | 「……哈。」「……要你管。」；不是所有說話都先加省略號 |
| **——** | 被打斷、拉長氣口、動作或聲勢未結束 | 軍士吼叫的長音、泰奧來不及說完時被插話 |
| **、** | 口吃／重新找詞時，在字中造成微小卡頓 | 「不、不是！」與「元、元帥閣下！」表現不同緊張 |
| **。** | 冷回、定案、氣氛忽然下沉 | 「喔，我看見了。」「閉嘴。」能比三個驚嘆號更強 |
| **～、♡** | **本輪選取 Gemini Grave/Digger 原稿中沒有觀察到** | 跨世界親暱／調戲符號可作未來個別角色候選，但不能標作 Gemini 本系列已確認風格，也不能因別的小說常用便自動灌入 |

**標點應依人物意圖與心理時間選擇**，不是「平句換成！？就更有戲」。有效節奏是「對方提問 → 有一瞬停頓／錯解 → 一句短答 → 對方被逼出新反應」。標點只把這個因果變得可聽。

## 六、粗口分層：不排斥，但不以罵人取代角色魅力

**本輪真正讀到的範圍**：
- 37 的馬庫斯說「放屁！」；34 的潔西也用「放屁！」反駁八卦，馬庫斯有「好玩個屁！」「小兔崽子」。
- 34／33 有「閉嘴」，但其感受取決於說話人；佩恩在危險中冷聲截斷兩人，效果比再添一串粗口更強。
- 「屁都不敢放一個」「屁股」「操練」「幹活」等雖含「屁／操／幹」字，**不等同於角色講了明顯粗口**。原文須先人工看語境，不能用單字搜尋假裝整部小說粗口率很高。
- 33／38 餐廳裡，瑟薇媞雅可以說「閉嘴啦」、阿爾德里克可以吐槽她會死於酒精、露塔可以冷淡提醒先喝湯。**三人的互動夠好笑，主要靠立場錯位與反問，不靠辱罵**。
- 所取 Gemini 作品**沒有靠持續高強度髒話建立人物性格的證據**；亦不能因此推定 Gemini 所有作品都沒有重粗口，這僅是本輪 Grave/Digger 樣本。

### 選擇語體，不是強制「文明」或「粗俗」

| 語體層次 | 典型功能 | 可用話語（部分新造） | 合適來源／人格 |
|---|---|---|---|
| 不罵人也有刺 | 嘲弄、自信、熟人拆台 | 「你還真敢說。」「非常好，繼續。」 | 瑟薇媞雅、阿爾德里克、露塔等可各自使用不同口吻 |
| 口語化抱怨 | 日常不滿、不拘小節 | 「少來。」「煩死了。」「你有完沒完？」 | 新兵日常、熟人互損 |
| 輕度粗魯／軍營斥喝 | 急躁、責罵、強壓混亂 | 「放屁！」「好玩個屁！」「閉嘴！」「小兔崽子！」 | 34／37 中有明確角色及情境先例 |
| 較重辱罵／粗口 | 極端暴怒、仇恨、失控語境或某些人物穩固語言習慣 | 此類可由後續需要創造；**不要直接把其他小說慣用髒話塞給整個帝國軍** | 依人物履歷、對象、前後權力差與情緒決定 |
| 不說話 | 真正被擊中、恐懼、想說卻說不出、壓住怒氣 | 咬緊牙、唇動了又閉上、手停在半空 | 有時比任何粗口更有戲 |

**使用者的核心要求**：他在別的小說已經做過嘆詞／標點／語庫，但那一套與明顯粗口有較多聯結；這裡**不是禁止罵人**，而是證明可以不用大量粗口，也自然寫得跟 Gemini 一樣鮮活、幽默、激昂。這不是嚴格的「粗口上限」或「敏感詞黑名單」，而是避免所有角色說話被同一套髒話模板同質化。

## 七、人物聲線：同一聲詞不能在每個嘴巴裡都一樣

以下是從已知人物 DNA 衍生的**實際寫作候選，不等於 Gemini 每句已確認原話**。

| 人物 | 氣息與節奏 | 可以展現的微聲線 | 要避免的誤用 |
|---|---|---|---|
| **瑟薇媞雅** | 休假時自然、漂亮、有玩心；進入戰場可凌厲而迅速，甚至危險地笑 | 「哎呀」「喔？」「嗯，有道理」「欸，等等——」「來呀」等依情景選用 | 強制每句撒嬌／全程優雅／全程冷酷；不可把喜劇語氣寫成能力不足 |
| **阿爾德里克** | 比較有耐心但熟人間能反擊；氣到頭疼時會短答 | 「非常好。」「妳說呢？」「……又來了。」 | 永遠只當監護人、永遠不笑、永遠不會震驚 |
| **泰奧** | 認真且容易緊張，但不是每句都結巴 | 「報、報告……」「等一下！」「我不是那個意思！」 | 一旦當新兵就終生語塞或只能擔任觀眾 |
| **盧卡斯** | 膨脹誇張、八卦強、遇到師長縮脖子、受困時會著急 | 「等等、等等！」「我跟你說！」「真的假的？！」 | 永遠負責傻笑與搞砸，沒有能力與成長 |
| **佩恩** | 安靜、簡短、有身體行動；真正急時能突然命令 | 「先停。」「讓開。」「我來。」 | 每一個轉折都靠多字咆哮或粗口證明關心 |
| **馬庫斯** | 受戰爭磨礪的軍士長，怒斥清楚、對細節和人命敏銳 | 「放屁！」「少廢話！」「給我重做！」 | 全場不停咒罵、讓下屬聽不出實際訓練要求 |
| **露塔** | 務實、嘴上不饒人，真正關照時用飯菜和動作 | 「吃飯。」「桌布昨天才換。」「先把帳結了。」 | 每遇到元帥都突然失去本人的店主語氣 |
| **赫妲** | 工兵實務感、俐落、可以戲謔，也能在危險時喝令 | 「先別動！」「誰批准的？」「行，這回換我。」 | 只負責喊開始／停止的工具人 |
| **尤里烏斯** | 早稿中驕傲、在階級受挑戰時會提高音量，可能因後續經歷改變 | 官樣措辭與失態破功之間有張力 | 把一個候選片段永久鎖為單一傲慢原型 |

**不是人物口癖配給表**。同一人面對陌生敵軍、朋友、女王、部屬、父母或自己的傷員，可能有不同語速、語體與音量；也可能在最劇烈情緒時一句話都說不出來。永遠由當下真實欲望、關係與承受的事件驅動。

## 八、創新引擎：不靠抽籤挑「喔」「啪」「！！」

真正的創作次序不是「抽 1 個嘆詞＋2 個擬聲詞＋1 個驚嘆號」。應先形成：

**人物正在想要什麼／不願承認什麼 → 對象與權力距離 → 情緒是往上升還是往下壓 → 手腳和物件正在做什麼 → 真正有什麼聲音 → 最適合角色的句子與標點 → 聽者因這句話做了什麼。**

從原稿學到的四種高產生性機制：
1. **反向按字面理解**：泰奧說別從長椅跌下來，她便整個人挪進牆角，得意宣告問題解決；新事件可讓不同人以性格迴避另一人的真意，不重複原台詞。
2. **反差型語氣**：有軍權的人用最輕鬆的聲音給出令對方發冷的命令；也可能反過來在私下聽到關切時突然說不出話。
3. **聲音引發的連鎖反應**：啪嗒不是為了加入「啪嗒」，是某個人真的被一句話嚇到掉叉子，下一位再看向他；物件能替眾人呈現心理波動。
4. **情緒換檔後保持生活**：從拌嘴轉成老婦人送肉，又回到阿爾德里克幫忙調正叉子。新情節的嚴肅不能自動取消人物既有的玩笑和親近。

### 五組獨立新例（全部〔新造候選〕，絕非 Gemini 原句／已發生章節）

**1. 低聲、沒有粗口，但熟人互損**

「今天又是誰忘記簽領物資？」

阿爾德里克一面翻著名冊，一面把那張漏了名字的單子推到她面前。

瑟薇媞雅望了一眼，歪著頭笑了。

「哎呀，你猜猜？」

「我不猜。」

「好嘛。這樣就一點都不好玩了。」

**2. 機械聲與慌亂：聲音造成事件**

喀啦。

盧卡斯指尖一僵，眼睜睜看著那枚小小的槍機扣件從桌沿滑了出去。

「佩恩！」

佩恩伸手在半空中一接，穩穩托住零件，抬眼看他。

「……你能不能等我掉下去再喊？」

盧卡斯張了張嘴。

「你這算哪門子的安慰？！」

**3. 同一聲音，用壓低聲線製造危險**

滴答。

兩人都停下了腳步。

赫妲抬起提燈，看向那道原本乾燥的接縫。岩壁上的水並沒有流成一道線，只是不緊不慢地又落下一滴，正好砸在她伸出去的手套上。

「別再往裡走了。」她說。

這次她沒有提高音量，反而比剛才更輕。

**4. 慣於罵人的軍士長，突然不罵才讓人害怕**

「報告軍士長！我只是——」

馬庫斯沒有吼他。

他把那條鬆開的擔架帶放回泰奧手裡，朝躺在旁邊的模擬傷員抬了抬下巴。

「再來一次。」

泰奧突然更希望他直接罵自己兩句。

**5. 真的有衝突時，也可合理說粗話，但不讓粗話負責全部戲**

「放屁！」馬庫斯一掌拍在桌沿，「你叫我把能走的兵全撤回來，那後面抬擔架的呢？」

對面的軍官臉色陰沉，卻沒有再拍桌，只把染滿泥水的圖紙轉了半圈，指著最窄的那段支道說：

「所以我才要你留這一隊。」

馬庫斯的手停住了。他低頭看圖，過了兩秒，才慢慢把胳膊收回來。

這段有粗口，但後面仍須由**兩個有能力的人繼續討論戰術與負責人命**；不能把骂聲當成戲已完成。

## 九、反模板、可驗收的小說聲線

### 容易失敗的假學習

- 每句「欸？！哎呀！喂！」「啪！咚！砰！」堆在一起，把小說寫成擬聲詞貼紙牆。
- 以「很會罵髒話」取代人物的專業、笑點、慌張與內心。
- 認為看到「～♡」才是活潑，忽略本輪 Gemini 樣本不用這些符號仍然很活。
- 認為「噗哧」「哼」「……」是標準口頭禪，每一位男性、女性、新兵、元帥都同樣使用。
- 反過來為了防止重複，把原稿有效的「放屁！」「咕咚」「啪嗒」悉數刪掉。
- 用物理聲音詞取代真正的結果：寫「轟！」但沒有說明誰趴下、誰護住人、誰看見支架出問題。
- 為了表現音節停頓，每兩句就插入 Markdown「---」：**普通連續場景用自然空行即可**，不要讓畫面被橫線切成教學投影片。
- 一篇長文不管場合都維持同一強度的驚嘆號與咆哮；**真正的高峰需要對比和累積**。

### 每次正式章節可做的匿名閱讀驗收

1. 不看作者，人物的聲音是不是各不相同？聽得出誰正在說話、跟誰說話、想掩飾什麼嗎？
2. 讀者是否能**真的聽見**地下世界：水、軌道、軍靴、器械、碗盤、笑與槍聲；是否都有相應物件與動作？
3. 有沒有足夠強烈、好笑或柔軟的台詞，而不必靠「連續髒話」才有情緒？
4. 拿掉幾個嘆詞或擬聲詞後，場景是否仍有戲？如果拿掉就完全沒有戲，那是人物行動還沒成立。
5. 台詞是否會改變另一人的行動、表情、關係或決定？還是只像在完成設定說明？
6. 長短段落有自然呼吸、重要短句有重量，而沒有過密或過多橫線嗎？
7. 與同題相近篇幅 Gemini 原稿並排閱讀，使用者是否會真心想看 GPT 版本下一場？**自評不能取代使用者盲讀**。
