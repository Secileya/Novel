SERIES_TOTAL_VOLUME_COUNT = UNDECIDED

**2026-10-10 正式進度**：第001章《警報不是答案》已於 `11_正式章節/` 發表並 ACK；第一卷因此**已開寫但尚未完結**，第二卷的入口仍只可由第一卷規劃投影，而非已完成第一卷的 Canon。第二章正文未開始；最新故事游標以 `../14_寫作流程與劇情引擎/00_索引與現行寫作游標.md` 為主。

正文與規劃是兩條不同游標：

```text

VOLUME_PLAN_RESUME_CURSOR = BUILD_VOLUME_002_ENTRY_DEPENDENCY_MAP
```

不得以第二卷已有規劃游標，誤稱第一卷已經在故事中發生。

## 3. 如何判定下一個要規劃的卷

1. 若 `IN_PROGRESS_VOLUME_PLAN` 不是 `NONE`，先完成該卷，不另開新卷。
2. 否則取最高的 `LATEST_FULLY_PLANNED_VOLUME + 1`。
3. 若前一卷已有正式正文，以章後 ACK 的實際終態作入口。
4. 若前一卷只有卷綱，以 `PROJECTED_FROM_VOLUME_N_NOT_CANON_OCCURRED` 作入口；所有依賴均須保留回基線能力。
5. 正式正文日後偏離預計終態時，把所有受影響後續卷標成 `DOWNSTREAM_REBASE_REQUIRED = TRUE`，逐項重算人物、物件、情報、關係、制度與時間依賴，不把舊規劃當幽靈前提。

## 4. 完成一卷後必須更新

- 本檔的卷級索引、兩條游標與 `LATEST_FULLY_PLANNED_VOLUME`。
- 新卷完整規劃檔，命名為 `VOLUME_NNN_<工作名>_完整規劃.md`。
- `../00_專案交接與最新進度.md` 的 Gate 與文件地圖。
- `../13_版本紀錄與原對話交接/CHANGELOG.md`。
- 若原作大型事件被納入，新增或更新對應 `SOURCE_NODE`，不得只記結果。

詳細執行規則見 [`01_後續卷動態規劃協議.md`](01_後續卷動態規劃協議.md)，完整欄位見 [`02_卷級完整規劃模板.md`](02_卷級完整規劃模板.md)。
