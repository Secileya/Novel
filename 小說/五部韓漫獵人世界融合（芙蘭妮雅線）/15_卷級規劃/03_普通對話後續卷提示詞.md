# 普通對話後續卷規劃提示詞

> 使用方式：把**本檔的 GitHub 連結**交給普通對話，再貼下方指令。普通對話必須沿連結讀取，不得只根據提示詞猜測專案內容。

```text
請完整讀取這份 GitHub 文件，並依其中連結進入：
1. 現行專案總入口；
2. v0.6.0 普通對話接回檔；
3. 卷級索引與續接游標；
4. 後續卷動態規劃協議；
5. 卷級完整規劃模板；
6. 上一卷規劃，以及本卷會用到的人物、事件、系統、社會與原作證據檔。

先動態判定目前下一個尚未完整規劃的卷，不要把任務固定理解成第二卷，也不要要求我重新口述先前設定。

接著只規劃這一個卷，做到與第一卷同級或更完整：入口依賴、本卷命題、Franiya 主線變化、建議章數、五至九個階段、事件依賴佇列、六線幕前／幕後演化、POV_OWNER／ACTION_OWNER／ARC_OWNER、關係與知識里程碑、資產持有鏈、跨系統取得、制度／普通人／經濟／犯罪／文化後果、原著事件適應、卷末高潮、卷末六線差分、來源 Gate、一致性測試及下一個規劃游標。

判定優先順序為：明確作廢／否定 ＞ 後期明確修正 ＞ 後期較完整補充 ＞ 早期仍相容設定 ＞ 助手提案。

不得把 AU 提案冒充原作事實；未讀到的原作過橋標 SOURCE_UNSTATED。不得把上一卷預計結局冒充 CANON_OCCURRED；若上一卷尚未寫完，本卷入口必須標 PROJECTED_FROM_PREVIOUS_VOLUME，並保留日後重基線機制。

Franiya 是系列主角，但其他五作人物與普通人仍有自身選擇；不採全員固定組隊、共享全知、系統自動合併、SSS 高塔自由出入或 Franiya 替所有人完成人生。

有 GitHub 寫入能力時，依協議新增卷檔並同步索引、總入口、交接與 CHANGELOG；沒有寫入能力時，輸出完整可直接保存的 Markdown 與逐檔更新清單，明確標 NOT_SAVED_TO_GITHUB。

完成前不得只交靈感清單、簡略大綱、待續或「之後再補」。若必讀連結無法讀取，列出確切未讀檔名；只處理不依賴缺檔的部分，不得假裝完整接回。
```
