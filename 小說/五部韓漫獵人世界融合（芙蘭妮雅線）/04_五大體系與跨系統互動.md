# 五大體系與跨系統互動

> **v0.1 歷史／共用規則檔**：系統不合併、等級不直換仍可用；個別跨系統結論須按 v0.2 事件測試重判。現行索引見 `05_力量系統與交互規則/`。

## 1. 統一框架：同一世界，不同權限

- **[融合AU改編｜AU-SYS-001]** 五套體系共享物質因果，但不共享後台。一次攻擊可以同時被物理、魔力、故事／概然性、技能權限與靈魂契約判定；任何一項名稱相近都不代表其他項自動通過。
- **[融合AU改編｜AU-SYS-002]** 跨系統作用固定檢查六道門：`TARGET_VISIBILITY`（能否觀測目標）、`ENCODING`（本體系能否描述該效果）、`PERMISSION`（有無權限）、`SCALE`（量級是否足夠）、`DOMAIN`（所在地由誰執法）、`COST`（能量／概然性／代價）。
- **[融合AU改編｜AU-SYS-003]** 戰力不是單一數字。跨作勝負至少拆成輸出、防禦、速度、資訊、權限、續航、復活／回歸、場域控制、社會資源與是否願意升格。

## 2. 各體系原作基線與 AU 接法

### 2.1 《我獨自升級》：覺醒者、傳送門與影子

- **[原作事實｜OF-SYS-SL-001]** 覺醒者被稱為獵人，通常以 E 至 S 等級管理；傳送門連接地下城，攻略與魔晶石形成職業、公會與產業。
- **[原作事實｜OF-SYS-SL-002]** 成振宇因系統成為能持續升級的特殊個體，之後取得影子君主相關力量；他的成長例外不能推成所有獵人都能刷怪升級。
- **[融合AU改編｜AU-SYS-SL-001]** 獵人測定器讀到的是當下外放／可被本地魔力模型編碼的部分。對芙蘭妮雅只能得到局部輸出、溢位或「無法分類」，不得把測不到寫成無能力，也不得把溢位數值當成她的完整上限。
- **[融合AU改編｜AU-SYS-SL-002]** 影子抽取對「死亡後留下的影子／人格資訊與君主權限」生效，不等於取得所有屍體材料、Ego 裝備人格或星流故事所有權。

### 2.2 《無法升級的玩家》：玩家、一般塔、傳送門與 Ego

- **[原作事實｜OF-SYS-PWCLU-001]** 金基圭獲得玩家邀請與獨特能力，五年仍無法超過 Lv.1；他透過連結 Ego 提升能力並進入特殊傳送門。
- **[融合AU改編｜AU-SYS-PWCLU-001]** 「玩家」在法律上登記為特殊獵人，但玩家等級、連結率、Ego 成長與一般獵人魔力等級保留獨立欄位。
- **[融合AU改編｜AU-SYS-PWCLU-002；名稱更新 v0.5]** Lou 與 El 是具人格／歷史的 Ego，不寫成金基圭隨手召喚的無名雙劍技能；未取得正式繁中小說譯名以前，正文直接使用英文。
- **[融合AU改編｜AU-SYS-PWCLU-003]** 外人若奪取 Ego 的物理載體，不自動取得連結、人格同意或完整權能；芙蘭妮雅也不會只因能分析結構就抹去其人格與契約。

### 2.3 《SSS級自殺獵人》：技能卡、高塔與二十四小時回歸

- **[原作事實｜OF-SYS-SSS-001]** 高塔獵人可持有技能卡；金孔子的複製能力以「被對方殺死」為觸發，而他取得的回歸能力會在死亡時把時間拉回二十四小時並保留記憶與能力。
- **[原作事實｜OF-SYS-SSS-002]** 高塔技能只在塔內世界有效；入塔者不能自由回到地球。
- **[融合AU改編｜AU-SYS-SSS-001]** 技能卡系統可以辨識芙蘭妮雅在塔內自願提交的本地技術／投影，不能把她的本體能力、家庭關係、跨世界錨或完整存在複製成一張卡。
- **[融合AU改編｜AU-SYS-SSS-002]** 若金孔子被芙蘭妮雅殺死，複製判定先問「她是否使用可被塔編碼的本地作用」。若只是本地短刃技術，可形成塔能理解的技術卡；若涉及本體層作用關係，結果為不可編碼／降格近似，而非完整複製。

### 2.4 《全知讀者視角》：星流、任務、故事與概然性

- **[原作事實｜OF-SYS-ORV-001]** 星流以鬼怪頻道把化身的任務與故事提供給星座觀看；主線、支線、幣、背後星、故事與概然性共同限制干涉。
- **[融合AU改編｜AU-SYS-ORV-001]** 星流能對其任務域內的芙蘭妮雅提出任務、顯示介面、計算她造成的故事影響，但不能以 UI 訊息改寫她本體或強迫她接受背後星／化身契約。
- **[融合AU改編｜AU-SYS-ORV-002]** 芙蘭妮雅若自願成為「訪客化身」，星流只取得任務結算與域內觀測權；本體所有權、記憶修改權、強制回歸權與跨界去向明文排除。
- **[融合AU改編｜AU-SYS-ORV-003]** 她做出超出當前任務敘事容許的行為時，概然性成本優先落在試圖解釋／阻止／播送該行為的星流與干涉者身上；這不等於她無代價無限制行動，她仍需承擔自己選擇造成的社會、地理與人物後果。

### 2.5 《獨行死靈法師》：職業卡、任務與死靈

- **[原作事實｜OF-SYS-TLN-001]** 職業卡在災變開端出現，拾取後使人被系統視為玩家並取得不同職業；星數反映職業稀有／強度層級，Seongwu 選擇死靈法師。
- **[原作事實｜OF-SYS-TLN-002]** 原作職業卡災變是全球性，怪物、地下城與任務重塑社會；本線局部化屬明確分歧。
- **[融合AU改編｜AU-SYS-TLN-001]** 卡域內原住民在倒數結束前可選職業；既有獵人／玩家同樣可選，但新職業只新增職業卡權限，不抹除原能力，也不保證兩套數值相乘。
- **[融合AU改編｜AU-SYS-TLN-002｜v0.6.5 修正]** 芙蘭妮雅以**完整現實本體**進入本作，不需選職、等級、裝備槽或職業卡便能使用自己的能力。她若自願接觸卡系統，可被記錄為外來訪客、參與者或另外建立本地展示介面；這不代表她得到低階角色殼、不代表她的本體被鎖入職業／MP／冷卻，不默認她有義務接受任何介面。

## 3. 轉譯與數值規則

- **[融合AU改編｜AU-TRANSLATION-001]** 外系統掃描只回傳可編碼投影：`OBSERVED_LOCAL_OUTPUT != TRUE_CAPACITY`。
- **[融合AU改編｜AU-TRANSLATION-002]** 任何「升級」只提升原生或明示連動的數值層。職業卡升級不自動提高獵人覺醒級；星流幣加點不自動提高 Ego 連結；高塔排名不自動增加成振宇系統屬性。
- **[融合AU改編｜AU-TRANSLATION-003]** 技能複製只複製可被來源系統描述的部分，且不複製人格、血統唯一權、契約對象、故事所有權或跨世界根權限，除非原作／AU 另有明示。
- **[融合AU改編｜AU-TRANSLATION-004]** 抗性不是絕對免疫。每次交互要回答抗的是能量、狀態、概念、故事、靈魂、時間還是權限；「S 級所以免疫」不成立。

## 4. 死亡、死靈、影子與 Ego 的資產拆分

- **[融合AU改編｜AU-DEATH-ASSET-001]** 一名死者至少拆成：`BODY_MATERIAL`、`SOUL_OR_SELF`、`SHADOW_IMPRINT`、`MEMORY_INFORMATION`、`STORY_OWNERSHIP`、`ACTIVE_CONTRACTS`。
- **[融合AU改編｜AU-DEATH-ASSET-002]** Seongwu 的死靈術、成振宇的影子抽取、Ego 化、星流復活與高塔回歸可能瞄準不同層；不能因都與死亡有關就默認可同時複製一個完整人格。
- **[融合AU改編｜AU-DEATH-ASSET-003]** 衝突順位：具自我者的明確意願 ＞ 已成立且仍有效的唯一契約 ＞ 所在域執法權 ＞ 先成立的合法占有 ＞ 後來嘗試。沒有合法結果時，後來能力失敗或只取得無人格材料。
- **[融合AU改編｜AU-DEATH-ASSET-004]** 芙蘭妮雅能切斷或改寫作用關係，不等於她會替任何一方無理由搶奪死者。她是否介入仍依關係、意願、成本、必要性與後果判斷。

## 5. 芙蘭妮雅能力映射

- **[家庭總檔作者真源｜FRANIYA-CORE-v0.6.5]** 芙蘭妮雅能直接感知並介入存在之間的**作用關係、權重、力、質量／慣性／動量及更深的時空、因果和存在結構**；廣泛的武器、魔法、瞬時重構與精準實戰技巧同樣完整有效。『作用權重』是**作者層理解工具**，不要求成為每次招式發動前說出的正式技能名。事件視界、黑洞、天體級及其他宏觀／深層表現也屬於她的可能性，**但沒有任何一項必須擔任本作固定職業、戰鬥階梯或段落配額**。
- **[融合AU改編｜AU-FRANIYA-001｜舊流程 SUPERSEDED]** 不設定『平時純技巧→較高魔法→事件視界→黑洞／天體級』的固定升級序列，也不宣告對再生／傳送／回歸必須使用事件視界。她可依眼前目標、習慣、興趣及具體情況直接改變作用與權重，或自然使用刀、槍、法術及其他已掌握的技巧；**當下使用了什麼就描寫什麼**，由可觀察效果決定呈現層次。
- **[融合AU改編｜AU-FRANIYA-002｜v0.6.5 校正]** 本地儀器可以顯示「超出量程」「無法分類」；若她實際同意註冊某個本地系統，該系統才可能額外顯示僅對該介面有效的數值／訪客狀態。這些顯示不能定義、限制、封印她的完整本體，也不該用精確的『無限等級』假量測充當劇情。
- **[融合AU改編｜AU-FRANIYA-003｜舊本地硬限制 SUPERSEDED]** 若她**真的選擇**以事件視界或其他高層干涉作用，具體結果按家庭總檔和她實際建立的作用條件判定；不得把五部本地系統的『距離、場域、權限、概然性』直接列為她本體必須逐一取得許可的七道關卡。這些條件仍應**用來判定原著人物、物品與本地系統彼此的交互**。與真正近似／高於她的存在互動時另依家庭本體真源和特定能力相性分析，但五部本地稱號不自動創造同級敵人。
- **[融合AU改編｜AU-FRANIYA-004｜v0.6.5]** 本地規則不強制削弱她。她是否干涉、關注多少、用什麼方式取決於她現下的生活與選擇；**作者核對時可以分析自限，但小說旁白不必反覆強調『她其實能做到更大，只是……』**。她是活在現實世界的人，不是一名必須按照其他網遊線 Lv.1／MP／技能槽或裝備冷卻操作的遊戲角色。

### 出現、失效與跨作命名的界線

- `事件視界／黑洞／天體級` 是角色本體可用表現與宏觀尺度**不是本作第一卷必備法術清單**。在本卷特定場景若確實有動機使用，亦不因另一條網遊世界線的規則而被禁止；只是不能為炫技突然強插，不能借給原著 A 級角色當通用掉落技能。
- Franiya 的普通短刃飛行若被她介入，已離手後的加速、停滯、折返、改線可以直接由作用關係控制。對**其他原著人物**和普通物件，若未有這種能力仍依物理、技能、能源或契約規則。這是能力持有者區分，不是『現實世界不能這樣』。
- 本地『只觀測到有限效果』不等於『她只能有有限效果』；本地『判定失敗』也不等於『本體被系統擋住』。
- 跨世界借用**角色表現方法**（平靜、咖哩興趣、人際距離、生活方式）不等於繼承別部小說的獨特招式冷卻、道具取得、已建立關係或結局。

## 6. 跨系統快速矩陣

| 交互 | 預設結果 | 必查例外 |
|---|---|---|
| 獵人測定器→玩家／化身 | 讀取可見魔力，不讀全部系統欄位 | 對方是否主動轉譯 |
| 星流任務→既有獵人 | 可強制任務域規則，不抹除獵人能力 | 是否在圓頂／是否有豁免契約 |
| 職業卡→既有玩家 | 新增職業卡層，不改寫原玩家等級 | 卡片是否明示融合或互斥 |
| 高塔技能卡→外界 | 塔外不運作或失去塔後台 | 是否有明示跨域權限 |
| 影子抽取→死靈已契約目標 | 先拆資產與意願，通常不能雙重完整占有 | 所在域、契約是否已終止 |
| 技能複製→芙蘭妮雅 | 只可能複製塔能編碼的本地表現 | 是否涉及本體根權限 |
| 星流觀測→芙蘭妮雅 | 可觀察她允許／域內發生的現象 | 主動資訊自限、觀測代價 |
| 本地回城／傳送→SSS 高塔外 | 失敗 | 得到高塔正式出口權限或完成離塔條件 |

## 7. 戰力敘述禁用

- **[融合AU改編｜AU-POWER-DONT-001]** 禁止建立「E<S<五星<星座<君主<Franiya」這種單線排行榜。
- **[融合AU改編｜AU-POWER-DONT-002]** 禁止為了保留原主角戲份讓芙蘭妮雅忘記能力、站著挨打、無理由不觀測，或被普通系統通知強制改造。
- **[融合AU改編｜AU-POWER-DONT-003]** 也禁止只用她能否秒殺衡量戲劇性；資訊不足、他人意願、社會後果、場域封鎖、救援優先與她是否想介入都可構成真正限制。
