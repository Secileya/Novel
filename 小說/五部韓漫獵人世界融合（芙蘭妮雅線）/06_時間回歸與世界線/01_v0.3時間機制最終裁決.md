# v0.3 時間、回歸、輪迴之杯與 Franiya 連續性裁決

> 「最終」指本版本已能執行，不代表把 AU 規則偽稱為五部原作共同宇宙真相。若日後原文證據推翻某個作用域，只修改對應域，不動 Franiya 四項硬不變量。未另標為 `[原作事實]` 或 `[使用者已確認]` 的跨域結算一律為 `[融合AU改編]`。

## 1. 唯一總則：回歸不是同一種動作

每個時間事件以四欄判定：`MECHANISM`、`ENFORCEMENT_DOMAIN`、`BRANCH_OR_REWRITE`、`MEMORY_AUTHORITY`。不同作品都使用「回歸」一詞，不代表同時倒轉同一個宇宙時鐘。

## 2. Franiya 四項硬不變量

```text
FRANIYA_INSTANCE_COUNT = 1
FRANIYA_SUBJECTIVE_TIME_MONOTONIC = TRUE
LOCAL_MEMORY_OVERWRITE = DENIED
FORCED_SELF_ROLLBACK_OR_BRANCH_TRANSFER = DENIED
```

- 她保留經歷，不表示自動回到原座位或原事件；落點依機制與她的選擇處理。
- 普通人、普通物件與紀錄不因被她碰過就獲得免疫。
- 她可主動把特定物件納入 `CONTINUITY_ENVELOPE`；必須在事件前或事件當下有明確錨定，不能事後為保留道具倒填。

## 3. 四類時間機制

### 3.1 金孔子的二十四小時回歸

- **[原作事實]** 死亡觸發，金孔子保留記憶並回到二十四小時前；具體高階作用域需原文節點繼續核讀。
- **[融合AU改編]** 執法域固定為 `SSS_TOWER_RECORD_BRANCH`。塔內環境、任務、人物狀態與塔原生物品回到快照；地球與其他後台不倒退。
- **[融合AU改編]** Franiya 若在塔內，塔的環境在她周圍重建；她本人不回朔。她被對接到「快照中最近的合法空間」，不是自動回到上一輪同一張椅子。
- **[融合AU改編]** 回滾時她持有的塔原生資產依塔快照返還，除非事前取得塔主權限承認的跨回歸持有權；單靠抓在手上不能複製神器。
- **[融合AU改編]** 外界時間持續前進。金孔子連續回歸會讓塔內穩定分支落後於地球；對外窗口只在塔內連續穩定二十四小時後重新握手，避免把未定分支消息反覆送出。

### 3.2 劉衆赫式回歸／星流世界線

- **[原作事實]** 回歸會形成新的回歸輪次／世界線，回歸者保留關鍵記憶。
- **[融合AU改編]** 本線採「分支，不抹除舊線」。新世界線會重新實例化地球與本地人物；舊世界線仍是已發生的分支，不被一句回歸化為幻覺。
- **[融合AU改編]** Franiya 不被新線複製。她可留在舊線、拒絕跟隨，或自願以同一個自我跨到新線；跨線後舊線只保留她造成的結果，不留下第二個完整她。
- **[融合AU改編]** 長篇只指定一條 `NARRATIVE_ACTIVE_WORLDLINE`。若劉衆赫離開而 Franiya 不跟，正文可繼續舊線；若她跟隨，必須建立世界線分支交接，不能把兩線狀態混寫。

### 3.3 輪迴之杯

- **[原作事實]** 輪迴之杯能把世界時間倒回十年；具體次數、記憶與終局細節需在正式啟動前完成專題原文稽核。
- **[融合AU改編]** 杯重寫「當前敘事世界線的地球物質史」，連同附著於該地球的獵人、一般玩家塔入口、卡域與當前星流地球胞域回到十年前狀態。
- **[融合AU改編]** SSS 高塔內部是域外紀錄，不倒退；但地球入塔接點、家屬、法規與對外窗口歷史被重寫。塔內居民因此成為來源歷史已刪除的域外人口。
- **[融合AU改編]** Franiya 保持當下身體、能力、記憶與主觀年齡。她若在地球，留在被重寫後的同一世界線；若在高塔，則先留在高塔，直到合法出口／跨界選擇另行建立。
- **[融合AU改編]** 杯啟動即建立 `CUP-R` 分支快照與新交接，不在同一狀態表把十年前後當成普通隔天。

### 3.4 復活、Ego 重構與職業卡重生

- 只重建被該機制辨識的身體、靈魂、載體或角色狀態；沒有明示便不改寫歷史。
- 與影子／死靈衝突時使用跨系統資產拆分，不因都和死亡相關就生成兩個完整人格。
- Franiya 自身重構仍是同一個她，不向本地系統登記為新生命實例。

## 4. 同時觸發的裁決順序

1. 鎖定觸發事件的物理座標與主域。
2. 處理不改寫歷史的復活／重構。
3. 處理 SSS 高塔域內二十四小時回滾。
4. 處理輪迴之杯對當前地球分支的十年重寫。
5. 處理星流回歸所建立的新世界線。
6. 最後執行 Franiya 四項硬不變量與 `CONTINUITY_ENVELOPE` 清單。

這是避免重複實例的結算順序，不是力量排行榜。若兩個觸發根本位於不同域，可並行記錄而不互相覆蓋。

## 5. 記憶、關係與證據

| 對象 | 高塔24h回歸 | 輪迴之杯 | 星流新世界線 |
|---|---|---|---|
| 金孔子 | 依技能保留 | 若人在地球作用域，依杯專題判定；若在塔內不受地球重寫 | 新線本地版本依星流規則；不是自動保留全部塔分支記憶 |
| 劉衆赫 | 塔外通常不受影響 | 當前地球版本被重寫 | 回歸者保留其機制允許的記憶 |
| 成振宇 | 塔外不受影響 | 正式啟動前須完成杯原文 `SOURCE_NODE` | 新線生成本地版本；舊線仍存在 |
| 普通人 | 只隨塔內快照 | 記憶與歷史通常隨地球重寫 | 新線版本不知道舊線 |
| Franiya | 全部保留；位置重新對接 | 全部保留；單一實例 | 不複製；是否跨線由她決定 |

記得被刪除事件不等於擁有可被別人接受的證據。回歸後第一次相認必須分開處理：記憶、外部紀錄、私密驗證、信任、秘密暴露與稱呼變化。

## 6. 六個必過場景

| ID | 場景 | 裁決 |
|---|---|---|
| TIME-V3-01 | 金孔子回歸，Franiya 在塔內 | 塔回滾；她不回朔，對接合法位置；塔外時間前進。 |
| TIME-V3-02 | 她在上一輪取得塔內神器 | 神器回到塔快照；她只保留記憶，除非有事前合法錨定。 |
| TIME-V3-03 | 劉衆赫回歸而她拒絕跟隨 | 新線沒有她；舊線的她繼續生活，無第二實例。 |
| TIME-V3-04 | 她自願進入新世界線 | 同一實例轉移；舊線只保留因果結果與他人記憶。 |
| TIME-V3-05 | 輪迴之杯啟動時她在地球 | 地球退十年；她保持現在狀態，身分紀錄需重新建立。 |
| TIME-V3-06 | 輪迴之杯啟動時金孔子在塔內 | 高塔不回朔；地球接點歷史消失，對外窗口中斷。 |

六項均有唯一答案；正式啟動輪迴之杯前仍要補「原作物件能力與使用條件」的來源閉環，這是證據債，不是設定矛盾。
