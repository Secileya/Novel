## 2. 每次災變擴張要同步的社會面

| 層次 | 必填結果 |
|---|---|
| 行政 | 誰宣布、誰執行、哪個機關失聯、中央與地方如何衝突 |
| 救援 | 軍警／公會／醫院能到哪裡，為何到不了，誰被優先 |
| 交通 | 地鐵、公路、橋樑、機場、塔接點與封鎖線 |
| 經濟 | 韓元、系統貨幣、掉落物、保險、工資、價格、黑市折價 |
| 資訊 | 官方公告、直播、論壇、謠言、星流觀看與審查 |
| 人口 | 死亡、失蹤、難民、家屬、未成年人、入塔者法律狀態 |
| 犯罪 | 搶卡、攻略權、人口販運、詐騙入塔、情報壟斷、掉落物洗白 |
| 文化 | 粉絲、迷因、創傷、紀念、邪教、遊戲與娛樂的再解釋 |

## 3. 高塔社會邊界

- 入塔不是通勤，而是近似不可逆移民／失聯／高風險職涯。
- 地球資產、遺囑、債務、家屬補償、物資管道與訊息延遲都必須落地。
- 地球災變消息如何進塔需有管道；塔內人物不能看到新聞後直接出現在首爾。

## 4. 黑市最小閉環

任何黑市交易須回答：供貨者、買家、貨物來源、運輸路線、鑑定、支付、信用、執法風險、失敗後果。只說「黑市有人賣」不通過。

## 5. 普通人事件測試

選一名無系統、無公會背景的首都圈居民，追蹤七十二小時：收到何種警報、交通是否中斷、錢能否使用、家人在哪裡、醫療與住宿如何取得、網路消息真假。若世界只對主角產生反應，社會模型 FAIL。
