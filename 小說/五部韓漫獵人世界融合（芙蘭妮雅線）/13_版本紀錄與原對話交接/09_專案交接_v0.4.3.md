# 專案交接 v0.4.3｜Franiya 主軸式多視角群像

> 日期：2026-10-09  
> 性質：使用者最新敘事決定的版本化交接。  
> 本檔取代早期未區分「群像」與「系列主角」的籠統說法；不改寫任何已確認的世界觀、人物本體或原著事件規則。

## 1. 使用者最新確認

- 本作本質仍是「把 Franiya 放進五部獵人／玩家世界」；Franiya 是系列主角與長期人物弧中心。
- 可以採群像，也可以用別人的視角推進另一個人的故事。
- 因此唯一現行敘事模式為：**Franiya 主軸式多視角群像**，不是六線平分、不是機械輪流，也不是每章都必須讓 Franiya 出場。

```text
NARRATIVE_MODE = FRANIYA_CENTRIC_ENSEMBLE_MULTI_POV
SERIES_PROTAGONIST = FRANIYA
POV_ROTATION = CAUSAL_NOT_EQUAL
SCENE_POV_POLICY = SINGLE_POV_PER_SCENE
```

## 2. 三種所有權必須拆開

```text
POV_OWNER: 本場可直接呈現誰的感知、判斷與有限內心
ACTION_OWNER: 誰作出改變因果的不可替代選擇
ARC_OWNER: 本場結果主要改變誰的長期人物弧
```

三者可以不同。使用 A 的視角推進 B 的故事時，A 可觀察、誤判、施壓或回應，但不能替 B 知道、選擇或總結其未表露的內心。需要日後回到 B 視角才能理解的部分，記為：

```text
INTERIOR_DEBT: 尚未揭露、不得由旁觀者代寫的內在理由
```

## 3. Franiya 不在場時如何仍屬主線

其他原作人物、制度角色與普通人可持有完整章節，不需讓 Franiya 遠端觀看或突然介入。每個無 Franiya 的故事單位仍須交代：

```text
MAINLINE_RELEVANCE: 本段改變了哪些日後會抵達 Franiya 的條件
RETURN_CAUSE: 後果將經哪條物理、情報、制度、資源、人物或系統接觸邊回到主線
```

若刪掉該段後，Franiya 的選擇與融合世界對她形成的條件都完全不變，則該段應壓縮為幕後台帳或另列支線。這不是要求所有事件圍著她轉，而是保證長篇仍有清楚的系列主軸。

## 4. 第一章的所有權

```text
EVENT = EVT-ENTRY-FRANIYA-001
POV_OWNER = 禹鎮哲
ACTION_OWNER = 禹鎮哲＋Franiya
ARC_OWNER_PRIMARY = Franiya
ARC_OWNER_SECONDARY = 禹鎮哲／協會制度
VIEWPOINT_FUNCTION = 以成熟制度執行者的有限觀察，讓讀者先感到她無法被現行分類
INTERIOR_DEBT = Franiya 對新世界的完整評估不一次揭盡
```

禹鎮哲是最適合承接龍山異常警報的觀察窗；Franiya 仍親自決定姓名、資訊揭露、合作界線與是否接受短期程序。因此，第一章採禹鎮哲視角不等於他取代 Franiya 成為系列主角。

```text
LATEST_FORMAL_CHAPTER = NONE
LATEST_CANON_OCCURRED_EVENT = NONE
RESUME_CURSOR = DRAFT_FULL_CHAPTER_001_FROM_EVT-ENTRY-FRANIYA-001

```
