## 4. 普通對話的讀取驗收

普通對話若真的讀完最小包，至少應能正確回答：

```text

LATEST_FORMAL_CHAPTER = NONE
LATEST_CANON_OCCURRED_EVENT = NONE
RESUME_CURSOR = DRAFT_FULL_CHAPTER_001_FROM_EVT-ENTRY-FRANIYA-001
NARRATIVE_MODE = FRANIYA_CENTRIC_ENSEMBLE_MULTI_POV
FRANIYA_INSTANCE_COUNT = 1
FRANIYA_SUBJECTIVE_TIME_MONOTONIC = TRUE
LOCAL_MEMORY_OVERWRITE = DENIED
FORCED_SELF_ROLLBACK = DENIED
```

並應知道：五位主角開篇互不相識；第一卷不是全員組隊；SSS 高塔不可自由出塔；卷末域衝突只是 `AU_LOCKED_FOR_OUTLINE`，尚未發生；正式中文名不足時使用正式英文。

## 5. 圖片與長條漫畫不能獨立承擔的內容

- 圖片可證明可見文字、站位、表情、物件、出手先後與畫面內持有鏈；不能單靠「畫面沒出現」證明小說設定不存在。
- 長條漫畫可能因懶載入、截圖裁切、低解析 OCR、對話框閱讀順序、無字過場、重複／漏載影像段而漏讀。
- 改編漫畫也可能刪節內心、合併場景、調整台詞或提前視覺揭露；不得把改編差異冒充小說原文。
- 因此主序列、能力條件、知識邊界與後續用途以正式小說優先；漫畫只補物件位置、可視反應、動作順序與改編差異。
- 若圖片未通過連續載入與可讀尺度檢查，結果只能標 `IMAGE_TEXT_PARTIAL` 或 `SOURCE_UNSTATED`，不能標 `PROSE_SEQUENCE_READY`。
