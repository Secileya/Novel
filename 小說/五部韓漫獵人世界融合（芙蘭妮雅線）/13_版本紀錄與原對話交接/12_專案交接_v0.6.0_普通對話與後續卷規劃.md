# 專案交接 v0.6.0｜普通對話與後續卷規劃入口

> 本檔是 v0.5.1 零上下文接回的增量現行入口。它新增「動態完整規劃下一卷」能力，不撤銷既有世界、人物、來源與正文規則。

## 1. 普通對話先判定任務路由

- 要寫或續寫正式章：依 [`11_專案交接_v0.5.1_普通對話接回.md`](11_專案交接_v0.5.1_普通對話接回.md) 的 `MUST_READ_ORDER` 與正式章分流。
- 要補完後續卷：除上述最小包外，依序讀取：
  1. [`../15_卷級規劃/00_卷級索引與續接游標.md`](../15_卷級規劃/00_卷級索引與續接游標.md)
  2. [`../15_卷級規劃/01_後續卷動態規劃協議.md`](../15_卷級規劃/01_後續卷動態規劃協議.md)
  3. [`../15_卷級規劃/02_卷級完整規劃模板.md`](../15_卷級規劃/02_卷級完整規劃模板.md)
  4. 卷級索引指定的上一卷現行真源，以及本卷涉及的 `SOURCE_NODE`

## 2. 現行雙游標

```text
DOCUMENT_VERSION = v0.6.0
LATEST_FORMAL_CHAPTER = NONE
LATEST_CANON_OCCURRED_EVENT = NONE
PROSE_RESUME_CURSOR = DRAFT_FULL_CHAPTER_001_FROM_EVT-ENTRY-FRANIYA-001

LATEST_FULLY_PLANNED_VOLUME = VOLUME_001
LATEST_CANON_COMPLETED_VOLUME = NONE
NEXT_VOLUME_TO_PLAN = VOLUME_002
NEXT_VOLUME_ENTRY_STATE = PROJECTED_FROM_VOLUME_001_NOT_CANON_OCCURRED
VOLUME_PLAN_RESUME_CURSOR = BUILD_VOLUME_002_ENTRY_DEPENDENCY_MAP
SERIES_TOTAL_VOLUME_COUNT = UNDECIDED
```

兩條游標互不覆蓋：可以先規劃第二卷，但不能因此聲稱第一卷已發生。第一卷正式章日後若造成不同終態，第二卷必須按依賴重基線。

## 3. 一卷完成規劃的最低標準

普通對話必須交付完整的：

- 入口狀態與上一卷依賴；
- 本卷命題、Franiya 主線變化、時間窗與章數預算；
- 五至九階段與有前件的事件佇列；
- 六線幕前／幕後活動及跨線接觸邊；
- 視角、行動、角色弧所有權；
- 關係、知識、資產與持有鏈；
- 制度、普通人、經濟、犯罪、文化和媒體後果；
- 原著事件保留／改道／取消與來源 Gate；
- 卷末高潮、不可逆差分、一致性測試與下一規劃游標。

少於上述內容只能標 `IN_PROGRESS` 或 `PROPOSED_PARTIAL`，不能更新 `LATEST_FULLY_PLANNED_VOLUME`。

## 4. 規劃與正史邊界

- `AU_LOCKED_FOR_OUTLINE`：現行唯一可執行卷綱，仍未在正文發生。
- `PROJECTED_FROM_PREVIOUS_VOLUME`：入口依賴上一卷預計終態，可在正文差分後重算。
- `CANON_OCCURRED`：只有正式章與章後 ACK 才能賦予。
- `SOURCE_UNSTATED`：原作未讀到或過橋未明，不能自行補成原作事實。
- Franiya 的完整本體、不可強制回朔、單一主觀時間、SSS 高塔不可自由出入、五後台不自動合併及其他世界線隔離，不因規劃新卷而重新開放。

## 5. 普通對話直接使用入口

可把 [`../15_卷級規劃/03_普通對話後續卷提示詞.md`](../15_卷級規劃/03_普通對話後續卷提示詞.md) 的 GitHub 連結交給新對話。該檔會要求它動態尋找下一個未完成卷，而不是永遠重做第二卷。

## 6. 現行規劃狀態

- 第一卷已有七階段、十二件事件、`C-DAY -14 ~ +14` 時間窗與域邊界高潮，狀態為 `AU_LOCKED_FOR_OUTLINE`。
- 第二卷尚未開始規劃；第一個動作不是先挑反派或硬接某部原著高潮，而是建立第一卷預計終態的入口依賴圖。
- 全系列總卷數與終局仍未決；普通對話不得假定固定卷數或輪流一卷處理一部作品。
