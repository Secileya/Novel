# 正文 Runtime 與設定依賴圖｜v0.6.6

> 目的：設定越多，正文越應「少讀、準確讀、碰到才載入」。本檔管理如何調用既有設定，不創造新世界觀。
> 核心：DATABASE LARGE / ACTIVE CONTEXT SMALL / LOAD ON CONTACT / AUDIT AFTER CHANGE。

## 1. 三層 Runtime

### L0｜常駐最小包
每章只固定讀：
1. 00_專案交接與最新進度.md 的最新版區塊。
2. 14/00_索引與現行寫作游標.md 的日期、正式章狀態與下一游標。
3. 上一正式章＋章後差分；無正文時讀本章章前包。
4. 08_正文文風與對話表演.md 的現行文風禁區。
5. Franiya 在場才讀 07_Franiya角色適用規則.md 的現行摘要；家庭／能力專題真的發生才載家庭總檔對應段。

L0 不包含五作全部人物、全部裝備、全部 SOURCE_NODE 或歷史 CHANGELOG。

### L1｜場景按需包
| 觸發 | 載入 |
|---|---|
| 原著人物第一次在本章說話／作重大選擇 | 此人當前狀態、關係、聲線 Gate、原著游標 |
| 原著事件進場 | 該事件 SOURCE_NODE、前件與原著結果 |
| 重要武器／道具／Ego／技能進場 | 取得時間、持有人、啟動、人格／契約、跨域存續 |
| 兩作系統互動 | 只載這兩套規則；Franiya 在場再加她的本體規則 |
| 普通人／A-B-C級／學生獨立篇 | 此人的工作、家庭、物件、地理和當日社會狀態 |
| 新地點 | 地理、交通、管轄與現場制度 |
| Franiya 使用特殊能力 | 家庭真源對應能力；本地觀測只決定旁人看見什麼 |
| 家庭成員／跨世界家庭聯絡 | 家庭總檔＋本 AU 已建立的聯絡路徑；不得借別線傳送方式 |

### L2｜章後差分
只核本章真的改變的項目：
- 誰的知識改變？
- 誰的位置、傷勢、職務、關係改變？
- 哪件物品取得、遺失、消耗、損壞、借出或換手？
- 哪個原著事件改變狀態？
- 哪條跨作接觸邊真正成立？
- 哪個新事實需要 SOURCE_NODE？
- 沒碰到的線若未受本章世界事件影響，不必逐一寫假動作證明仍存在。

## 2. 六步正文流程
1. RESUME：讀 L0，確認日期、地點、上一章結果、POV。
2. SCENE DECLARATION：先列本章真的會碰到的人／物／系統／原著事件，再決定 L1；不讓資料庫反過來決定劇情。
3. SOURCE GATE：只查即將正式使用且尚未通過的原著事實。無關資料未查不阻塞本章。
4. DRAFT：先寫人物正在做的事、生活與選擇；設定按因果顯露，不在正文輸出作者資料表。
5. LOCAL AUDIT：查 POV 知情、時間、物件持有、能力來源、人物存活、地理；首次跨作使用才開跨域 Gate。
6. DELTA COMMIT：只更新本章改變的狀態與正式章游標，不重列所有 OFFSCREEN 人物。

## 3. 真阻塞與非阻塞

### 真正阻塞
- 即將登場者是否已死亡、尚未加入組織或根本不在此地不確定。
- 即將使用的原著能力／物品此刻是否已取得不確定。
- POV 即將說出按當前時間可能不知道的祕密。
- AU 改掉原著結果而下游依賴尚未處理。
- 正式譯名造成兩個人物互相錯認。
- Franiya 家庭真源與本線舊規則尚有未裁決衝突。

### 不阻塞
- 本章不登場的後期人物尚未完成聲線研究。
- 某作品後期數百章道具還沒建百科。
- 普通路人的完整家譜未建立。
- 沒有跨作使用的物件尚未填跨域相性。
- 未受本章影響的 OFFSCREEN 線沒有新狀態。
- 中文譯名暫缺但本章可以不用該名字或沿用已標來源層級的現行名稱。

## 4. 設定依賴方向
家庭真源 → Franiya 本體／人格 → 當場行動 → 現場人物有限觀測。
五作原著時間線 → 人物當前狀態＋物品／技能取得 → 場景可用資產。
共同 AU 歷史／地理 → 場景條件。
跨作接觸邊成立後 → 才啟動跨系統相性／持有／後果 Gate。

禁止反推：
- 不因後期神器有趣就提前取得。
- 不因某人是 A 級就假定此刻活著、在首爾或認識主角。
- 不因本地系統無法分類 Franiya 就反推她沒有能力。
- 不因支線沒有 Franiya 就反推它沒有價值。
- 不因設定檔有事件視界／黑洞／天體級就要求正文展示。
- 不因五作融合就讓所有人共享情報。

## 5. Lazy Load 卡

人物只填：姓名／作品、當前日期、是否活著且可出場、位置、職務、場景用到的關係、知情邊界、聲線 Gate、來源游標。

重要物品只填：名稱／作品、此刻是否已存在、現持有人、取得方式、類型（實物／技能／系統權限／人格／貨幣）、啟動方式、人格／契約、這一場是否真的跨域、來源 Gate。

只有「這一場真的跨域」才讀完整跨域矩陣。

## 6. 日常輕量流程
吃飯、回家、值班、採買、休息、聊天、普通工作不套目標→阻礙→選擇→代價五欄。只問：
- 誰在這裡？
- 他們正常正在做什麼？
- 此刻在意什麼？
- 有什麼小事完成或改變？
- 是否真的碰到需要原著來源核對的事？

最後一項若為 NO，就直接寫，不製造研究阻塞。

## 7. 第一章 Runtime
- DATE = C-DAY -14。
- PRIMARY POV = 禹鎮哲，受限近距第三人稱。
- ACTION OWNERS = 禹鎮哲＋Franiya＋現場各自工作的普通人。
- 只載禹鎮哲當前協會職務／S級重測後社會狀態的必要部分。
- 其他四作核心人物不因資料庫存在而載入。
- Franiya 載人格、外觀、當場能力與資訊自限；家庭完整揭露只在故事真的觸發時。
- 沒有跨作物品接觸就不跑物件跨域 Gate。
- C0／C+3／C+7／C+11 全為 NOT_YET_TRIGGERED。

第一章可寫貨運、醫療配送、封鎖、技術員、商戶與回家生活；故事先決定需要誰，再載設定，不因資料庫有某人就把他塞進第一章。

## 8. 流程膨脹警報
若為寫兩人談話先讀十份無關設定、為晚餐填六線狀態、為普通刀跑五套跨域權限、因後期人物未考據而阻止早期章、章後重抄所有人物狀態，或正文為證明讀過設定而硬塞能力／人物／道具，優先刪除無關載入，不新增 Gate。
