# 原著事件適應器與五線同步

> **[專案規則]** 本線是「五作一界、六線同期」，不是五條原著各演各的，也不是每逢大事就讓五名主角同場。原著事件先保住人物壓力與必要功能，再讓共享歷史、地理、制度與其他系統的既成後果改寫它的條件。

## 0A. v0.6.6 六線同步不是六線每章打卡

五條原著線與 Franiya 線在**世界內持續存在**，不等於作者每章都必須替每條線新增事件。由 `06_v0.6.6按需載入正文Runtime與設定依賴圖.md` 控制：
- **實際跨作接觸／公共世界事件影響**到某條線，才更新該線狀態、資訊、人物或物件。
- 沒有受影響的線直接繼承既有狀態，不為完成六線表格虛構『今日也做了某件事』。
- 章內沒有出場的原著人物仍可在其自身因果中生活；等其事件真正需要入鏡再載入。
- 五作角色不因讀者看過其他 POV 就共享資訊；已建立的接觸邊仍需追蹤。

## 1. 原著事件包

任何準備進正文的原著事件，先建立：

```text
SOURCE_EVENT_ID:
WORK:
SOURCE_LABEL: 原作事實 | 正式改編事實 | 待原作查證 | SOURCE_UNSTATED
CANON_EVENT_SUMMARY:
SOURCE_CURSOR_BEFORE / AFTER:
PREREQUISITES:
ORIGINAL_CAST:
ORIGINAL_TIME_AND_LOCATION:
KNOWLEDGE_BEFORE / AFTER:
ASSET_CUSTODY_BEFORE / AFTER:
CORE_CHARACTER_PRESSURE:
ORIGINAL_OUTCOME:
DOWNSTREAM_DEPENDENCIES:
QUOTATION_OR_EVIDENCE_SCOPE:
```

`CORE_CHARACTER_PRESSURE` 比「原作每一步照抄」更重要。例如：金獨子的情報優勢必須遇到書外變數；Seongwu 必須親自面對選職與生存；金孔子的死亡不能變成無成本讀檔。若 AU 改了手段，這些壓力仍要由新因果承擔。

## 2. AU 碰撞掃描

原著事件進場前逐項比較：

1. 共同歷史是否讓人物、制度或技術提早存在？
2. 原作在場者現在是否仍在同一地點、同一時間且有進入權？
3. 原作缺席者是否因救援、任務、家庭或制度而合理抵達？
4. 原作事件所需的人、物、情報、死亡、能力或組織是否仍存在並在正確持有者手中？
5. 其他系統是否會讀取、排斥、誤認或爭奪同一目標？
6. 交通、通訊、物價、醫療、軍警、公會與黑市是否已受先前事件改變？
7. Franiya 是否知道、是否關心、是否在場、是否願意干涉？四題分開回答。
8. 回歸、分支、窗口或域內時間是否改變「誰記得」與「何處已發生」？

不能用「原作本來如此」跳過任何已被 AU 改掉的前提。

## 3. 事件適應狀態

| 狀態 | 判定 |
|---|---|
| `PRESERVED` | 前提、主要經過與結果仍成立，只需換到共同曆。 |
| `PRESERVED_WITH_CONTEXT` | 核心事件不變，但目擊者、制度反應、外部壓力或後果已不同。 |
| `ADVANCED` | AU 因果讓事件更早發生；必須重算原本尚未取得的能力、關係與資源。 |
| `DELAYED` | 事件仍需要發生，但交通、資源、任務或人物位置迫使其延後。 |
| `REROUTED` | 核心壓力與功能保留，地點、參與者或手段改道。 |
| `SUBSTITUTED` | 原事件無法發生，由新事件承擔同一個不可缺的角色／世界功能。 |
| `CANCELLED` | 前提已永久消失，事件及依賴它的後續一起取消或另行替代。 |
| `BRANCH_ONLY` | 只存在於明確分支，不得回寫現行主線；輪迴之杯 `CUP-R` 屬此類。 |

每個狀態都要記 `WHY`。`CANCELLED` 不是刪完就算：所有下游依賴必須標成「仍成立、另有替代、或同時取消」。

## 4. 接觸邊：後果憑什麼跨線

只有存在下列至少一條邊，另一線才受影響：

- `PHYSICAL_EDGE`：同地、相鄰作用域、可通行的門或合法入口。
- `REPORT_EDGE`：協會、公會、政府、塔窗口或正式通訊傳遞。
- `RUMOR_EDGE`：直播、偷拍、難民口述、論壇與錯誤消息。
- `RESOURCE_EDGE`：人力、武器、藥品、運輸、醫療、電力或價格被抽走。
- `SYSTEM_EDGE`：兩套後台爭奪同一人、地、屍體、獎勵或任務結果。
- `PERSON_OR_ASSET_EDGE`：角色、物件、屍體、契約或情報實際轉手。
- `TIME_EDGE`：回歸、分支或跨域窗口使記憶與世界狀態不一致。

「大家都在韓國」「都是主角」「Franiya 感知得到」均不足以單獨建立接觸。感知得到只解決她能否知道，不解決她是否注意、是否願意說與他人如何知道。

## 5. 影響級別

| 等級 | 對其他線的影響 |
|---|---|
| `L0` | 無接觸邊；只在本線發生。 |
| `L1` | 傳聞、價格、交通、失聯或供應變化。 |
| `L2` | 組織正式重分配人員、任務、門禁或資訊。 |
| `L3` | 人物／事件直接相遇，足以改變當前事件結果。 |
| `L4` | 系統後台、回歸分支、世界線或跨域規則發生衝突。 |

級別越高，越需要完整事件卡與來源閉環。跨作露臉不等於 `L3`；如果人物只是看見新聞，仍是 `L1`。

## 6. 五線＋Franiya 同期結算

每一正式章都填六列：

```text
LINE_ID: SL | SSS | ORV | PWCLU | TLN | FRANIYA
ACTIVITY: ON_SCREEN | OFFSCREEN_ACTIVE | NOT_YET_TRIGGERED
SOURCE_CURSOR_BEFORE / AFTER:
AU_CURSOR_BEFORE / AFTER:
IMPACT_LEVEL: L0-L4
CONTACT_EDGE:
ADAPTATION_STATUS:
KNOWLEDGE_CHANGE:
RELATIONSHIP_CHANGE:
ASSET_OR_LOCATION_CHANGE:
NEXT_CAUSAL_ACTION:
```

`NOT_YET_TRIGGERED` 只可用於系統／事件尚未啟動，不可用來凍結已在生活中的人物。`OFFSCREEN_ACTIVE` 表示人物仍按自己的目標行動，只是本章沒有切畫面。

## 7. 分歧傳導算法

原著事件一旦變動，按四圈向外傳：

1. **立即圈（同場／同章）**：生死、物件、任務結果、目擊與受傷。
2. **近程圈（後一至三章）**：報告、救援、追查、家庭反應、稱呼與信任。
3. **篇章圈（同一階段）**：組織資源、物價、犯罪、交通、下一個原著事件的前提。
4. **長程圈（卷後）**：勢力版圖、角色成長、系統權限、死亡資產與回歸策略。

每一圈都問：原作後續曾再次使用這個人、物、情報或結果嗎？若曾使用，不能讓它在 AU 中消失後又無說明復活。

## 9. 三個已鎖定的同步示例

### A. `C-DAY 0` 星流啟動

- ORV：`ON_SCREEN / L3 / PRESERVED_WITH_CONTEXT`，第一輪主線成立。
- SL：`OFFSCREEN_ACTIVE / L1`，成振宇在圈外門內，先受通訊與回程影響。
- PWCLU：`OFFSCREEN_ACTIVE / L2`，一般玩家塔啟動緊急放行與出入口程序。
- SSS：`OFFSCREEN_ACTIVE / L0`，塔內尚未收到地球消息。
- TLN：`OFFSCREEN_ACTIVE / L1`，Seongwu 仍是學生，只接觸首爾失聯與校園不安。
- Franiya：`OFFSCREEN_ACTIVE / L1`，她可感知異常但當下在高陽節點，沒有自動介入理由。

### B. `C-DAY +3` 水原職業卡啟動

- TLN：`ON_SCREEN / L3 / PRESERVED_WITH_CONTEXT`，校園選職與初始求生發生。
- ORV：`OFFSCREEN_ACTIVE / L1`，任務圈內只能取得不完整外界變化。
- SL／PWCLU：`OFFSCREEN_ACTIVE / L2`，各自所屬制度重分配救援與調查。
- SSS：`OFFSCREEN_ACTIVE / L0`，窗口尚未開。
- Franiya：`OFFSCREEN_ACTIVE / L1`，得知不等於趕到；她不替 Seongwu 做選擇。

### C. `C-DAY +7` SSS 高塔收到摘要

- SSS：`ON_SCREEN / L2 / PRESERVED_WITH_CONTEXT`，塔內人物第一次取得延遲摘要。
- 其餘四作：`OFFSCREEN_ACTIVE / L1-L2`，它們的災變資料成為輸入，但不因塔內閱讀而立刻得知塔內反應。
- Franiya：`OFFSCREEN_ACTIVE / L0`，仍在地球；沒有合法入口前不與金孔子同場。

## 10. 禁止的錯誤適應

- 為了照原著結果，讓已被改掉的救援延遲、物件持有或人物位置無說明復原。
- 因為融合 AU 存在，就取消所有原著人物的核心選擇，改由成熟制度或 Franiya 代辦。
- 把五作每個事件都升成全球同步直播，讓每個主角無視接觸邊立刻知道。
- 用回歸或輪迴之杯清帳，而不保留 Franiya 的單一連續與被刪分支的關係後果。
- 在來源只核到入口時，替原作補出完整中間過程再標成「原作事實」。
