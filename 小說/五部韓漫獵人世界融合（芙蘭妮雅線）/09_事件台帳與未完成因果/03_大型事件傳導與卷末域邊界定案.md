# 大型事件傳導與卷末域邊界定案｜v0.5

> 本檔把「五作大型事件會不會影響其他作品」和第一卷卷末事件由開放功能收斂成可寫方案。狀態為 `AU_LOCKED_FOR_OUTLINE`，不是 `CANON_OCCURRED`。

## 1. 大型事件傳導的固定管線

每個原著大型事件依序檢查：

```text
SOURCE_NODE
→ LOCAL_EVENT（原作核心壓力／角色不可替代選擇）
→ PHYSICAL_SPILL（傷亡、怪物、交通、能源、空間）
→ INFORMATION_EDGE（目擊、報告、媒體、系統公告、謠言）
→ RESOURCE_EDGE（醫療、糧食、武器、貨幣、難民、黑市）
→ SYSTEM_CLAIM（哪個後台承認參與者、擊殺、屍體、地點與獎勵）
→ INSTITUTION_RESPONSE（協會、玩家機構、政府、高塔公會）
→ OTHER_LINE_DELTA（其餘四作與Franiya各自改變什麼）
→ DOWNSTREAM_DEPENDENCY（原作後文保留／改道／延後／取消）
```

**v0.6.8 覆蓋：** 一場五作原著事件可以只在自己的角色與社會網中完整成立，**不要求每一場都產生跨作品 `OTHER_LINE_DELTA` 才有價值**。真正有跨線接觸時才記報告、交通、價格、情報等變化；沒有真實接觸就留 `NONE`，不得為證明『融合』編造影響。

## 3. `EVT-DOMAIN-BORDER-001` 定案

```text
STATUS = AU_LOCKED_FOR_OUTLINE
CANON_OCCURRED = FALSE
AU_TIME = C-DAY +11, 15:40–17:10
PHYSICAL_COORDINATE = MAP-ANYANG-GUNPO-BORDER-01
LOCATION_DESCRIPTION = 安養—軍浦交通走廊旁的虛構緊急貨運轉運場；使用真實城市關係，不占用真實敏感設施
ACTIVE_DOMAINS = CARD_DOMAIN_EXPANSION + STARSTREAM_TRANSFER_SUBSCENARIO
```

### 前件

1. `C0` 後首爾南向鐵路與道路運能下降，大量傷患／難民在南部轉運。
2. `C+3` 後卡域沿水原生活圈與物流節點擴張；Seongwu 的隊伍因護送倖存者、取藥與尋找出口向北移動。
3. 聯合本部為避開主星流胞域，於安養—軍浦走廊設置臨時轉運場；其位置被兩套系統分別判為「未登記人口節點」與「可生成故事的救援節點」。
4. 成振宇在 `C+1~+2` 回到地表後先確認家人安全，再接受一項有明確平民目標與時限的南部物理突破任務。
5. Franiya 已與協會形成有限可靠性，但沒有加入公會；她因先前談定的「涉及不可分類域衝突須告知」條款到場，不是被徵召。

### 直接／間接參與

| 類別 | 人物／線 | 到場理由與不可替代工作 |
|---|---|---|
| 直接 | Franiya | `NEGOTIATOR → LIMITED_INTERVENTION`；辨識兩後台互斥聲明，建立短時不互相覆寫的邊界，不代替任何人救完整場。 |
| 直接 | 成振宇／《我獨自升級》 | 擊破已越過物理封鎖的怪物群、保護撤離通道；其影子只處理由其系統合法持有者，不接管卡域屍體。 |
| 直接 | Seongwu／《獨行死靈法師》 | 保持其倖存者隊與本地亡靈指揮鏈，辨認卡域提示與屍體歸屬；不把現場主導權交給公會。 |
| 間接 | 金獨子／《全知讀者視角》 | 所在任務圈不能自由離開；星流公開紀錄與一項「救援敘事」規則經報告抵達轉運場。他本人不瞬移到場。 |
| 間接 | 金基圭／《無法升級的玩家》 | 玩家機構把門／能源判讀與便攜穩定器送至聯合本部；他不與成振宇共用任務出口。 |
| 延遲 | 金孔子／《SSS級自殺獵人》 | 只在下一個七日窗口收到摘要；無人員出口、無即時遠端參戰。 |

### 互斥主張

- **星流主張：** 轉運中的群眾成為限時救援子情境的參與者；救援行為、犧牲與目擊可被登記成貢獻／故事。
- **卡系統主張：** 該區已被卡域擴張標為生存區；職業者、卡生怪物、其掉落與卡系統屍體鏈由卡域管理。
- **真正衝突：** 兩者同時嘗試把「被救的人」「擊殺」「屍體」「安全區」寫進自己的唯一權威記錄。若不裁決，會出現重複任務、屍體雙重召喚與撤離線反覆開關。

### 七門裁決

| 交互門 | 結果 |
|---|---|
| `TARGETING` | 兩後台都能觀察區內事件；能看見不等於能改寫對方帳號。 |
| `ACCESS` | 星流只取得子情境覆蓋；卡系統保有已完成選職者與卡生怪物登記。 |
| `RESISTANCE` | 既有契約、影子／亡靈權屬與個人選擇抵抗重新分類。 |
| `COST` | 建立 90 分鐘中立轉運窗；兩後台各放棄對方既有帳號的強制轉職／轉化。Franiya 不替後台支付代價。 |
| `RESULT` | 人員可撤離；物理怪物被擊殺；屍體、影子、亡靈、故事貢獻分帳。 |
| `PERSISTENCE` | 中立窗結束後只保留已完成的撤離、獎勵與契約，不把整區永久變成安全區。 |
| `AUDIT` | 每次擊殺只由承認該參與者、任務與貢獻的後台結算；無雙倍／五倍自動獎勵。 |

### 結果

1. **[融合AU改編]** 90 分鐘中立轉運走廊成立，第一批平民完成撤離；它是一次性協議，不是永久結界。
2. **[融合AU改編]** 卡系統保有職業者、卡生怪物、卡掉落及其亡靈鏈；星流可記錄救援貢獻／故事，不能把 Seongwu 改成星流職業。
3. **[融合AU改編]** 成振宇處理物理突破口，但沒有因更強而取得 Seongwu 的亡靈或隊伍指揮權。
4. **[融合AU改編]** Franiya 只切斷造成重複覆寫的那條權限衝突，沒有抹除兩套後台；她公開表明「互相承認邊界」是合作條件，形成其第一卷關係弧的不可逆選擇。
5. **[融合AU改編]** 三名直接人物建立「可再合作」而非朋友／固定隊關係；聯合本部形成第一版《重疊域處置暫行準則》。
6. **[融合AU改編]** 星流與卡系統都記住此次拒絕覆寫，下一卷會改採代理人、獎勵與輿論競逐；勝利不會終結系統衝突。
