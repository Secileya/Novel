# v0.3 跨系統裁決表

> 原作各自的能力前提另見來源檔；本檔未另標的跨作優先權、結果分類與案例一律為 `[融合AU改編]`，因為原作沒有共同後台可直接提供答案。

## 1. 不建立單線戰力榜

**[融合AU改編]** 跨作事件不採 `E級＜S級＜五星＜星座＜君主＜Franiya`。每次作用依序檢查：

1. `TARGET_VISIBILITY`：來源系統能否看見目標或作用。
2. `ENCODING`：能否用自身規則描述目標。
3. `DOMAIN_AUTHORITY`：所在地由誰執法。
4. `PERMISSION_OR_CONTRACT`：是否有技能、契約、任務或目標同意。
5. `EXCLUSIVE_CLAIM`：人格、靈魂、故事或資產是否已被有效唯一契約占有。
6. `SCALE_AND_COST`：量級與代價是否足夠。
7. `RESULT_CLASS`：完整成功、局部轉譯、遭拒、無目標、由域權限改寫或自願介面。

強者可以用足夠輸出破壞載體，卻不必然取得載體背後的靈魂、故事、契約或系統所有權。

## 3. 多重身分與獎勵

- 新系統不抹除舊能力；各層建立獨立 `SYSTEM_ACCOUNT_ID`。
- 一次擊殺只由實際承認該事件且取得有效記錄的系統結算。多系統都提出獎勵時，先查任務條件與貢獻記錄；不得默認五倍經驗。
- 職業卡或星流加點不自動提升獵人覺醒級、玩家等級或 Ego 連結。
- 法律可把多人統稱為「超常能力者」，但行政稱呼不會合併後台。

## 4. 死亡資產裁決

死亡事件至少拆為：

```text
BODY_MATERIAL
SOUL_OR_SELF
SHADOW_IMPRINT
MEMORY_INFORMATION
STORY_OWNERSHIP
EGO_PERSONHOOD_AND_CARRIER
ACTIVE_CONTRACTS
DOMAIN_RECORD
```

裁決順位不是永恆宇宙排行榜，而是：具自我者當下明確意願 ＞ 有效唯一契約 ＞ 所在域執法權 ＞ 先成立的合法占有 ＞ 後來嘗試。若來源系統根本看不見該層，結果是 `NO_TARGET`，不是自動突破。

### 標準案例

- 成振宇先合法抽取影子後，Seongwu 仍可利用剩餘屍體材料，但不能無條件再取得同一完整人格。
- Seongwu 先建立具有排他性的死靈契約時，影子抽取須尊重該契約或只取得不衝突的影子印記。
- Ego 載體被摧毀不等於 Ego 人格立即消失；先查連結、備援與重構規則。
- 星流要復活塔內人物，必須先能看見並取得高塔域權限；「也叫復活」不構成跨域許可。

## 5. Franiya 的裁決

- 本地測定只能回報她願意外放且能被本地編碼的輸出；結果可為溢位或不可分類，不能反推本體上限。
- 本地任務可向她顯示介面、提出交換與記錄域內結果；不能因顯示成功便取得她的本體所有權、記憶修改權或強制回歸權。
- 技能複製只能取得來源系統可描述的本地表現。她若用純短刃技巧，可能生成技巧近似；若使用本體層作用關係，只能得到降格投影或不可編碼。
- 她的投射物效果須先標 `TECHNIQUE_LAYER` 或 `ABILITY_LAYER`。純技巧層受當地物理／遊戲規則約束；能力介入層可在投射物離手後持續改變力、慣性、動量、方向、碰撞與作用權重，本地系統不得以「普通武器不會轉彎」反推她不能控制。
- 能力介入形成的追蹤屬 Franiya 對作用鏈的持續控制，不會把普通箭矢、子彈或飛刀永久改造成可供他人繼承的自動追蹤裝備；本地技能複製也不能只靠目擊便取得其本體權限。
- 她能破壞本地規則，但是否使用取決於自己。戲劇限制來自資訊選擇、關係、救援優先、社會後果與是否願意介入，不來自本地暗中削弱她。
- 本世界沒有已知本地存在因「星座／君主／塔主／系統」頭銜自動與她同級。這不妨礙本地人物在不知道真相時作出錯誤比較。

## 6. 八個交互結果

| 事件 | 結果 | 理由 |
|---|---|---|
| 獵人測定器掃描 Franiya | `PARTIAL_TRANSLATION` | 只讀到可見本地輸出。 |
| 星流向 Franiya 發強制任務 | `DISPLAY_SUCCESS / SELF_OVERRIDE_DENIED` | 域內規則可展示與影響環境，不能覆寫她自我。 |
| 金孔子複製她的短刃技術 | `PARTIAL_TRANSLATION` | 可複製塔能編碼的技術近似，不含本體根權限。 |
| 職業卡覆蓋既有獵人 | `NEW_LAYER` | 新增職業層，舊覺醒能力保留。 |
| 影子抽取與死靈術爭同一死者 | `ASSET_SPLIT_OR_ONE_SIDE_DENIED` | 先拆資產、意願、契約與域權限。 |
| 普通回城道具送人離開 SSS 高塔 | `DOMAIN_DENIED` | 高塔出口權不在道具後台。 |
| 金獨子用《滅活法》辨認 Ego | `NO_INFORMATION` | 書中沒有另一作資料；只能從現象推理。 |
| 本地系統觀測 Franiya 控制普通投射物急轉／追蹤 | `VISIBLE_RESULT / ROOT_MECHANISM_UNENCODABLE` | 可記錄軌跡與結果；不能把能力介入誤登記成武器固有技能或據此複製本體權限。 |
| Franiya 主動接受本地角色殼 | `VOLUNTARY_INTERFACE` | 是她的玩法與公開身分，不是本體被降格。 |
