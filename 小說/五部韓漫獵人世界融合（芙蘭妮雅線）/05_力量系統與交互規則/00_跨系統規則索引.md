# 力量系統與交互規則｜索引

## 1. 不做單表換算

- **[可用]** S 級、Lv.、塔樓層、職業卡星級、故事格位與星座位格只在原生體系內直接有效。
- **[明確否定]** 不建立「五星＝S級＝Lv.100」式統一換算。
- **[可用]** 跨系統只判定事件中的實際輸出、資格、資訊可見度、契約、代價、恢復與所在域。

## 2. 六道交互門

```text
1. TARGETING_GATE      能否辨識並鎖定？
2. ACCESS_GATE         是否有進入該域／資產層的權限？
3. RESISTANCE_GATE     目標以何種本體、契約或故事抵抗？
4. COST_GATE           哪一方支付魔力、概然性、壽命、硬幣、任務或載體代價？
5. RESULT_GATE         命中後改變身體、靈魂、影子、人格、故事還是記錄？
6. PERSISTENCE_GATE    回歸、復活、域切換後結果是否保留？
```

## 3. 資產拆分

同一目標至少拆成：身體、生命狀態、靈魂／人格、影子資訊、Ego 載體、故事／星流登記、職業卡登記、既有契約。成振宇影子提取與柳成宇死靈術若同時瞄準同一死者，沒有跨作原作答案；須逐項判定，不能產生兩個都自稱完整本人的複本。

## 4. Franiya 的位置

- **[可用｜使用者已確認]** 本地量測只能讀到她允許或當場外顯的結果，不能把測量上限當成她的上限。
- **[明確否定｜使用者已確認]** 本地最高存在不能僅憑體系稱號與她同級。
- **[可用｜使用者已確認]** 她若不破壞本地規則，是選擇；不是星流、塔或系統擁有能迫使她服從的更高權限。
- **[可用]** 她的永久性因果破壞等能力仍需寫明實際命中、切斷的關係與後果，不能只用術語跳過場景因果。

## 5. 最小交互事件

正式採用一條跨系統規則前，至少測試：既有獵人選卡、玩家擊殺星流怪物、影子與死靈競逐、Ego 載體受損、星流對高塔人物發任務、Franiya 接到本地 UI。任何結果若讓五套系統同時發獎勵或互讀等級，均 FAIL。
