# 新版重構 v2｜Level 0 縮至2～3章的節奏研究與首次離層方案

> **2026-10-30：作者端更新，優先於舊版「Level 0 十章細綱」及先前「首度停留4～5章」節奏估算。** 這是新版優先試寫的節奏目標，不是強制每層都在3章內通關、也不是先把完整劇情定死。使用者希望全書探索大量不同層級與人事，不要拖成數百上千章；舊40章抵達的位置及大約推進速度可以作節奏參照，亦可彈性改善。
>
> **確認與待測分離**：[已定] Level 0首次旅程優先連到The Pitfalls，之後到Level 9、Level 10、The Safe Place、Level 1；[編排建議] 第2～3章首次進The Pitfalls，若事件真正需要可放至第4章；[尚未確定] 短杖在何處入手、是否先見Redrooms、Bone Thief追逐如何發生、第一章要不要修到包含完整Manila Room事件等。

## 2. 原始Backrooms Level 0與《REDACTED》要分層看

**共同恐怖核心**：泛黃、潮濕、刺耳恆定的燈聲；無人陪伴、空間廣闊且相似、原路不一定能回去、時間和方向逐漸失去依據。這幾件事在[Backrooms Wikidot Level 0](https://backrooms-wiki.wikidot.com/level-0)已足夠支撐「進來之後很難出去」的壓迫感，毋須同一地圖走八章才被證明。

**本遊戲另外加入、作者需要知道但首次未必要用完**：
- **Manila Room**：有自成一處的小空間與音樂，可以承載一次非常具體的異常遭遇。
- **Redrooms／通風口／Glitch Cube**：可作視覺差異、選錯門的威脅或回訪，**不必首次去全套**。
- **Slide Room／Pool Room**：不同出口、物理質感或無法確認的危險；可以一閃而過，亦可首次完全不遇到。
- **Bone Thief**：局部領域的實體，**不能寫成能從任意遠方一路追到任何位置的全圖Boss**。
- **A-Sync設施／The Pitfalls**：具有遊戲來源的自然地域與深坑出口，能接出下一個地理舞台。它是當地的一部分，不是「已知正確出口」的標示。
- 現行來源：[REDACTED Level 0](https://backrooms-redacted.fandom.com/wiki/Level_0)、[REDACTED The Pitfalls](https://backrooms-redacted.fandom.com/wiki/The_Pitfalls)。與[本作既有Level 0層級卡](../03_世界觀設定/層級與地點設定/沈耀重寫版_Level0完整層級卡.md)互相校對。**遊戲內一切HUD、實體固定刷新點、攻略已知出口、觸發線，不等於沈耀知道的規則**。
- **出口差異**：經典Level 0常可透過異常／閃爍牆進Level 1；我們已選的小說路網首站是**The Pitfalls**。因此向番茄作品學的是**第2～4章就首次離開 Level 0**，而非強迫改成第3章直接進Level 1。

## 3. 優先測試的新版3章Level 0結構

| 章節 | 一章裡真正應發生什麼（可重組） | 不要寫成什麼 |
|---|---|---|
| **第001章** | 現實人物與正常生活；意外切入；最初的求救和第一份空間異常；**若有餘地，讓Manila Room音樂導向一個有實際後果的小事件**，章尾不是純粹「牆後有人嗎？」 | 三千字現實→兩千字查訊號與記號→戛然而止；或一章完全只驗證一面牆的方位 |
| **第002章** | 隨不同場景出現的變異，沈耀不得不作出一個錯誤、危險或有明顯代價的選擇；本章推動他離開熟悉的黃色區域並真正承受後果。可遇一處增添色彩／地標的房間，但**不能像攻略路線展示所有出口** | 人物逐項檢查Redrooms、Slide、Pool、Glitch、Moai；每項都記筆記再回頭 |
| **第003章** | 某條已建立的危險因果收束：若選用Bone Thief必須真的碰到其局部領域；遭逢A-Sync痕跡或深坑時，做出**無法百分百確認安全的現場選擇**。本章末或附近**首次離開Level 0，進入The Pitfalls** | 突然主角以遊戲知識知道下面有減速；或為了第3章通關在任意地方召喚Bone Thief；或卡在準備跳坑的懸崖把下一章也耗在同一個動作 |

**第四章的開放用途**：若前三章自然未收束，Level 0可到第004章，但要有新的劇情因果；否則**第4章應已處於The Pitfalls，並且可以開始銜接Level 9**。不可為滿足「下章換地圖」而硬截斷真正有重量的故事；也不可因原本十章有十個地標，拖回八至十章。

**首次切層不等於必須先取得神器**：短杖在 Level 0 入手或更晚才入手都可，只要人物經歷與物件流轉合理，初得能力不變成禮包，且不失去本世界已建立的神器來源和限制。若短杖遺留舊房間，允許多次回訪才發現；不必在第3章安排資格試煉。

## 4. 如何快，但沒有匆忙感

1. **每一章需有相對完整的現實發展**：一次重要認知更新、一次實際失誤、人物對真實處境的反應或危險與選擇。不是每章都得擊殺實體或強迫資訊揭曉。
2. **一個恐怖體驗，通常只需一兩次不同角度的建立**。黃色走廊的壓迫與空間錯亂已成立，就讓下個場景導入更不同的人事，別每次都重新證明無法依左右辨路。
3. **一個層級的戲劇功能決定篇幅**：路過層級可幾頁甚至併入一章；具有獨立關係、私人情緒或重大衝突者可自然停留數章。Joke Hub、Level Fun等不必因地圖多或NPC多而自動擴至十章；也不能讓完整情感線被壓成路過照相。
4. **章節篇幅**：可用每章約8,000～12,000**中文字元／含標點字元**作長篇通常閱讀參考，但**不以字數逼出重複描寫**。新版首章v1約5,436總字元／4,344中文字，本身尚像故事前半；優先「增加真正事件、刪除重複流程、適度延展Manila段」，而非純為湊長。
5. **原40章的路線速度可作有用尺度**，但舊稿很多篇幅花在反覆測試、情報解說、過早揭露人物心境；新人事和地圖推進可以比它更密實，不必重新把省下的篇幅塞回空間紀錄。
6. **不把全書鎖成60／100／200章**。可將60～100章作早期粗估而非承諾；真正結束取決於幾條重要人物線、旅行與感情長線是否完成。避免把上百個層級清單誤作上百個必走關卡，也避免無限新謎團。

## 5. 第一章v1的具體返工建議

- 目前[〈牆的另一面〉](../09_新版正文試寫/第001章_牆的另一面_試寫.md)約5.4k總字元，已具同事／家人生活、切入後求救、牆壁與個人記號錯位；**保留真正有生命力的對話，不要為快節奏把前半變成3行角色簡介**。
- 現在收於牆內似乎有人拖動椅子；**這是懸念但還不足以自成第一章事件收束**。可以把Manila Room裡的音樂、物件與一次真實危險／誤解／機會展開到第一章內，並讓他付出實際代價或得到足以改變接下來決定的經驗。這裡是否有活人要符合Level 0人際隔離設定，不能為湊戲憑空出現另一名流浪者。
- **第2章就要發生不同種類的事**，不是繼續列GPS、電量、記號或牆壁不同顏色。
- 進入The Pitfalls必須有現場推動的理由：A-Sync留下的器材可能提供不完全、可能誤導的安全提示；他真實害怕、選擇、受傷，而不是知道下面不致命所以「理性跳下」。
- 不先規定他一定見過Redrooms與所有出口。真正值得記住的其他區域可以到後期回訪時再用。

## 6. 這份研究**沒有**證明的事

- 無法僅由番茄公開目錄推導**受歡迎的因果機制**；「高評分一定因為第3章到Level1」不是已核事實。
- 沒有核對到每部受歡迎作品全文的場景節奏或具體表現技巧；以上主要有**目錄級證據**，第一章內容僅部分可讀。不可主張這是對數十部暢銷小說的完整研究。
- 不必像別部作品主角先讀過M.E.G.的百科或生存指南；我們的沈耀當時不知道Backrooms，這個認知差是刻意的故事選擇。
- 第三章從Level 0出來的安排是**本作優先試寫節奏目標**，不是在未寫時就已發生的Canon。

**真正採用的一句話：早點讓讀者看到「世界還有別的地方」，但不要跳過讓人物活在場景中的必要時間。**
