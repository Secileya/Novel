## 效力分層，**這是整包最重要的規則**

| 註記 | 意義 | 可以直接用嗎？ |
|---|---|---|
| **【固定／有效設定】** | 使用者已確定的人物DNA、世界運作、特殊物品本質、八名Mimic既定舊交等；後期明確修正優先 | 可當作者層真相，但不得無資訊來源塞進角色腦袋 |
| **【遊戲或專屬Wiki已載資訊】** | `THE BACKROOMS [REDACTED]`及其專屬Wiki的層級、NPC、地圖、機制 | 先核對遊戲版本／來源頁，分清遊戲UI、資料庫文體與世界內事實 |
| **【小說世界線固定新增】** | 原遊戲未必有的Stiliya／Versiliya舊旅行、部分人物關係與禮物 | 對本小說為作者真相，**不是**原遊戲官方故事 |
| **【參考／候選】** | 可以採用的相遇、層級走訪、情緒回收、特殊危機或地點改寫 | 可討論、改順序、合併、推翻；**不是正文必發生** |

| **【未驗證／待查】** | Wiki版本衝突、未有官方來源的種族能力／出口、個人真實知情等 | 必須標不確定；不可推測成確定數據 |

**衝突排序**：使用者後來明確撤回或修正 ＞ 專案最新明確定案 ＞ 較新的完整補充 ＞ 與之相容的舊設定 ＞ 候選方案／舊草稿。專屬Wiki不是自動支配本小說獨立改編，小說已修改的遊戲機制應如實標「小說世界線」。

## 作者視角 ≠ 角色視角 ≠ 公開消息

| 層級 | 寫什麼 |
|---|---|
| A｜作者真相 | 原理、真正身分、已成立私人過往、能力上限與來源 |
| R｜讀者從正文實際得知 | 有沒有真正演出／揭露；讀設定包本身不算 |
| K｜指定角色實際知道／猜想／誤信 | 來自親眼目擊、被告知、讀檔案、直覺或推測 |
| D｜已對外說／寫／展示 | 具體人物、對象、說法、時間與場景 |
| U｜第三方實際接收與轉傳 | 對方是否聽到／讀到／相信、能否再傳播 |

本包的**作者層資料可能直接劇透未揭露真相**，不能因新模型看過資料便讓沈耀知道雙翼姓名、每個Mimic的過去、實體分類、某條出口目的地或秘密房間完整來歷。

## 全局不能混淆的事

- 本小說以Roblox`THE BACKROOMS [REDACTED]`為主要後室基準，混合Wikidot／Fandom來源與遊戲獨有內容，**不是統一的所有後室版本**。
- **死者真的死亡**：Level 0黑X「死了會回來」是來源不明、錯誤的世界內留言；沒有遊戲通用重生。
- **Stiliya／Versiliya是超越後室尺度的旅行者**：她們自願體驗，不是被層級規則限制；有生活、友情、強烈愛意、玩笑和界線，不是只會留下線索的背景神明。
- **雙翼神器不是兩人的力量完整轉移**：沈耀會受傷、疲累、缺水、誤判與死亡；它不讀心、不自動救人、不會讓Mimic全部倒向他。
- **八名核心Mimic真與兩人有過不可取代的過往**，但八者獨立、並非一群自動認人或共享所有故事的接待員。
- **Level Fun仍非常危險**：Partygoers對舊友的複雜感情不等於不再獵殺人類；保留房不是獎勵房，也不是誰持有翅膀圖案都能進。
- **層級路網不屬章次計畫**：新交通、高度危險路線、Level Fun、Bonus、Neon Express均可回訪；詳見`050`。不要把原先某章出現某Level當作承諾。
