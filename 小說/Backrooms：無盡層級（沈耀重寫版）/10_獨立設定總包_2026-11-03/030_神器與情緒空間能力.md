## 一、客觀來源與意義

短杖由Stiliya與Versiliya**共同留下**，不是某種系統獎品，也不是她們把全部根源級力量灌給人類。Versiliya構成鐮刀、切斷和強硬保護的骨架；Stiliya構成情緒殘響感知、辨認、控制、凝定與防止誤傷；兩人共同留下雙翼標識、對真實雙翼痕跡的共鳴、旅行接縫記憶及輸出限制。

神器主要使命是提供「察覺被忽略的情緒／規則痕跡」「在特殊異常面前有限度介入」「讓旅行痕跡被繼續走過」三種**可能性**。它不指定善惡、不下任務、不替沈耀做所有選擇。與兩位超然原主的完整力量完全不可同尺度比較。

**取得原則**：使用者最新偏好為沈耀是兩人留下短杖之後，首位真正在原址親手把它取走的持物者；不安排商販、隊友、其他NPC先拾取再轉交。這不代表雙翼預言沈耀會來，亦不等於「認主之屋」或有固定四條通關考試。短杖首次觸碰時可以沒有特殊反應。具體房間與啟動時間仍可改寫。

## 二、外觀三形態

| 狀態 | 真正外形與特徵 | 功能 |
|---|---|---|
| **完全休眠黑短杖** | 約35–45cm；黑色、偏冷，材質近金屬／石／骨但無法歸類；沒有按鈕、接縫與可拆元件；兩枚極細翼痕（藍紫的細翼、黑紅的蝠翼）不明顯 | 只可當極堅固、相對小巧的物理探測／敲擊工具；**沒有殘響感知、導航、自行救命** |
| **部分啟動短杖** | 兩側翼痕可能從材質深處浮出微色，不是每次發光、每次遇NPC都自動特效 | 可逐步感知真實情緒、殘響與少量異常接觸；**無法自動展開鐮刀** |
| **雙翼鐮刀** | 杖身延長、暗色刀刃翻出；斬普通物理物件通常是深黑刃，觸及異常連結才顯藍紫／黑紅細線 | 具體斬實與後續干涉能力；首次展開並不使沈耀掌握專業鐮刀格鬥 |

**同期限制**：若持物者受傷、體力崩潰、精神遭重壓或能力超限，可能無法維持形態。神器的異常耐久不代表使用者無損；格擋受力仍可震傷手腕、讓人被擊飛。

## 三、十一類能力

| 能力 | 可確知作用 | 邊界、代價與最常被寫錯之處 |
|---|---|---|
| **① 殘響感知** | 感知**當下情緒**與**留下的真實情緒殘留**，可比較大致方向、質感、重量及是否群體重疊 | **不是讀心／記憶回放／測謊器**。可靠的是客觀情緒存在與大致方向；人對距離、動機、對象的解讀可能錯。接觸最清楚，同室次之；隔牆只可能收到夠強的訊號。過量可胸悶、耳鳴、失衡、外來情緒壓過自身 |
| **② 真痕共鳴** | 辨認雙翼真正使用或改動過的物品、空間、深刻接觸者及具有同源影響的舊殘響 | 可能只有極輕牽動；不是「每次見到雙翼畫就發光」；有舊交者仍可警戒或敵視持杖者。其他人重畫一張畫不等於雙翼親筆真痕 |
| **③ 行跡記憶** | 記住**自己與持物者親自走過**的空間接縫觸感，察覺同類或不同類的路 | 不是地圖、GPS或目的地預知；無法替別人記住未曾經過的路；同樣接縫亦不保證抵達同Level |
| **④ 異常接觸** | 短杖也可碰觸某些半實體、黏附異常物、位移邊緣與虛假聲學接縫 | 「碰得到」不等於「能擋住／傷到」；接觸遠超輸出上限之物時仍會受其壓迫 |
| **⑤ 鐮刀展開／斬實** | 展開後刃口可讓目標的可見形體與真正異常承載處短暫重合，使已命中斬擊**真實成立** | 不是輸出倍率、必中、隔空砍、必殺或全自動武藝；傷口深度仍視體力、角度、命中處、體量；只能處理真正碰到的部分。首次展開有反作用與耗竭 |
| **⑥ 凝定** | 將已存在、正在閉合／崩落／位移的一段小範圍異常狀態暫時維持，換取數秒到短時間的處理機會 | 不是停時間、不是創造新出口；要直接接觸實際承載點，需持續專注；範圍越大、變動越激烈越難維持 |
| **⑦ 斷連** | 切斷**已存在、可辨認、有承載點**的異常追蹤、污染連結、強制支配、錯接空間等 | 先辨認→必要時凝定→由沈耀自己判斷後果→再切；不能切抽象命運、人格、他人的普通感情；錯切可能令出口與陷阱一同毀壞、傷到宿主 |
| **⑧ 破界** | 在本來就薄弱／錯位的空間邊界製造短暫可通行切口 | 不能普通牆隨處開門、不能指定目標Level；切口可通過的人有限，可能進入更危險區或不完整空間，反覆使用會失穩 |
| **⑨ 護痕** | 在真實門、人、物品或小型休息處留下有限期防護痕，降低輕度異常侵蝕或提供觸發警示 | 非全方位護盾；不防普通子彈、普通物理攻擊或所有污染。前期同時一枚、熟練後最多兩枚，超限會破碎 |
| **⑩ 回響傳遞** | 經接觸傳遞沈耀此刻真正具有的某種情緒／極粗略意向給能感受情緒的存在 | 不能偽造不存在的愛或信任、不能傳句子／影像／作戰計畫；受者可拒絕、誤會甚至暴怒，蜂巢可能情緒反灌 |
| **⑪ 雙翼合用** | 藍紫辨認／穩定，黑紅切斷／排斥，於**同一個已理解的核心問題**中複合運作 | 不是重寫整個Level或創造萬能免疫；同時承受被留下與被切掉之物的情緒壓力；超限時鐮刀強制收回並休眠 |

### 額外高階組合：歸徑

**歸徑不是第十二項獨立權能**。它結合「行跡記憶＋預先留下的護痕錨點＋凝定＋破界」，試圖在**真正走到底**且正在閉合／轉場的路線中找一條極短的歸路。

前提：本人攜神器走過原接縫、實際留下錨點、真正抵達支路終點，且結局仍有可抓住的接縫；成功也只可能回最近仍有效錨點附近。錨點通常一次消耗；使用會導致失明、失向、舊傷裂開、劇烈疲勞與可能數日休眠。**不能倒流時間、復活同伴、讀取存檔或隨時放棄冒險直接回家**。

## 四、可靠感知和人類誤判必須分離

殘響感知傳來的「確有恐懼、方向大致在左方、重得驚人」應是可靠感官訊息；「是不是一個人在哭？是否想殺我？離我三公尺？」則是角色自己的判斷，完全可能錯。強烈情緒的重量同時取決於強度、持續、關係深度、反覆行為、是否深入環境或群體，而非只依年齡或秒數。

正常寫作應像對待視覺與聽覺：沈耀可以逐漸信任感官，但不應每次都突然跳出一份「悲傷63％、敵意15％」報表。精神與情緒代價是實際負擔，卻不把能力寫成毫無可靠性的幻覺。

## 五、成長結構（**能力層次，不是章節計劃**）

**物理短杖→首次情緒與真痕的感受→可主動接觸異常→第一次鐮刀與斬實→辨認、凝定、護痕、斷連、回響傳遞的精細運用→蜂巢級情感分層→高風險破界／雙翼合用／歸徑。**

時間點不鎖定Level 1或Level 7；核心是逐次學會**看懂與選擇**，而非每換層必獲技能點。原稿中四條房間條件、固定第幾關考驗及與舊四人隊伍綁定的初次展開案例均為歷史版本，不自動採用。

## 六、絕對不能做的事

不能自帶百科、遊戲介面、導航、任務提示、復活功能；不能自行飛回持有人、主動護主、讀心、測謊、判善惡或遠距掃描整個Level；不能讓所有認得雙翼者都變成友善NPC；不能任意指定傳送地點、永久消去整個層級、逆轉已發生死亡；不能把強度和冷卻寫成無視傷勢／情緒壓力的固定遊戲數值。

**任何真正舊友看到短杖後的驚訝、欣喜、眷戀或戒備可以很強，但那是角色本人的情緒，並不是神器替她朗讀內心故事。**
