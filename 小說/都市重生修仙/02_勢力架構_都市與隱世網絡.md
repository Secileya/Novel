# 勢力架構｜現代都市、武道圈與隱世仙道網絡

> 狀態：勢力「多層、各自具社會功能」為討論中接受的整體方向；**以下組織名稱、全國版圖、具體權力分工多數為〔PROPOSAL〕**。不可將草案勢力或人物當作已在正式正文登場。

## 一、總設計：現代都市不是武道世家的附屬背景

城市有獨立的公共制度、家庭生活、學校教育、公司治理、文化娛樂、交通與醫療資源。暗勁高手／武道宗師的力量可以改變某個地方利益平衡，卻無法替代企業管理、司法、政治協商、情報、銀行、全球運輸、軍事組織與醫學研究。

異能和修士情報分層流傳：
- **普通大眾**：或許聽說武術高手、民間傳說、詐騙大師，並不確認修仙。
- **一般富豪／政商圈**：有人知道某些武館高手、古武世家與特殊保安，仍不必知道完整境界。
- **武道圈中層**：懂內勁門檻、各派交涉禮儀與若干宗師名聲。
- **全國頂級武道界**：可能知道宗師名錄、神境爭議、個別高層情報。
- **少量隱世修士與國家核心專家**：較了解地脈、功法、法器、秘境與真正修仙途徑。
- **主角及部分高層人物**：主角擁有前世仙道理解，但不自動了解這一世每名普通人的意圖與每個家族尚未發生的秘密。
五位 OC 擁有自身觀測與力量設定，是否使用不能由普通角色的情報上限機械規定。

## 二、勢力類型總表〔作為世界觀分類候選〕

| 勢力類型 | 可能實際控制的資源 | 不能簡化成 |
| --- | --- | --- |
| 國家政府與特殊事務部門 | 法律、情報、調查、武裝、公共管理、跨地區行動 | 專供宗師打臉的無能官方 |
| 武道總會／地方協會 | 武館登記、比武規則、師承交流、武道情報、資源仲介 | 每個人都是宗師的軍隊 |
| 地方武館／拳館 | 教學、弟子、社區聲望、場館、私人保安 | 只會圍觀主角的嘍囉 |
| 古武世家 | 傳承、地產、產業、家族人脈、古老關係 | 一家數十宗師的無限刷怪點 |
| 古武宗門 | 武學、師徒、閉關山門、技藝與隱私 | 所有宗門都等於修仙門派 |
| 隱世修仙道脈 | 真正煉氣功法、法器、符籙、靈脈、丹方 | 遍地築基金丹的公開商城 |
| 資源商會與拍賣行 | 藥材、玉石、古物、真偽鑑定、供應鏈 | 永遠拍到同一件神器 |
| 豪門／財閥／企業 | 金融、醫藥、房產、物流、人才、媒體 | 有錢就等於會修仙 |
| 地下交易與犯罪網絡 | 非法委託、走私、假靈藥、黑市情報、地下擂台 | 永遠只有惡人等待主角斬殺 |
| 海外與跨國勢力 | 海外武術傳承、研究機構、商務與外交 | 只用來一批批提高敵方等級 |

## 三、國家官方：制度不應淪為固定配角

**候選機構名：華國特事局／特殊事務調查局。** 其起源、法定職權、設立年代尚未定案。可負責超凡事件的專業聯絡、調查、危險評估、事故封控、跨省協作及與武道界談判。

- 真正可以倚賴的是國家情報、指揮資源、技術與聯合執法，**不以麾下有十數位宗師來證明強大**。
- 內部有行政、科研、法務、情報、行動與對外窗口，不是全員戰鬥系。
- 不會為每場鬥毆派出高層；按照社會影響、傷亡、財產、保密需求與政治後果動用不同級別資源。
- 可以同武道世家、宗門與富豪合作，也可能因法律、秩序和公共安全與之衝突。
- 對主角態度不必「知道能打就跪拜」，可先關注證據、身分、行為風險、是否願意遵守基本法律與社會秩序。

## 四、武道總會與地方武道圈

**候選機構名：華國武道總會。** 若採用，設全國與地區分會，但主管範圍、是否官辦、是否半民間、證照制度與裁判權仍需決定。

- 主要日常：武館交流、比武、師承糾紛調解、珍稀武學討論、情報互通、從業者利益、武道青年選拔。
- 內勁高手就能是地方重點人物，不必靠化境宗師到每場會議坐鎮。
- 真正的宗師可以是受尊敬的顧問、榮譽席位、獨立人物或隱居者，**不必人人受總會直接指揮**。
- 可以有正派、重利、保守、革新與腐敗人物，但組織不作全員善惡定性。
- 武道聚會既可以發生技擊，也可以處理傳承合同、弟子爭執、賠償、流派權益與地盤。

## 五、古武世家與宗門：按傳承與資源分層

| 候選層次 | 通常可合理寫的重點 | 對宗師稀有度的意義 |
| --- | --- | --- |
| 地方武學家族 | 明勁或內勁初中段，與地方企業／武館往來 | 沒有宗師仍可影響一城 |
| 地區大型世家 | 內勁後期、數名骨幹、重要產業與弟子網 | 高階內勁就足以坐鎮 |
| 全國一流世家 | 內勁巔峰、與宗師的師承／人情關係 | 不必有現役宗師才能有大名 |
| 宗師坐鎮世家 | 有一位真正宗師；繼承與宗師年歲成重要問題 | 視為全國罕見頂級節點 |
| 歷史名門宗派 | 古代曾有宗師、藏典籍或具有名義傳承 | 名聲不等於現役戰力無限 |

**候選宗門名稱：蒼岳門。** 只是方便描述的起始名字，尚無已確立掌門、宗門所在地、弟子數與祖師史。

這些勢力需要地方生活紋理：弟子如何謀生、武館如何收徒、武學是否收費、家族如何與街區互動、公司與武館的保險或保安委託、婚姻關係、鄰近居民怎樣看待。不要每個「百年世家」只有高牆豪宅和囂張少爺。

## 六、隱世修仙道脈：不與世俗武道自動重合

**候選名稱：清微觀。** 可保留道觀、閉關、法器、符籙、煉丹、地脈與少量修士，但尚未鎖定是否為純道教系統、師承時代和勢力等級。

- 有些家族僅練武卻保有古修士斷代典籍；另有些修行道脈對正面戰鬥不擅長，但擅長丹道、陣法或物理／地理佈置。
- 門中真正能煉氣的弟子可以非常少；築基、金丹是否存世屬開放問題。
- 與現代社會的接觸可能透過藥材、古籍修復、私人捐贈、山林保育、地質勘查、文物、宗教或學術。
- 主角能輕易識別功法疏漏不代表隱修者必然俯首；他人也有倫理、傳承與不能立即放棄的使命。
- 真修仙者不必人人比武道宗師強；法器／專長／準備與資源差異是重要劇情材料。

## 七、資源商會與拍賣行

**候選名稱：萬珍閣。** 公開部分可經營高端古物、藝術、名貴藥材與合法拍賣，私下則有武道與少量修士的資源渠道。

完整流程不只「發現寶物→主角撿漏→眾人震驚」：
1. 物品如何取得？是否有真偽證明和權屬爭議？
2. 物品為何在普通市場被誤判？是缺少專業、遮蔽、功能損壞還是另有目的？
3. 主角為什麼需要它？是修煉、鍛器、救人、保留，還是交換？
4. 出售者、競拍者、鑑定師、買家各有什麼動機？
5. 誰得知結果？誰沒有看到？消息沿何種關係網擴散？
6. 物品帶出後如何保管、使用、合作、引發爭奪與後續影響？
「撿漏」可以是真爽點，但不等於每場拍賣都有只有主角看得懂的絕世寶物。

## 八、財團與都市神豪元素〔少量點綴〕

- 大型企業可以跨醫藥、科技、能源、物流、地產、食品、娛樂與銀行；個人富豪的身分不必總是有武道背景。
- 主角可以因救人、投資、鑑寶、藥材交易、配方合作或保護而獲得資源；獲得股份、人情與現金，不能自動推導永遠掌控整個集團。
- 有專業管理者、合夥人、風險、商業保密、合規及利益衝突。
- 讓企業人物真正能做主角不擅長的事，才不會在主角擁有仙尊知識後全部失去存在價值。
- 富豪、明星、會所、慈善、私人遊輪、豪宅、跑車、拍賣等可以出現，但不以每天花錢刷返利驅動主線。

## 九、地下武道與犯罪生態

地下擂台、走私、非法珍寶、偽藥、僱傭安保與情報中間人可增加都市質感，但每種類型應具有不同利益與風險：有人專做真偽鑑定，有人販售稀有藥材，有人幫富豪找私人醫生或武館供奉，有人涉黑；不是見地下勢力就必定是屠城級敵人。

對犯罪與復仇應按具體行為追查責任，不因身分或說一句狂話便自動證成滅滿門。主角可以強勢，但世界仍有因果與社會後果。

## 十、地域與國際擴張

- 普通縣城：武館師傅、少量明勁／內勁、熟人社會。
- 地級／中型城市：內勁人物、商會、武學家族、地方官民關係。
- 一線都市：更多資金、國際企業、武道情報交易和高階修煉資源，而非必定一城多宗師。
- 首都／核心武道中心：宗師出現機率相對高，但仍極稀少。
- 隱秘山門／秘境：人少、封閉、資源特殊；不必套用同一城市人口邏輯。
- 國外：同樣有社會制度、武術文化、企業、國際政治和研究體系；不能只作「外國高手來被主角打臉」。

地域、國名、人口、核心城市地圖尚未正式鎖定。

## 十一、固定寫作邊界

1. 宗師數量必須由總體稀有度約束，而非每個勢力先放兩名。
2. 武道地位／財富／政治／個人戰力要分開衡量。
3. 五位 OC 不必登記在官方強者名冊；沒有證據的外人不得自然知道其真實家庭背景。
4. 每個勢力有可能幫主角、反對主角、保持中立或轉變立場；不可全員效忠或全員作惡。
5. 會談、委託、拍賣、救治、投資、科研都能是重要事件，不能每一輪只寫鬥法。
6. 名稱「特事局／總會／蒼岳門／清微觀／萬珍閣」是方便延伸的待定候選，今後若使用者另定名稱，直接按正式決議修正。
