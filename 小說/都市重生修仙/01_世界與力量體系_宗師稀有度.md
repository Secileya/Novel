# 世界與力量體系｜開局宗師稀有度、武道與仙道分野

> **【2026-10-24 新增：跨所有小說通用的 OC 本體絕對無敵】**本小說的宗師、仙尊、仙帝與其世界法則是真正強大的本土體系，但使用家族原始本體設定的 OC 相對此**完整本土力量體系客觀絕對無敵**。這不是重生仙尊專屬特例，而是家人進入其他題材小說時同樣適用的共通硬規則。唯一需要區分的是 **OC 自己選擇**遊戲角色殼／特殊活動規則時，受限形式可有正常輸贏（如 Franiya 玩遊戲），並不意味其本體被當地力量擊敗、傷害或強制削弱。家內相對實力排序不變。以 [家庭共通 13 第零節](../家庭總檔/13_跨世界力量體系與客觀層級差_共通寫作準則.md) 為權威。

> 狀態：宗師「開局極稀少」為〔USER-FIXED〕。境界用詞、精確人口、地域與國名屬〔PROPOSAL〕或〔OPEN〕，需嚴格分層。

## 一、世界觀基調

現代都市表面是完整的世俗社會：家庭、學校、企業、資本市場、醫院、新聞傳播、政府、公共安全、普通法律與現代科技照常運行。武者和修仙者存在，卻沒有讓所有人都把宗師當成隔壁鄰居，也沒有令現代文明因少數修行者而失去全部自主性。

地球可以有古武世家、地方武館、武道圈人脈、宗門和秘密交易；更深處可以存在修仙傳承、靈脈、洞天福地、古代遺跡及對星空修真界的線索。上述是助手建議的分層背景〔PROPOSAL〕，是否統稱「地球」、具體國家架構與修仙起源仍可調整。

**最堅固的開局判準：宗師是武道界的稀有頂端人物，不是常見中層單位。** 主角與家庭 OC 能遠超他們，不會使宗師對一般社會突然失去真正價值。

## 二、世俗力量不等於武力數值

- 普通人占絕大多數；地方政府、軍隊、法院、媒體、金融、產業、學術與醫療不因修仙存在而停止運作。
- 有權勢的商人可能控制上市公司、供應鏈、土地與僱員，卻不表示能指揮宗師；宗師能打敗普通保鏢，也不表示他懂得經營企業、掌握完整產業資料或有治國能力。
- 現代武器、戰術、情報、監測與法制會使超凡衝突受到真實限制。對不同境界的有效性應依能力、裝備、情報和場景判斷，避免「宗師可以無代價對抗整個國家」與「普通警械瞬間處理所有修士」兩個極端。
- 武力不會自動等同社會評級；醫師、企業家、朋友、親戚、學者、特種技術人員都有自己的獨特作用。

## 三、武道層次：兩種討論版本的來歷

### 版本 A：早期提案〔PROPOSAL，後續有更新建議〕

外勁 → 明勁 → 暗勁 → 化勁宗師 → 罡勁大宗師 → 神境。

此提案曾配上表現：明勁為全身發力；暗勁為深層勁力控制；化勁可以開宗立派；罡勁比宗師更罕見；神境在開局無公開活動記錄。但這是助手將多部類型作品常見寫法混合的草案，**不是哪部作品的唯一官方境界**，亦未由使用者逐一確認。

### 版本 B：較後提出的精簡經典都市武道方案〔RECOMMENDED PROPOSAL〕

| 地球武道名目 | 位置與敘事用途 |
| --- | --- |
| 外勁 | 正式習武者；外界仍常能接觸到武館、武術圈 |
| 內勁 | 真正高手、家族骨幹、門派核心；內部分初中後期可待定 |
| 化境宗師 | **極其稀有**，可開宗立派、坐鎮地域，具有巨大聲望與現實影響 |
| 神境 | 超越宗師的傳說級強者；公開活動者可能屈指可數 |
| 地仙 | 近乎神話，可與更深仙道傳承接軌；是否採用尚待定案 |

助手依較接近《重生之都市修仙》類型的風格推薦 B。使用者只明確鎖定「宗師很少」，**尚未在 A/B 間明確選一版**。因此不可把「罡勁存在」或「地仙必定存在」寫成正典；到正式正文前可以再擇一或建立第三版。

### 同境界也不必相等

即使採 B，也不應把每次對決變成無條件同境界秒殺。武學、內勁品質、實戰、機動、兵器、地形、戰術、團隊和個人狀態可令結果不同；更高境界通常優勢顯著，但人物不會被完全取消個性與技術。

## 四、宗師人口尺度：重點區分「稀少」與「精確數」

### 使用者已確立〔USER-FIXED〕

- 故事**起點**宗師極為稀少；開局更不能把宗師當成每個城市、豪門都有的免費供奉。
- 一位真正宗師出現、接受委託、坐鎮家族、授徒、受傷、失勢或隕落，本身具備社會、門派、政治與情報重量。
- 主角可以早早強過宗師，但不能為了給主角刷戰績，臨時向同一城市追加五十位毫無前史的宗師。

### 曾經討論的具體示例〔PROPOSAL，非正式定員〕

助手提出過一個人口超過十億的架空大國「華國」：
- 化境宗師「可靠確認」約 **8～12 人**；
- 華國境內「估算實際存世」約 **15～25 人**；
- 罡勁大宗師約 **0～2 人**（僅在版本 A 用語下）；
- 已確認公開神境人物 **0 人**。

這組數字的**目的**是可視化極度稀有，而非表示作者必須照此設定。若將來採用，應先定義是否含海外國籍、隱世、壽命、宗門閉關者、修仙者是否統計等。不能用「還有沒被發現的」無限制增加數量，也不能反過來讓這些估值成為世界內所有人都知道的精確名冊。

### 實際場景效應〔可用寫作判準〕

- 普通縣城可能只知道有名的武館師傅；城市名流即使財富巨大，也未必親眼見過宗師。
- 千萬人口大城市可能沒有常駐宗師；暗勁／內勁中高層便足以成為地方核心人物。
- 百年古武世家若現役真有一位宗師，已可列為頂級勢力，而非靠「家裡藏著十位宗師」製造震撼。
- 地區武道交流、拍賣、宗師生日、武館衝突，主角能影響局勢不表示每場都需宗師參與。
- 真正宗師戰敗會牽動弟子繼承、盟友重新站位、保護約定、家族利益、武道總會與國家監管；「打完就刷新下一名」不符合稀有規則。
- 神境／地仙在開局可僅是記錄、爭議或零星高層情報；不能在第一卷以多名隨身保鏢形式出場。

## 五、真正修仙與武道屬不同技術路徑

**仙道修士不是沿地球外勁→內勁→化境練上去**。他們若吸納靈氣、凝煉法力、修術法、符籙、丹藥、陣法、神識及本命器具，應擁有不同的修煉方式與消耗條件。

### 修仙境界候選〔PROPOSAL〕

- 感氣／引氣：初步感知靈氣。
- 煉氣一至九層：入門到成熟的基礎仙道修煉。
- 築基：重要生命／法力質變。
- 金丹：更高仙道門檻。
- 元嬰、化神：地球早期近乎傳說。
- 煉虛、合體、大乘、渡劫：可留給星空修真界。
- 真仙與其上：可留給主角前世仙界記憶、後期宏大世界。

這是一個經典修仙階梯**候選**。前世主角究竟修到何處、是否使用真仙／仙尊術語作為境界名、境界是否另有拆分，仍待後續定案。

### 嚴禁機械換算

- 一名煉氣初期修士可能難敵強大內勁武者；另有人有術式、特殊器物或傳承可以跨層取勝。
- 築基修士通常擁有超出一般化境宗師的綜合潛力，但不是寫死為「築基等於十位宗師」，也不是所有築基術式都擅長正面決鬥。
- 地球宗師能否看出修士境界，取決於對仙道傳承與感知知識的掌握；不能人人天生懂得仙界術語。
- 主角若重生後修到煉氣低階就能壓過宗師，是**跨體系的技術與眼界優勢**，不是「三天修煉便完成地球武道化境的完整進階」。
- 修仙者本身也不無限產生修煉資源；天材地寶、地脈、修煉環境、時間與材質依然可能成為情節因素。

### 地球隱世修士人口示例〔PROPOSAL〕

助手曾提議：一個架空大國內真正有持續煉氣傳承者僅數十到上百人；築基存世 0～3 位；金丹沒有可信的當代公開紀錄。這份估計與宗師數字一樣尚未正式定案，**不能假裝是使用者已指定的精準統計**。

## 六、力量舞台逐步擴張而非無限通膨

| 敘事舞台 | 敵友、社會與資源面貌 | 實際核心 |
| --- | --- | --- |
| 開局城市 | 同學、親族、普通商界、武館、內勁高手、少量特殊事件 | 前世遺憾、生活變化、重新修煉 |
| 地區武道界 | 世家、門派、武道交流、真正宗師、地區資源 | 勢力、人脈、聲望與罕見宗師重量 |
| 國家／國際舞台 | 國家部門、特殊組織、海外傳承、傳說級人物 | 政治影響、情報、高端資源 |
| 隱世仙道與秘境 | 修仙傳承、洞天、古代遺跡、神境／地仙的真正情報 | 法器、宗門、修行規則 |
| 星空修真界 | 仙宗、星域文明、仙道上位境界 | 主角的另一段人生與大世界 |
| 仙界／諸天 | 前世故人、道統、盟友與敵手、巔峰之路 | 長線回收，而非開局搶戲 |

表中屬推薦展開曲線，不等於已敲定每卷章數。舞台變大後，地球舊人與都會生活也不應被一次性拋棄。

## 六之一、跨世界層級差不能用「修煉體系不同」抹平〔2026-10-24 新規〕

地球宗師、仙尊、後期仙界仙帝有各自真正的戰力與法則理解；五位 OC 在家庭正典中也有確立的高層本體和個人權限。**當兩邊確實存在客觀巨大層級差時，不可為了安排「不同體系的公平戰鬥」自動把強弱寫得差不多。**當地頂尖強者可以真強、真聰明，卻不保證其大道能支配 OC 本體。若未來仙尊觀測高層能力，可能因此改善法則認知、功法效率與修煉速度，但**得到可自行驗證的啟發，不代表複製 OC 根源權能**；重大效應主要在後期修仙界。具體評估請見[家庭共通 13](../家庭總檔/13_跨世界力量體系與客觀層級差_共通寫作準則.md)和[本線 12](12_仙尊與OC_力量層級和後期仙界認知蛻變.md)。

## 七、五位 OC 在力量分層之外

小曦、Franiya、Celeste、洛琪莉卡、菲璃安有 GitHub 家庭總檔賦予的跨世界力量與人格；她們不可按「宗師、神境、金丹、元嬰」強制降格，也不列入當地宗師／修仙者的人口估值。

她們是否顯示自身能力、是否讓外界知道身分、是否插手衝突，取決於她們自己的生活目的、感情、當下因果和主動選擇，而不是為了展示當地某級高手多麼不堪。對其他角色來說，知道她們的名字、認出本人、理解她們的真實力量也是不同層次的情報。
