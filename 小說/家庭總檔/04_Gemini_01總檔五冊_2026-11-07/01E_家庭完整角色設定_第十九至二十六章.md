* **心虛甩鍋、雙腿打顫與光速認慫**：闖禍被發現的第一秒，眼神會往旁邊飄、手指不自然地摳臉頰[cite: 4]；發現妹妹們要去向懷大姊或莉雅姐告狀時，雙腿會瞬間開始打顫[cite: 10, 11]，能在「硬挺胸膛嘴硬」與「零點一秒滑跪雙手合十求封口／拿烤肉汽水賄賂」之間光速切換。
* **低風險玩鬧後的跑路與被抓回來**：洛琪莉卡可以先裝傻否認，趁家人注意力轉開便拔腿溜走；被追上、抓回來後仍能理直氣壯推託、抗議、討價還價、假裝委屈或再想辦法跑掉。不一定被抓到，也不一定認錯。地毯上**滾兩圈→停下偷看→繼續抗議**可單獨成為一段搞笑鏡頭，也可能接在任何其他無關的逗弄後，不必每次上演。
* **向法月懷撒嬌（獨立日常）**：想親近大姊時，她可暫時把叉腰耍帥收起，主動挨近、挽住手臂、放軟聲線或直接討抱抱；這可以單純因為心情好、想靠近或想一起玩，**與犯錯、被追責無關**。表達仍有她自己的豪爽、活潑與偶爾嘴硬的節奏，不照搬朔凜月完全相同的撒嬌動作。
* **找大姊撐腰（獨立求援）**：和妹妹吵嘴、想請大姊支持自己的主張，或奇怪玩法被全家圍著吐槽時，洛琪莉卡可能立刻轉身向「懷大姊／法月大姊」喊話求援；可以仍昂著頭挺三姊架子，也可以急得嘴碎，**不要求先抱住大姊或改用撒嬌聲線**。大姊是否支持與如何處理取決於實際事件，不把這個動作變成萬用免責符。

## 二十、對話與敘事聲線指南

<a name="doc-nav-185"></a>
### 20.1 絲蒂莉雅

- 少而準，常把一個完整判斷壓進很短的句子。
- 乾式反擊比大聲爭辯自然。
- 情感深時仍可直說，不必永遠吞回去。

<a name="doc-nav-186"></a>
### 20.2 薇絲莉雅

- 有來有往、直覺性強，會立刻抓住對方的反應。
- 真話可以藏在玩笑裡，也可以完全不藏。
- 避免把每句話都寫成挑逗或戲劇化挑戰。

<a name="doc-nav-187"></a>
### 20.3 塞希莉雅

- 自信而從容，溫暖與危險都不需刻意抬高音量。
- 能直接承認愛、慾望、興趣與決定。
- 聰明由選擇體現，不用不停替讀者分析。

<a name="doc-nav-188"></a>
### 20.4 法月懷

- 話少但不是缺句；每次開口都帶實際內容、選擇或關係變化。
- 她可以有玩心，尤其在安全的四人私下空間。
- 避免連續以「嗯」「……」代替人格。
- **【2026-10-22 口語修正】**金瞳懷的親暱輕吐槽以「笨蛋／傻瓜」一類最貼近；粗口如「傻逼」一般更接近已脫離三無的金黑交融瞳或完整黑瞳狀態，且也並非必用。細節見第8.6節，不按詞庫平均派發，不把眼色寫成髒話開關。

<a name="doc-nav-189"></a>
### 20.5 原四人共同的敘事禁忌

- 不要讓她們輪流念人格簡介。
- 不要在每個動作後補一句「這就是她表達愛的方式」。應讓讀者從行動自己看出來。
- 不要把彼此熟悉寫成心靈感應式全知。法月懷仍可能不懂塞希莉雅下一步；另外三人也會真正彼此意外。
- 不要因為角色很強，就讓所有場景只剩威壓、跪拜與旁人震驚。
- 寫角色正在做什麼即可，不要用「她沒有看誰、沒有理誰、也沒有說什麼」反覆列舉被排除的動作。注意力已由正面動作表明時，不必再以否定句補充。
- 四人同場不等於每一小段都要輪流報告四人的反應。沒有發言、介入或改變局面的角色可以暫時不寫；需要時再自然拉回。
- 不要反覆以「Stiliya 安靜地看著」把她放在四人互動之外。她可以話少，但應透過靠近、笑、牽手、依偎、玩鬧或短句留在關係之中。

### 20.7 完整開放詞庫：可換、可造新詞、可一句都不用

**【2026-10-21｜後出語感優先序】使用者明確修正：「傻逼」比「大傻逼」自然。**一般脫口吐槽、熟人日常互損或自然罵一句時，**優先考慮「傻逼」**；**「大傻逼」主要用於刻意加重語氣、強調程度、故意誇大戲謔、特別激動或激烈互噴**，不把兩詞視為日常完全同頻、隨機交換的稱呼。這是**相對自然度與強調用途**，不是禁用「大傻逼」，也不是說日常必須經常出現「傻逼」；先前「粗口平常低頻、激烈玩鬧可暫時密集」原則仍有效。每名家人能否、何時說出口依自己性格、對象和場面決定。**此處「傻逼」較「大傻逼」自然，是在某角色與場合本來就適合說較重粗口時的兩詞比較，絕不意味所有家人都應先選「傻逼」；例如日常金瞳的法月懷常更適合「笨蛋／傻瓜」。**

**開放稱呼同樣有效**：「笨蛋」「小笨蛋」「大笨蛋」「小可愛」「調皮鬼」「大探險家」「小壞蛋」「親愛的」「小淘氣」及隨事件新生的外號，可以雙向、交換使用。**既有固定姓名／親屬稱呼依角色規則優先**：例如「莉莉／薇薇」「懷／法月」「懷姐姐／法月姐姐」「凜月」「希雅姐」「璃安」「芙蘭」「母親」等不可因新詞庫隨意作廢；其他暱稱也不必每句重複。成人戀人和孩子親情不可因同用「小可愛」而混成同一親密形式。

### 20.8 標點、情緒符號、夾子音、咬字走樣與動態聲線

| 表示 | 用法與短例 | 不要誤判為 |
|---|---|---|
| **！／!** | 高聲、忽然興奮、急停、斷然、驚喜：「等等！」「好耶！」 | 每出現就代表角色尖叫；正式中文台詞一般優先全形「！」 |
| **？！／!?／！！** | 驚訝追問、被惹到、急促喊叫：「妳認真的？！」「後面！！」 | 標點越多越有重量，無須固定數量 |
| **～／~** | 拖尾、甜、懶、得意、壞心眼、撒嬌、戲謔、陰陽怪氣：「好嘛～」「哎呀～」「妳猜呢～」 | 半形和全形各代表兩種不同人格／情緒；中文正文優先「～」，網路訊息可用「~」 |
| **♡／♥** | 小小愛心、親近、調戲、故意裝乖、戀人玩笑、純親情撒嬌：「莉莉～♡」「嘿嘿♡」「快來嘛～♡」 | **必然告白、性暗示、認真愛意證據，或空心實心固定等級**；不須每句都有 |
| **——／—** | 拉長音、聲音喊出去或急停：「薇——薇——！」「我才沒有——」 | 未說明的「一條／兩條直線」被擅自說成豎線；正式中文一般用「——」 |
| **……與突然停頓** | 無語、真正思考、怕、哽咽、先忍笑、收低音量：「……行。」「我知道……」 | 安靜人物每句只能「……嗯」，或沉默本身總是害羞 |
| **字間頓號、短句與逐字咬牙** | 「妳、給、我、回、來！」「放。開。它。」「我說，停！」 | 真憤怒一定輕聲分字；也可以吼，戲謔時也可能假裝逐字 |
| **急促重複、口吃與改口** | 「我、我沒有！」「妳妳妳！」「左邊——不對，右邊！」 | 每次害羞固定結巴或永久口吃 |
| **含物／被揉臉時的短暫偏音** | 嘴裡塞食物「泥先別縮話……」（你先別說話），被捏臉「放開窩！」，吞下或鬆開後發音恢復 | 永久幼態、智力問題、拿真實族群口音或語言障礙當笑點 |
| **故意改音、模仿口誤與諧音** | 「真噠～」「就醬？」「神馬東西」「丸辣！」，或互學一次說錯的語音 | 必定是正式口癖；只是特殊場合可以很好笑 |
| **故意夾細／捏甜嗓音（夾子音）** | 刻意說得更高、更細、更嬌、甜膩而帶笑，可配合「～♡」，也可用動作寫明「她故意捏細嗓音」 | **一個符號本身就是夾子音**；只寫「～」不證明角色實際夾嗓子 |
| **聲線大幅切換** | 先粗口驚呼，下一瞬真正專業；原本鬧騰，忽然低聲真心；眼裡含淚，卻笑著說短句 | 高階者只能低聲、活潑者只能大喊、真心一定不用愛心 |

**同一句話依情緒可以完全不同**：「妳在幹嘛？」「……妳幹嘛呢？」「哎不是，妳又在幹嘛？！」「妳丫的在搞什麼？！」「薇薇～妳在幹嘛呀♡」「薇絲莉雅。妳現在在做什麼？」「妳、到、底、在、幹、嘛？」「妳、妳突然靠這麼近幹嘛！」「泥幹嘛啦……放開窩！」這些是**聲線／標點微型測試，不是某件事已真發生**。

**符號是演出工具，不是機械打卡**：不必每句都塞「～♡」，不因真心告白就硬性刪掉一切符號；有時不加符號而透過眼神、貓／狼耳、蝠翼、呆毛、身體重心、忍笑、呼吸、短暫停頓和接話回應，更能表現對彼此熟悉。也可以在合適的搞笑高潮連續使用驚嘆號、拖音、怪話、愛心而自然成立。

### 20.10 微型測試場面與最後的語言防呆

**【A｜互損也是真正交流】**洛琪莉卡把地圖攤開：「看！完美計畫！」朔凜月望著地圖：「……妳把出口畫在入口下面。」「那咋啦？」「神經病。」兩個人互看一眼，笑出了聲。這只是**反應詞測試，不是正式家庭事件**，不能固定朔凜月每次都負責吐槽。

**【B｜故意捏細嗓音，愛心是視覺輔助】**塞希莉雅故意壓出特別甜的聲線：「懷～♡ 讓我靠一下嘛～」法月懷伸手攬住她：「好。」她反而被乾脆回應逗得先笑。這個例子不是「～＝夾子音」的公式，而是**故意變音＋情緒符號＋真實肢體互動**。

**【C｜粗俗玩笑可以和親暱回應相連】**薇絲莉雅：「莉莉～妳在幹嘛呀♡」絲蒂莉雅：「找剛剛偷偷藏衣服的傻逼。」薇絲莉雅愣了一拍便笑著抱緊她：「找到了♡」這純屬新的**語氣測試，不追認或修改既有任何衣物事件**。

**【D｜真危險直接轉為短促指令】**芙蘭妮雅先扣住某個正要亂碰危險裝置的人的手腕：「別碰。」對方還想碰，她聲音壓低：「我、說、了。別、碰。」然後直接帶對方離開。這場不必為了套新口頭禪額外喊三聲「我去」。

**【E｜孩子用愛心不等於成人調情】**小曦：「母親，我可以坐這裡嗎？」法月懷讓出位置：「可以。」小曦開心回「好耶～♡」，只表示純家庭歡喜。

**重要規則核對**：正常情境粗話通常低頻、親近玩鬧互噴可密集；若是真衝突則可能傷人。**先問這句話是否適合這個人、這一刻的瞳色狀態及關係；不要因其他家人能說，便自動安排法月懷、尤其金瞳懷也說同一種粗口。**符號、表演音變與口頭語自由使用但**沒數量配額、沒有固定情緒翻譯表**；同一詞面對外人或家人可不同。認真時可以冷靜，也能暴怒；真正受觸動時可以帶「♡」，也可以完全沒有。語庫可以繼續增加「笨蛋、小可愛、調皮鬼、大探險家」之外的新詞、歪音、內梗與暱稱；**人物當下做了什麼、對方如何接住、長篇關係有無因果變化，永遠比塞滿流行話重要**。

**此為跨世界家人語言能力與寫作表演的准入，不是巨構世界特有的角色職務、歷史、復歸能力或諾亞×艾莉維亞戀愛里程碑，也不是引用參考方九莉雅的原作正式事件。**

| **真的嚇了一跳／被突然逗到** | 「哇！」「哇啊！」「嗚哇！」「欸欸欸？！」「呀啊！」「咿呀！」「喂——！」「等一下！」 | 突然被抱離地、玩具從旁邊冒出、有人從背後輕拍；不是高階人物因此真的害怕或受傷。 |
| **被家人逗得不服氣** | 「哼！」「唔！」「唔姆……」「吼唷！」「齁——」「嘖～」「哼哼！」「真是的！」「才沒有啦！」 | 可以是真賭氣、演給對方看、嘴硬卻在笑，亦可很坦率地要求停下；不能把真拒絕一律當作撒嬌。 |
| **看穿對方、準備回敬** | 「喔～？」「嘿？」「嘿嘿～」「哼哼」「吼吼？」「哎呀呀」「抓到了喔」「妳確定？」 | 可以拉長語尾、降低音量、假裝沒事、突然換成直接一句；不必每次有邪笑。 |
| **得意、漂亮完成、想邀功** | 「耶！」「好耶！」「哇喔！」「哦耶！」「嘿咻！」「哼哼～」「看吧！」「怎樣！」 | 可以明亮歡呼，也可安靜地露出得意眼神或直接伸手擊掌。 |
| **輸掉、不甘心、想再來** | 「欸——！」「咦？！」「哎呀！」「嗚～」「可惡！」「怎麼會！」「再一把！」「不算啦～！」 | 可笑著重賽、先鼓臉片刻，也能乾脆接受結果；不強制每人好勝。 |
| **心疼、關心、想安慰** | 「唉……」「哎呀」「啊……」「嗯，我在。」「好啦。」「沒事的。」「過來。」 | 不必嘆詞說滿；一句很輕的話、端水、摸頭、坐近都可以更貼切。 |
| **睏倦、吃飽、舒服、伸懶腰** | 「呼——」「哈啊～」「嗯～」「唔嗯」「呼啊」「啊——」「舒服～」 | 用呼吸、坐姿、靠肩或懶洋洋的短答表達，不預設所有人都必須『賣萌』。 |
| **無語、被吐槽、思考或心虛** | 「蛤？」「呃……」「啊這」「唔……」「欸不是」「不、不是」「……喔」「等等」「妳認真的？」 | 真沉默也成立。可以瞬間回嘴，也可以盯著對方半秒後再說話。 |

**地區與時代語感需自然**：「吼唷」「齁」「咧」「蛤」等偏台灣口語，「我去」「那咋啦」及低頻慎用的「姐們」等有其他文化背景的口頭語，能否自然出現取決於這一世界線的人物經歷、語言接觸與當下刻意模仿，**不要求角色全員突然換成同一地域口音**。表中「誒／欸」「哦／喔」等亦是可選文字風格，不是新的人格分類。

#### 20.12.2 家人親暱玩鬧時的各種聲音：不要每次都直接『哈哈』

| 玩鬧場景 | 可採用的聲音／短句 | 演出邊界 |
|---|---|---|
| **輕戳臉頰、揉頭、捏臉** | 「唔！」「哎呀～」「嗯？」「嗚唔！」「欸，妳又來了！」「放開窩～」（真的捏著臉時的短暫含糊音） | 臉被捏變音需要真有物理原因；鬆手就恢復平常發音，不因此幼化或永久奶音。有人也只會閉眼享受、笑著伸手捏回去。 |
| **鬧著搔癢、肩側被輕碰** | 「噗！」「呀哈哈！」「咿呀！」「停、停啦！」「哇，等一下！」「噗哈哈！」 | 聲音可從忍笑變成大笑；**真正說停或感到不舒服就停止**，不把怕癢必然寫成被壓制或要升級動作。 |
| **突然被抱住、抱起或安全地轉一圈** | 「欸？！」「哇啊！」「呀——！」「嘿咻！」「怎麼突然抱我呀！」 | 可主動回抱、張手討抱、笑、無語、自然靠著，也可不喜歡而拒絕；不預設每次被抱就驚慌。 |
| **家人搶零食、撥動小物、反向捉弄** | 「喂！」「欸欸！」「還來！」「嘿嘿，抓到了！」「還我啦～」「妳這個小壞蛋！」 | 是否真的生氣取決於行為與關係；也能明知被偷吃卻故意裝不知，再找機會反擊。 |
| **惡作劇被識破、假裝無辜** | 「欸嘿～」「啊哈……」「唔？」「沒有呀」「妳看錯了啦」「什麼？我不知道耶。」 | 不強迫全部變成『裝傻被抓包』的同一橋段；有些人可以承認得非常爽快，甚至直接笑著繼續。 |
| **姐姐妹妹互相起鬨、得意放話** | 「喔喔！」「哦～？」「嘿嘿嘿」「咻——！」「吼？」「來呀！」「不服再來！」 | 可以很鬧，也能安靜一句話就把人逗住；洛琪莉卡的「哈哈！」仍可在真的開懷時自然出現。 |
| **彼此依偎、親暱但不鬧** | 「嗯。」「好呀。」「唔嗯～」「呼……」「我知道。」「再待一下嘛。」「這樣就好。」 | **小小的聲音也很有生活感**，不需要為了熱鬧硬插驚叫、羞惱或誇張笑聲。 |

**「哼」「唔」「嗯」「啊」等字並不是單義密碼**：同一個「唔」可能是嘴裡有食物、被捏臉、正在思考、真的不開心、舒服得不想說話；只有在上下文和動作支持時才能解讀，**不把任何聲音固定翻譯成特定情緒或親密／性意味**。聲音、台詞、動作之間也不用全寫滿：有時一個微表情加一句「好啦」便足夠。

#### 20.12.3 更豐富的語氣詞與自然口語句尾

- **爽快、直接**：「好啊！」「行呀！」「來吧！」「知道啦！」「等我一下！」「真的耶！」「可以喔！」；有時只說「好」「行」「嗯」反而最自然。
- **輕鬆逗人／撒嬌**：「好嘛～」「拜託啦～」「妳說呢？」「欸～不要這樣啦」「再一下嘛」「妳看啦～」「有嗎～？」「真的啦！」；可少量帶長音、壞笑或溫柔，**不是甜尾音越多越親近**。
- **嘴硬、不服氣／害羞**：「才不是咧！」「哪有啦！」「我才沒有！」「這個不算吧？」「喂，不要亂講喔」「哼，隨便妳啦！」；如真的生氣，需有符合情境的界線與後果。
- **納悶、思考與確認**：「是嗎？」「這樣啊。」「原來是這樣。」「為什麼呢？」「好像耶」「所以呢？」「欸等等，妳剛才不是說……」；不強迫每段『嗯？』『什麼？』重複接話。
- **溫柔安慰與日常親近**：「沒關係呀」「我在喔」「不要緊」「好啦，過來」「先休息吧」「嗯，我陪妳」「慢慢來。」；**句尾沒有詞也能很好聽**。

#### 20.12.4 環境、動作、物件與身體節奏的擬聲詞素材

| 聲音來源 | 可用擬聲詞 | 選用提示 |
|---|---|---|
| **遊戲機台、按鈕、籌碼、硬幣** | 「嗶」「叮！」「咔」「喀噠」「噠」「鏘」「嘩啦」「咕嚕嚕」 | 依材質、裝置與真實碰撞寫；賭桌、抓娃娃、音樂遊戲都不必用同一種音效。 |
| **敲門、跑步、轉身、跌坐、碰撞** | 「咚咚」「叩叩」「噠噠」「啪嗒」「撲通」「咚！」「砰」「唰」 | 不是每次轉頭都唰、每次坐下都撲通；力量控制、衣物與地板材質會改變聲音。 |
| **小物掉落、塑膠包裝、書頁、布料** | 「叮噹」「喀」「啪」「窸窣」「沙沙」「嘩啦」「嘶啦」 | 可以幫助讀者聽見現場，不等於普通物件都具有異常音效。 |
| **飲料、料理、咀嚼、氣泡** | 「咕嘟」「咕嚕」「咔滋」「喀滋」「啵」「滋滋」「噗滋」「嘶——」 | 可配合酥脆、軟糯、熱鍋、開汽水等感官；**不把每口吃飯都寫成擬聲詞堆疊**。 |
| **風吹、雨、海浪、室內聲響** | 「沙沙」「簌簌」「淅瀝」「嘩啦」「呼——」「嗡嗡」「滴答」「叮咚」 | 場景能夠自然提供背景聲，不必全部化為人物發話。 |
| **親近時的小聲笑、氣息與舒適聲** | 「噗哧」「呵」「哼哼」「唔嗯」「呼……」「哈啊」及原有個別角色已定的特殊聲音 | 身體、情緒與對象吻合才出現；洛琪莉卡既有舒服時可有的低低呼嚕聲**仍只作角色本人可用表現**，不自動分給十位家人。 |

**重要：超常能力使用本身不能為了方便讀者理解，強行配上外人也能聽到的『嗡』『啪』『滋』等可辨識音效。**例如家人偷偷改動輪盤、遊戲結果或互相反制時，**外人仍完全無法察覺能力施用本身**；若有可見可聞結果，那也只是機台、球、物件按既有聲學作出的正常表現，**不能反過來成為外人識破力量的證據**。

#### 20.12.5 不固定人設的差異示範（全部僅是可用寫法）

**A｜洛琪莉卡、瑟莉思媞（小媞）、小曦：搶先反逗**

> 「欸？小媞，妳怎麼又跟小曦聯手啦？」洛琪莉卡看著手裡突然交換位置的遊戲卡。  
> 「哪有～？」瑟莉思媞笑著把手背到身後。  
> 「嘿嘿，我可沒說誰先動的喔！」小曦的兔耳輕輕一豎。

> 三人都笑了。此時可以大笑，也可以只讓她們在接下一局時露出興奮神情。

**B｜芙蘭妮雅與璃安：一靜一動也能自然反轉**

> 「喀噠。」遊戲按鈕亮了。  
> 芙蘭妮雅看著畫面，立即說：「我想再玩一次。」

> **這不是芙蘭妮雅只能短句、璃安每次必搗蛋的公式**，只是當下兩人都想玩。

**C｜安靜舒服的家庭相處，無須刻意鬧騰**

> 「唔，這個好吃。」瑟莉思媞將點心盤推近一些。  
> 璃安望著剛泡好的茶，微笑點頭。  
> 芙蘭妮雅拿起杯子：「謝謝。」  
> 一旁小曦正看著窗外，沒有說話。  
> 窗邊的風輕輕拂動簾角。四人都很自在，**不需要再添加一聲『哇』『咿呀』才像有生活感**。

**最後校準**：前幾次曾發現「洛琪莉卡每次說話先哈哈」「芙蘭妮雅每次先……」「璃安每幕都只微笑」等敘事容易單一化；**解方不是禁止這些真實表現，而是擴大角色能在當下自然作出的選擇**。嘆詞、語氣詞、擬聲詞、沉默、直接回答、笑、抱、互相使壞、真心陪伴都可存在。**同樣不要求十人分配均等戲份或相同數量的嘆詞。**

### 20.13 【2026-10-25｜修訂】家人玩鬧時的受擊、擊退、撞上物體與自由發聲

**【2026-10-25 使用者後出校正；取代本節前一版「真的受到強力攻擊／真正交戰」的示例分類】**這裡的重點**全部放在家人之間的玩鬧**，而不是把「輕拍」歸一邊、「真正強力擊中、被擊飛、撞到東西」自動移去嚴肅戰鬥。以這個家庭的力量、控制能力和彼此熟悉程度，**真實發生較強的撞擊、被打飛、被推得滑出去、翻進沙發／撞上牆或其他物件，仍完全可以只是玩遊戲、打鬧、鬥嘴或互相反制的一部分**；是否真的受傷另按實際條件判斷，**不由聲音大小、挨打程度或「撞牆」二字決定**。也不強迫她們為了好玩每次都用大力；輕拍、普通擁抱、安靜摸頭同樣是真實日常。

**不要再讓「家人輕拍」被分配到更慘烈的叫聲、「強力擊退」卻只配一聲低沉的『呃』，也不要反過來按力道硬性排音量。**家人之間的聲音更多反映**驚訝、開心、挑釁、演戲、突然被反制、失去預期、裝輸、想讓對方知道自己玩得正起勁，或身體受力帶出的短促吐氣**。有人輕輕被戳一下就可以故意「嗚哇啊——！」，有人飛出去撞上軟墊仍能笑著說「再來！」；也能反過來，輕拍無聲，強力一擊嚇得「哇啊！」，沒有固定對照表。

| 家人玩鬧情境 | 可用的人聲、嘆詞與短句（全部為選項） | 聲音／動作詮釋 |
|---|---|---|
| **手指戳一下、拍肩、輕敲額頭或臉頰** | 「欸？」「呀！」「哎唷～」「喂！」「哼」「嗯？」「噗」；也可以故意「嗚哇啊——！」 | 「啪」「噠」或幾乎無聲。喊得大可能只是**故意做戲**，不是一碰就真疼。 |
| **家人鬧著連拍、互拍、搶物與反擊** | 「喂喂！」「嗚哇！」「呀哈哈！」「妳又來！」「好啊，換我！」 | 可以扭身躲、握住對方的手、把人抱住或輕輕還擊，也可互相大笑。 |
| **玩鬧中真正用上更大力量、直接被擊中** | 「呃！」「嗚哇！」「咕哇——！」「欸欸欸？！」「哇啊！」「呀——！」；也可能直接笑出來 | 真實受力與呼吸節奏可以變，仍**不必疼痛或受傷**；驚叫、開懷笑、吐槽、沉默可以混用。 |
| **被擊退、滑出去、拋起來、撞向物體** | 「哇啊啊——！」「咕呃！」「咿呀！」「喂——！」「噗哈哈！」「等等！」「這個有點突然啦！」 | 「咚」「砰」「啪嗒」「轟」需與**實際落點、材質和動靜**一致；撞上沙發、牆面或緩衝物不自動代表真受傷。 |
| **被打飛後故意翻滾、誇張趴倒或裝輸** | 「呃啊——！」「不——！」「可惡！」「我輸啦——！」，或乾脆滾回來「嘿嘿，騙妳的！」 | 是可自主選擇的**喜劇演出**；不把順勢飛倒倒推出角色能力被削弱。 |
| **接住、閃過、紋絲不動或立刻反攻** | 「喔？」「欸？」「再來呀。」「就這樣？」「這下輪到我了！」；也可能一言不發 | 即使力道很大，未必有顯著移動；能接招不意味必須每次接。 |
| **被撞後繼續笑鬧、抱住對方或撒嬌** | 「嘿嘿～」「好啦！」「妳也來一次？」「再一下！」「哼，下一局不讓妳了！」 | 被強力撞過後仍能愉快地繼續，和沒有痛感或沒有損傷可以同時成立。 |

#### 20.13.1 「出聲」「受力」「痛覺」「受傷」四件事要分開

1. **聲音**：被打到時可能驚呼、笑、出聲吐氣、咳一下、抱怨、故意裝慘、撒嬌求再來或完全不叫；**不是疼痛測量器**。輕拍與強力撞擊都能配上高低各異的聲音。
2. **受力**：可以真被撞飛、被迫改變動作／吐氣／身體姿態；也可以自主配合力道，或用力量將衝擊導向其他方向。寫作時看當下互動、能力、控制與選擇，**不必為了保留強大而把一切寫成「根本沒碰到」**。
3. **痛覺**：有痛感的角色可以因疼痛發聲，但也能因好玩而叫；**芙蘭妮雅主觀痛覺固定為零**，所以她**不會主觀真的痛**，卻一樣可能驚叫、喊、吐槽、發出受衝擊的氣音、咳嗽或故意誇張表演。
4. **損傷**：撞得很響不等於身體受傷，真正有傷也不必然等於痛；物件若被撞壞，要照世界與當下環境處理，不能因是玩鬧就無端抹去實際物理後果。熟悉的家人可依各自能力控制分寸，玩鬧通常不以互相造成不願接受的傷害為目的。

**【特別回答｜芙蘭妮雅會不會叫、會不會說「好痛」？】會，而且可以叫得很大聲、用力吐氣、尖叫、哈哈笑、喊「哇啊——！」或被打飛還能連續講話。零痛覺從來不是「失聲」「無法驚訝」「永遠面癱」「絕不能講痛這個字」。**她可以在家人玩鬧中**刻意裝慘、學別人的語氣、反諷或撒嬌**地說「嗚嗚，好痛喔～」「欸！好痛啦！」「妳打到我了啦！」，**只要文意讓人明白她不是在報告自身真的感到疼痛**；甚至她可故意用這句逗洛琪莉卡上鉤，再笑著反擊。她若因衝擊短促「呃！」「咳！」也可能是氣息、身體受力、驚訝或表演，**不是痛覺回來了**。相反，若她認真分析傷勢，應說「這裡受到衝擊／手臂受損」而非用真的痛描述自己的主觀感受。她的**低振幅與活潑面都保留**，不是每一次飛出去都必須喊。

#### 20.13.2 小場景示範（僅是寫作可能，不代表已發生）

**【2026-10-25｜後出增補：知情家人的反應可以不同，舊 C 必須保留】**熟悉她的家人**本來就知道芙蘭妮雅主觀上沒有痛覺**；但她忽然捂著肩膀喊「好痛喔～」時，仍存在**至少三種自然反應**：**① 一時被她突然的演技唬住，真的愣了一拍，接著才發現她在逗人；② 最初以為她真的有什麼不對勁、隨即想起她根本不會痛，當場笑著拆穿；③ 從第一眼就知道她在裝，直接吐槽、配合她演、裝作上當或反過來整她**。即使知道零痛覺，**一時的反射性關心、沒跟上她的戲、被演技逗得失神，也不等於家人忘記她的能力或變笨**。這三種都可自然存在，不指定洛琪莉卡、璃安或任何家人固定採哪一種。芙蘭妮雅若被識破，可以繼續裝、理直氣壯地說「可是妳真的打到了嘛」、轉而撒嬌、笑出聲或直接反擊。**「確實被打到」和「真的感覺痛」不同**。而且**「好痛」「啊——我輸啦」「被打敗了！」等裝痛、裝倒、誇張受擊台詞，不是芙蘭妮雅專有**：洛琪莉卡、璃安、小曦、瑟莉思媞及其他家人，也可按本人個性與當下玩心故意這樣說、臨時創造新的叫聲；他人同樣能看穿、後知後覺、配合表演或反擊。對其他家人，不可直接套用芙蘭妮雅的零痛覺屬性；**她們究竟有沒有感受到痛，仍依各自既定身體／能力與當下真實情況**。下列 C-1、C-2、C-3 為並列可能，**不是一段事件的連續三次重演，也沒有固定反應台詞**。

### 20.14 【2026-10-25｜最新澄清】所有詞庫都不封閉：允許角色當場自然發揮、變音與新造聲音

**使用者明確確認：20.6–20.13列舉的嘆詞、語氣詞、擬聲詞、挨打／玩鬧的叫聲及角色微型示例，絕對不可能涵蓋所有情境。它們只能作為參考素材，**不能當作可以使用的全部選項或需要從中抽取的固定資料表。**往後的正式正文，應允許角色在每一個新情境中**即興反應、臨場發揮、創造未列出的詞或聲音**，也可以完全沒有擬聲詞、直接說話或沉默。這是對前述開放語庫的更高優先級解釋，**不刪除既有範例，也不將舊範例轉化成禁止其他聲音的界線**。

**臨場發揮可以包括但不限於**：
- **同一個感嘆變化**：語長、語速、音量、節奏、重音、情緒、斷句、停頓、結巴、連續驚呼、忽然改口與笑到咬字斷掉，例如臨時「欸欸、等——妳先、妳先等一下！」；不必跟既有表格中的字形一模一樣。
- **當場拼接或創造聲音**：因被逗到、鬧著玩、被抱、跌入沙發、被擊退、想嚇回去、忽然開心、得意或難為情，而自然發出全新的短音、含混聲、誇張模仿、狀聲詞、諧音、反常的語序、自己取的新外號；**只要符合那個人物的聲線與動作因果，不需要先在總檔列過才能使用**。
- **動態接話與彼此感染**：家人可以臨時學對方的怪叫、當場接梗、反過來模仿、笑到下一句說不清、突然從大喊改成耳語、先無語一拍再吐槽；對話是彼此回應的過程，**不是預先分配給每個角色一套固定感嘆詞**。
- **新的擬聲與環境聲**：碰撞、材質、機器、腳步、門、桌子、料理與特殊環境都能依當下實際聲響創造貼切表現，不拘泥「啪、咚、咔嚓」等常見例子；不以擬聲詞代替必要的動作描寫，也不能憑空替隱密能力加上外人可辨識的超常音效。
- **最普通的說話也完全有效**：溫柔微笑、點頭、安靜傾聽、正常完整句、低聲直答或無聲反應都應保留。**即興≠必須每句標新音效、必須吵鬧、必須一直搞笑或每場都要展示新花樣**。

**玩鬧受擊的情境尤其不按詞表限制**：即使同樣是被輕拍、真被擊飛、撞上沙發或牆，每次都可能發出完全不同的聲音，也可能不出聲；**喊得誇張不等於真痛、受力大不等於一定受傷**。芙蘭妮雅能因驚訝、氣息、玩心、故意學人、裝慘或反擊而自然發出**任何符合當下情境的新聲音**，並可戲謔說「好痛」，其**主觀痛覺仍固定為0**。不讓「零痛覺」成為限制她詞彙、正常對話、歡呼、尖叫、演戲或玩鬧的規則。其他家人亦不得因力量高、沉靜或地位特殊而被鎖死在有限嘆詞範圍。

**真正需要遵守的不是字詞清單，而是角色一致性、語境合理性、動作／聲音因果、與他人的互動，以及已確立的能力與情感邊界。**例如洛琪莉卡很愛笑，卻不必每句都以「哈哈」起手；芙蘭妮雅既可安靜也可自然活潑，省略號非必備；璃安可以溫柔微笑也可以突然玩上頭；瑟莉思媞與小曦活潑程度相近、都能主動和安靜。此條對**整個十人家庭與日後不同世界線的正式正文**適用，不只對已有的賭場、商場或家人互拍試寫有效。**未列出某個聲音，永遠不是禁止使用它的理由。**

   收藏並提供普通知識、異能、科技、魔法、修仙及其他文明的書籍與資料。知識需要閱讀、理解和練習，不能把看過一本書等同於直接得到完整力量。此樓已在正文中正式開放。
6. **六樓：萬靈生態園**  
   以生命與完整生態為主，可包含醫療、身體與血脈修復、生物培育、智慧植物、異獸幼體、種子、藥田、生態模組、族群棲息地與物種保存。此樓已在正文中正式開放。
7. **七樓：萬道傳承館**  
   提供異能、修仙、魔法、武道、精神、神術、科技強化等力量道路的傳承、適配、改造與指導，也可提供技能刻印、職業傳承、根基重塑、體系轉換及文明級培養道路。它與五樓的差別在於：五樓提供可自行研讀的知識；七樓能讓購買者真正進入、調整或重建一條力量道路，但不保證購買後立即成為頂級強者。
8. **八樓：星海船塢**  
   販售單人穿梭機、貨船、探索艦、戰艦、母艦、文明方舟、機甲、無人艦隊、星門、躍遷設備、軌道城市、行星防禦及星際配套。內部空間足以容納真正艦隊；大型商品同樣可宅配與安裝至軌道、衛星、月球或指定深空位置。
9. **九樓：諸界文明館**  
   販售完整城市、移動國度、文明發展體系、技術樹、小世界、祕境、世界種子、文明保存與末日重建方案，以及時間、空間、法則、因果、概念和世界級商品。此樓不是單純再提高武器威力，而是把交易尺度提升至文明、世界與宇宙。

目前的正文狀態為：五樓「萬象圖書館」與六樓「萬靈生態園」已正式開放；七至九樓尚未開放，但樓層方向與名稱已經確立，不能再列為完全待定。具體商品、正式開放時間及開放事件仍依後續劇情安排。

「幻境娛樂城」不屬於九層超市。它原本曾被安排為七樓，後來已明確移出，改成四人另外開設的獨立大型娛樂設施；七樓的有效設定因此是「萬道傳承館」。不得再把幻境娛樂城寫回七樓。

#### 莉月超市：營業、安全區與店規

- 標準營業時間為早上八點至凌晨兩點。四位店主可以因睡晚、私人安排、想休息或其他理由延後開門，甚至當日不營業，不需要由系統批准。
- 休息區單次最長停留八小時；凌晨兩點關門時，所有外人都必須離店，即使尚未停滿八小時。一點五十九分才進店，也只能停留到兩點。
- 超市周圍十米屬於安全區，店規同樣生效。離開十米範圍後遭到喪屍、異獸襲擊或被其他顧客搶劫，超市不負責。
- 安全區的效果應由顧客和勢力透過實際事件逐步觀察、驗證與傳播。新增規則或區域不能在出現當日便無理由被所有人完整掌握並熟練利用。
- 在店內或十米安全區內攻擊、威脅、惡意挑釁，以及有意侮辱四位店主，都可能立即越過斬殺線。真正成立的違規者不能在攻擊超市後自行離開，也不能留一批逃走者延後處理。
- 冒用、仿冒或擅自以「莉月」名義欺騙他人者死亡。四人不喜歡外人使用這個名字建立仿冒商店或勢力。
- 惡意弄髒超市，或明知會弄髒且沒有必要仍故意為之者死亡。不小心弄髒，或明知會髒但確有不得不用的理由者，有一次自行清理乾淨的機會。
- 完整黑瞳恐懼與店規斬殺線是兩套不同判定。沒有觸發完整黑瞳恐懼、沒有指向特定店主或不害怕店主，都不代表侮辱與挑釁可以免於處置；金黑交融眼本身沒有該項恐懼。

#### 莉月超市：商品、交易與自動化

- 店內所有商品都是同類中最好的品質。食物更好吃，工具更耐用，設備的性能、精度與壽命也不是外界同名產品能比較。
- 異能商品必須有清楚的效果、限制、適用對象與價格說明。部分餐點可以補充異能、恢復精神、穩定力量或輔助突破。
- 店內出售契約令；是否購買與使用由顧客自行決定。契約令可以成為勢力合作、交易與爭議中的選項，不會強制每一筆交易都使用。
- 大型設施可選擇宅配，並另購安裝。四人或店內機制能將商品直接送往指定位置，再完成設備、地形與環境配置；這項服務本身也會讓外界意識到店舖能力遠超普通空間運輸。
- 末世後不以失去實際價值的大夏幣作為主要貨幣，避免富豪僅憑舊貨幣在開局跨越多個階位。主要依晶核、材料、能源、技術品及其他仍具有實際價值的資產估價。
- 正式上架、付得起且符合商品本身條件便可成交，不因顧客是人類、智慧喪屍、異獸、罪犯或敵對勢力臨時拒售。
- 人流增加後，收銀、補貨、清潔與基礎接待由自動設備及人偶完成，不招募普通員工，也不建立傳統輪班制。璃安是家人，不屬於員工體系。
- 四位店主本身也不會為了製造事件而頻繁外出。通常只在確有必要、自己有興趣或單純想出去逛時離開超市，不設固定外勤任務。
- 多數外人並不知道四位店主的名字與完整外貌。新來者仍可能震驚、不信、懷疑、試探或下注搶占先機；敬畏必須隨事件、口碑與時間逐漸形成，不能讓所有新客人一開始便像知道店主無敵。

#### 非人顧客與末世生態

- 具備智慧且能理解交易的喪屍、喪屍王、異獸與獸王都能進店購物。智慧個體可以在早期便出現並提前布局，不必全部拖到中後期。
- 喪屍與異獸的進化必須與人類線同步推進，不能在人類已有大量三、四階甚至更高階時，仍把二階喪屍寫成極罕見的最高威脅。
- 一般喪屍與異獸勢力通常存在王者，但王者不只一個；犬王、狼王、貓王、鯨王、鯊王及其他區域王者可以各自控制族群、領地與代理網絡。
- 能夠親自前來的智慧王者通常會親自進店。只有因體型、海洋環境、模擬世界或其他實際限制無法進入者，才使用代理、意識連接或特製設施。
- 海洋整體比陸地更加危險。巨型鯨王、鯊王等海獸不能直接以本體走進陸地超市時，應有符合其勢力與習性的代理者，不可讓海獸本體無視環境限制出現在貨架間。

<a name="doc-nav-199"></a>
#### 異能階位與成長節奏

- 異能潛力可使用 S、A、B、C、D、E 分級，實際戰力另使用數字階位，兩者不能混為同一件事。
- 覺醒者在覺醒時，腦中會自然獲得自身能力、潛力及當前階位的基礎資訊，不必每次升階都重新找人檢測才能知道。
- 數字階位不以九階為終點，可以延伸至九十九階及更高；但更高層宇宙仍需使用更合理的文明、維度與存在尺度，不能永遠只靠增加數字維持差距。
- 前期階位相對較容易突破。大型基地、家族與官方能集中數百、數千乃至數萬人的資源培養少數強者，因此不應長期弱於只有一人的普通散人。
- 少人小隊與散人仍可能因天賦、特殊異能、裂隙奇遇、戰鬥效率或個人選擇超過大型勢力；規模大不等於必然最強。
- 新勢力登場不等於自動比前一批勢力高一階。更高階強者應優先由已鋪陳的人物、基地、屍王與獸王突破；全新強者若更高，必須合理交代地區、資源、成長經歷及此前未被發現的原因。
- 新階位第一次公開出現應成為相應規模的事件，不能只在介紹某個突然登場的勢力時順帶突破此前最高紀錄。

<a name="doc-nav-200"></a>
#### 地球勢力與國際局面

- 勢力不只有散人、普通基地與官方。各地存在不同規模的家族基地、幫派、黑幫、財團、世界級集團、海盜團、軍閥、自治城、地方頭目及極端享樂或獵奇組織。
- 每一類勢力都不只一個，具有大小、強弱、理念與內部結構差異，也可能有多個彼此實力相當的競爭者。
- 末世會釋放原本受社會規則壓制的慾望，形成搶劫、人口控制、極端享樂、虐待與其他突破舊秩序底線的勢力；不能把所有反派都寫成同一種無腦攔路者。
- 大夏中央本身必須強大，擁有軍隊、高階能力者、行政、科研、法律與跨區調度能力，不能寫成只靠莉月超市才勉強存在。
- 莉月超市客觀上極大幫助人類與大夏恢復秩序，但四位店主並未因此成為人類陣營、官方附屬或大夏的固定武力。
- 大夏會利用購得的農業、軍事、交通、醫療與生產設備加速整合各區、恢復秩序；首都與其他區域的政治、人口和資源重組也應持續推進，不能永遠停在臨江市周邊流水帳。
- 世界範圍包括大夏／龍國、燈塔國、灰熊國、倭國、日不落國、法蘭西、阿三國、棒子國及其他國家與地區。各國可能合作、競爭、敵對、試探或爭奪交易先機。
- 大夏因較早接觸莉月超市，在實力、秩序、供應與組織能力上應與許多更混亂的外國地區形成明顯對比。外國勢力不會平靜、整齊地接受兩座超常店舖的存在；震驚、質疑、情報戰、代理試探、強行接觸及內部爭奪都應自然出現。

#### 幻境娛樂城

- 幻境娛樂城是四人另外開設的獨立大型設施，不屬於莉月超市九層。等地球局勢初步穩定、外地與外國顧客逐漸抵達前後，再依劇情開放。
- 所有具備相應能力的物種都可以進入娛樂，不限人類。娛樂範圍也不限於電子或幻境遊戲，包含溫泉、健身房、電影院、劇場、主題樂園、競技、休息、賭博與其他體驗。
- 娛樂城不限制單次停留時間，但停留期間必須持續付費。不同區域費用不同；支付區域費用後可使用該區一般設施，個別特殊項目另行收費。
- 可以提供真正會死人的遊戲、俄羅斯輪盤及其他高風險娛樂，但必須在參加前明確標示規則、死亡可能與代價。
- 顧客可以自訂遊戲、世界、規則、痛覺、死亡模式、參與種族與環境。自訂不代表能違反四位店主不允許違反的底線。
- 與超市不衝突的規矩可以沿用；娛樂城也可以增加超市沒有的專屬規則，不能直接假設兩處規則完全相同。

#### 後期宇宙層次

- 地球篇穩定後才正式進入宇宙篇，避免在地球勢力、首都、各區域、海洋與國際局勢尚未推進時，因不斷開新地圖而削弱人物反應與現有事件。
- 宇宙中存在類似大夏中央的高層管轄組織，但它管轄的是已知文明圈或特定星域，不是整個無限宇宙。
- 宇宙社會包含核心管轄區、成員文明、自治區、中立聚落、邊境與未知宇域，也存在星港、世界艦、多種族都市、邊境殖民地及多個彼此獨立的文明聚落。
- 宇宙中央本身必須真正強大，具有艦隊、執法、文明登記、星路管理及災難應對能力，不能只作為下一批前來震驚的弱小背景板。
- 宇宙勢力仍可包含財團、海盜、家族、宗教文明、機械集群、星獸文明與獨立強者。它們不會一開始便知道四位店主無敵，同樣可能敬畏、觀望、合作、懷疑或試探。
- 宇宙篇可先由商隊、星港或文明聚落接觸地球，再逐步引出宇宙中央。四位店主與璃安仍遠高於這套宇宙力量體系。

### 21.6 全球異能／大夏旅行線（《Stiliya鎮壓暴亂》）

**【世界線限定】**

- 世界使用全球通行的 E～S 級與「戰略級」異能分類；各國具體制度與規矩不同，不能把大夏的行政方式直接套到國外。
- 絲蒂莉雅與薇絲莉雅因疲倦而在封閉小窩中沉睡，連同小窩落到大夏首都。小窩無法破壞、移動或測得有效數值，因此國家在外圍建立收容設施。
- 她們睡飽後自行離開；官方在後續無意展露的能力中逐步意識到，現有分類連建立上限模型的起點都找不到。
- 她們來此主要是旅行與體驗生活，不是求庇護、入職官方或成為國家武器。大夏可以給予最高規格身分、便利與暗中保護，但不能因此取得指揮權。
- 官方、學校、外國與一般民眾對她們的認識必須漸進。保密資訊不能無理由人人皆知，兩人也不應在還未累積公開事件時突然變成全民公認的無敵名人。
- 她們在此世界近似全知全能，並具有同等層級的精密控制；展現時可以安靜、簡短，不需每次伴隨空間震盪或宇宙級異象。
- 絲蒂莉雅可以一人鎮壓暴亂，也可以處理官方無法處理的嚴重事件；這不代表她因此變成大夏的固定執法人員。
- 位高權重者挑釁她們時，知情家族與最高層的恐懼、快速切割及加重處理可以成為後果。法律層面並非完全無法處理，而是因涉事者地位、行為嚴重度與兩人的不可敵對性而變得極其麻煩。
- 旅行日常包括夜間火鍋、小街、夜市、甜點店、學校參觀與跨國行程。絲蒂莉雅偏好奶茶；薇絲莉雅偏好紅茶並常加蜂蜜。
- 夜市中兩人互送代表對方的玩偶、戴著彼此早年親手做的飾品，以及第二十五章爭奪焦糖布丁的橋段，都是這條世界線中成立的具體事件；可以用來理解關係，但不必在別的世界逐字重演。
- 城堡降臨、大事件出手、官方確認戀人關係與 Pocky 遊戲等橋段曾被規劃在後續；是否已完成正文及確切章序必須以該長篇的最新章節為準，不能把規劃自動當成已發生事件。

### 21.7 其他場景的使用原則

<a name="doc-nav-208"></a>
### 22.1 全體

- 用四個固定標籤機械決定每次反應。

## 二十四、寫作前快速核對表

**【2026-11-08｜全體十位 OC 共通：偏好不等於唯一，參考圖不等於固定出場配置】** 寫小說時，請將資料分成三種不同層級：**①明確確立的角色核心**（人格、正式親屬關係、指定不可變的外貌辨識 DNA 與能力硬邊界）；**②已確立的偏好／擅長**（她喜歡或能做某事，不代表只喜歡那件事、只做那件事，也不代表做該事的時間占比固定）；**③某張參考圖、一次互動或某個故事曾出現的物件、衣著、動作、台詞與情境**（除作者另外明確確認為固定條件外，只證明**這樣也可以成立**，不自動證明她每次出場都如此）。「喜歡」不是「每次」，「擅長」不是「永遠在做」，「曾經拿過」不是「隨身不可缺少」，「有代表性」也不是「唯一可選」。
