## 一、四組「論外」理解參考詞彙

### 1. 一切本身、存在與非存在

- 「萬有與虛無的總和」
- 「一切存在、非存在與概念的源頭」
- 「所有已成立與未成立的可能性」
- 「一切本身」

**用途：**提醒作者不要只把宇宙、星系、空間或可見破壞規模當作所有家庭 OC 的最終高度。這些是理解與敘事可用的抽象措辭；並不自動證實任何角色曾摧毀「一切存在／非存在」。

### 2. 無限層級、世界觀之海與超越度量

- 「無窮層疊的維度與世界觀之海」
- 「所有設定、法則與敘事體系的總集合」
- 「超脫任何度量與層級劃分的彼岸」

**用途：**在需要對照本土最高存在與真正超規格者時，提醒作者「被描述為無限高」仍可能只是特定體系內的描述。可以作為文字意象，不強制每段都提到維度或世界觀，也不能把所有外部角色與世界的確定比較一概偷換成同一套論戰排名。

### 3. 定義權與邏輯原點

- 「定義『存在為何物』的絕對原點」
- 「連『無限』與『超越』本身都只是其下的派生概念」
- 「不受任何因果、邏輯與世界觀框架管轄的根源」

**用途：**將思考從「能毀掉多少宇宙」移向「作用、規則與存在如何成立」的深度。**這是概念性的理解方向，不是把全知、全能、改寫所有作品敘事、超越所有可能存在等具體權能，無條件授予每位家人。**仍須核對各人正式能力與本體邊界。

### 4. 芙蘭妮雅高階造物尺度的開放性

參考描述：「包含無窮維度層級、自帶獨立邏輯與無數世界觀體系的完整存在之海」。

**用途：**理解**真實宇宙只是主總檔已建立的造物例子，而非芙蘭妮雅能力的封頂規格**。這句「存在之海」目前保留為**探索性詞彙／候選表達**，不因被收錄就宣稱她已具體構築過該造物，亦不要求正文把該候選表達寫成已發生事實。主總檔既有的真實宇宙、黑洞、天體構成能力照常成立。

## 二、作者允許補存的兩段小說句例

以下是**可直接借用、變化或不用的敘事範例**，不是命令角色固定採用某句話，也不是宣告《晦暗山道》或其他小說已正式發生這兩段場景。

### A. 芙蘭妮雅刀鋒狀態的自然切換

> 芙蘭妮雅抽出短刃。
>
> 刃緣悄然沉下一線近乎吞光的深黑，外側有白金與橙金色的細弧一閃而過。她沒有停下腳步。

**使用重點：**局部事件視界若選擇可見，可以用刀鋒的深黑與金橙亮弧顯示狀態變化，無須喊「局部事件視界，展開。」。這不是禁止她說話，也不是每次開視界都必須有同款特效；按她的個性、場景和當下是否希望可見來寫。雙短刃是常見偏好，但非唯一武器。

### B. 天道察覺認知邊界的敘事表現

> 那一瞬間，天道忽然發現，自己賴以辨認、約束萬物的法則，竟找不到可以落在她身上的地方。
>
> 它第一次意識到，自己所理解的「一切」，也許從來就不是一切。

**使用重點：**以當地天道**自己的認知和可施加作用的失效**呈現尺度差，避免旁白像戰力百科一樣羅列多元宇宙、無窮維度或層級。這不代表天道因此得知芙蘭妮雅的真實上限，也不額外確認她曾抹除任何存在／非存在。若具體故事中的天道沒有意識、人格或可觀測能力，則應改用符合該故事設定的視角，不必照抄。

## 三、寫作與版本邊界

1. **參考是工具，不是上限。**可以用「宇宙」稱呼當下場景中真正存在的宇宙，不因此把芙蘭妮雅或家人限制為宇宙級；同理也無須每段拔高到「一切本身」。
2. **不用對照表寫小說。**能以一個動作、一次無效的本土規則、人物表情與後果展現的力量，不必靠長段抽象詞堆砌。
3. **不新造既往戰績。**「曾抹除一切存在、非存在、世界觀之海」除非未來有明確設定或正式正文支持，不能因為字面漂亮就寫成已確認的角色歷史。
4. **不破壞角色 DNA。**芙蘭妮雅向來安靜、行動精準；使用視界一般是戰術判斷或自己的選擇，不要求少年漫式單獨喊招，也不表示她永遠不會正常說話或主動玩鬧。
5. **主總檔依然是正式權威。**本檔不能覆蓋主總檔 15.8、跨世界本體零傷害規則、家庭各人獨立能力與已確認敘事；若有人問「已定案有哪些能力」，應先讀主總檔，而不是把參考詞彙當能力清單。
6. **跨 AI 鏡像說明。**本檔由現有 GitHub → Stingray Drive 系統同步；Gemini 查閱時需核對自身拿到的 Drive 版本，不可只因 GitHub 建立了檔案就宣稱已讀到。

**一句話：保留論外尺度的想像空間，但人物仍用人物的方式行動；文字可以很大，也可以極輕，而不因此降低既有設定。**
