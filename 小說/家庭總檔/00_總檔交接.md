# 家庭總檔｜交接

- 外層資料夾名稱正式改為 `家庭總檔`。
- `01_家庭完整角色設定總檔.md` 是跨世界線共用角色資料的權威入口。
- 主檔名稱使用「家庭」，因內容已包含原四人核心、璃安、小曦，且之後還會繼續增加新的固定家庭成員；新增第七名、第八名時不再改主檔名稱。
- 原四人核心仍是絲蒂莉雅、薇絲莉雅、塞希莉雅、法月懷；璃安、小曦各自擁有獨立人物章。
- 原四人核心的共同歷史、雙人關係與四人專屬設定仍保留原本四人分類。
- `03_互動文案/` 專門保存依「幾人組 → 誰跟誰 → 文案」拆分的互動場景，不再重複塞回主總檔。
- **互動文案即時同步規則：**之後只要在對話中完成一篇可成立的家庭／OC互動文案，完成後預設立即補入 `03_互動文案/` 中最合適的角色組合檔，不等待另外一次「存檔」指令。若同一組合已有文案，依內容加入本組文案索引並追加新篇；若新版本明確取代舊版本，則直接替換舊文並同步索引／說明。
- **先寫入、後修正是正常流程：**寫入 GitHub 不代表第一次版本不可變。若使用者之後不滿意、要求局部重寫、大幅重構，甚至整篇重寫，直接以最新要求修改／替換已寫入的互動文案；被後續版本否定的舊內容不再作有效依據。GitHub 中的互動檔應盡量保持與目前對話中最新完成、最新確認的版本一致。
- `references/` 是人物外貌與局部細節參考圖，只作視覺校準。
- 各小說世界線可以有情境差異，但不得擅自改寫共用角色的核心人格、關係與外貌正典。
