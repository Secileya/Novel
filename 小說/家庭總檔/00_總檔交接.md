# 家庭總檔｜交接

- 外層資料夾名稱正式改為 `家庭總檔`。
- `01_家庭完整角色設定總檔.md` 是跨世界線共用角色資料的權威入口。
- 主檔名稱使用「家庭」，因內容已包含原四人核心、璃安、小曦、芙蘭妮雅，且之後仍可繼續增加新的家庭成員；**家庭總人數不固定**，後續新增成員時不再改主檔名稱。
- 原四人核心仍是絲蒂莉雅、薇絲莉雅、塞希莉雅、法月懷；璃安、小曦各自擁有獨立人物章。
- 原四人核心的共同歷史、雙人關係與四人專屬設定仍保留原本四人分類。
- **家庭成員的道德／行動判斷不能只看結果。**家庭成員都可能擁有極漫長、跨世界、複雜的人生；在這種生命尺度下，殺人、欺騙、背叛、利用、犧牲他人、與敵對者合作等不乾淨或艱難的行為，都可能在不同時期、不同環境與不同必要性下出現。不能僅因「做過某件事」就把角色簡化成善／惡、冷血／聖母；必須連同當時環境、角色掌握的資訊、可選方案、關係、目的、威脅、代價與人物性格一起判斷。
- **相似結果不代表相同人物邏輯。**不同家庭成員面對類似事件，可能因各自經歷、價值觀、感情與性格做出完全不同的選擇；同一角色也可能隨時間、成長、關係與世界背景改變判斷。上述原則不等於硬性宣告「全家都一定做過完全相同的事」，只固定不能用單一結果反推人物本質。
- **芙蘭妮雅的必要性與生存史要單獨保留。**她確實可能做過在普通道德框架下很髒或殘酷的事，包括必要時殺死本性不壞甚至是好的人、背刺、說謊、利用他人等；這些行為必須依當時情況與必要性理解，不能寫成她享受作惡或天生冷血。背刺尤其可以成立於對方長期操控她、把她當工具隨意使喚、消耗、犧牲或準備棄置／處理她的關係中；當她判斷合作關係實質已被對方破壞後，可能先下手。說謊則可只是普通生存手段。
- **芙蘭妮雅不是「見殺必救／見惡必管」的自動英雄模板。**看見有人正在被殺、本性善良的一方受害，或看見明顯惡意，本身都不是她必然介入的充分條件。她是否出手，要依當時是否與自己或在意的人有關、她是否已經捲入、她想不想管、成本與風險、雙方關係、後果、興趣／厭惡與當下選擇判斷；她可能救人、旁觀、幫其中一方、兩邊都不管，或只做到自己願意做到的程度。這不代表她沒有感情，而是她不把善惡標籤本身當作絕對行動規則。
- `03_互動文案/` 專門保存依「幾人組 → 誰跟誰 → 文案」拆分的互動場景，不再重複塞回主總檔。
- **互動文案即時同步規則：**之後只要在對話中完成一篇可成立的家庭／OC互動文案，完成後預設立即補入 `03_互動文案/` 中最合適的角色組合檔，不等待另外一次「存檔」指令。若同一組合已有文案，依內容加入本組文案索引並追加新篇；若新版本明確取代舊版本，則直接替換舊文並同步索引／說明。
- **先寫入、後修正是正常流程：**寫入 GitHub 不代表第一次版本不可變。若使用者之後不滿意、要求局部重寫、大幅重構，甚至整篇重寫，直接以最新要求修改／替換已寫入的互動文案；被後續版本否定的舊內容不再作有效依據。GitHub 中的互動檔應盡量保持與目前對話中最新完成、最新確認的版本一致。
- **長事件／多人文案允許拆出自然成立的較小子互動。**判定依當下實際互動人物，不依整條事件總共出現過誰；只在子互動本身完整、具有獨立關係價值且能提升檢索時拆，不為填滿組合檔硬切。第三人若仍持續插話、改變節奏或影響反應，就不能硬降成雙人互動。
- **所有拆出的子互動都要標來源。**至少記錄來源檔案、來源文案標題，以及是「同一事件文字截取」還是「同一事件後續／延伸子互動」；完整來源與子互動任何一邊後修時，都要回查另一邊，避免同一事件被寫成兩次或產生台詞／因果矛盾。具體細則與既有案例見 `03_互動文案/00_互動總索引.md`。
- `references/` 是人物外貌與局部細節參考圖，只作視覺校準。
- 各小說世界線可以有情境差異，但不得擅自改寫共用角色的核心人格、關係與外貌正典。
