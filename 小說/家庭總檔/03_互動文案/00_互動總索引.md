# 家庭互動文案總索引

這個資料夾專門收納目前已建立角色——**絲蒂莉雅、薇絲莉雅、塞希莉雅、法月懷、璃安、小曦、芙蘭妮雅**——之間的互動文案。這只是目前已建檔範圍，**不代表家庭總人數固定為七人**；之後新增家人時再延伸組合與索引。

目前固定使用三級結構：

1. **互動文案總索引**
2. **按參與人數分資料夾**
3. **每一個「誰跟誰」再各自獨立成檔**

例如：

`03_互動文案／01_兩人組／01_絲蒂莉雅×薇絲莉雅.md`

每個組合檔裡，再放該組自己的「本組文案索引」與完整文案。**組合檔已建立不等於該組所有具體關係細節都已固定**；沒有正式文案的檔案只保留結構位置，等實際互動成立後再收錄。

## 整理規則

- 每個「誰跟誰」都是獨立檔案，不再把同人數的所有組合塞在同一份大檔。
- 每個組合檔即使尚無文案，也保留自己的「本組文案索引／狀態」；有正式文案後再依序加入。
- **對話中每完成一篇可成立的家庭／OC互動文案，預設立即同步進最合適的組合檔。**不要因為「之後可能還會改」就先放著不寫入；如果使用者後續不滿意，直接回頭改 GitHub 裡已收錄的版本即可。
- **第一次寫入不是永久定稿。**使用者後續可以要求局部修改、大改、整篇重寫或完全替換；此時以最新要求為準，直接修改／替換已存版本，必要時同步文案索引與狀態說明。被後續版本否定的舊文不繼續當作有效正典。
- 若同一組合又完成另一篇不同情境、且不是舊篇的重寫，則作為新文案追加到同組檔案，不覆蓋彼此。
- **長事件可以拆出較小組合的獨立子互動。**判定看「該片段當下實際由誰互動」，不是只看整個事件總共出現過誰。若第三人已退出當下互動，只剩被提及、成為話題來源或前情背景，可以歸入雙人互動；反之，只要第三人仍持續插話、改變節奏或影響兩人的反應，就不能為了補檔硬切成雙人片段。三人、四人等較小組合亦同。
- **不是所有長文都必須拆。**只有當子互動本身足夠完整、具有明確角色關係價值、單獨保存能提升日後檢索時才拆；短暫的一兩句對話、其他人在場且持續影響節奏的片段、或切開後必須靠大量外部正文才能理解的段落，原則上保留在原文即可。
- **拆出的子互動必須追蹤來源。**子互動檔需在文案標頭或情境說明中標明：`來源檔案`、`來源文案標題`、`來源關係`。`來源關係`至少區分「同一事件文字截取」與「同一事件後續／延伸子互動」；不要把不是逐字摘錄的後續場景誤標成文字截取。
- **截取版只補最少必要前情，不把同一事件寫成發生兩次。**完整多人版本與子互動版本可以同時存在，但兩者是同一條事件鏈的不同檢索切片。完整來源後續若被重寫，已拆出的子互動必須一起回查；子互動若被重寫，也要確認與來源事件的因果、資訊邊界、時間線一致。
- **既有來源案例：**`01_兩人組/11_塞希莉雅×璃安.md` 的《走廊上的秘密：被希雅師祖一眼看穿》屬於「同一事件後續／延伸子互動」。其前置來源為 `02_三人組/03_絲蒂莉雅×薇絲莉雅×璃安.md` 的《門沒關好：璃安撞見兩位師尊的夜晚》；之後再銜接 `03_四人組/02_絲蒂莉雅×薇絲莉雅×塞希莉雅×璃安.md` 的《假裝什麼都沒發生：撞門事件後的早餐》與 `04_五人組/01_絲蒂莉雅×薇絲莉雅×塞希莉雅×法月懷×璃安.md` 的《懷姐姐也知道了：早餐桌上的集體害羞》。這個案例不是把走廊文誤當成前一篇的逐字摘錄，而是同一事件鏈在人物焦點收束後形成可獨立保存的雙人段落。
- 若舊文後來被修正、否定或被更完整版本取代，只保留有效版本，必要時標明修正原因。
- 角色設定以《01_家庭完整角色設定總檔.md》為權威入口；互動文案在此獨立保存，不再重複塞回主總檔。
