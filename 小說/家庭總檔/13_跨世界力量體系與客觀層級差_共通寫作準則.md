# 跨世界共通寫作準則｜「不同力量體系」不等於「力量層級相近」

> 2026-10-24｜來源：使用者在「都市重生仙尊＋五位 OC」討論中指出多部跨世界作品反覆出現的偏差——「OC → 不同體系 → 只是不同體系的力量而已，力量層次沒差多少」——並要求補進長期設定。
> **性質：跨世界角色力量比較與寫作判斷的高優先共通準則〔USER-FIXED 的原則＋其敘事實作〕。**
> 本文**不替代** [家庭角色主總檔](01_家庭完整角色設定總檔.md)、既有修正／人物補充，也不擅自把未寫出的權能當成十名家人共有。當某人的精確能力邊界或特定世界的客觀上限未定時，依正式設定判斷並保持 OPEN。
> **跨世界原則 ≠ 所有世界線已發生同一事件。** 新故事裡的相識、教導、贈寶、交戰、突破，仍須各自有時間與因果。

## 一、被指正的核心錯誤：不同體系的「敘事性強行平衡」

錯誤模式：
1. 當地世界的仙尊、仙帝、神王、創世神、宇宙法則持有者登場，作者認可其在當地確實是頂點；
2. 跨世界 OC 進入，使用其他來源的力量：本源之火、因果支配、事件視界、法則之上權柄、極高階神識或巨構管理權限等；
3. 旁白為了營造「彼此尊重、各有長處」，只說「一個用仙道、另一個用不同體系」；
4. 因而**在沒有客觀依據的情況下**，讓雙方的力量效力、法則深度、有效抵抗、碰撞結果甚至本體受傷可能性自動變成相近；
5. 久而久之，家庭 OC 在每條世界線都被「在地最高等級」無形地壓回同一檔，與已確立的跨世界本體實力矛盾。

**正式修正：不同體系，只回答力量「怎麼來、怎麼運作」；不回答「和誰同級」。不同來源與力量級別可以無關、接近、懸殊或不可用同一標尺度量；必須用已固定的客觀力量層次、法則支配深度、能力上限與情境實際比較。**

正向表述：某位仙帝真能操控其宇宙的時間大道，並不表示他能把時間能力施加到根本不在那套時間規則約束內的高層 OC。仙帝的能力不因此變假；**他的作用域與上限是真的，OC 的更高層邊界也是真的**。當雙方差距極大，不能以「兩個法術流派各有千秋」偷換為「同等力量碰撞」。

## 二、必須分開的九個比較維度

| 面向 | 要問的具體問題 | 禁止混淆 |
| --- | --- | --- |
| 1. 力量來源／體系 | 仙氣、法力、魔力、科技、神性、血脈、根源權柄、角色殼？如何接入？ | 異源 ≠ 等階相近，也 ≠ 絕對無法互相影響 |
| 2. 客觀力量規模 | 實際可造成、抵擋、維持多大的效果？能作用多久？精度與並行如何？ | 同樣叫「毀滅世界」可能所指結構不同 |
| 3. 法則權限與深度 | 是在既有法則下使用術法、改寫局部規則、作用於法則結構本身，還是根本不受該法則管轄？ | 都寫「時間」或「因果」≠ 都有同一級權限 |
| 4. 存在與本體層級 | 當事人本體、分身、投影、化身、低階角色殼各是什麼？能否被對方規則有效指向？ | 角色殼受限 ≠ 本體被永久削弱 |
| 5. 作用域與合法條件 | 權能僅在自造世界內有效，還是跨世界皆具有相應本體能力？有哪些界域、合約、媒介限制？ | 自家世界的管理權 ≠ 在所有世界同款最高管理權 |
| 6. 相性／抗性／交互規則 | 攻防是否作用同一對象？防護與破解在當地確實成立嗎？ | 相剋可改變交手結果，不能當作無證據平衡器 |
| 7. 技術、理解與控制 | 使用者是否熟悉此力量？能否即時最佳化、精確收放、跨系統建模？ | 不熟當地 API ≠ 高階技術倒退為新手 |
| 8. 可觀測性／情報 | 角色知道多少？見到現象是否足以推論本體、原理和上限？ | 看見一招 ≠ 自動識破全部權柄 |
| 9. 主動選擇／自限 | 是否為了遊戲、觀察、旅遊、交易而刻意少用力量？ | 自限、禮讓、沒有出手 ≠ 客觀力量下降 |

不可只看名稱「仙帝」「神王」「超十級」「創世神」斷言同級，也不可不經設定核對就對 OC 加上「超越任何已知／未知存在」的全能斷言。**共同硬核是尊重已確立的力量邊界，而非製造另一套沒有證據的無限比較表。**

## 三、三個高頻誤寫的對照

### 例 1｜同樣能影響時間

- 當地仙帝：在自己的宇宙法則架構內加速、倒流、封鎖時間，是真正極高層的修行成就。
- 一名高階 OC：依其已確認的實際能力，可能作用於該時間規則的更深結構，或不被相同的時間法則拘束。
- **錯誤**：「兩者都是時間能力，只是不同修法，因此暫時平手。」
- **正確**：先判定客觀作用域、規則優先級、能否有效作用其本體。若差距極大，出手結果必須承認差距；當地仙帝仍可以是其宇宙內毋庸置疑的至尊。**是否某位 OC 實際具有上述具體時間權限，要依個人原始設定，不能由這個示例擅自添加。**

### 例 2｜當地宇宙級轟擊與 OC 的防禦

- 當地強者可以真實摧毀無數星體、宇宙或世界；其戰績不必被改成幻術。
- 若已固定 OC 的本體不受該等級／該世界機制有效干涉，攻擊可以對環境造成真實後果，卻不因此能傷到本體。
- **錯誤**：為讓打鬥激烈，臨時讓「當地仙帝至強的一擊」重傷原本根本不在其可及尺度上的 OC。
- **正確**：若故事真正需要同等風險，要先有**更高等級且能合法作用本體**的威脅，或改以人命、承諾、城池、信息、護送、社會後果構成事件壓力，**不是憑空削弱人物**。

### 例 3｜主角觀察高位力量後的領悟

- 觀察者可能真能從所見現象中發現自己舊功法的隱含假設、法力路徑冗餘、法則理解片面、神通成本不合理；
- 但「看懂一部分現象」或「由現象得到啟發」**不等於**取得該 OC 對法則的權限、本體層級、所有技巧或任何未獲得的材料。
- **錯誤**：「他從芙蘭妮雅的因果力量悟出新的因果神通，於是達到了與她同等的根源層級。」
- **正確**：「他從那個與自身仙道根本不同的現象，重新推演了原本仙術，取得真實而可能很大的效率、穩定度、掌控力或境界成長；但與所觀察權柄的客觀差距仍存在。」

## 四、當地最高強者不應被貶低成無知炮灰

- 仙尊／仙帝可以有真正漫長的修行史、完整大道理解、自己的師徒、敵友、文明責任與重大戰績。
- 他對自己世界的法則、戰鬥、醫術、煉丹、劍道可以確實頂尖；即使無法對某 OC 造成有效傷害，也不是「所以修了百萬年全部都是笑話」。
- 若高層人物初次無法理解某現象，可表現為**清醒地認知未知、謹慎實驗、更新理論**，不必傲慢到失去判斷。
- 旁人對高位 OC 本體仍可能不知道；**客觀階差 ≠ 全世界自動知道階差**。旁人的質疑不需自動引發暴力。
- 低階人物偶然猜中某個「高階現象」的外觀，不代表他掌握形成原理。
- 不同層次也可有正常社交、真誠欣賞、互相友好。**力量不對等不等於人格、情感、技藝審美與社會價值也不可交流。**

## 五、十名家庭成員在跨世界比較中的內部規則

以 [01 主總檔第二章](01_家庭完整角色設定總檔.md) 的最新十人相對純實力為準：

**法月懷 ＞ 塞希莉雅 ＞ 朔凜月 ≥ 洛琪莉卡 ＞ 絲蒂莉雅 ≈ 薇絲莉雅 ＞ 璃安 ≈ 芙蘭妮雅 ＞ Celeste ＞ 小曦。**

1. 此為家內純實力排序，不是各人的地位、家庭順位、情感價值或可見表演強度。
2. 家內排名較後者，在普通都市修仙、魔法或低層宇宙仍可能遠遠超出世界最強者；**不能從「家裡最小」推導「在外界只是入門級」**。
3. 排序中的 ≈、≥ 表示相近或有情境彈性的關係，不表示每次交手必然固定勝負。
4. **璃安**：最新資料已確認神識可及大量星系、戰力遠超普通低層宇宙；不能因對方冠以「仙尊」就自動判定他與她同階。其具體技能由主總檔13章界定。
5. **芙蘭妮雅**：全武器、瞬時重構、作用控制、事件視界和極高階信息／魔法理解，不能被降成「一名懂不同武技的高手」。同時若她自願接受某遊戲角色殼限制，須分清本體、輸出載體與該系統規則，不能借用角色殼倒推本體真實上限。
6. **洛琪莉卡**：本源之眼與本源之火作用於更深的存在／法則／概念等層面；**不是當地火系仙法的同級變種**。不能因她愛玩、搞笑、帥氣而讓她在真正危機時被本來遠低的敵人機械性壓制。
7. **Celeste**：她在**自己巨構世界**具有管理權限與本地手段無法真正傷害她的特殊地位；跨世界家內純實力仍明確低於芙蘭妮雅、高於小曦。不得將**巨構世界的管理權限**擅自改寫成她去任何世界都天然擁有的萬用管理後台，也不能說離開巨構就變成當地普通法師。
8. **小曦**：有自己的意志、理解與極高階本體，不因年紀感、兔耳、懵懂或家內排序最後就被按地球「低階修士」處理；若需界定具體法則可行範圍，回查主總檔，不自動把其母親全部能力當成她已能同級運用。
9. **法月懷、塞希莉雅、朔凜月、絲蒂莉雅、薇絲莉雅**等其他家人的既有能力也完全沿用主總檔，不為了跨世界可讀性將其改寫成「當地某系最高境界」；各人的力量形式與人格、親密家庭關係依其固定章節。

**關鍵：高階 ≠ 十人同能力、同權限、同知情範圍。** 判斷哪一位能做到什麼，要找到其個人正式條款；本共通準則只阻止無根據的降格或假平衡。

## 六、針對跨世界戰鬥／法則接觸的作者層檢查

正式安排一次高層對抗前，至少釐清：

1. **當地最強者的客觀戰績與境界**：是否只是傳聞，還是真實已發生？
2. **OC 在此世界使用的是本體、投影、分身、載體還是自選規則身份**？不能混成同一個血條。
3. **雙方具體力量可作用的規則和對象**：能否相互指向？哪些只影響環境？
4. **已確立的實力／法則深度差**：有沒有因為想要打得好看而無證據抹平？
5. **相性和局限有具體世界法則支撐嗎**？不能只說「異體系互相克制」就無條件平衡。
6. **當地人物能知道哪些情報**？看見現象 ≠ 知道底層權限；不說明 ≠ 一定隱藏。
7. **OC 是否主動收力、自限或配合玩法**？怎樣寫才不讓讀者誤以為其本體被削弱？
8. **如果真的能力懸殊，事件要靠什麼推進**？可以靠城市人際、承諾、價值觀、被保護者的願望、交易、修仙者自己的難題等。
9. **若地方強者仍是真強者，他還能有哪些可敬或有趣的表現**？不必被宣告數值差距後整篇失效。
10. **是否錯把 OC 的觀測能力、權能或局部提示當作可複製獎勵**？得到啟發與取得權柄必須分開。
11. 若真正同級／更高位的特殊對手出場，**是否有先前明確建立的來源、合理稀有度和能力互動**？不可為了平衡臨時追加任意高位者。
12. 這段故事是否仍符合該世界線的鏡頭優先級？**本原則不要求用一場高層對決來「證明 OC 很強」。**

## 七、知識、理解、境界、權能四者分開

特別容易在修仙、法則小說中誤判：

- **看見**：知曉有一個現象發生。
- **描述**：能以自己的術語表述該現象的一部分。
- **建模**：能提出可檢驗的機制與限制，排除錯誤理解。
- **應用於自身**：能在現有法力、靈根、功法和世界條件下開發受用的方法。
- **達到相同效果**：對某一有限對象可得到相似結果；不等於實現同一底層原理。
- **取得相同權限／本體位階**：必須有**額外已正式成立的高層因果與能力前提**，不能靠觀察、交流或被指點自動成立。

因此一位仙尊完全可能大幅改善自己修煉效率，卻仍不是當地 OC 的等級；也可能理解了更深的理論，暫時因肉身／靈氣／道基未到位而無法實行。

## 八、敘事語氣與防模板化

**禁止的固定句型與後果：**
- 「同為掌控因果，所以兩者同階。」
- 「雖然是不同世界力量，但碰撞下誰也奈何不了誰。」（若沒有能力依據）
- 「仙帝這些年修煉都白費了」。（以嘲諷取代尺度分析）
- 「OC 因當地規則不同而完全失去高層能力，只剩普通武技。」（除非已設定真有限制及其作用範圍）
- 「仙尊看了三秒便完全破解高層 OC 的本體構造。」
- 「仙尊吸收一次啟發便達到 OC 的存在層次。」
- 「力量相差很大，所以兩人不可能有真實友情、認同、談笑或彼此學習。」

**允許而且值得的表現：**
- 高層強者真有資格讓地方社會敬畏，但在某個不屬於自身規則上限的現象前願意謹慎研究；
- OC 精確控制自己的強力能力，維持普通社交、玩心或欣賞他人的技藝；
- 仙尊經過真實長期推演，重新優化本命功法，甚至超越前世；**不靠 OC 白送同級權柄**；
- 兩者沒有交戰，只靠一場技藝交流，讀者也能逐步感覺到能力理解的層級差；
- 面對世界原有強者、商人、醫生、學生與家人，OC 有自己的選擇，故事仍由世界自有因果推進。

## 九、權威關係和跨線使用方式

1. **最高權威仍是使用者對每位 OC 的最新個別決議與家庭主總檔**。本文只能協助正確比較，不能任意修改人物原始實力。
2. 本文適用於把家庭 OC 帶入都市修仙、仙界、魔法、科技、末世、遊戲、Backrooms、其他原作融合世界等所有**使用相同家庭本體 DNA**的跨世界線；但每條世界線自己選擇的角色殼／投影／合法規則／已發生關係也須遵守。
3. 本文不要求已存在所有小說正文被無證據改寫；若發現與既定能力矛盾的橋段，應按正式版本管理進行核對與具體修訂。
4. **巨構世界 Celeste 與其他家人「尚未相遇」只限該特定故事當時進度**；跨世界家庭共通設定中十名家人已相處很久、彼此熟悉（2026-10-24 正式校正）。
5. 目前**沒有**依這份原則替任何人新增全宇宙唯一最高權能、無限技能，也沒有決定任意兩位異世界神明必定如何交手；若某個新世界客觀力量上限、具體角色存在位階、低階角色殼效力不明，必須留待本世界線具體設定。

## 十、一句話核心

**OC 不會因為進入另一個世界，就自動被其「仙帝／神王／創世神」的境界詞拉成同級；保留雙方既有真實能力與客觀層級差。當地強者可以依真實見識學習、成長，甚至得到突破，但「看見更高層次」不等於「擁有更高層次」。**
