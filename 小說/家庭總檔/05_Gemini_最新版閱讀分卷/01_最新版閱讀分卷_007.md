### 9.2.13 《鬼》的角色意象映照

**【全曲情緒／原始家庭悲劇群像／不是正式正文】**草東沒有派對《鬼》（《醜奴兒》），完整歌詞核對：[LINE MUSIC](https://music-tw.line.me/track/7143541008)及[歌詞資料](https://www.mulanci.org/lyric/tl218170/)。本節依原曲的歉意、自卑、愛與傷害、敘事主詞的反轉、重複的副歌與最後「鬼」的意象逐段解讀，不將歌詞當成角色確實說過的話。

**人物前提：**杏親歷的原始家庭悲劇中，塞希莉雅首先死亡，之後才出現一系列牽動其他家人的事件、選擇與分歧；杏的表現可反常到抱著逝去的塞希莉雅笑。這些事件如何演變、各人的具體責任、死因與相見先後，目前仍須留待正式情節。

<a name="doc-nav-240"></a>
#### 歌曲結構：並非單純的無敵之鬼

原曲先談原本不願傷害別人與歉意，接著把自身的自卑與所愛之人的毀滅相連；下一句主詞轉向「妳」，讓對方的傷悲反過來摧毀「我」。副歌兩度重複追問流血與流淚的原因，最後躲在夜裡取笑黑暗，以鬼無法被殺死收束。

**它不是純粹的強者宣言。**自我否定、相互造成的傷害、愛、怨與難以終結的痛，才是完整情緒。映照 OC 時不可固定每個「我」都是杏、每個「妳」都是塞希莉雅；需要給各位家人自己的位置。

<a name="doc-nav-241"></a>
#### 開頭：不想傷害，不等於沒有造成後果

沒有傷人的原意與對後果感到歉意，可以映照塞希莉雅第一個死亡後，仍然存活的家人試著保護、理解、挽回彼此，卻讓更多行動互相影響的連鎖結構。原本出於愛作出某項決定，不保證結果就不會傷害人。

**歌詞不能代替責任判決。**這不等於杏有罪、無罪或已正式向誰道歉；杏與妹妹、三姐及外部因素究竟如何參與因果，仍須有真實的故事過程。

<a name="doc-nav-242"></a>
#### 自卑與愛：力量的無限，不代表情感沒有裂縫

歌曲將「自卑」寫成扼殺所愛之人的深層原因，這不能機械套成杏力量不足：**杏的天賦、理解、成長與突破能力原本沒有上限**，能重建並改寫存在與歷史。

較合適的映照是自我否定、對自己的選擇感到複雜、或在一連串不幸後承擔甚至過度承擔責任的可能性；是否真的如此、程度多深，仍待正式劇情。**「我殺了家人」在此不是杏親手逐一殺害家人的客觀認定**，而可能是對連鎖後果的情感說法。

<a name="doc-nav-243"></a>
#### 由「我」到「妳」：悲傷也能反過來傷害所愛

原曲相鄰兩段將傷害方向翻轉：一人的自我否定傷害所愛，另一人的傷悲又摧毀了前者。此處適合家庭群像，因為悲劇中各人的愛、痛苦、判斷和選擇不會互相隔絕。

塞希莉雅死亡後，杏與朔凜月、洛琪莉卡可能仍然深愛彼此，也真的在某些事情上無法相互認同。妹妹們所感受到的失望與憤怒不是假的，杏的痛與瘋狂也不是假的。這裡的「殺死我」可作為原本熟悉的生活和關係遭摧毀的意象，不等於妹妹能在字面上殺死杏。

<a name="doc-nav-244"></a>
#### 副歌：流血、流淚，究竟為了誰

血指向確實造成的傷害與死別；淚可以指向悔恨、悲痛、心疼與難以言說的愛，但**絕不要求杏依照普通人的哀悼方式哭泣**。杏本來就有瘋狂、強烈、極端而情緒豐富的反應；家人也不會只有一種哭法或責備方式。

副歌兩度提出問題而沒有給出唯一答案，適合漫長的連鎖悲劇：每一次傷害為何發生、誰想保護誰、誰承擔後果，不應簡化成「都因為杏」或「杏完全沒有責任」。比 Stiliya／Versiliya 更早的家人也有自己的生活與感情。

<a name="doc-nav-245"></a>
#### 夜裡笑著的鬼：抱著塞希莉雅的反常之笑

最適合杏的畫面，不一定是哭泣或咆哮，而可能是**她抱著已逝的塞希莉雅，仍然笑著**。那笑可以古怪、瘋狂、令人毛骨悚然，也可能纏著愛、悲痛、自嘲與旁人難以辨認的情緒；不能立即解釋成享受塞希莉雅的死亡。

朔凜月與洛琪莉卡看著熟悉的大姐如此反常，可以憤怒、失望、悲傷、害怕，也仍然想她回來。這種笑不能拿來宣判杏失去智慧或真的不愛家人，具體鏡頭與心理留待未來正文。

<a name="doc-nav-246"></a>
#### 無人能殺死鬼：字面的不可傷害與無法保護的一切

原曲鬼的意象可指向被痛苦、過往與自己所作之事纏住的存續；杏則更進一步具有**外界沒有任何存在能傷害她**的字面條件。她卻仍真切經歷家人相繼失去的歷史。

杏最後抹除的是所有生命、未誕生之物、所有可能性與一切本身，沒有留下能繼續存在的念頭、意識或能力；不是普通「殺死一次」可概括。她之後能重建與重寫事實，不會自動抹掉她選擇保留的主觀經歷。

**外界不能殺死杏，不等於她不能自行消散。**她重製為懷時曾真心打算從懷最深處逐漸消散，後來因整個家人活出的新人生而留下；《鬼》與《転生林檎》《分かっちゃいないね》可以藉此形成時間上的呼應。

<a name="doc-nav-247"></a>
#### 重複副歌與《無職轉生》轉折點四的連鎖結構

使用者明確提出可參照《無職轉生》轉折點四：一個起初局部的變故，經悲傷、誤解、外力、選擇、彼此關係的改變，最後擴散為漫長且難以挽回的失去。**借用的是敘事因果的形狀，並非直接把老鼠、疾病或原作人物換名搬入本世界。**

杏的原始悲劇不能只寫成「塞希莉雅死→杏笑→所有人死→杏毀滅一切」。其間必須讓妹妹、三姐與其他家人真正生活、行動、分歧甚至互相傷害，而不是只等待結局。歌曲重複的血與淚，更像同類痛苦以不同事件不斷回到人物眼前，並不證明實際滅世多次發生。

<a name="doc-nav-248"></a>
#### 更早的家人：朔凜月與洛琪莉卡

家庭位置暫定：杏／懷為大姊的參照；**朔凜月（Shuolyue；非血緣妹妹）**與塞希莉雅都可算二姊，但**朔凜月在重製前已與法月杏相識，早於塞希莉雅與這位大姊相識**；**洛琪莉卡（Loqilica；綠髮）**列三姊，絲蒂莉雅與薇絲莉雅在後。兩人的名字現已確定，其餘個人設定仍待補完；這不表示已建立全部家人名單。

朔凜月對杏**從未停止愛**。她會難過、傷感、憤怒、失望、心疼與盼望，與杏發生真實分歧，卻仍愛她直到生命最後；決絕、遺憾、釋懷不表示完全原諒或斷絕愛。洛琪莉卡也擁有對大姐及朔凜月的獨立牽掛，後期「附隨二姐而去」是未鎖死死因的敘事方向。兩人的人生不能被簡化成杏的創傷素材。

<a name="doc-nav-249"></a>
#### 《鬼》的核心與必須留下的空白

這首歌最能承載的是：**沒有人能殺死杏，而杏所愛的家庭卻仍然在連鎖悲劇中逐漸崩毀；她甚至可能笑得像瘋子，愛卻沒有因此消失。**同時，妹妹們可以深愛她，卻仍因她做出的選擇而真正憤怒與失望。

固定的是塞希莉雅先死、後續有連鎖與分歧、杏極端反常、朔凜月臨終的三種感情，以及杏後來終結一切與重製自身。**未定**的死因、事件順序、誰對哪個後果負責、臨終言語、衝突細節，不能因為這首歌就擅自補成正典。

### 9.2.14 《蘭亭序》的角色意象映照

**【全曲情緒／朔凜月的親情／不是臨終台詞】**周杰倫《蘭亭序》，方文山作詞、周杰倫作曲，收錄於《魔杰座》。來源：[官方 MV](https://www.youtube.com/watch?v=s5Xl5MXboas)、[完整歌詞](https://www.shazam.com/zh-tw/song/1721460918/%E8%98%AD%E4%BA%AD%E5%BA%8F)。本節從臨帖真跡、日常意象、反覆副歌、回憶怨懟，到最後副歌的新詞意完整映照。

原曲是戀愛歌曲，本節轉譯成**朔凜月（Shuolyue）與大姊杏的深厚親情**；她是法月的非血緣妹妹、二姊之一，在重製前已與法月杏相識，早於塞希莉雅與這位大姊相識，與同可列二姊的塞希莉雅不是同一人，後者才是杏／懷已確立的伴侶。**朔凜月始終愛著大姊，直到生命最後。**

<a name="doc-nav-251"></a>
#### 臨帖與真跡：珍惜無法簡單複製的過去

書法真跡、摹本、墨香與筆勢的開篇意象，適合映照妹妹與大姐有過真實且值得珍惜的共同生活，而不只是後來的悲劇。兩人相遇較早，便應有自己的日常、笑話、習慣與陪伴，不能只有衝突和死亡。

書法能重寫，心情無法用外觀直接取代；但這只是詩意的情感類比，**不能變成杏無法復活、重建或改寫死亡與歷史的能力限制，更不能斷言重建的家人客觀上都是複製品**。忒修斯之船仍屬身份哲學命題。

<a name="doc-nav-252"></a>
#### 夕陽、墨香、餐食與曾經幸福的生活

前半段的飲食、黃昏與日常美感，可以讓妹妹與大姐在悲劇以前的親近具有重量。她可能記得某次玩笑、照顧與普通午後；具體哪件事仍留待人物日後補完。

**她不是只為了在杏的生命裡死去才存在。**即使後來有《蘭亭序》的遺憾，她與洛琪莉卡、塞希莉雅及其他家人的感情也必須獨立存在。歌詞中的古代物件不需要按字面成為世界線的住處、服裝或事件。

<a name="doc-nav-253"></a>
#### 第一段副歌：等大姐回來，愛從未離開

反覆等待對方歸來的副歌，很適合妹妹眼看熟悉的大姐走向越來越難以理解的道路時，仍保有的盼望。**等待不是因為她不會再愛如今的杏；她一直都愛著，從來沒有停止。**

盼望的「回來」不必是把杏變成毫無傷痕的舊樣子，而是希望兩人仍有機會重新聽見、看見對方，不需要讓家庭不斷走向更深的失去。她可以對杏的做法堅決反對、真的失望，仍然希望她好。這是情感方向，並非某次特定挽留已發生。

<a name="doc-nav-254"></a>
#### 懸筆與情字：難以說盡，不是不知如何去愛

反覆寫不盡情感、缺少對方完整理解的副歌，能轉譯成**深愛和深刻分歧並存**：妹妹知道自己愛杏，但有些話太輕無法讓杏理解、有些責備太重又不足以傳達心疼。彼此親近也不等於知道對方每段經歷、認同每個選擇。

不能再寫成「妹妹不知道怎麼繼續愛著走向深淵的大姐」。更精準的是：**她一直愛著；令她悲傷的，是兩人明明曾經那麼親近，現在卻走到了無法認同彼此某些選擇的地步。**她的憤怒、失望與盼望都是真實的，不需要其中一種取消其他感情。

<a name="doc-nav-255"></a>
#### 重複副歌：同一份愛，經過不同的時間

前半段副歌以不同形式重複；對妹妹可以成為相同情意穿過不同日子的意象。她可能仍盼望大姐停下來，之後也可能選擇反對與分開行動；但**她是否曾說出口、是否曾勸過杏幾次都沒有定案**，不能憑歌曲重複而生成「三次挽留」等固定情節。

妹妹的等待不等於被動。她可以在關係持續的同時，保有自己的判斷、立場與尊嚴；停止追逐某種結果，也不代表停止愛那個人。

<a name="doc-nav-256"></a>
#### 後段：回眸、遠行、眼淚與怨懟

後半段寫短暫歲月、回憶中的容顏、遠離、流淚與藏在細小物件中的不滿。這些適合妹妹對家庭逐漸失去原樣的傷感：**過去的幸福是真的，當下的憤怒與失望也是真的。**不能把她每次強烈反對杏，都旁白轉成溫柔奉獻，以免抹去妹妹的人格。

原曲的古街、南飛、繡花鞋等是古典情歌的視覺意象，不能因此規定家庭的確切年代、地點、服裝，也不必安排某次寫詩或雨夜告別。

<a name="doc-nav-257"></a>
#### 最後副歌：無愧、決絕與獨立的選擇

最後副歌與前面不同，加入無愧自身選擇、不畏外界是非的意味。這可與妹妹生命最後的**決絕**相合：她不必等大姐同意，才能決定自己要走什麼路、堅持什麼；即使仍深深愛著杏，她也能選擇與杏不同的行動。

**無愧不是她絕無錯誤，決絕不是她不再愛杏。**臨終的遺憾不必被剔除；她可以清楚知道自己作出了決定，仍希望與家人共享另一種未來。具體死因、如何決定、最後是否與杏相見，都待後續正文，不能由歌詞直接填空。

<a name="doc-nav-258"></a>
#### 雨夜與春雷：釋懷不是原諒一切

歌曲最後仍有綿延的雨和未來的呼應，並未把等待簡化成已獲得完滿回答。對妹妹，可讓**決絕、遺憾、釋懷同時存在**：她可以接受自己的最後選擇，仍然難過，仍然記得曾經幸福的家庭。

釋懷不等於大姐的所有選擇都正確，不等於她已無怨、已不愛、全然原諒，甚至不等於她臨終必須安詳微笑、說出某種標準遺言。**她到最後始終愛著大姐。**

<a name="doc-nav-259"></a>
#### 洛琪莉卡與朔凜月：彼此並非陪襯

洛琪莉卡除了對杏有難以簡化的難過、失望與盼望，也**深深牽掛朔凜月本人**。三姐的選擇和她對二姐的感情值得獨立描寫，不能只是杏主角悲劇的附屬鏡頭。

朔凜月在原始歷史裡確實走向生命終點；洛琪莉卡「彷彿在二姐之後附隨而去」仍是暫定的感情／結局方向，不得推成必然自殺、殉死、固定死法或固定間隔。兩人的決絕、遺憾、釋懷能互有回聲，也必須各自成立。

<a name="doc-nav-260"></a>
#### 《鬼》《蘭亭序》《山海》的分工與邊界

**《山海》**適合妹妹們望著大姐漸入深淵的「為何至此」：憤怒、失望、難過，仍有盼望。**《鬼》**適合整個家在塞希莉雅第一個死亡後的連鎖悲劇、多人互相牽動的傷害，以及杏抱著愛人反常笑著的極端。**《蘭亭序》**則主要屬於朔凜月始終不變的親情與生命最後的決絕、遺憾、釋懷。

三首歌是互補的情感透鏡，不是三條互相矛盾的正史。仍未確定的死因、對話、相遇細節、具體責任與行動，均不能從歌詞直接推出。其後杏重製為懷、原本打算消散，最終因整個家庭真正活出的後續而留下，仍與《転生林檎》《分かっちゃいないね》的映照互相承接。

- 她能主動維持這個狀態，不會因外界恐懼、誤會自己違規或集體崩潰便被迫關閉。是否暫時收回，取決於她自己的選擇以及對家人的照顧。

## 十、原四人的知識、力量與價值判斷


<a name="doc-nav-121"></a>
### 10.1 見識與理解能力

- 四人都活過或經歷過極其漫長、廣闊的事物，可概括為「沒有什麼是完全沒見過的」。
- 進入新世界時，不應把她們寫成面對普通槍械、魔法道具、科技商品、末世資源或異常現象便震驚失語。
- 她們通常能直接理解物品、能量或規則的本質。需要詢問的部分多半是當地用語、標價、社會規則、官方分類或持有者如何理解它。
- 她們可以覺得某個設計有趣、某種文化新鮮，但「感興趣」和「完全不懂」不同。


<a name="doc-nav-122"></a>
### 10.2 成長、力量尺度與控制

- 四人現在的強大不能寫成「生來就拿到無敵力量，從未成長」。至少絲蒂莉雅與薇絲莉雅是從原本可能比許多後來旅經世界更低的世界層級出發，經歷漫長旅行、學習與成長，才一步步抵達現在超出論外天花板的層級。
- 原四人核心內部仍是法月懷位於最上層，塞希莉雅其次，絲蒂莉雅與薇絲莉雅大致相當。**【2026-10-15 九人時期歷史純實力排序，非現行全家總表】法月懷 ＞ 塞希莉雅 ＞ 朔凜月 ≥ 洛琪莉卡 ＞ 絲蒂莉雅 ≈ 薇絲莉雅 ＞ 璃安 ≈ 芙蘭妮雅 ＞ 小曦**。**現行十人排序請以第二章及第15.9節為準，瑟莉思媞已正式位於芙蘭妮雅與小曦之間**。朔凜月與洛琪莉卡均高於絲蒂莉雅及薇絲莉雅；朔凜月可能略高於洛琪莉卡，但這不鎖死每一次交手結果。家內強弱不代表誰更受愛、擁有更高地位或掌握話語權。
- 即使是四人內部相對較低的 Stiliya 與 Versiliya，也絕對具有將某個存在連同其全部時間、因果與一切可能性徹底消除的能力。從所有可能性中抹除存在不是法月杏、法月懷或黑瞳狀態的專屬權能。
- 因此外界的敵人、規則、境界或異常不應被寫成真的有能力把四人中的任何一人逼入無法挽回的存在性死亡，也不能用「敵人太強」解釋法月懷切換黑瞳。
- 她們的力量控制與力量規模同樣達到不可理解的程度。日常揮翅、走路、擁抱或使用能力時不會被動毀滅城市、宇宙或周遭結構；只有她們選擇造成影響時，力量才會以相應尺度落下。
- **【最高優先固定；目前全家固定OC共通】她們不受普通生物性的維生需求強制限制。**飢餓、口渴、缺氧、睡眠不足、一般代謝、普通疲勞、環境溫度與長時間不進食／不飲水等，不會因「身體需要」而把她們逼入衰弱、失能或死亡。這不是沒有味覺、嗅覺、呼吸、睡眠、疲倦表情或身體感受，而是這些都不再是不可違抗的生存條件。
- **吃飯、喝東西、睡覺、泡澡、呼吸、休息等仍可以非常自然地存在。**她們可以因為喜歡味道、想陪家人、享受口感、習慣、放鬆、想睡在某人旁邊、想聞氣味或單純「現在想做」而去做；也可以出現主觀上的睏、懶、想休息或吃飽後滿足等生活感。必須區分「願意體驗／享受」和「不做就會因生理需求出問題」。
- 這條規則不等於所有外來傷害都無效，也不等於她們在任何**自願使用的低層載體／遊戲角色／當地化分身**中都拒絕當地規則。若她們主動接受某個角色殼、化身或特定世界線的玩法，該載體可以有HP、體力、飢餓值、氧氣值等；限制的是那個載體或她們自願參與的規則，不是她們本體被普通生理需求綁死。
- 不必每次施展能力都附加空間震動、威壓擴散、世界顫抖等視覺特效。真正精確的控制可以完全安靜，甚至讓旁人只看見結果。
- **【最高優先固定；四人共通】四人對「什麼被誰看見、感知、記錄與理解」具有完整的顯現決定權。**她們可以讓任意指定的存在看見或感知她們自身，也可以開放或遮蔽某件物體、能力、造物、痕跡、行動、過程、結果乃至與之相關的資訊；對象可以是一人、一群人、某種生命、某套系統、某個世界或宇宙，也可以彼此不同。即使觀察者原本沒有視覺、感知器官、心智或相應認知方式，只要她們願意，仍可使其以她們指定的方式接收到該顯現；反之，即使對方具有極高感知、全域監測或近似全知的能力，只要未被允許，也不能憑自身層級繞過這項選擇。
- 這不是普通隱形、幻術、遮光、速度過快或干擾感知，也不是四人必須一直開啟的被動效果，而是對存在如何進入他者認知與紀錄的精確控制。同一場景中可以只有一人看見、部分人只看見結果、另一部分人連結果都不會察覺；也可以讓所有存在共同看見。可見、可感、可記錄、可理解與是否實際受到作用彼此獨立，不能因某人被能力影響便推定其必然看見能力，也不能因某人看不見便推定該能力天生隱形或在場所有人都看不見。
- 這項共通權能同樣涵蓋她們以外的「其他東西」：只要在她們的選擇範圍內，既有物體、外來力量、別人的造物、環境、世界結構與純粹資訊也能被指定向誰顯現或不顯現。正文必須依她們當下的意願與場景效果決定知情邊界，不能把單一觀察者沒有看見寫成全場共享的客觀不可見。
- 時間、空間、瞬間移動與其他跨體系能力都可以依情境使用；但尚無一份封閉、唯一的完整技能表，不能把某條世界線的武器技能誤寫成角色本體能力。
- 絲蒂莉雅常用太刀，薇絲莉雅常用鐮刀，但兩人都能使用其他武器。常用武器只是偏好，不是力量來源、專屬職業、唯一戰鬥方式或封閉武器限制。
- 當地 E～S、戰略級、修仙境界、SCP 等級或其他分類只能描述當地人的理解，不能真正框住四人。
- 新世界的人不會無理由一開始便知道她們無敵。旁人認知、官方保密、名聲與敬畏應由可見事件逐步累積；角色本身的力量尺度與外界知道多少，是兩個不同問題。

### 10.3 道德不是共用模板

**【2026-10-24｜十位家庭OC跨世界的道德與認知主體性；使用者明確補強】** 家庭OC不是普通人類社會的道德觀、常識、價值優先序、風險知覺或認知限制的放大版。**不得把一般人的「應該救人、應該安慰、應該寬恕、應該懲罰、看見痛苦就應主動照顧、看見弱者就應伸手、善良角色必須遵循普遍人道尺度」當成她們的預設責任或全家共通人格。** 她們經歷、力量、資訊取得方式、存在尺度與私人價值可能和當地居民根本不同；外界角色可以依自己立場讚賞、恐懼、批評或譴責她們，**但作者旁白不可不經人物因果便拿普通人類社會尺度替OC裁定其必須怎麼想、怎麼感受或怎麼選。**

- **「不強加一般人的道德與認知」不等於「全家都沒有倫理、同情、愛或判斷」，更不等於「全家必然殘酷或漠視生命」。** 各人的私人關係、愛憎、偏好、經驗與選擇同樣真實，能救、能殺、能不介入；同一人換了對象、前因、心情，也會改變行動。不要把全家寫成同一套極端非人處事模板。
- **「知道」不等於「認同」「被感動」「必須介入」。** 她們可以完整理解當地人正在悲傷、傷病、求助或死亡，卻選擇不處理；也可以出於興趣、私人關係或一時心意直接解決問題。旁白不應用凡人對未知力量的揣測去限制她們原本確立的洞察與能力；反過來，沒有文本依據時也不能因為「她們很強」就寫成全員自動讀取每位陌生人的全部隱私。
- **外人、熟人、家人不可隨意等同。** 家人之間毫無保留的信任、親近、安慰、保護和溫柔，不預設自動施予陌生人；但對外人也不必一律冷漠、輕蔑或拒絕。當事OC自己想不想做，才是核心。

- 四人沒有必須服從的通用善良、慈悲或不殺人濾鏡。
- 她們能救人，也能殺人；關鍵是當時那個人、事件與她們自己的判斷。
- 對方只要是有意的侮辱，就可能在話未說完前被立即處理；不限於「嚴重侮辱」。絲蒂莉雅也包含在內。
- 這不表示四人聽見任何難聽話都必然殺人，而是不能預設她們一定容忍、說教或給反派講完整段台詞。
- 薇絲莉雅的玩心、塞希莉雅的溫暖、絲蒂莉雅的安靜、法月懷的沉穩，都不能被用來強加仁慈結論。
- **這套判斷原則同樣適用後來加入家庭的菲璃安、芙蘭妮雅、小曦與未來成員。**家庭成員的人生可能極漫長、跨世界且充滿不同時期；殺人、欺騙、背叛、利用、犧牲他人、與敵對者合作等結果本身不能單獨決定角色是善／惡、冷血／聖母。必須連同當時環境、資訊、可選方案、關係、目的、威脅、代價與人物性格一起判斷。
- 相似結果不代表相同人物邏輯，也不能反推「全家都一定做過同一件事」。同一個人在不同時期、關係與世界背景下也可能作出不同選擇。

### 10.4 商店與交易

在開店、餐館、修仙商店或相近世界線中：

- 正式上架並標明價格的商品，只要買方付得起，原則上就會賣。
- 不因「配不配」「品德是否高尚」「會不會濫用」而臨時拒售，除非該世界線另有明確規則。
- 四人知道自己在賣什麼，不需要把商品拿來研究半天，也不會因普通效果而驚訝。
- 職務只決定她們當下做什麼，不把薇絲莉雅變成標準服務員、不把塞希莉雅變成鑑定師、不把法月懷變成店長，也不把絲蒂莉雅變成溫柔客服。

### 10.5 能做到與願不願意做

- 四人不是不能修改、控制、重塑或抹去他人的意志。她們具備相應能力，也不受某項更高規則禁止。
- 她們通常不願把意志改造列為處理普通外人的常態手段；這是選擇與偏好，不是能力限制。不能把「不想做」誤寫成「做不到」。
- 已經挑釁、侮辱、越過規則或遭到處置者，不必然仍受這項自我限制保護。是否改造、保留或抹去意識，依當時的人物、情境與興趣決定。
- 四人沒有一人被固定成只能使用某種處置方式。法月懷較常直接消失或徹底抹除，塞希莉雅較可能把處置轉化成帶有審美與創作性的作品，薇絲莉雅可能偏好更具玩心、過程性或借助外部環境的方式；絲蒂莉雅也能直接處理，不能因安靜便預設她只會旁觀。
- 可形成的作品不侷限於雕塑、面具或人體藝術，也可能是多人巨型構造、武器、裝飾、食品或其他難以歸類的成品。作品可以具有實際效果，也可以單純因為漂亮而存在；可以保留意識，也可以不保留，並可能被展示、收藏、使用或出售。
- 以上是可能範圍，不是固定招式表。不能讓每次冒犯都機械地重演同一種人體藝術，也不能把任何一位店主寫成永遠只會一種處置。
