## 一｜使用者已同意的規則：口語詞可以借，角色不必照搬

可以使用「我去」「我靠」「臥槽」「媽耶」「媽呀」「哎不是」「你丫」「你丫的」「你小子」等莉雅參考裡的詞；可以某一段大量互噴，也可以整章一個都沒有。先知道**艾莉維亞正在做什麼、想說什麼、對誰說、在什麼情況下說**，才選起手詞、語速和標點。她可以突然專業、突然嘴欠、突然害羞、突然反攻；她有自己的技藝、判斷、主動目標、情感和社會關係，不是「諾亞出奇招—維亞喊我去—維亞吐槽」的陪襯。

**第058份曾說「不能直接搬原作招牌口頭禪」**，現在須嚴格限定為**反對機械固定與抄寫整段原作劇情**，而不是禁止通用口頭語實際使用。第059份「傻逼／大傻逼／神經病」在普通時段一般低頻，激烈的親密互罵例外可以密集；這**不等於**整體情緒、標點、語音表演都必須低頻。平常日常、溫柔、曖昧、無語、認真、恐懼與沉默繼續成立。

## 二｜莉雅來源可見詞句庫：可選而非固定個人標籤

| 用途 | 來源可見詞句 | 節奏、自然使用條件 |
|---|---|---|
| 突然發現／短促驚呼【A】 | 我去、我靠、臥槽、媽耶、媽呀 | 輕重不是精確等級制；也可完全不喊 |
| 沒聽清／想再確認【A】 | 啊？、啥？、嗯？、不是？、你認真的？ | 一聲「啊？」可能比三句髒話更自然 |
| 想打斷與反駁【A/B】 | 哎不是、等會、不是你……、我不是這個意思 | 之後要真的指出疑點或做出行動 |
| 熟人式惱怒、催促【A】 | 你丫、你丫的、你丫有病吧？、你就不能……？ | 有惱怒或玩鬧推力，不作平淡稱呼 |
| 熟人狐疑、看出對方想搞事【A/B】 | 你小子……、不是吧大哥？又來啊？、哥們 | 熟稔的審視與玩笑，也可能是真的不安 |
| 更強的粗口／被惹火【A/B】 | 你他媽的——、操、tm | 危急、惱火或互噴時才自然；粗口本身不證明人格 |
| 不可思議／荒唐【A/B】 | 這啥玩意？、這什麼情況？、這都什麼亂七八糟的？、這有啥 | 也可能只看了兩眼開始拆解問題 |
| 得意或要對方認帳【A/B】 | 你就說是不是吧、你就說好不好用吧、看到沒有！、你就說……吧 | 語氣可以熱烈，也可以笑得慢悠悠 |
| 高興／慶祝【A/B】 | 真的？！、好耶、夸夸夸夸～等重複音 | 不是每次有成就就必須發癲 |
| 危急求救【A/B】 | 救救救救——！、救救救 | 得有迫切、身體反射與具體危險 |
| 退一步或反評估【A/B】 | 行、……操，還真能行、大不了 | 用實際風險與下一個行動承接 |
| 專業推論【A】 | 理論上、準確來說、問題是、首先／其次、其實也不能說是準確度的問題 | 很多專業場合無須先用口頭禪開場 |
| 搞笑造詞【B】 | 雷霆XX等誇張命名玩法 | 可學臨時誇張命名的機制，不指定固定「雷霆」招牌 |

**不錯置**：第058份提到「往好處想」「我有個想法」「我尋思」「問題不大」主要是**方九**的語言參考，不可反說這是「莉雅原作已說過的專屬台詞」。它們作為通用口語仍可由合適的角色說。

第104份歸納「媽耶」有時偏驚奇，「媽呀」有時偏生理驚嚇；「我去」有時較瞬時，「臥槽」有時更猛烈。**這些只是傾向、不是語法表**，同一個詞可以因音量與上下文改變感覺。

### 新增開放詞庫【C】，不虛稱莉雅原句

- 小意外與確認：「啥情況？」「你說啥？」「真的假的？」「等一下」「這裡不對」「你確定？」
- 想辯解或打斷：「不是，我的意思是……」「先別急」「哎，停停停」「你聽我說完！」
- 無語與嫌棄：「我服了」「……行吧」「你還挺會挑地方」「你真行」「真有你的」「我就知道」
- 熟人打趣：「少來～」「就你會？」「看把你能的」「你這什麼破主意」「得了吧」「有本事你來」
- 得意或反攻：「你看！」「看見沒！」「來，誇兩句」「你現在知道誰厲害了吧～」
- 危急與行動：「停！」「後面！」「撤！」「躲開！」「先救人！」「現在就走！」
- 真擔心與不捨：「你先坐下」「我看看」「別鬧了」「……你沒事就好」「這次聽我的，好不好？」
- 長出私人語彙：某次錯音、技術笑話、尷尬插曲、旅行事件自然變成內梗，過很多章後偶爾回收，優於每章硬造十個新口頭禪。

這些皆為**開放詞彙範例**，不意味艾莉維亞會全部使用、用後必定成為永久口癖，也不排除諾亞或其他角色因個性合適而自然使用。

## 三｜標點可呈現情緒波形：使用者所說的 !、~、直線、拉長

| 記法 | 大致聽感與身體表演 | 可用短例【C】 |
|---|---|---|
| ！ 或 ! | 高聲、突然、斷然、驚喜，或急得沒時間拐彎 | 「等一下！」「找到啦！」 |
| ？！／!? | 不敢相信、追問、惱火與驚訝同時出現 | 「你真要下去？！」 |
| ！！ | 極短而強的喊叫；少量才能保持力度 | 「後面！！」 |
| ～ 或 ~ | 甜、拖長尾音、慢吞吞逗人、慵懶、得意，也可能陰陽怪氣 | 「哎呀～」「你猜呀～」 |
| —— | 拉長、聲音衝出去、突然截斷、話被人切斷 | 「諾亞——！」「我才沒——」 |
| — | 單長橫作節奏或聲音拉扯的可能記法；完整中文破折號常用「——」 | 「喂—等等！」（須全書格式一致） |
| …… | 沉默、思考、意識到不妙、還沒準備好說、咽住尾音 | 「……行。」「我知道……」 |
| 、置於字間 | 一字一句咬字、帶壓抑怒意或故意耍狠 | 「你、給、我、回、來。」 |
| 分成兩三短句 | 逐步變重、情緒突然收斂 | 「不行。」「這次真的不行。」 |
| 音節重複、急停、重新起句 | 結巴、腦子比嘴快、突然慌了 | 「我、我不是——等會！」 |

**不要把表情感當成排版計數器**。例如「等一下。」「等一下！」「等、等一下！」「等一下——！」是四種不同聲音；同一句可完全不用驚嘆號，照樣能靠動作、場面和前後台詞有情緒。

**關於「一條直線兩條直線」**：先理解並納入單長橫「—」與雙長橫「——」這組候選記法，不擅自把使用者口述等同於某一個固定 Unicode 字元；倘若後來使用者是指「｜／‖」等豎線，另依明確指定補入，不預設豎線是本故事正常對話標點。

## 四｜一字一句、咬牙切齒與壓著聲音的怒意

同樣是阻止諾亞碰一個未知裝置，使用的不是「憤怒＝固定咬牙句」：

- **普通提醒**：「先把手拿開。」
- **急到大喊**：「諾亞！手拿開！」
- **壓住怒火**：「諾亞。你、現、在、把、手、拿、開。」
- **咬緊牙、字字截斷**：「我說，放。開。它。」
- **危機中急促指令**：「手！拿開！現在！」
- **熟人玩鬧的佯怒**：「諾——亞——！你故意的是吧？！」
- **真正受傷或失望**：「……你明明答應過我。」

**咬牙切齒**不只靠每個字插頓號：還可以描寫牙關發緊、唇角壓住、吸一口氣、原本想喊卻收小聲、盯著對方手指或平靜得不尋常；她也可以真的暴怒大喊，不能倒過來限制角色「真生氣就一定安靜」。

## 五｜口吃、結巴、字音唸歪與諧音：不同機制，允許有趣但不強制定型

### 甲｜慌張或高興造成的停頓、重複與改口【C】

- 「我、我沒有！」
- 「你你你、你先別過來！」
- 「等、等一下，這不對！」
- 「左邊——不對！右邊！」
- 「我剛剛是想說……不是！你別這麼看我！」
- 話說到一半因哭腔、呼吸、驚嚇或太開心而斷掉，也可**只寫動作，不必每次改變字形**。

### 乙｜因物理狀況咬字不準，把標準音短暫唸歪【C】

- 嘴裡塞了食物：「泥先別縮話……」（原意：「你先別說話。」）
- 臉被揉擠、嘴唇被擠歪：「放、放開窩！」（原意：「放開我！」）
- 說話太快且沒嚥下餅：「唔唔……等窩一下。」（原意：「等我一下。」）
- 冷到牙齒打戰、嘴麻、口腔受傷、醉意或疲乏：依**實際原因**使少數音節含混、吞字或變音，也可以完全不寫諧音字，改用「她後半句含糊得幾乎沒咬準」。
- 一旦把食物嚥下、放開臉、恢復呼吸，發音自然回到平常，不讓她為賣萌長期每句都說「泥／窩」。

**「泥」「窩」「縮」是讀者能理解的近似書面擬音，不是方言或口語音變的客觀精確記錄。**每次只改一小段，並用原意、對方反應或現場動作讓讀者看得懂。

### 丙｜故意裝可愛、模仿別人、玩同音與歪音笑話【C】

- 故意軟化尾音：「真噠～？」「就醬？」「不給～」
- 玩網路諧音：「神馬東西？」「丸辣！」等只作**網路口語候選**；不預設每個世界層的居民都懂同一套網路語言。
- 特殊情況故意模仿對方口誤或裝傻，對方發現後反過來模仿；這段可成為私人的長線笑話。
- 「你、你……」可以只是羞赧／卡殼；**不必把所有害羞都寫成幼兒式發音**。

**人物尊重與世界連續性**：若有人物確實有固定的口吃、口腔傷或語言障礙，應另按人物設定和成因處理；不能拿真實語言障礙、族群與口音當純笑柄。艾莉維亞此處的錯音指**情境性短暫咬音偏差**，不是預設永久性的生理特徵。

## 六｜同一句「你在幹嘛」，可聽到完全不同的艾莉維亞【C】

1. 普通詢問：「你在幹嘛？」
2. 困惑：「……你幹嘛呢？」
3. 突然發現不對：「哎不是，你又要幹嘛？！」
4. 熟到能互損、被惹毛：「你丫的又在幹嘛？！」
5. 慢慢逗他：「諾亞～你在幹嘛呀？」
6. 真正警戒：「諾亞。你在做什麼？」
7. 咬牙逐字：「你、到、底、在、幹、嘛？」
8. 被突然靠近而口吃：「你、你幹嘛突然靠這麼近！」
9. 臉被擠著含糊說：「泥幹嘛啦……放開窩！」

**這些都不是固定配方**，同一種情緒可以另有十幾種自然說法；最重要的是眼前真正發生什麼。

## 七｜跨場景原創演出短劇（非正式正文，不能倒灌初章）【C】

### 1. 平常修設備：零口頭禪

艾莉維亞把接頭轉回去，聽見管線另一邊響了一聲。

「嗯？剛才不是這裡吧？」

諾亞搖頭。她低頭又看了一眼。

「那就怪了……你讓一下，我重新查。」

### 2. 玩鬧時一字一句，末尾又拉軟

「我說的是隨、便、你、選！誰讓你連我的杯子一起拿走了？！」

諾亞遞還杯子。

艾莉維亞接過來，嘴角還繃著，下一瞬卻笑了。

「哼，這還差不多～」

### 3. 驚呼後突然變專業

「臥槽？！」

她才看見整排管路亮起，視線已經轉到最末端的回授燈。

「等會，別碰。那不是供能。再扳下去你會把舊站所有接合閥一起開了。」

### 4. 害羞卡字、呆毛輕彈（偶爾即可）

諾亞：「剛才多虧妳。」

「我、我……」

她像是想頂一句嘴，卻先瞪他。

「先把傷處理好再說，行不行！」

諾亞還沒來得及回話，她頭頂那撮微微側彎的呆毛已輕彈了一下。

### 5. 真嚴重時低聲、逐字

「諾亞。」

少女的指尖還壓在控制台邊緣，沒有移開。

「我、說、了。」

他停住。

「別、碰、它。」

### 6. 含著食物咬不準

艾莉維亞咬著半塊甜餅，想把諾亞伸過來的手拍開。

「泥先等會……」

她好不容易把餅嚥下去，才補了一句：

「我是說，先等我吃完！」

### 7. 熟人調戲用長尾音，不代表每次都要波浪號

「小諾～」

「妳這個語氣準沒好事。」

「幹嘛這麼想我呀～？我只是來借——」

「不借。」

「我都還沒說！」

### 8. 真的害怕時不必先喊『我去』

「諾亞。」

沒有回答。

「諾亞！」

她跑過去，在碎石邊蹲下。

「……看著我。先看著我。」

可見情緒完全足夠，不一定需要粗口或過量標點；但其他場景她自然喊出「媽呀！」也並不被禁止。

## 八｜寫之前選聲音：不是每章符號打卡

1. **事件**：她目擊、理解或正在處理什麼？哪些情報仍不知道？
2. **對象**：諾亞是陌生人、搭檔還是多年伴侶？此處是否能使用私人互損？其他人聽見會怎麼理解？
3. **目的**：她要糾正、阻止、哄人、炫耀、辯解、求助、質問、確認、撒嬌，還是只想陪他坐著？
4. **情緒與身體**：震驚、憤怒、開心、心虛、害羞、哽咽、疲倦、咬著東西或口腔被擠住？
5. **聲音**：語速快慢、升降、音量、是否喘息、是否咬字清楚、是否要吞尾音、是否突然中斷？
6. **最後才選詞句和符號**：「我去」「媽耶」「你丫的」「！」、「～」、「——」、「……」或諧音字；不需要就不放。
7. **看後一句**：對方是否理解、誤會、笑出來、回答、接住情緒、真的停手？人物與劇情應有因果，不靠符號空轉。

**不要過度保守**：使用者的最新意圖正是要有聲音、有情緒、有各種詞彙、偶爾非常誇張、偶爾不標準的音，**不是要求全部收斂為短句和沉默**。也不要矯枉過正寫成每句「我去！」「哎不是！」「～」「——」的大雜燴。兩種極端都會讓她像機器。

## 十｜2026-10-20 後出補充：夾子音、半形／全形波浪號與調戲愛心

**使用者原意**：「夾子音是用~嗎，對了要區分~～嗎，然後調戲時也可以用你說話會加的那個愛心。」

**已允許的寫作形式：**

1. **「夾子音」不是一個標點符號**：它是人物在某個場面刻意把聲音捏得偏細、偏高、偏甜、偏嗲／柔軟的語音表演；是否出現應從人際目的與情緒自然決定。可以用「～」拖長尾音幫助讀者聽見，但**只出現「～」不表示角色必定在夾嗓子**。描寫「她故意捏細了嗓音」「尾音甜得有些刻意」「說完自己先笑出來」通常更可靠。
2. **半形 `~` 與全形 `～` 不必規定不同情緒**：二者在此可表達基本相同的音尾拖長／帶彎的語氣。**中文正式敘事與台詞優先統一 `～`**，因字面版式更整齊；聊天紀錄、手機訊息、角色故意模仿網路文字或其他格式可用 `~`。不要設成「~＝夾子音」「～＝正常撒嬌」等沒有依據的硬規則。
3. **愛心符號可進入角色台詞表演**：使用者說的「你說話會加的那個愛心」以空心愛心 **`♡`** 為主要參考；**`♥`** 亦可作視覺感更濃的候選。它們可以輔助表達甜甜的調戲、故意裝乖、撒嬌、親暱、壞心眼的逗弄、戀人之間的玩笑；**不等於正式告白、必然性暗示或客觀證實愛意**。不必強制規定空心／實心的絕對情緒等級，差別主要在視覺密度和場景風格。
4. **組合可用，但不需每次組合**：`「小諾～♡」`、`「你是不是害羞了呀♡」`、`「哎呀～你猜呢？」`、`「快一點嘛～」`都可以；同一個艾莉維亞也可以只說`「我在這裡。」`。若特定段落刻意演夾子音，文本可在對話旁清楚交代她的嗓音、唇角、肩膀與隨後變回正常聲線的動作。
5. **這是表達自由，不是新的固定口癖**：艾莉維亞有活潑、專業、冷靜、毒舌、害羞、親暱、直球等不同語體；夾子音、拖尾和愛心只在想調戲、故意甜聲或自然撒嬌等情境用。對外人、嚴肅指揮、極高情感重量時，不要為了展示符號硬塞。諾亞同樣可以在合適場合反過來使用甜膩語氣或愛心式玩笑，雙向攻防但不要求機械對稱。
