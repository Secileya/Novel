* 上方的真正來源。
* 下方的傳導、回響，或者另一件具有相關性質的物件。

### 一、沒有觸發對話，不等於刻意隱瞞

例如某個修理升降機的普通老人，可能曾經認識一位重要人物。

後來可能出現完全不同的情況：

* 諾亞帶來一件老人認得的舊工具，兩人才聊起當年的事。
* 艾莉維亞先從別處聽見某個名字，再回來詢問老人。
* 另一名角色主動介紹兩人認識，讓老人願意談得更深入。
* 老人因故離開、過世或拒絕再談，兩人改從其他人的回憶和舊紀錄理解那段歷史。

這些不是單純的「好感度達到50，解鎖祕密對話」，而是對話之所以會發生，其情境條件終於成立了。

更重要的是，這個老人不必只是等待主角觸發的 NPC。他可以有自己的工作、朋友、生意、偏見與生活，甚至因為其他事情而自行行動。

因此，我會把原先過於籠統的「隱藏情報」區分成：

| 情況 | 真正原因 |
|---|---|
| 尚未談及 | 沒有共同話題或合理的詢問契機 |
| 尚未察覺 | 人物自己不知道某項經歷或物件有特殊意義 |
| 尚未理解 | 已經掌握部分事實，卻缺少解讀它的知識 |
| 尚未信任 | 有些私人事情不會對初次見面的人隨便談起 |
| 刻意隱瞞 | 知情而主動保密、說謊或阻止他人調查 |
| 不能透露 | 受到契約、職務、威脅、風險或其他現實條件限制 |
| 已經失去機會 | 當事人離開、死亡，或資訊因事件變化而無法再取得 |

這些類型之間還可以重疊、轉變，不能把人物固定分類。

作者層仍然要提前向你交代已規劃的伏筆與真相，但人物在正文中完全可以因為時機未到，而沒有理由說出相關資訊。
