* 上方的真正來源。
* 下方的傳導、回響，或者另一件具有相關性質的物件。

### 一、沒有觸發對話，不等於刻意隱瞞

例如某個修理升降機的普通老人，可能曾經認識一位重要人物。

後來可能出現完全不同的情況：

* 諾亞帶來一件老人認得的舊工具，兩人才聊起當年的事。
* 艾莉維亞先從別處聽見某個名字，再回來詢問老人。
* 另一名角色主動介紹兩人認識，讓老人願意談得更深入。
* 老人因故離開、過世或拒絕再談，兩人改從其他人的回憶和舊紀錄理解那段歷史。

這些不是單純的「好感度達到50，解鎖祕密對話」，而是對話之所以會發生，其情境條件終於成立了。

更重要的是，這個老人不必只是等待主角觸發的 NPC。他可以有自己的工作、朋友、生意、偏見與生活，甚至因為其他事情而自行行動。

因此，我會把原先過於籠統的「隱藏情報」區分成：

| 情況 | 真正原因 |
|---|---|
| 尚未談及 | 沒有共同話題或合理的詢問契機 |
| 尚未察覺 | 人物自己不知道某項經歷或物件有特殊意義 |
| 尚未理解 | 已經掌握部分事實，卻缺少解讀它的知識 |
| 尚未信任 | 有些私人事情不會對初次見面的人隨便談起 |
| 刻意隱瞞 | 知情而主動保密、說謊或阻止他人調查 |
| 不能透露 | 受到契約、職務、威脅、風險或其他現實條件限制 |
| 已經失去機會 | 當事人離開、死亡，或資訊因事件變化而無法再取得 |

這些類型之間還可以重疊、轉變，不能把人物固定分類。

作者層仍然要提前向你交代已規劃的伏筆與真相，但人物在正文中完全可以因為時機未到，而沒有理由說出相關資訊。

# 討論續錄 31｜事件先有骨架、長期伏筆先有作者層規劃，並讓故事真正收束

## 2026-11-05｜最新校正：**情報未揭露 ≠ 人物刻意隱瞞；存在多入口的自然觸發條件**

**使用者補充的核心意義**：類似「尚未滿足對話條件的 NPC」：一位普通人可能知曉一段往事、技術、目擊、關係或某個人的下落，但沒有適當話題、相遇時機、可信理由、實物或相關人事物的接觸，就沒有理由把這件事隨口告訴主角。這不代表他故意說謊、保密、神祕兮兮或藏有陰謀。另可由**其他人的話、地方傳聞、文書、物件、交易紀錄、環境痕跡、人物間的轉介**將主角引向他，也可能先取得有意義的線索，之後才重新理解他之前一句普通話。

**寫作時分清五種互不等同的情況：**
1. **刻意隱瞞**：角色知道事實且有原因不願說，可能撒謊、迴避、拒答；需建立他為何如此選擇。
2. **知道但沒有談及契機**：並非隱瞞，只是沒人問、與當下工作無關、尚未見到引發聯想的東西、不熟悉到談私事、時機不對，或根本不覺得那件事值得說。
3. **知道部分、自己也未連上關係**：他說過的是真實片段，但不知道片段與另一件大事有交集；未來他或其他人獲得情報後，才把兩件事接起來。
4. **另有外部資訊入口**：物證、帳簿、檔案、第三人回憶、不同地區的流言、目擊、同行者介紹可提供方向，**不一定要回頭找到這位NPC親自觸發對話**。
5. **角色不知情或已有錯誤認知**：他沒有答案，或以為自己知道卻記錯、看錯、推錯；不能為了發放線索而突然讓他掌握真相。

**作者層在寫該章前給使用者的說明，重點不是統一填「他在隱瞞什麼」，而是**：
- 此人客觀上知道／不知道什麼、是否確有故意隱瞞；若非刻意隱瞞，應寫清**未談及的自然原因**。
- 哪些接觸、事件、問題、物件、信任變化或其他條件會讓資訊自然出現；觸發不必是固定密碼或機械任務條件，人物仍依情緒、性格、時間與自主選擇反應。
- 其他哪些人事物、地點或材料可能先指向此人；允許**多條可信線索路徑**與部分失敗／錯過，不要求唯一路線。
- 這份資訊最後能回收哪段既有伏筆、預計大致何時有價值；不把一個普通居民無故升級成唯一掌握世界真相的秘密守門人。

**示例（非正式劇情設定）**：修鐘匠多年前曾替某名貨運員修過特殊鎖扣。他在平常買賣裡完全沒有理由談起；但主角之後看到帶相同刻紋的貨單、從其他工人處聽到這位修鐘匠的名字，或把一枚損壞鎖扣交給他，他才可能認出當年的手藝。這是**線索接通**，不是「修鐘匠一直有意隱瞞終極秘密」。

**一樣適用章前告知規則**：只要作者打算讓該人物或相關細節承載可回收伏筆，即使普通路人沒有隱瞞、甚至本人也不知道線索價值，仍要在相關章節開始前向使用者展示作者專用資訊與回收方向。反之，未計畫成伏筆的普通交談不需預先建立事件劇透檔。**這些情報路徑只給作者掌握；正文不得顯示任務選單、觸發條件標籤或刻意安排所有NPC等著主角問話。**

## 二、每個獨立事件的作者層基本骨架（正式動筆前至少掌握）

- **核心命題／事件為何發生**：最初原因、主要矛盾、涉及的具體人物及其真實動機；避免只有表層懸念而根本原因始終缺席。
- **因果鏈與情報邊界**：事件前哪些事已發生，哪些人在什麼時點知道什麼；角色只能依自身經歷與可靠情報推論，不能因作者已知而全知。
- **預計發展與主要轉折**：起點、實質推進、關鍵選擇、確認／推翻哪些判斷，直至高潮；不必死鎖每句台詞與每個路徑選擇。
- **大致結尾與收束條件**：作者先知道本事件最重要的問題準備如何被回答、何時算完成、誰付出代價、各人的生活有何改變。可留未解之事，但要清楚它是否**本事件的必要答案**，或已明確轉移至另一條長線。
- **後果如何繼續存在**：事件可以結束，而人際關係、傷勢、技術、地圖改變、組織得失、物資、市場、長期情感與政治後果仍自然留在世界裡；後果延續不等於原事件不能結案。

| 最初埋設位置與表層樣貌 | 讀者／角色第一次看到的是什麼？當時資訊能支持什麼合理理解？ |
| 作者掌握的真相與保留範圍 | 哪些已大致確認，哪些細節可隨後續故事調整？絕非每個物件都必須藏陰謀 |
| 預定回收窗口或條件 | 可能跨哪個事件／篇章回收？若未定章數，至少要有觸發條件和大致階段 |
| 中途必要的鋪墊與證據 | 回收前需要哪些已發生的選擇、相遇、事實、情報流動或生活變化？ |
| 與其他事件的分界 | 本事件要回答到哪裡？哪些明確保留給長線，避免拿長線當藉口不讓當前事件完結？ |
| 狀態與修正紀錄 | 待埋／已埋／推進中／已揭示／已回收／正式作廢，並標明修改緣由 |

**作者層「有規劃」不等於一開始就必須決定所有細節或封死角色選擇。**可以先有答案方向、幾個必要因果錨點、高潮與回收條件；若後續自然發展出更好的方案，可調整長線計畫，**但要同步修正台帳、前後證據與預計回收方式**，而不是把失控延伸美化成神秘。

## 四、事件收束、長期伏筆、開放世界三者可以同時成立

- **事件本篇要有開始、發展、高潮和真正的結局**。隨著走向核心，通常應逐步收回本篇主要問題，而不是線索越收越多、每個答案後硬加「還有更大幕後」。
- **長線可以繼續**：一篇已解決地方事故，仍可能留下角色習慣、人際恩怨、遠方組織行動、一件物品的來源或尚未解開的歷史，未來隔許多章才回收。但那是**另有作者層計畫的長線**，不等於本篇永遠不能結案。
- **巨大主線可以長期存在**：本企劃「收集模組、擊敗最終敵人、登上真正最高層」是已由使用者確認的作者層主骨架；中間各城、各區、各群落事件有自身動機與結局，不必每篇硬把中央主線往前扯一格。
- **世界不圍繞伏筆運轉**：普通人的日常、交易、探索、建造、旅行、矛盾與樂趣可以自成完整故事，永遠不必被追認為主線提示；不要每個看似普通的地方都藏終極祕密。
- **伏筆回收要有因果和情報合法性**：不是因為作者想揭露，世界內的人就突然知道；必須有接觸、調查、記憶、推理、偶遇或其他合理途徑。讀者知道也不代表角色知道。

## 五、每章續寫前的執行檢查

1. 目前屬哪個事件？在預定骨架的哪一段？上一章真正推進了什麼？
2. 本章預計回收／確認／排除什麼？是否讓本篇更接近高潮與結局？
3. 新出現的線索是已規劃因果的一部分，還是我只是為了延長故事臨時加的新謎？
4. 若需新增長期伏筆，它的作者層目標、可能回收方式和事件分界有沒有記錄？
5. 當前事件是否已足以收束？若是，就讓它結束，轉入正常生活、另一個事件或真正更大尺度的既有計畫，不要以「更深幕後」無限續命。

## 六、此文件的權威邊界

**【使用者確認的寫作原則】**動筆前先掌握事件大致走向、高潮、結尾與收束；允許長期伏筆，但作者層必須有可追蹤、可調整的回收規劃。

**【助手提出的實務化方法】**以上表格欄位與每章核查流程，旨在落實要求，可依不同作品調整，不是每篇必須展示給讀者的表格或硬性章數配額。

# 第189份｜白瓷面具人作者層身分／萬鈞鐘心事故骨架與防白鳥式無限延伸續寫門檻

## 2026-11-05｜再校正：**普通人可能只是尚未遇到說出情報的契機**

第031份最新補充的「NPC 對話尚未自然觸發」優先適用：**角色知道某件事，不代表他刻意隱瞞**。普通人可能只是當時沒人問、沒有碰到能喚起記憶的物件、不知道那件事與主角調查有關，或正在做其他事情。主角可以先從旁人的談話、貨物、帳簿、地方傳聞、維修紀錄等處得到線索，再決定是否拜訪此人；也可能不走此途，透過另一條有效線索完成調查。

**白衣人案亦同理**：第189份方案A中「他因害怕證據被扣而不願說」只是**未採候選**的一種性格與因果走向。不能預設所有知情工匠、守衛、塞拉或目擊者都在蓄意隱瞞；有些人可能真不知道事情相關、有些人只在特定話題或證物出現時才想起情報，有些人會自行主動提供資訊。作者須在章前向使用者明確交代**知情狀態、未談及原因、可能的外部線索與回收方向**，不以「故意藏秘密」作預設答案。

**不是遊戲式固定對話按鈕。** 觸發條件只供作者掌握人物因果與資訊流動，不要求在正文塞任務提示、條件表、唯一正確NPC，或讓角色非得等待主角滿足某項硬門檻才會說話。

## 2026-11-05｜作者最新補充：**有秘密或伏筆，連普通路人都須在章節前向使用者告知設定**

第031份新增的規則優先：**適用門檻由「核心神秘人物」擴大至「任何被賦予秘密或伏筆的人」**。身分地位、戰力、戲份、是否有名字均不豁免；即使只是店員、修工、守衛或普通旅人，只要其言行、過去、物件或身分將來有隱藏真相／伏筆回收，**本章開始撰寫前，必須先向使用者提供作者專用、含劇透的真相、動機、當下情報差、預計線索與回收方向**。只在助手心裡想好、存檔卻沒事先告知使用者，不算符合要求。

這是**作者先知道 + 使用者事先知道**，但**人物／讀者不提前知道**。無秘密、無回收意圖的普通人物不用被強制加神秘身世；也不能為逃避告知而將既定伏筆假裝成普通背景。若寫作過程臨時產生秘密構想，先向使用者說明再提交該章，或暫不把它寫作伏筆。

**以下過時句要由此條取代：** 舊版第二節「只有承擔主要謎團和篇章因果的角色／物件需達此門檻」不再適用於有秘密／伏筆的普通人；但對**沒有秘密／伏筆的純日常路人**，仍不要求預先設定完整傳記。

參見[第031份統一的章節前告知流程](031_討論續錄_事件骨架_長期伏筆與作者層收束規劃.md)。

## 二｜明確規則：防白鳥式失控（使用者確認，繼承第031份）

- **未先定核心答案，不再接力新增懸念。** 每名承載核心事件的神秘新人物，作者至少知道其真實身分／具體人生位置、當前目的、如何到場、知道什麼與誤判什麼、關鍵藏物或情報的真實內容、本事件如何與他發生關係，以及預計去向。
- **當前事件有封頂因果與具體終點。** 「線索→大謎→新組織→古代事故→更大真主謀」不可成為預設續章機制；避免把小型／區域工程事故連續抬升為宇宙級真相揭露。
- **不能無限延後本篇答案。** 作者層拆成：誰／何時／如何發生、真因、哪些人知道、怎麼止損、誰承擔責任與後果。中後段應朝確認與排除、核心因果、後果及收束前進；新資訊優先**解答已存在的問題**，而不是只帶來更大新問題。
- **長期伏筆允許，但要另有回收指向與事件分界。** 黑銃真正制造者、世界原文明、人物長遠命運可以很久後揭露；不能用「這是長線」當藉口讓**眼前鐘擺是否會毀城、白衣人為何闖入與鉛盒證物**永不回答。
- **人物照樣可以犯錯，不用每個人都理性。** 塞拉、守衛、白衣人或主角可以在有限情報下受騙、猜錯、隱瞞或冒險，但作者應預先知道什麼是錯，不能用角色「可能不可靠」取代作者答案。
- **沒有足夠作者骨架前，不寫下一章正式接續。** 若尚未選定候選，先補設計或只寫明確標示非正史的試演，不硬用懸念擴張故事。
- **普通日常不必全建傳記；但任何秘密／伏筆都必須事先向使用者揭露作者設定。** 無秘密的路人與普通物件不需全面檔案；即使僅一句話的普通路人，只要埋伏筆或隱藏真相，就要先告知作者層答案、因果與回收方向。詳見本文件最前方補充與第031份。

[第031份原則](031_討論續錄_事件骨架_長期伏筆與作者層收束規劃.md)已明確要求作者先知道起因、轉折、高潮與結案；本次是針對**白衣人／鐘擺黑銷**新增可驗收的硬性寫作門檻。

| **高潮的工程選擇** | 改變承力條件、局部停擺／卸載與搶修，並由塞拉、維修隊、白衣人、雙主角在制度與能力範圍內互相配合或衝突；能保住多少由當時條件決定。 | 不硬設一定無傷全勝或全員瞬間變天才；也不突然追加都市級外部黑手。 |
| **結尾與後果** | 鐘擺危險有明確處理、事故責任可以追查／處置、白衣人作出留下／受審／遠行等具體選擇；雙主角可繼續自己的旅行，地方社會繼續維修和生活。 | 不把本篇結尾寫成「真正幕後剛剛開始、所有答案都還未知」。 |

**篇幅不是機械配額**：地方工程事件應依實際戲劇與情節密度自然收束，通常後續數個場景／少數章便可閉合；若要拉成十幾章、增加跨區上層主謀，必須**另有完整且先於擴寫的作者層主幹與結局**，不能順手擴寫。

## 五｜不可混為同一項目的問題帳本

1. **本篇必須回答**：白衣人為何來、實際在修什麼、三天前發生了什麼、鉛盒對這件事有何意義、鐘擺是否真的會斷／如何阻止、塞拉如何處理事故與兩名守衛。
2. **可在本篇提供線索但不必解到底**：黑銷究竟是否和諾亞的黑銃具有同一來源、其完整工作機理、誰在更古老年代留下它。若留下，須有**具體回收方向與事件分界**；諾亞當下不必知道作者全部答案。
3. **不能單憑一句台詞就變成新事實**：面具人說「不出一個鐘頭鐘擺會砸城」、說「贖罪庭一定滅口」、說「白庭墜物撞歪黑銷」，都是角色可能正確或錯誤的主張，需要來源、驗證和角色差異。
4. **已見角色的未來不是一定要收編主角隊伍**：白衣人可以留下工作、受罰、與塞拉和解、離開、重逢或永不登場；只需本案責任和結果有交代。人物離場不等於停止生活，但也不等於再開無限主線。

## 六｜續寫前硬性檢查（給任何AI作者）

**沒有通過以下檢查，不應繼續把第八章寫成更多未知幕後。**
- 能在作者層一句話回答：「白瓷面具人本名／社會身份是什麼？他到底在做什麼？」
- 能在作者層一句話回答：「鉛盒究竟裝什麼？三日前的事故因果怎樣發生？」
- 能分清面具人**真正知道、以為自己知道、故意隱瞞**的三種情況。
- 能指出**本篇高潮的具體選擇與結案條件**，而非只說「更大的謎團尚待揭露」。
- 能交代**塞拉、地方維修體系與主角不需無條件正確／無敵**的各自選擇。
- 長線原槍線索若延遲揭露，另有可追蹤的回收方向；**不利用原槍線拖著地方鐘擺案永不結案**。

**狀態標記**：
- 「禁止白鳥式套娃、作者先定骨架」＝**作者已確認的高優先寫作原則**。
- 「白衣人多恩・斐斯、白庭外聘校準技師、鉛盒事故殘片、當代違章吊運」＝**作者尚未採納的完整候選A**。
- 「現有第七章」＝**使用者聊天提供之新候選文本，仍未正式採用**。

## 一｜真正要借鑑的不是「觸發對話UI」，而是「此人為何此時自然開口」

角色知道某件事不代表他有義務在初次見面的買賣中主動交代。可能是沒人問、彼此不熟、對方無從理解、他自己沒把兩件事連在一起、正在忙別的工作、事情還沒發生、談了也無益，甚至只是上次忘記提。反過來，真的有隱瞞、故意說謊、受契約限制的角色也可存在，但須有個別理由。

資訊露面的自然入口可分作**人際**（相識、欠情、信任、親屬／職務關係）、**知識**（有能力聽懂術語、先看過事故紀錄、知道該問什麼）、**實物**（舊照片、零件、印記、傷痕、物證）、**地點與時機**（在同一工坊、過去一週、經歷災後）、**利益**（交換、合作、交易、競爭）、**心態與偶然**（愧疚、愉快、疲憊、喝醉、口誤）、**別人的引薦**（第三人提及、不同組織的流言、書信）等，可相互重疊而不是像門禁卡一樣全部必備。

信息可以反向流動：先拿到實物再問人、先聽傳聞再回看舊話、先找到缺席者後才知道他去過哪裡、別人主動找到雙主角、甚至沒有任何人說話而由環境顯露。**不預設唯一正確的問話NPC、固定任務鎖、善惡分支或每個對話都必須推主線**。

## 三｜不只NPC對話：可長期擴充的八個研究方向

**1. 地區生活與社會位置。** 出身、工坊訓練、證照、交易夥伴、居住地、語言與習俗改變一個人認得誰／能去哪／願跟誰聊；某人的職務正式權力和私人感情分開，組織不是只用強弱分級。

**2. 由人物與實物共同構成的情報網。** 人物可傳遞片段、物證可反駁記憶、帳目可引出別的貨站；至少有一些替代調查路徑，允許錯判、遺漏、暫時不知道；**不是所有路徑都必須成功，也不是每位NPC都知道最終答案**。

**3. 空間本身的故事。** 穿越巨構不是把W層級當成關卡列表；風道、橋、廢井、供水、暖氣、升降車與交通費有實際生活和工程意義。一座荒廢巨構未必藏神物，也可以只留下歷史和危險；某地因新資訊而有了可去的理由。

**4. 失敗、折返與代價。** 前路封閉、錯過車期、受傷、誤會、器材損壞可以讓旅途改變方向；不需要每次都安排突然傳送來的更高階救援或遺物。高階能力能做什麼，仍需承受情境、信息和人物判斷的限制。

**5. 裝備／工坊／經濟互相支撐。** 裝備的價值包括修理成本、可靠度、能耗、零件來源、材料可得性和獲得方式，而不只是「戰力多少」。地方制度可能影響銷售、資助、走私、保固、借用與衝突；資金與物權須在章節連續。

**6. 戰鬥不是一套固定招式表。** 格擋、失衡、逃跑、地形、談判、援手、搶先進入安全區與突襲，會比每次定期更新招式更像活人；勝敗有職業、社會與情感後果，戰鬥外的生活亦有篇幅。

**7. 自主生態與主角缺席的後果。** 商隊、居民與異質生物有自己的目的、資源和時間，不應主角一進鎮就同步停在發任務位置；他們自己也可能互相幫忙、打架、搬走、死亡、換路。作者有因果，不等於每件小事都神祕化。

**8. 真相、身份與世界尺度。** 人民未必知道作者的文明分級；有人精通古科技卻不懂世系，有人懂往事但不知道眼前零件已變異。不同知情者的真實對話可以彼此矛盾，而**原理未知不等於作者沒有為預計回收的伏筆準備答案**。

## 四｜可檢驗示例：同一個普通人、三條可能的接觸路徑（非正文Canon）

假設某位常修升降軌的店主，多年前曾協助一名外地旅人換過一組特殊鎖扣。她從沒把此事當成機密。

- **路徑甲／人際**：雙主角認識旅人的舊同行，對方順口提到那位修理師；兩人有了合理拜訪原因。
- **路徑乙／實物**：另一座橋上出現同款鎖扣，維修標記可循商會資料找到她；她看到零件才回想起當年工單。
- **路徑丙／事件自行發展**：她主動來處理塌軌，發現兩人帶著同款零件，可能先問他們從哪得到。

這三條都不是主角必做的遊戲任務。若她已搬走，兩人可能從另一位工人找到資料；若她記錯，該線索不一定正確。她在大部分日常交易中只會正常收費、修理、聊天；**不是強制微笑等待主角出示專用道具的NPC**。

若作者將此人的往事視為可回收伏筆，仍要在撰寫首次埋線索的那章**先向使用者交代：她真知道什麼、以前發生什麼、為何尚未提及、可從哪些來源指向她、何處收束。** 不需要把未來三條路線都寫成固定章數，也不需要為路人建立數十頁傳記。

## 五｜讀者體驗的非機械轉譯

**可用**：人物先有生活，資訊因相遇與選擇才有意義；同一線索可先誤解、幾章後改觀；某個地區的習俗、經濟、危險和角色關係會自然決定談話；主角錯過什麼，也不代表世界停擺。

**避免**：出門就派任務、人人掌握一塊拼圖、每個普通人都藏重大身世、所有秘密必須由特定道具「解鎖」、所有組織能有同一套全知情報、所有獎勵都只為升級、所有險境都要有更高規格BOSS、每章末都出現一名戴面具的人說還有更大黑幕。

**作者層程序保留**：可回收的伏筆必須事先向使用者交代本質和回收方向；本文的遊戲參考只提供**可選的創作手法**，不改變既有角色的身分、作者權威與《巨構世界》的Canon。比起增加設定數量，更重要的是令已存在的角色／街區／裝備之間真的發生互動。

## 六｜下一批可研究的不同方向（純候選）

不只追逐與上列作品相同的題材；可延伸研究《空洞騎士》的地圖與支線人物節奏、《來自深淵》的垂直環境與探險代價、《BLAME!》的巨大尺度／文明斷層、《Outer Wilds》在先知道答案之後改變探索方式、《Rain World》的獨立生態、《Disco Elysium》的認知與對話差異，也可研究貿易、建造、政治、職業、家庭日常、生活美學、幽默和互相競爭的社群。**這些只是後續研究題目，尚未在此文件聲稱逐一完整核對。**

**狀態**：遊戲事實＝依上列公開來源的有限查證；具體小說應用＝研究候選；本輪使用者確認的核心原則＝「未談到不等於刻意隱瞞；人物可由彼此、物件與其他線索互相指向；不只研究NPC，還要開放吸收各種遊戲設計」。本檔不是設定定案表，任何新增角色劇情需另有作者層規劃並提前向使用者說明。

# 第191份｜跨遊戲世界生命力深度研究：建造、經濟、文明日常、信仰學術、戰鬥、喜劇、環境敘事與旅途偶遇

> 研究日期：2026-11-05。**外部作品研究／創作素材庫，全部為候選，不是《巨構世界》Canon。** 回應使用者「這些遊戲不必是固定名單，繼續主動研究地區建造、物品經濟、文明日常、宗教學術、戰鬥、喜劇、環境敘事、純粹有趣的偶遇」的指令。本次研究涵蓋十餘款不同類型作品，不以Roblox RPG為上限；重點是理解運作原理、移植方法和不宜模仿的錯誤。外部遊戲內容依官方遊戲頁、開發者文章／訪談、官方支援或開發商Wiki核對；**沒有宣稱逐一通關或完整觀看每場遊戲劇情**。 
>
> **本企劃既有權威**：[第004份人口群落知識](../01_世界本體與文明/004_群落社會與知識.md)、[第031份作者層事件／伏筆](031_討論續錄_事件骨架_長期伏筆與作者層收束規劃.md)、[第183份人物可誤判](183_人物誤判有限理性與前六章修稿規則_作者後出確認.md)、[第189份防無限套娃](189_白瓷面具人作者層因果骨架與防白鳥式無限延伸_續寫門檻.md)、[第190份Roblox與RPG自然情報探索](190_跨遊戲研究_NPC自然情報觸發_多入口線索與活世界系統_非正史.md)。本文件不把建造系統硬塞入G8D／第七章，也不先行採用任何新城鎮、宗教、商品、人物身世或劇情。

## 核心研究結果：讓世界的各部分「有自己的理由」

小說世界的建築、工坊、宗教、道路、居民、怪物與節慶**不應只是服從主角路線的背景貼圖**。它們之所以存在，是因為人們要住、維修、賺錢、求學、思念、信仰、旅行、取樂或生存。主角可以碰到它們、改變它們、錯過它們，也可以完全不介入。

研究採四層：**（A）查證作品實際有什麼→（B）為何產生效果→（C）如何轉為文學演出→（D）過度照抄會造成什麼缺點。** 下面的小說示例均為新的非正史概念，不是宣布該地已有該組織或該角色。局部現實技術與虛構機制可共存，作者不能由遊戲的架構數字硬推巨構世界的科技／經濟公式。

## 一｜建造與基礎設施：一座城有施工、維修與交通史

### 查證A｜《Workers & Resources: Soviet Republic》
- 開發商官方站把從礦山到工廠的加工鏈、道路／鐵路／傳送帶／管路、水電設施、住宅和居民服務視為連動系統。
- 官方Wiki在真實模式下寫明建築不會憑空完工，建材與人力必須抵達現場；施工分階段，需要不同材料、設備與工人。
- 來源：https://www.sovietrepublic.net/ ／ https://wiki.hoodedhorse.com/Workers_Resources_Soviet_Republic/Game_settings ／ https://wiki.hoodedhorse.com/Workers_Resources_Soviet_Republic/Construction

### 查證B｜《Frostpunk 2》
- 11 bit studios在Xbox開發者文章區分了第一作圍繞發電機的城市設計，以及第二作進入大規模治理後的政治、派系和互相競爭的城市未來；設施和城市政策並非獨立於居民。
- 來源：https://news.xbox.com/en-us/2025/09/18/adapting-frostpunk-2s-depth-to-a-gamepad/

**原理：** 讓基礎設施有「誰建、誰用、誰維修、壞了誰受影響」的分布式因果，而非巨構奇景只有尺度和秘密。

**小說轉譯：**
- 一座巨型升降軌道可由原建造者、後世改裝工會、收稅機構、守夜者和乘客共同使用；相關方不必友善，也不必都懂軌道原理。
- 一次正常保養會讓商人改走另一條路；小吃店營業時間隨換班表變動；商販知道最方便的溫水來源，但不會憑此理解整座巨構。
- **不同工程無需全是現代可解釋技術**：未知古代結構仍可能保留完全無解的尺度，但周邊居民為生存所加的橋、燈、油井、工具間應呈現可追溯維護關係。

**避免：** 每章突然加一座超巨機關，卻沒有運行和維修需求；或反過來在正文插入數頁工業流程圖。規格只在人物行動需要時進入鏡頭。

## 二｜物品與經濟：所有權、製作、修理、價格與需求的實質後果

### 查證A｜《EVE Online》
- 官方製造頁列明藍圖、材料、製造設施、距離與成本的依賴。公開經濟研究論述玩家主導採礦、加工、運輸、交易與分工，形成由玩家互動產生的社會經濟網絡。
- 來源：https://support.eveonline.com/hc/en-us/articles/203210292-Manufacturing ／ https://pmc.ncbi.nlm.nih.gov/articles/PMC7577455/

### 查證B｜《Roadwarden》
- 官方Steam介紹把旅行護衛、隔離村莊的連接、商人支援、有限資源、NPC和時間選擇融入道路冒險；旅途中「交換資訊」與「提供服務」本身有價值。
- 來源：https://store.steampowered.com/app/1155970/Roadwarden/

**原理：** 物品價值來自用途、稀缺、當前供應／需求、可修復性、持有人及社會制度，而非一個固定稀有度數字。

**小說轉譯：**
- 同一只齒輪箱：對車站是停運風險，對工坊是修理訂單，對二手商是存貨，對居民是晚間班車會否誤點。
- 交易可有押金、賠償、抵押、委託、證照、代工、保固、資訊不對稱。每筆帳不是「解鎖任務獎勵」，而有真實對價及誰負責。
- 主角有時出得起錢、有時選借工具、有時為了節省兩天等待而多花錢；人物價值觀在選擇中自然外露。
- 重要裝備未必天天買賣；優秀機械師可能花大部分人生修理普通貨物，而不是各章都得到前文明孤品。

**避免：** 複製EVE市場公式／貨幣通膨當小說規則；主角隨處擊敗敵人便收穫貨物卻永不遭物權爭議；物品的錢和責任憑旁白消失。

## 三｜文明日常與地方文化：相似技術，不等於相似生活

### 查證｜《Caves of Qud》
- 官網以物理、社會、歷史模擬編織手寫劇情，官方早期路線圖列生成村莊的地方資源、專屬料理、諺語、講故事傳統、建築、人物、歷史和派系。
- 來源：https://cavesofqud.com/ ／ https://cavesofqud.com/roadmap/ ／ https://wiki.cavesofqud.com/wiki/Reputation
- 這裡「村莊系統的設計目標」與「現時每個版本全部已實作」應區分；本研究只採合理已述之設計原理。

### 查證｜《Pentiment》
- Obsidian官方介紹：16世紀小鎮、修道院、貴族／手藝人／農民／修士，識字與印刷社會變動，角色背景和決策能跨世代留下後果。
- 來源：https://pentiment.obsidian.net/ ／ https://www.obsidian.net/news/obsidian/obsidian-entertainment-announces-pentiment

**原理：** 文明差異產自地形、職業、風俗、學習、飲食、交通、家庭與歷史的長期互相塑造，並非「一城一皮膚」或「科技越高性格越高貴」。

**小說轉譯：** 對每個需要停留的聚落，內部作者筆記可用五個問題：人吃什麼、怎麼工作、哪種能力被視為體面、學童從小學什麼、什麼事情最容易吵起來？這些答案能自然進入街市對話、家庭場景或職業爭執，**不需整張民俗學清單寫入小說**。

**避免：** 將文化變成全體居民單一人格、每個居民說一樣的諺語、地方風格只是百科標籤；也不要求每個聚落都極端異形，因為歷史移民和貿易會使文化混合。

## 四｜宗教與學術：知識是人日常從事的活動，不只是宇宙真相的密碼

### 查證｜《Pentiment》與《BOOK OF HOURS》
- 前者以修道院、印刷術、教育、階級、私人信仰與小鎮歷史交互影響；後者由Weather Factory明確強調圖書館修復、書籍整理與編目、訪客、不同智慧傳統和神秘知識研究。
- 來源：https://pentiment.obsidian.net/ ／ https://weatherfactory.biz/book-of-hours/

**原理：** 任何宗教或學術團體都需要教育、儀式、記錄、師承、分工、資源、權力、異議、私人關係；信仰與專業技術不互斥。

**小說轉譯：**
- 承光贖罪庭裡可能有誠懇信仰又極精明的工程者，也有只會背教典卻努力學修理的年輕人、只在乎財政的行政者，以及把古代材料當成值得測試之物的研究人員。
- 同一份測量報告可以有神學詮釋、機械實用解釋、歷史保存爭議；不同看法可能有其證據，也可能有人犯錯。
- 儀式不必都暗藏神秘效果；有些作用就是使跨世代工班在換班時完成責任交接、為死者留名或維繫社群。
- **重要區別**：外界觀測者如何稱呼現象，不等於他已知道前文明的真實歷史；宗教不被作者全知旁白簡化成純無知或終極真理。

**避免：** 一看到神職人員就設成愚蠢／壞人；只要發現新設備就等同觸及全宇宙秘密；讓所有信徒同步成為陰謀組織。

## 五｜戰鬥與能力：動作、站位、預判、環境和後果形成戲劇

### 查證A｜《Sekiro: Shadows Die Twice》
- FromSoftware官方操作說明：攻擊、彈反影響架勢，體力亦影響架勢恢復；突破架勢後可進行致命攻擊，不是純比較傷害數字。
- 來源：https://www.fromsoftware.jp/manual/sekiroshadowsdietwice/stadia/mechanics.html

### 查證B｜《Monster Hunter Wilds》
- Capcom透過PlayStation Blog介紹怪物會隨氣候、地形及族群動態行動，群居、領地與掠食習性影響遭遇，而非一律靜止等待狩獵。
- 來源：https://blog.playstation.com/2024/05/30/monster-hunter-wilds-new-gameplay-details-from-todays-state-of-play/

### 查證C｜《Kingdom Come: Deliverance II》
- 官方網站強調武器維護、不同兵器和戰法、格擋及連招；裝備維護與失誤可造成損失。
- 來源：https://www.deepsilver.com/games/kingdom-come-deliverance-ii

**原理：** 強弱差可以存在，但真正戲劇來自角色在具體環境下的選擇、準備、資訊、身體成本與相性，不應只用數字或「不可能」重複宣稱。

**小說轉譯：**
- 諾亞原槍精確斷接，戰鬥可描寫視線、可接觸部件、盟友安全、彈道與站位，而不是每次新敵人都變更大的防禦力數值。
- 艾莉維亞的界側技術可讓她切換對不同空間的理解；她也可因預判錯誤暫時被限制，而不是因此被削弱人格或變成無能。
- 守護繫繩的生物也許只是為保暖而爭奪管線；牠們的位置、聲音、休息習慣可能使戰鬥不必要。
- 不論階級高低，工坊、治療、賠償、撤離與恐懼都可能在戰鬥後繼續存在。

**避免：** 正文寫成姿態槽／血量條；每個人都必中同一套完美解；強者不允許意外或失策；每隻怪物都是有意進攻主角的敵人。

## 六｜喜劇與角色魅力：讓荒謬由人物與情境自然產生

### 查證A｜《Like a Dragon》系列
- RGG Studio在2025年PlayStation周年訪談說：故事的戲劇核心先決定，次要內容依題材及舞台設計；其獨特幽默可包含把道歉做成股東會的攻擊技等荒謬表現。
- 來源：https://blog.playstation.com/2025/12/19/like-a-dragon-20th-anniversary-interview/

### 查證B｜《West of Loathing》
- 開發商Steam介紹直接把荒謬西部冒險與一整個可探索世界、奇怪職業、支線、角色對話及大量笑話結合；它不是「只剩一串搞笑台詞」的作品。
- 來源：https://store.steampowered.com/app/597220/West_of_Loathing/

**原理：** 喜劇要有自己成立的情境與角色邏輯，即使荒唐，世界裡的人也會認真對待自己的小事。反差可由職業尊嚴、誤會、嘴硬、物件用途及不同優先級產生。

**小說轉譯：**
- 假設商販嚴肅談論十噸吊籠的維修契約，卻因諾亞把甜餅包裝放在契約上、留下油印而大發雷霆；笑點來自契約真有法律與生意重量、兩人也各有急事，而不是硬安排「所有NPC降智」。
- 艾莉維亞可以不經意說出讓諾亞臉紅的話；諾亞也能一本正經編出破綻百出的藉口；同一反應不要每次都照抄「出神兩秒→嘴硬→被拆穿」。
- 某位普通修理師對自己的假花比對巨型設備更加較真，可能只是私人喜好；**無須追認假花藏宇宙級關鍵秘密**。

**避免：** 一切嚴肅場面都用笑話砸碎情緒、把所有工匠/教團寫成笨蛋、讓主角永遠以吐槽凌駕其他人、每章使用固定搞笑配額。

## 七｜環境敘事：地點應在沒人講解時仍能說出東西

### 查證A｜《Hollow Knight》
- Team Cherry官方介紹強調差異化、彼此相通的環境與特異居民；開發者早期公開文提到遺跡中的角色仍有自己的日常工作，某些生物遭異常影響。
- 來源：https://www.hollowknight.com/ ／ https://www.teamcherry.com.au/blog/introducing-hollow-knight

### 查證B｜《Return of the Obra Dinn》
- Lucas Pope作品官方Steam介紹以失蹤船員、船隻殘跡、保險調查和邏輯推理為核心，觀察比「所有人輪流解說」更重要。
- 來源：https://store.steampowered.com/app/653530/Return_of_the_Obra_Dinn/

**原理：** 一個場景的材質、布局、使用痕跡與改建層次，可以讓讀者自行推想「這裡以前為誰而設、後來發生什麼」，但並非一眼就能準確得知整段歷史。

**小說轉譯：**
- 舊行道有兩套不同年代的警示牌、相互不合的軌距、後世居民補上的安全繩，這表示不同使用歷史；主角不應只憑看見痕跡便判斷千年前的全部原理。
- 可以讓旅人看見已經被廢棄但仍能供暖的小房間、微妙的植物生長、同一段橋上不同修補技術；不需要立即觸發機關或遇見BOSS。
- **背景事實和伏筆要區分**。如果作者刻意規劃某個標記、留言或物件未來會揭露秘密，仍須依第031份在本章動筆前向使用者交代；否則它就只是此地的普通歷史與生活痕跡。

**避免：** 把所有磨損都升格遠古文字；放十個標誌卻沒有後續因果；角色憑20m感知就知道幾千公里結構、或看一眼就得知真正造物者。

## 八｜旅途偶遇、休閒與純粹好玩：一段路不必都服務主線

### 查證A｜《A Short Hike》
- 原創作者Adam Robinson-Yu強調登山休憩、自由走路、認識旅人、小型探索和單純欣賞風景的喜悅；可以釣魚、游泳、走不同小路。
- 來源：https://www.ashorthike.com/ ／ https://blog.playstation.com/2021/08/05/crafting-a-tiny-open-world-a-look-behind-the-scenes-at-the-creation-of-a-short-hike/

### 查證B｜《Roadwarden》與《Hollow Knight》
- 一個強調沿途幫助商隊與偏遠村落、透過不同人物關係認識道路；另一個讓探索地點與奇異旅人本身即有吸引力。**純生活片段的存在理由可以是人物喜歡、需要休息或單純偶遇**。
- 來源：https://store.steampowered.com/app/1155970/Roadwarden/ ／ https://www.hollowknight.com/

**原理：** 不是每個片段都必須貢獻戰力成長、原槍模組、主線伏筆或巨大危機。讀者會記得兩人一起吃過什麼、在何處看過風景、認識哪個古怪但友善的居民。

**小說轉譯：**
- 偏遠轉運市場可以有小型音樂會、當地特色熱飲、風大的觀景椅、修理傘骨的老人、喜歡和旅客交換點心的小孩；都不必自動製造謎題。
- 偶遇可在之後自然再見，但沒有再見也不算「伏筆未回收」。如果作者從最初就**有意埋下未來身分或重大回收**，才須提早向使用者告知作者層答案。
- 諾亞可以只想看窗外，艾莉維亞可以為了好吃的繞遠路；這些小選擇也可以改變兩人對彼此的理解。不是每章都要打架。

**避免：** 假裝是支線生活卻每次掉出傳說碎片；為了數量硬塞三個好笑NPC；讓所有市民只等主角來訪才開始工作。

## 九｜跨主題組合：如何不用設定說明書腔也創造一段生動事件

以下四個「微事件設計」都**不是正式劇情**，僅示範從不同遊戲得到的機制如何交錯。

### A. 收工後的車站餐館｜經濟＋生活＋幽默
同一座車站有早班、中班、晚班工人。餐館老闆根據吊籠到站時間備餐。一個普通維修員因被改班，錯過自己預訂的熱湯，和老闆認真爭執要不要退錢。兩位旅人進門，先被問「你們是等車還是等吃？」雙主角可能因一個小笑話認識這個地方，不必得到任何核心伏筆。

**作者層**：這是一段有生活功能的偶遇，沒有藏身分／祕密，不需先建黑幕。若日後要讓老闆知道某名失蹤人員的往事，**應在埋那條可回收線索的章節前先告知使用者設定**。

### B. 兩座世界層同款零件｜經濟＋知識差＋地理
某款貨運銷釘在兩處被不同名稱銷售：一地叫「短咬釘」，另一地按廠牌正式編號。商品不是前文明終極遺物，只是一次改裝產生了地方通稱。不同工坊因保固和規格互相爭論；旅行者既可以問技師，也可翻貨單，或者自己實測。

**作者層**：若只是文化差異，不一定有秘密；若以後要揭露同廠地理連結或走私責任，就先設好因果與可回收方式。

### C. 教團的學生考試｜學術＋信仰＋社會身分
一名年輕苦修學徒會背完整祝詞，卻在更換封油螺栓時緊張得手抖；指導師傅先確認安全，再讓他重新來一次。旁邊另一名學徒雖然不喜歡背祈禱文，卻對承重原理理解得很好。兩人都不是同一種「虔誠＝愚昧」角色；他們有考試、師徒關係、職務與彼此玩笑。**無需與白衣人案或新的教派密謀強行掛鉤。**

### D. 風道休息平台｜環境敘事＋生態＋小型人物記憶
兩人原本只是想避開鐘擺風。休息台前曾有人釘過不同年代的扶手，台邊長著偏愛溫暖蒸汽的矮小植物。兩人坐著等風變小，艾莉維亞吃最後一塊點心，諾亞看遠處空腔的光。可以只有安靜、好笑或略微心動，沒有隱藏墓穴；若該平台未來真的成為兩人回望的感情地點，也不需要當下透過神祕預言宣告。

## 十｜優先推薦順序（為了實際改善長篇，不是作品排名）

| 優先層 | 研究資源 | 現在最能改善的問題 |
|---|---|---|
| **立即** | 《Workers & Resources》＋《EVE Online》＋《Pentiment》 | 巨構工程有真實維修與經濟、宗教職級不扁平、故事不靠新陰謀推進 |
| **立即** | 《A Short Hike》＋《Like a Dragon》 | 雙主角的旅行、閒談、喜劇、情感記憶，不只調查和射擊 |
| **第二輪** | 《Caves of Qud》＋《BOOK OF HOURS》 | 不同文明的食衣住行、研究與信仰機構的日常；知識分類由誰使用 |
| **第二輪** | 《Hollow Knight》＋《Return of the Obra Dinn》 | 巨構遺構、物件痕跡、環境敘事與角色知識邊界 |
| **隨戰鬥需要** | 《Sekiro》＋《Monster Hunter Wilds》＋《Kingdom Come II》 | 動作分寸、地形代價、生態互動、能力表現 |
| **自由擴展** | 《Roadwarden》＋《West of Loathing》＋《Frostpunk 2》 | 不同地區的交往、荒謬生活事件、政治與集體選擇 |

此優先順序是**本研究的編輯推薦**，不是將各款作品變成正式世界設定，更不能要求每章按題目逐一展示。

## 十一｜寫作前六條檢驗與明確不能做的事

1. **地方的生活功能**：拿掉主角，這個地方是否仍有居民的真實理由存在？答案可以是「沒有，這是荒廢古代設施」，但要有因果。
2. **人物自己的目的**：新的NPC是否在工作、玩樂、害怕、賺錢、等待某人，而不是只為主角發一條任務？
3. **可見的成本**：一件物品、道路、技術或勝利是否具有可感知的時間、金錢、身體或關係代價？不必每項都精密計算。
4. **不同知識的合理性**：學者能說出自己真懂的、普通人也可十分博學；不要把作者的科技尺度直接放進所有人的口語。
5. **節奏與多樣性**：巨大奇觀之間允許安靜、普通勞動、惡作劇、搞笑、休息；戰鬥與重大秘密不必每章露面。
6. **伏筆作者層先交代**：若作者刻意將任何人、物件或一段普通話設為長期伏筆，**在包含該線索的章節動筆前，先向使用者交代真相／知情邊界／回收方向**；不能先寫再想，也不能以「看似平凡」豁免。

**整體禁則**：不因最近研究建造，就把下一章變成產業鏈報告；不因研究宗教，就在白衣人身邊增設神諭；不因研究喜劇，就讓守衛忽然全部很笨；不因研究環境敘事，就讓每塊磚頭指向原槍；不因研究遊戲，就把小說變成任務列表。**研究是可用的素材庫，故事仍由當前人物與事件因果自由生長。**

## 十二｜公開來源與查證邊界

| 來源類型 | 例子 | 信度用法 |
|---|---|---|
| 開發商與官方作品頁 | Workers & Resources、Caves of Qud、Hollow Knight、BOOK OF HOURS、Pentiment、A Short Hike | 支持作品定位、公開描述之實際機制與製作意圖 |
| 官方支援、操作說明與發行商Wiki | Sekiro操作、EVE制造、Workers & Resources施工 | 支持具體機制與操作範圍 |
| 開發者直接受訪／署名文章 | Like a Dragon製作人訪談、A Short Hike作者自述、Frostpunk 2製作團隊文章 | 支持對設計動機和效果的歸納 |
| 第三方社群資料與遊玩推測 | 某些詳細隱藏路徑或未經公告版本 | **本篇不以它們作為未證細節的確定依據**；具體問題應另查 |

以上確認的**外部遊戲機制不等於小說世界既有事實**；所有「巨構示例」都是可選創作原理。依作者以前已確認的工作方式，只有對應角色、地點和事件經過真正決議，才可移到Canon。

**研究後的編輯結論**：本書不應只靠遺跡、陰謀和宏大戰鬥支撐讀者的好奇。工作、貿易、技藝、飲食、幽默、私人關係、日常宗教與旅行本身，都能撐起大量值得記得的場面；重大事件因果需要收束，世界裡的人生則不會因此停止。

## 0｜真正的研究目標：不是把《巨構世界》塗成單一美術風格

《BLAME!》代表「人行走於失去可理解比例的建築」；《奇諾之旅》代表「每一站可形成自我封閉但可持續反思的文明鏡子」；《魔女之旅》代表「旅行者本身有鮮明人格，每一次遭遇可以換故事種類」。這三者構成**空間—社會—人物**三條不同研究軸，不應互相替代。

「漂亮／恐怖」「可愛／殘酷」「宏大／平凡」「空曠／熱鬧」「神秘／可理解」「血腥／溫柔」**不屬於互斥選項**。同一段旅程可先讓讀者喜歡一個聚落、再發現它的殘忍；同一片荒野可沒有任何人，也可存在維修工、祭祀、家庭與交易。基調來自當下具體的人、環境、因果與敘事節奏，不應以套用「每段必有一次反轉」「每章必有一個恐怖房間」「每經過一城就打一隻Boss」為流程。

**四層分析方法**：A. 來源可證實的作品事實；B. 有哪些表演／敘事運作機制；C. 原理怎樣轉化成新的長篇文字；D. 哪些表面特徵不能照抄。每個作品只提取所長，不把它當《巨構世界》客觀設定。

# 第一部｜三個核心主軸

## 1｜《BLAME!》：不只是大，而是巨大空間已失去為人類服務的義務

### 1.1 可核對的原作本質與版本

- **原作**：弐瓶勉的科幻漫畫。Kodansha 官方介紹：在未來地球，巨型都市增殖到居民已不再認得「地面」的程度；主角霧亥（Killy／部分英譯Kyrii）尋找 **Net Terminal Gene**，該特徵關乎人類進入 **NetSphere**；他持有威力極強的 **Graviton Beam Emitter**，途中面對人類、改造生命及矽基生命等危機，並遇見科學家希波（Cibo）。[官方漫畫系列](https://kodansha.us/series/blame/)；[第一卷介紹](https://kodansha.us/book/blame/)。
- **閱讀版本**：Kodansha 英文頁目前列出**六大本**英文 Master Edition（不是「原來只有六小卷」）；早期日文單行本常見**十卷**編排。全貌研究應分辨版本，不用影視剪輯冒充漫畫的內容。[Kodansha 英文完整系列](https://kodansha.us/series/blame/)。
- **前史**：《NOiSE》是設定在《BLAME!》事件**三千年前**的前傳，出版社將它描述為藉刑事案件帶出 Safeguards、NetSphere 起源的作品；更適合用來研究「失控前的制度性源頭」，而非把前傳所有細節投射進主線每個角色的知識。[Kodansha NOiSE](https://kodansha.us/series/noise/volume-1/)。
- **2017動畫電影≠逐格復刻漫畫**：動畫製作方 Polygon Pictures 自稱是以原作者監修展開的 **all-new story**，是便於觀眾理解的重新編組；不應把電影中事件節奏、聚焦人物與漫畫十卷視為一致。[製作方資料](https://www.ppi.co.jp/works/blame_/?l=e)；[Netflix原始發表](https://about.netflix.com/en/news/netflix-brings-original-anime-film-blame-to-a-global-audience-1)。

**目前查證界線**：NetSphere、基因、重力子武器、巨構與主要遭遇有官方佐證；特定段落的空間距離、精確星系尺寸、層號與所有角色的細節走向，未逐頁讀回時**不列為可無誤引用的原著數字**。下文所談「建造者／守衛／矽基生物各自扮演什麼敘事功能」是對世界已知基本構成的結構性分析，不等於已完成原漫畫逐段設定考證。

### 1.2 巨構感不是「在旁白寫很大」：十個互相支撐的機制

1. **比例錨點**。畫面裡必須有可被辨識的身體、門、梯、鐵軌、橋或物件；然後這個單位在更大的樑柱、腔室、斷層與層疊牆面前驟然變小。若只有「千公里」「百億噸」，讀者不一定有空間感。
2. **負空間的重量**。大面積無人的牆、黑暗、空腔和未被語言說明的距離，使讀者意識到這些地方**根本不需要有人在場**。空曠不是空白設定，而是讓人的活動顯得偶然。
3. **路程與閱讀時長對齊**。跨越一段長廊，可以由連續畫面、局部重複、變化極少的結構與突然不同的地貌讓讀者「走了一段時間」，而不靠資訊解說。
4. **重複中出現可感異差**。重複的管線、柱網、扶手具有系統性；損壞、腐蝕、錯位、材質與年代不一致又暗示此地不是全新一體建造。小說應有能記住的差異，不能十頁只重複「巨大且冰冷」。
5. **不完整的方向感**。主角知道自己往一個方向走，不代表知道外部總圖；一處裂縫、複合升降、死路都可能破壞直覺。閱讀中的迷失應有可觀察依據，而不是作者隨時瞬移地形。
6. **密與疏切換**。窄小技術維修道突然開向無邊腔室、宏闊空間又進入高度擁擠的機械核心，造成類似呼吸困難與突然放空的節奏。只寫無限大會讓尺度麻木。
7. **文明殘存的微小尺度**。旅途中偶見有人維持生存，或小群體仍保有工具、交易、恐懼與自己的選擇，反而加深無人地景之廣。若把全部人都降為無名即死的背景物件，會失去對比。
8. **無法完全控制的基礎結構**。建築系統、管理權與人類生活需求不再一致，使危險不需要總有壞人操控。從敘事功能看，「仍在執行的建造流程」「把人視為未授權者的防衛流程」「另有所圖的異質生命」帶來的是**不同**威脅。
9. **破壞是尺度展示，也是價值問題**。超高出力武器不只展示火力，會讓讀者看見距離、材質、穿透與環境後果；若每場交手都必須更大的光束或更巨大的敵人，真正驚異反而遞減。
10. **有意保留的未知**。讀者與主角不總是先拿到建築的完整物理功能、歷史、總層數、管理者答案。**未知有魅力的前提，是當前的生活、危機與行動有足夠可理解因果**，不是作者可以不設答案。

### 1.3 敘事節拍：沉默的長度，與暴力的突然性

漫畫可在大量低字數／近無字畫面中讓環境、行走、停頓、遠景和細節累積感覺；突然切換到槍擊、身體破壞、潰敗與追逐，衝擊便被前面低事件密度的沉默放大。Kodansha 官方頁引用漫畫評論者對「無盡相似景觀與血腥混亂爆發的對比」的評價，能支持這一方向。[Kodansha官方介紹附評論](https://kodansha.us/series/blame/)。

**小說不能機械照做**：漫畫的一整頁巨構黑白分鏡本身提供大量視覺資訊；若小說只剩「走過很久、非常空、又很高」會變成低資訊量文字。文字版應以聲音、材質、身體動作、距離估計、路面可走與不可走、光線來源、氧氣／重力／風、人對沉默的反應，讓讀者身體經驗成形。需要讓人物自然說話時，就讓人說話，不需為了模仿弐瓶勉而強迫全世界寡言。

### 1.4 巨構中的時間：尺度感可以透過「地貌代際」和「生命節律」呈現

同一座結構可能在無人管理的時期繼續變化；一些居民的一生只夠使用一小部分道路。研究時應把**建築年齡、維修時間、物資更迭、人口變化、交通週期、人的壽命**分開。敘事不必頻繁宣稱跨過幾千年；一盞被不同世代補過的燈、一段無人再用的舊路、不同人對同一建築的稱呼，就可以形成時間的厚度。

這是對《BLAME!》巨構體驗的**小說化推論**，不是聲稱其所有地區都有統一的社會史。

### 1.5 人與異質生命的不同功能：不能把所有東西都叫「怪物」

- **小型人類共同體**：提供依存、求生、脆弱與擁有自己的生活的尺度。角色可以與主角交易、恐懼、合作或拒絕；不必都知道 NetSphere 真相。
- **機械建築與自動流程**：提供無意識、無人格、未必有仇恨的系統性風險。機器繼續工作不等於它想消滅主人公。
- **守衛型安全系統（Safeguard）**：提供權限邊界與強制處置的危機，讓「不被系統承認」轉化成實體危險；和普通自然災害不同。
- **矽基生命及其他異質勢力**：可在完全不同於人類生存規則的立場上行動。**不同勢力必須有自身因果，不宜扁平化成所有非人都同屬一個大黑幕**。
- **同路或暫同行的人**：希波之類的角色提醒：哪怕主角寡言，陪伴、共同目標、失去與互信仍可承擔情感；巨構不等於沒有關係戲。

### 1.6 「殘酷」真正可學的是結果，而非血量

當行走者遠弱於環境、制度與某些戰鬥存在時，死亡／破壞可以突然、乾脆，事前未必有漫長宣言；反過來，一次看似簡單的火力展示也可能永久改變通路、住民安全或資訊流動。**血腥程度不自動等於敘事重量**。過度增加肢解描寫卻沒有角色失去、抉擇、後續社會或生存代價，會讓觀眾逐漸免疫。

### 1.7 哪些是《巨構世界》最值得學的，哪些不應照抄

| 可吸收的方法（研究方向） | 不能直接照抄的外表 |
|---|---|
| 空間透過可感比例、行走時間與無人結構成立 | 把所有地方塗成黑白鋼鐵、同一種空洞 |
| 城市與制度存在獨立於人類主角的運作 | 把現有巨構全部解釋成同一失控建造系統 |
| 無聲、血腥、稀少的相遇彼此對照 | 要求《巨構世界》也幾乎沒有對話、家庭、交易、節慶或風景 |
| 主角只知道當前可觀測的一小段世界 | 偷把讀者不了解當成作者也不必掌握長線因果 |
| 強武器展示要與環境、身體負擔、危險判斷結合 | 直接複製重力子射出器、Net Terminal Gene、Safeguard 或原作科技階級 |
| 小小的生活與超巨空間互相襯托 | 讓每一名居民都孤獨、滅亡、神秘或單純等待主角路過 |

**我的結論**：《BLAME!》最稀有的本領不是讓建築大到看不見盡頭，而是讓讀者相信「人在這裡只是極小的一個尺度」。但《巨構世界》可以保留同級的宏大感，**同時讓其中許多地方更熱鬧、更有人味、更富有文化差異**；這不是削弱巨構，而是拓寬它的情緒範圍。

## 2｜《奇諾之旅》：每一個國家，都有自己的「理所當然」

### 2.1 官方可核對的形式

時雨澤惠一的《奇諾之旅》以旅行者奇諾與會說話的摩托車漢密斯（Hermes）為中心；主角基本上只在每個國家停留**三天**。官方2017動畫網站明言：各國有自己認為正確的法律與常識，遭遇有時溫柔、有時悲傷、有時可笑、有時刺痛。[動畫官方故事](https://www.kinonotabi-anime.com/story/introduction/)；[Kodansha版本介紹](https://kodansha.us/book/kinos-journey/)。

**版本界線**：輕小說、2003動畫、2017動畫及漫畫改編的選篇和敘事處理不必相同；2017動畫不等於「按照出版順序補完輕小說」，也不拿任一動畫的個別國家視為唯一原著排序。[Crunchyroll 2017製作相關說明](https://www.crunchyroll.com/news/features/2017/10/9/what-stories-will-appear-in-kinos-journey)。

### 2.2 五層敘事引擎

1. **旅行者是有限停留者**。只看一小段，卻會經歷奇怪制度的效果。不是每站都要推翻政權或揭開世界源頭。
2. **國家的制度源於其人民**。法令、文化、偏見、過去事件、集體恐懼或理想都可能塑造「這裡人為何如此生活」。好的異國設計不只是「全城的人有一個笑話」。
3. **表面善意與潛在殘酷可同時成立**。一套最初看來合理的規範，可以對某群人產生荒謬後果；令人不舒服的習俗也可能真的支撐地方社會。不要每次設成「某國集體降智」。
4. **奇諾與漢密斯的互動不是配菜**。日常問答、不同理解、對奇怪事物的反應，讓旅行觀察有溫度和可讀性。故事的角色魅力不只能靠旅途中遇到的怪人。
5. **離開不等於問題已解決**。旅行者可以帶走一段見聞，當地居民則繼續生活、承擔結果；結局不必是一國毀滅或主角說出道德正解。

### 2.3 能移植到巨構長篇的不是「一站一個寓言」

可把每一座具有生活的城市視作多條彼此矛盾的生活經驗：法律與黑市不同、學術和家傳技藝不同、老住戶與新移民不同、孩童對禁忌與長輩不同；即使主角只停留一天，仍能從一件普通委託或餐桌對話看出其差異。

**不要照抄**：每到一個地方就必須遇見「所有人不許說謊／所有人都會說謊」那類單一全域思想實驗、最後三行來一次道德反轉。作者可以使用寓言式地區，但全書若一律同模板，世界會變成反轉景點清單；更長篇的地方社會需能同時容納各種不完全一致的人。

## 3｜《魔女之旅》：旅行不只觀察世界，也是在表演旅行者本人的性格

### 3.1 核對基礎

白石定規原作輕小說，Yen Press 的英文輕小說版本由 Azure 繪圖。官方作品頁顯示，伊蕾娜會遭遇怪誕人物、夢幻事件、神秘都市、生活化人物、旅行同伴與不同情緒的故事；漫畫改編資料也保留「從童年旅行理想到成為女巫，出發見識各地」的核心。[Yen Press輕小說](https://yenpress.com/series/wandering-witch-the-journey-of-elaina)；[Square Enix漫畫官方介紹](https://squareenixmangaandbooks.square-enix-games.com/en-us/series/wandering-witch)。

### 3.2 與《奇諾之旅》同樣旅行，敘事溫度卻可以不同

- **更明顯的旅行者自我**：伊蕾娜本人的愛好、自尊、好奇、判斷、喜好與人際互動可以構成故事的重要趣味；不是只當冷靜攝影機。
- **故事調性更容易突然換色**：漂亮童話式景觀、可笑的人、真誠感情、令人不安的倫理後果可以並存；不代表每個可愛故事都必須轉成血腥反轉。
- **停留方式具有彈性**：短暫觀察、被捲入地方麻煩、與人同行、與熟悉人物重逢，都能讓一站具有不同篇幅和親疏，不必硬套三天計時器。
- **善惡與救助不應機械化**：旅行者可以出手、拒絕、觀察、判斷錯誤，也可以純粹想玩或因私心選擇；其道德選擇要讓讀者感到源於這個人，而非固定「遇到苦難必離開／必救」的規則。

### 3.3 《巨構世界》可學的「差異化旅程」

一段路有時因食物值得記住，有時因某個故作高傲的學徒，有時因一個令人驚訝但無害的小法術，有時因陌生人的死亡，也可能只是某天兩位旅人心情極好而留下印象。**同一對雙主角不必每段旅程都演成調查員**；作品的旅行價值包括他們自身喜歡的東西、原本打算做什麼、以及對平凡快樂的不同反應。

**避免**：將伊蕾娜的語氣、人格、旅行日記直接移植給艾莉維亞；也不要以「魔女遊記」為理由將整個巨構的技術、政治、風土與既有因果替換成零成本奇蹟。

### 3.4 三軸對比表

| 提問 | BLAME! | 奇諾之旅 | 魔女之旅 |
|---|---|---|---|
| 最主要的閱讀推力 | 下一個空間會有什麼、如何活下去 | 下一個文明如何生活、有何不同 | 下一次相遇有什麼奇妙、旅行者如何反應 |
| 場所與人物比重 | 超巨場域常壓過個體 | 地方制度與旅人觀察互相照明 | 地方奇事與旅人性格互相增色 |
| 美感主要來源 | 空間未知、孤獨、斷裂與危險 | 道德多義、反差、出走與回望 | 漂亮、新奇、幽默、個性與偶爾陰影 |
| 適合長篇借鑑 | 尺度、極端環境、未知感 | 文明多樣、自成一體的小篇 | 角色魅力、旅途調性切換、重逢 |
| 不宜複製 | 全書長期寡言／單色 | 每座城都有唯一寓言規則 | 每段都賣萌／必有黑暗反轉 |

# 第二部｜擴展作品群：不只巨構，也不只「好看的世界觀」

## 4｜《少女終末旅行》——溫暖與絕望不是互相沖淡

**事實**：つくみず筆下兩名少女千戶、尤莉駕車穿過文明遺跡、逐步向城市高層前進；Yen Press 最終卷簡介明確提到抵達最高層、觀看文明創造留下的痕跡。[Yen Press](https://yenpress.com/series/girls-last-tour)。

**方法**：沒有重大事件時，吃飯、取暖、鬥嘴、看雪、記錄一點點發現，足以構成充實的畫面。情感後勁來自對「明天還能一起做普通事」的珍惜，不必天天把悲劇說出來。**複合氣質：廢墟 × 可愛 × 食物 × 寂寞 × 哲思**。不要強制《巨構世界》終將無人或文明註定滅亡。

## 5｜《來自深淵》——地理、探索欲與身體代價形成同一系統

**事實**：土筆章人的世界有巨大深淵、探窟家、失落遺物與危險生物；冒險者帶著探索理想向下深入。[Seven Seas](https://sevenseasentertainment.com/series/made-in-abyss/)。

**方法**：風景有吸引力，危險才更殘酷；往深處走時能取得新的經驗與知識，但也需要不同的代價、適應和社會資源。美麗的小型生物不必無害，恐怖異物也不必毫無生態功能。**複合：童話美術 × 生存 × 創傷 × 探索 × 崇高**。不要直接複製固定分層詛咒、白笛階級、不可逆下降，因巨構既有世界層／厚隔界／迴廊本來不同；也不要把對兒童的殘酷當必備創作強度。

## 6｜《蟲師》——非人並不總是邪惡，救助也不保證可逆

**事實**：漆原友紀描寫特殊生物「蟲」與人類共存的異常現象；銀古作為蟲師旅行，協助受到影響者。[Kodansha](https://kodansha.us/series/mushishi/)。

**方法**：先描寫異常如何影響一戶人家、田地、身體感官與地方習慣，再讓人物在不完全理解與有限技術中作選擇。研究者不必是正義英雄，異常也未必是攻擊人類的怪獸。**複合：幽靜 × 民俗 × 怪談 × 微小的人倫痛感**。不能每次設成「某個怪物其實想交朋友」的反轉套路。

## 7｜《異獸魔都》——血腥和友情可以在同一條街上成立

**事實**：林田球把骯髒城市「洞穴」、魔法師人體實驗、失憶的蜥蜴頭人物與跨界衝突結合；VIZ 官方強調殘酷而暴力的世界。[VIZ](https://www.viz.com/dorohedoro)。

**方法**：世界可以非常髒、危險、可怕，人物仍會做飯、打工、相互玩笑、珍惜朋友；喜劇不是暴力世界的錯誤，而是人在其中依然活著。**複合：怪誕 × 血腥 × 烹飪 × 黑色幽默 × 團隊情誼**。不要把「高頻肢解、怪話和噁心視覺」當作角色魅力本身；需要自主目的與關係的真重量。

## 8｜《大黑暗》（Dai Dark）——令人毛骨悚然的世界也可以很好笑

**事實**：同為林田球作品，七海出版社描述其結合太空、死靈法術、黑色幽默與角色對自己骨頭遭覬覦的求生。[Seven Seas](https://sevenseasentertainment.com/series/dai-dark/)。

**方法**：把可怖設定當日常生存條件使用，與角色的普通願望產生反差；把「怪」從怪物造型擴展到食物、修理方式、生活習俗、職業與社交。**複合：宇宙陰冷 × 血肉怪奇 × 少年式胡鬧**。不能直接移入其骨頭願望機制。

## 9｜《寶石之國》——美不是保護，身體變化不是單純升級

**事實**：市川春子的遠未來地球由寶石生命與月人衝突構成，主角磷葉石脆弱、被指派編纂自然史，與辰砂的孤立困境建立關係。[Kodansha](https://kodansha.us/series/land-of-the-lustrous/)。

**方法**：色澤、材質、脆弱性、身體缺失與人格記憶的連續性可以彼此影響；「力量成長」未必是線性爽感，也可能讓人離過去更遠。**複合：剔透美感 × 孤獨 × 慢變 × 殘酷**。不要把原作的身體部件與人格機制轉移到艾莉維亞白髮質變。

## 10｜《風之谷》漫畫——美麗的生態與複雜人類文明不是二選一

**事實**：宮崎駿漫畫以戰爭後的毒性腐海、巨大昆蟲、周邊小型王國及人類生存為核心。[VIZ官方](https://www.viz.com/nausicaa-of-the-valley-of-the-wind)。

**方法**：不只畫出毒霧森林，還要問風向、糧食、運輸、村落、軍隊、信仰與其社會後果。**複合：壯麗自然 × 生態威脅 × 文明政治 × 憐憫**。漫畫和吉卜力電影並非完全相同的篇幅與情節；若做完整人物政治研究，應優先參照漫畫，不以電影代替。

## 11｜《Piranesi》——無盡房間可以是家，而不只是牢籠

**事實**：Susanna Clarke 筆下屋內有成千上萬雕像、潮汐灌入階梯、雲層穿過高樓層；主角記錄潮水、探索房間，也對這個地方有親近與敬畏。[Bloomsbury](https://www.bloomsbury.com/uk/piranesi-9781526634108/)。

**方法**：同一建築對外人可能恐怖，對居民可以是熟悉的家。掌握潮汐與季節的住民，不一定知道建築最後起源；這正好能修正「只有揭開創造者才能理解地方」的誤區。**複合：空曠 × 聖潔 × 潮汐 × 奇異的家常感**。不能照搬其最後真相與敘事不可靠性。

## 12｜《House of Leaves》（葉之屋）——「尺度不可能」能直接改變閱讀形式

**事實**：Mark Z. Danielewski 小說中的房子內部比外部大，出現會改變的黑暗走廊；記錄、影像、手稿與註解形成多層敘事，出版社閱讀指南特別強調它作為「迷宮形式小說」的特質。[Penguin Random House閱讀指南](https://www.penguinrandomhouse.com/books/36526/house-of-leaves-by-mark-z-danielewski/9780375703768/readers-guide/)。

**方法**：空間恐懼不只在大小，而在測量的可靠性、人物對家的信任與知識媒介本身被擾亂。**複合：家庭 × 無盡黑暗 × 文字排版 × 心理恐怖**。可學多重記錄視角與觀測矛盾，但不把《巨構世界》全部道路寫成任意變形的陷阱，也不必複製其特定排版。

## 13｜《Scavengers Reign》——美到不像威脅的生態，可能極度不近人情

**事實**：WBD官方將它介紹為貨船倖存者在奇異星球求生；該星球美麗卻不寬容，生命系統不以人類需求為中心。[WBD](https://press.wbd.com/na/property/scavengers-reign)。

**方法**：異常植物、寄生、共生、傳粉、捕食、變態與物質交換各有功能，不必設成每只怪物都想殺主角。角色可能靠觀察和小心試驗活過一晚，也可能因過度自信被吞沒。**複合：絢麗 × 令人不舒服 × 生命驚奇 × 殘忍**。不能把一切生物連成終極控制者或一看就有科技原理。

## 14｜《Rain World》——對捕食者而言，主角可能只是今天的晚餐

**事實**：Videocult／發行方官方描述蛞蝓貓在古代文明廢墟獵食、躲避其他獵物與暴雨；生態具有自主掠食和生存運作。[Rain World官網](https://www.rainworldgame.com/)；[發行商](https://www.akuparagames.com/game/rain-world/)。

**方法**：生態本身不必知道主角名字，其他物種彼此有關係；一次偶遇的刺激可能來自「你碰巧打斷了一隻動物吃飯」，而不是那隻動物是Boss。**複合：可愛 × 食物鏈 × 陌生世界 × 無助 × 突然求生**。小說不能把遊戲的迴圈重生與房間系統硬移到既有諾亞復歸。

## 15｜《SIGNALIS》——壓抑場地最終可以承載極私人感情

**事實**：rose-engine作品背景涉及極權殖民文明、人形仿生人、毀損設施、失憶／記憶與心理恐怖；PlayStation 台灣官方頁標明其 brutalist nightmare 與陌生設施深處的探索。[PlayStation台灣](https://www.playstation.com/en-tw/games/signalis/)。

**方法**：身體受限、物資稀缺、音樂與重複空間可讓小物件、小承諾變得異常珍貴。**複合：冷硬科技 × 宇宙恐怖 × 私人眷戀 × 悲劇**。不可把人物愛情只當最後一秒的悲傷反轉，也不要每個異常空間都變成主角記憶隱喻。

## 16｜《NieR:Automata》——廢墟能承載音樂、悲劇、荒謬與戰鬥的不同節奏

**事實**：Square Enix與PlatinumGames設定在機械生命與仿生人交戰的未來地球；作品官方強調角色、戰鬥與情緒性敘事。[Square Enix](https://www.square-enix-games.com/en_GB/games/nier-automata)；[PlatinumGames](https://www.platinumgames.com/works/nier-automata)。

**方法**：景觀、音樂、動作節奏、非人角色與人物關係並行，不必讓「末日」只有一種悲情。原遊戲的多周目／操作視角也是敘事手段，但小說需要另找等價的資訊排列方法；**不直接照抄周目結局與遊戲UI**。

## 17｜《APOSIMZ》（人形之國）——巨構也能是冰冷的巨大人工星球

**事實**：弐瓶勉以巨大冰凍人工星球及軍事勢力為場景，Kodansha 英文出版 9 卷完結。[Kodansha](https://kodansha.us/series/aposimz/)。

**方法**：大型科技人造環境不必只是一座室內迷宮；冰原、天空、地表聚落、國家、病變與旅程可共同形成巨型人造世界。**複合：冰白空曠 × 工業殘骸 × 民族政治 × 戰鬥**。不讓《巨構世界》因此被固定為一顆完整人工星球。

## 18｜《Tower Dungeon》（塔之迷宮）——同一位作者的另一種「巨大」

**事實**：弐瓶勉轉向黑暗奇幻，巨大塔、死靈術師、騎士隊與原本是農夫的青年逐步向危險樓層攀登；日文講談社截至 2026-09 已推出第 7 卷，英語區官方頁依出版進度另列。[日文講談社](https://www.kodansha.co.jp/titles/1000045484)；[Kodansha英文](https://kodansha.us/series/tower-dungeon/)。

**方法**：高危探索有**小隊內差、受傷、角色分工、補給、樓層限制與互信**，不只是單人孤旅；同樣巨大的建築，奇幻冒險與科幻孤獨可以用完全不同的情感節奏。**複合：迷宮 × 古怪怪物 × 組織責任 × 短兵相接**。不要把塔樓等同於《巨構世界》的所有「世界層」。

# 第三部｜更少見的巨構與怪異遊戲：可拆成純視覺／移動／恐怖技術

## 19｜《Lorn's Lure》：行走與攀爬使空間難度具體

官方描述仿生人追逐視覺異常，被帶入不知原委的巨型結構；玩家可用工具攀爬很多原本並非設計為關卡的表面。[開發商Rubeki Steam](https://store.steampowered.com/app/1417930/Lorns_Lure/)；[Feardemic](https://www.feardemic-games.com/lorns-lure)。

**轉譯**：長距上行的好看，不必是道具解鎖。角色如何認出可立足表面、保護工具、防止墜落、找通風點、讓同伴跟上；到頂後的一口氣、一次回望即可產生回報。**複合：巨大 × 靜默 × 攀爬 × 體力 × 恐懼**。

## 20｜《BABBDI》：荒誕城市可以沒有戰鬥，也令人難忘

2022年免費短篇探索遊戲，官方 Steam 介紹為被遺忘的巨城外環、奇怪居民與各式移動道具；**沒有戰鬥**。[Steam](https://store.steampowered.com/app/2240530/BABBDI/)。

**轉譯**：陰沉混凝土城市依然能有滑稽住民、怪傢伙與探索樂趣。沒有敵人，不表示沒有趣味；地形、音色、語言、移動姿勢和道具本身就會創造「奇怪又喜歡」的感受。**複合：殘敗 × 搞笑 × 怪異 × 逃離**。

## 21｜《NaissanceE》：建築本身可以接近抽象藝術

2014年 Limasse Five 的第一人稱探索作品，開發方與公開平台將其定位為神秘、龐大、近乎原始的陌生結構之探索與氣氛體驗。[開發者官網](https://www.naissancee.com/)；[SteamDB資料](https://steamdb.info/app/265690/info/)。

**轉譯**：有些地方不需要立即回答「住多少人、哪個勢力管」；它可能真正是一段無人、無明確日常的巨構遺址。光、陰影、材質、不同方向的通路就能構成純粹地景體驗。**複合：抽象 × 空靈 × 巨大 × 焦慮**。但不可無限制用晦澀掩蓋所有交通因果。

## 22｜《ECHO》：建築不只是場景，而是記錄使用者行為的對手

2017年 ULTRA ULTRA 遊戲：一座古老宮殿觀察玩家行為，複製體逐步學會玩家使用的動作，在特定重啟週期更新。[Steam官方遊戲頁](https://store.steampowered.com/app/551770/ECHO/)。

**轉譯**：危險系統可因人物自己的習慣而改變選擇，迫使其不只比火力、而是換處理方式。**複合：華麗 × 壓迫 × 反身性 × 智力壓力**。不應照抄逐行「敵人AI學會衝刺／射擊」UI，或把所有古代設施擬人化成同類機關。

## 23｜2024–2026後出同系小眾：Rubeki 的《MEGANAUT》與《The Hollowing》

Rubeki 的公開開發紀錄說明《MEGANAUT》是與《Lorn's Lure》共用宇宙的另個項目（2025年公開Demo）；其 Steam 開發商頁在2026年列出《The Hollowing》試玩版，描述在**巨構通訊塔之間飛行維修**的敘事恐怖遊戲。[Rubeki開發誌](https://rubeki.itch.io/lorns-lure/devlog)；[Steam開發者總頁](https://store.steampowered.com/developer/rubeki)。

**有趣的差別**：同一類巨構，不只可被「攀爬探索」，也可被「飛行通勤、維修塔站、完成普通工作」經驗。這為巨構小說提供另一個角度：危險不一定是追求傳說模組，也可能是一份需要跨越無邊結構的普通職業工作。**目前僅依公開開發／商店資料，不聲稱已通關尚未推出完整版的作品。**

## 24｜《The City & The City》與《The Book of the New Sun》：兩條偏文學的異質路徑

- China Miéville《The City & The City》將警探小說與城市邊界的感知／社會秩序結合，值得研究「同處一地的人如何透過訓練、制度與禁忌忽略彼此」，不必以奇幻傳送門解決所有邊界。[出版資料](https://books.google.com/books?hl=zh-TW&id=WqnT0AEACAAJ)。
- Gene Wolfe《The Book of the New Sun》從受放逐的行刑者 Severian 展開遙遠未來的科學奇幻；值得研究技術、神話、職業詞彙、敘事者理解與古代真相之間的落差。[Macmillan作品系列](https://us.macmillan.com/series/thebookofthenewsun/1000)。

**使用方式**：這兩部作品偏高密度文學結構研究，不應只看作品簡介就宣稱已拆透敘事不可靠性。日後若取得正文與可靠評論，可另開逐章或指定段落的實證精讀。

# 第四部｜「情緒不是單選題」：可重疊的素材矩陣

以下是**研究性質的情緒／敘事組合**，不是「一城必配一組」、不是既定地理，也不是下一章的強制劇情。每一格都只描述能產生的**機制**和**何以有效**。

| 交疊組合 | 真正的戲劇力來自哪裡 | 常見失敗模式 |
|---|---|---|
| **空曠＋溫暖** | 大到失衡的結構裡，兩個人在煮湯、取暖或說小事；有人際尺度對比 | 把溫暖當「無論何時都要煽情」 |
| **美麗＋殘酷** | 美景與生存風險屬同一個自然／社會機制，轉瞬可能奪命 | 為殘酷而突然讓花叢吃人 |
| **血腥＋幽默** | 角色習慣了凶險工作，仍有職業尊嚴、口味、朋友和笑話 | 用笑話否認死傷的情緒後果 |
| **怪異＋平凡** | 居民以特殊身體、特異材料完成買菜、修理、做飯等日常 | 全部角色僅是一張異種怪物圖鑑 |
| **壓抑＋漂亮** | 優雅對稱的巨大建築與限制自由的制度／尺度同時成立 | 只寫漂亮拱頂，制度無具體作用 |
| **可愛＋恐怖** | 小生物既有令人親近的外貌，也有不因人類感情改變的食性 | 強制「可愛者一定隱藏黑暗真身」 |
| **刺激＋空曠** | 遠景原本安靜，突發墜落、失足、風壓、斷纜改變行動 | 每個安靜場景都要爆炸 |
| **浪漫＋絕望** | 兩人仍有當下互相選擇的權利，但無法保證明天 | 把所有感情寫成注定死亡倒數 |
| **宏大＋滑稽** | 巨型工程與一場很認真的小爭吵同時成立，尺度差製造趣味 | 人物全體降智以襯托笑點 |
| **神聖＋工業** | 信仰、儀式、輪班、技師教育、事故責任共處於同一設施 | 把宗教者都寫成瘋子／工匠都成無神論者 |
| **孤獨＋生態熱鬧** | 沒有人類，但大量生物仍互相捕食、遷徙與繁殖 | 全部非人動物都關心主角任務 |
| **熟悉＋異常** | 一個角色在陌生人眼裡不可理解的地方，仍能說出家常細節 | 一旦變熟便把怪異消除 |
| **殘酷＋慈悲** | 角色無力挽回一切，只能在局部做出具體關懷 | 每次慈悲都獲得奇蹟獎勵 |
| **熱鬧＋孤寂** | 市集繁榮中有某人與群體格格不入、但旁人仍自在生活 | 強迫整座城陪他一起悲傷 |
| **怪誕＋政治** | 異常職業、習俗、身體和制度長期磨合形成真實利益網 | 怪異設定一律都屬陰謀組織 |
| **荒蕪＋希望** | 人並非不知環境嚴峻，但仍願意維修、種植、出發與相愛 | 每個「希望」都必須先下大災厄 |

### 非正史原創微片段：只用來測試情緒組合，不建立新地點

**A｜空曠 × 溫暖 × 怪異。** 一條兩側看不到盡頭的舊懸廊只剩一道忽明忽暗的橙燈，遠方有巨大鋼樑傳來沉緩振動。從下方扳道洞口冒出來的老婦抱著熱鍋，問旅客要不要吃剩下的南瓜。她不知那根鋼樑造於何年，也不在乎；她只想在夜班工人回來前把湯盛完。**研究用途**：大世界不必靠旁白故意讓人渺小，生活本身足以製造反差。

**B｜漂亮 × 刺激 × 殘酷。** 海藍色的透明菌幕在一處巨大暖風空腔慢慢升降，許多旅人為了拍下最亮的片刻站上舊欄杆。風從看不見的下方反灌，眨眼間吹飛一只空杯；旁邊的監護工直接拉住小孩，沒人再去看光。**研究用途**：美景的物理環境與風險要同源，劇烈事故可以發生也可以被避免，不能為讓讀者刺激而強制犧牲角色。

**C｜荒謬 × 巨大 × 社會。** 某座巨型升降裝置因為低層登記室少蓋一個章而暫停送貨，工務員和商人吵得面紅耳赤；路過的孩子卻在比較哪個齒輪開合時的聲音像打嗝。**研究用途**：制度有可見代價，人們的興趣又不必始終服從制度；笑點來自不同優先級，而非降智。

**D｜怪異 × 療癒 × 憂傷。** 一名在孤立觀測站養小型發光生物的維護員，知道牠們每年同一天會朝一條已封死的走廊聚攏。他不認為那是預言，也未必想解釋；把牠們逐隻抱回暖箱已是工作。**研究用途**：怪異可以不立刻變成解謎鉤子。如果作者日後決定封死走廊另有重要秘密，要在**真正埋設可回收伏筆前向作者本人公開**，不能事後悄悄追認。

# 第五部｜從畫面／遊戲／小說「真正轉譯」成長篇文字

## 25｜漫畫「空白」怎麼變成文字節奏？

《BLAME!》的無字遠景不是純空白。小說若想取得類似效果，每次應選一至三個能改變讀者方向感的事實：**腳下有沒有承載／遠處聲音有多慢到達／冷熱氣流在何處轉折／人要怎麼繞過某條結構／上方看似天光其實是什麼可觀察現象**。不要每次都硬塞超大數字；極少數精準大數字可帶來驚異，但要和人物行動尺度相連。

## 26｜遊戲「探索」怎麼變成沒有任務列表的故事？

《Lorn's Lure》的攀爬手感、《Rain World》的自主生態、《ECHO》的行為回饋，都須轉成有意圖的**動作—阻礙—因果—代價—新的路徑選擇**。在遊戲中玩家親自試錯，小說不能重複記錄十次相同攀爬失敗；應寫出值得留下的那次錯誤、學習或人的反應。其他角色也不是等著被解鎖的NPC。

## 27｜動畫與音樂的情緒怎麼變成不空泛的描寫？

不要直接說「此時響起淒美配樂」。可以透過人物說話變慢、周圍本來一直存在的機械聲突然停掉、遠處集市還在發出笑聲、某人把尚未喝完的水放下；或讓讀者在急促的短句與悠長的地理句之間感到節奏差。**把聲音的戲劇功能轉化成文字中的可聽／可見變化**，而非照抄配樂評論。

## 28｜「血腥、刺激、殘酷」的三個獨立旋鈕

- **血腥**：傷害的視覺與肉體細節。可高可低，與作品倫理深度沒有直接等號。
- **刺激**：當下失敗風險、選擇時間、認知缺口與對抗強度。可以不血腥（如狹道追逐、臨界吊臂），也可以極血腥。
- **殘酷**：人物或社會承受何種不可挽回的損失；哪怕完全不寫出血，也可很殘酷。

三者重疊能產生衝擊，但不必每次「全開」。有時人物死於單純疏忽比十頁酷刑更恐怖；有時幸運地逃生後的笑聲才是讀者會記住的畫面。

## 29｜「漂亮、空曠、壓抑」也不是同一維度

- **漂亮**：光色、構圖、材質、形態、節律、精巧或壯麗；無論明亮或黑暗。
- **空曠**：可感空間大／人稀少／回聲遠／可接觸物少。不自動等於不存在文明。
- **壓抑**：選擇受限、長期負擔、被凝視、失去出口、社會規則無法改變，或人體尺度不再有安全感；擁擠熱鬧的城市也可更壓抑。

因此「壓抑巨構」不需永遠畫成黑色；通體潔白、清澈明亮但無法抵達出口的庭院同樣可以可怖。

## 30｜在研究情緒時不讓世界觀降級

本專案第115確立的**世界層是完整宏觀分域**；不能以《BLAME!》樓板或《Tower Dungeon》樓層直接取代。旅途、世界層、層間隔界、交通可達性和特異空間接合需分開。舊圖／新圖的W/K編號、已選第051首次相遇、諾亞復歸、艾莉維亞非同型復歸、Celeste 最高管理者身份等現有確認不因新研究而改變。

同時也不應為了證明世界很大，每次出城就「大到幾億公里」、每次見人就「神秘最高權限」、每次遇危險就「前文明究極武器」。**巨大之中需要有正常尺寸、正常人物、生活記憶與區域後果，才有真正差異。**

## 32｜下一輪若要做更精準的「完整」研究，應如何取得證據

1. **BLAME! 完整精讀（下一個高優先材料任務）**：依漫畫實際大本1–6卷逐卷建立「環境頁／人類共同體／異質勢力／交戰／日常／沉默／轉場／資訊新知」索引；標明出現在哪一卷、原來是否有對白、空間切換是否解釋、前後人物關係變化及反例。不因只看過動畫電影或分鏡精選而冒充六卷逐頁驗收。再讀《NOiSE》，另與2017電影做**改編差異**表。
2. **奇諾之旅**：抽取若干氣質顯著不同的國度篇，逐篇核「初見印象→制度如何落入生活→誰受益／受害→奇諾是否介入及原因→離場以後留下什麼」，同時收「沒有道德反轉」的反例，避免錯誤認為每國都是寓言惡搞。
3. **魔女之旅**：按小篇不同調性抽樣，不只看最獵奇或最催淚的集數；記錄伊蕾娜想要做什麼、哪次決策因其人格才合理、重逢如何帶回前情、溫暖與陰暗怎樣分流。
4. **中型作品專題**：把《Piranesi》的家園感、《蟲師》的非人尺度、《異獸魔都》的血腥友情、《Rain World》的無主角生態各做「事實／敘事技術／不適用情境／可反轉的反例」詳細卡。避免只列四個形容詞。
5. **最後才做原創事件設計**：作者若選定一種或數種要導入的情緒，才按第031預先建立必要事件真相、人物因果與收束；若只是普通日常，毋須硬創宇宙級秘密。

## 33｜明確禁止的偷懶綜合

- 不因研究《BLAME!》就要求所有聚落無人、所有街道只剩鋼柱。
- 不因研究《奇諾之旅》就把每座城變成只有一條奇怪法律的社會實驗。

| [Creatures of Sonaria](https://sonar.games/) | **A** 開發商 Sonar Studios 官方說明遊戲重點是成為奇異生物、成長、戰鬥、在Sonaria生存。**B** 生存、食物、飲水、群體／領地與交易的細節需依最新遊戲／來源核對。 | 在非人生態中**人類不是中心，主角也不一定是最重要的一個生物**；不同生物在一片土地上延續自己的生存、繁殖、吃飯、遷徙、互動。 | 角色可以有高度智慧／自己的社會，不能把所有異種一概降為「原始野生怪物」；亦不能抄生物外型、名稱或資源系統。 |
| [Block Tales](https://www.roblox.com/games/16483433878/Block-Tales) | **A** 官方稱多人回合制RPG，受Paper Mario 64與EarthBound啟發，採**章節更新**。 | 像素／童話風外表與嚴肅故事能並行；團隊演出、章節節奏、戰鬥驚喜、幽默對話不需要實際戰鬥規模大才能讓人想跟角色走下去。 | 目前研究僅建立「章節與視覺調性」候選，不聲稱已讀完全章、也不抄角色或任一Boss。 |

## 二｜關於 Deepwoken：從遊戲難度轉譯成「旅途不斷受人與地方改寫」

原作可直接核對的是：出身／構築、永久角色損失、多樣地點與遭遇、逐漸被解明的世界知識；NPC的具體對話門檻主要來自社群記錄，不代表所有NPC都有此規則。

真正讓小說有趣的**不是**「角色每過一城就獲得新技能」，而是：
1. 同樣一間工坊，對普通客人、曾救過某位店員的人、欠款者與敵對僱主的請託，**自然得到不同回應**。未回答可能只是時間不對或不熟，而非暗藏陰謀。
2. 嚴苛風險讓**準備、情報與撤退**成為有重量的選擇；主角可以遭到突襲、丟掉貨物、因一次看似很小的衝突損失兩日行程，也可能在沒有戰鬥的地方得到珍貴幫助。
3. 主角不是唯一的冒險者；不同專長、風格與謠言的旅人可能先前已去過某條路、並在主角離開後繼續活動。
4. 城鎮的繁榮與危險荒野不是矛盾：商旅之所以願意冒險，是因為實在有人需要運貨、上學、做研究、遷居或探望家人。
5. 深入後的恐懼若總是只靠血量膨脹，讀者會麻木。更有效的常常是**補給不能快速回復、路線已不適用、原以為安全的同行者受傷或資訊不全**。

**轉譯風險**：諾亞的復歸系統不同於Deepwoken的永久刪角，不能藉遊戲參考破壞已確立規則；艾莉維亞也沒有同型復歸。高風險在此可能來自她、他人、物權、時間不可倒帶、受損結構與下一次選擇，而不是憑空降低主角固有實力。

## 三｜關於 Archived：組織是社會，不是換皮技能菜單

**三個真正的讀者體驗要點**：
- **歸屬產生話語權與限制**：一名學術收集者、自由佣兵、地區執法者與獨立工匠對同一件高價部件的處置，可能都有自己合法或非法的權利聲索。
- **裝備不是「角色拾到＝所有權自動成立」**：物資可能來自交易、雇主借用、救災分配、代工、行會共有、私人物品或從屬於特別技術契約。獲得、使用、帶走和出售是**不同權利**。
- **權力與實力分開**：組織負責人未必是最強，最強戰鬥者未必能簽合約、調人或發出跨區通行證。私交也不能自動消除正式責任。

這些方法應用至第4–6章的**現有**白堊院、贖罪庭、承包交易、赫連・鴉與塞拉修女的關係即可研究，**不用新創第二套相同功能的機構**；也不可直接把月亮計畫原作機構寫成此世界的正式翼／協會。

## 四｜關於 Mountfall：戰鬥不是必須永遠升到巨獸級別

可拆成五個互相獨立的對抗層：
1. **距離與進入**：武器的最佳工作距離、道路寬度、可用掩體、別人能否插入。
2. **試探與預判**：攻擊會暴露哪個部位或習慣？角色能否識別？為何識別？
3. **反制與失衡**：格擋要承受力道、角度和持續時間；無論成功或失敗都應改變下一次行動。
4. **人與同伴**：隊友可切入，但不能每個人都知道所有人的動作；合作需要熟悉與即時情報。
5. **結果**：武器、傷害、退路、時間、地面結構、敵人的意志和其他旁觀者都受到真實結果約束。

對第5章鏡殼擬態蟬戰尤其有用：兩位主角與赫連的定位已不同，巨蟬殘影可以使**看、鎖、判斷、攻擊的次序**成為驚險來源；不能只把各人招式堆成漂亮特效。而第6章的水母戰要重視環境誘敵與路線，不必再添加一位更強的敵人維持刺激。

## 五｜新補 Roblox 研究：在意想不到的地方找情緒與世界生命力

### Regretevator：不要每件怪事都升成陰謀

**證據**：官方說明它是隨機電梯、謎題、休閒和秘密；對玩家而言，一次能遇上安靜社交房間，一次是混亂的特殊遭遇。借其**不同情緒快速換色**，小說則保留客觀可理解的地理與交通：一個地方可好玩，不必留下未解重大伏筆。

**非正史小說微實驗**：一段高聳寂靜的通勤梯裡，有兩名陌生人各自抱著一盆不會開花的鐵葉。兩人不是在準備儀式，只是在等園藝競賽評審的列車。旅人很想問為什麼葉子是鐵的；還未開口，兩位參賽者卻先為花盆擺放角度吵成一團。這樣的荒謬具有自己的日常目的，不需要立刻揭示黑幕。

### Creatures of Sonaria：非人生命的自主生態

**證據**：開發商官方宣傳自己成為生物、成長和生存，細節由玩家wiki補足並要留意變更。可學：
- 同一片空域，飛行小型生物、大型捕食者、可捕食其他物種的智慧生命、定居村落、遷移商隊可以在不同時間使用。
- 一隻捕食者對雙主角毫無私人仇恨。牠只是追逐另一個獵物，主角碰巧站在路上；危險發生後動物也未必追到天涯海角。
- 讀者要能感受自己看到的是**整套生存關係的一瞬間**，不是一張等主角登場才啟動的怪物圖鑑。

**非正史微實驗**：空腔壁上緩慢移動的三列巨大菌脊蟲群看似會吞下懸橋，居民卻擠在橋邊圍觀，因為每次群體換季，都會把高處的礦鹽屑震落。有人只想撿鹽，有人想拍畫面，也有老人抓住孩子說快回家。此地的「漂亮、危險、實際用途、生活」本來同時成立；**此蟲與地點未加入世界設定**。

### Block Tales：童話外觀可以承受真正故事重量

它的章節式遊戲定位可供比較：可笑的角色聲線、明亮的簡化畫面與真正的危機能在同一段敘事裡成立。但不能把「章節更新」誤推成作者只能每章一個Boss；真正的小說篇幅應服從人物、關係、資訊密度與事件容量。

## 七｜六種可重疊但不必同時具備的閱讀回報

1. **「我想到那裡看看」**：地貌與行動可能性強，即使未必有寶物。
2. **「我想認識那個人」**：性格、專長、生活方式與互動可愛，而不只藏秘密。
3. **「這個世界有自己的生活」**：市場、工坊、宗教、音樂、睡覺、旅人、家人、動物、產業。
4. **「事情可能真的失敗」**：力道、時間、失去財物、受傷、賠償、退路與人際代價可信。
5. **「好怪，但我喜歡」**：怪異不一定殘酷，漂亮也不一定安全，幽默可以不為高潮服務。
6. **「我想知道後來怎樣」**：人物關係的進展、事件後果、有限伏筆回收或一個未完成的生活願望，來源不限解謎。

**研究批判**：這六個不是「每章需六項」的清單，而是作者能選用的不同吸引力來源。小說也不必每一章都帶來探索、打架、秘密或反轉。

## 八｜後續可實證的精讀樣本與風險

- **Deepwoken**：找可確認出處的同一NPC在不同聲望、前置人際或不同出身下的完整對話比較；若只找到社群條目，標版本與不確定性。
- **Archived**：選一個工坊／事務所的實際加入、接單、修理和裝備取得路徑，以錄影／官方頁／一致資料交叉核對，區分借用Project Moon的制度本體與遊戲操作化設計。
- **Mountfall 原版／Descent**：分開找原版戰鬥片段與重製版區域危險例子；不能把重製版「地圖九層」當成原版通用結構，操作招式以各版實際影片為準。
- **Regretevator**：至少找兩種調性完全不同的樓層，研究其「偶遇因果」而不是只統計樓層數。
- **Creatures of Sonaria**：找一段自主捕食／被捕食／繁衍／交易影響區域環境的真實遊戲過程，避免以遊戲宣傳簡介冒稱已證實複雜AI。
- **跨媒介長篇**：把《BLAME!》的真正分鏡、《奇諾之旅》的具名篇章、《魔女之旅》的具名篇章同《巨構世界》第3–6章逐場比對，來源未取得時明言**研究路線尚未完成**。
