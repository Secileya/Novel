## 這份新版確實修改了什麼

第01～12章以既有11/08已套補丁順讀版為底，第13章使用 **R1b**（「前夜結案」改為「先前結案」），第14章使用 **R1a**（已修 B1/B2、作者用語）。此外第03章及第11章按最新[統一正文錯誤台帳](../../00_分類導航/設定關聯引擎/正文待修_統一問題台帳.json)的 SHA＋原行比對再套3處新補丁：

1. 第03章：諾亞將「我剛分到的十五張銀券」改說「我剛分到的那份賞金」，不虛構枚/張兌換。
2. 第11章：賀老太太說免收熱水5銅時，實際將5枚銅索幣退還給諾亞。
3. 第11章：付費前諾亞同時放上兩張銀鉚券和一張五銅值零券，避免後面抽走零券卻沒有來源。

**這三處已真正存在於本新版正文，並非只是 README 宣稱已補。** 原始11/08版本維持不動，因此舊問題台帳對原SHA的 OPEN_REVIEW/候選狀態仍有歷史效力，**不等於作者正式核定新版**。
