## 一、先固定已確認的尺度底線

- 巨構文明多樣；有工業、機械、賽博、高階空間技術、生體改造、異質生命、不同成熟社會與跨層生存方式。同樣是某文明的軍人、學者、普通居民，可能持有極不同的身體與技術。
- **原初前文明不是「普通高科技更上一級」**：它遠超使用者所稱十級、處於升維前夕，本身有星團尺度破壞、超光速、黑洞等作為宏觀創作尺度示例，具體每件裝備性能仍需逐件設定。它與普通後來文明之間可能存在很多個巨大的、質量不同的科技斷層；**不可自動讓若干弱者以等級相加擊敗前文明完整武備**。
- **Celeste 與法月懷的世界外權柄不進入一般世界內戰力排序**。一位持有 Celeste 製作小紀念物的路人也不會因此有無上戰力，造物**來源**與實際**功能**分開。
- 諾亞的武器**原件出處**屬前文明自身亦極稀少的最高端特殊品，**現階段可用武備性能**受原裝配套、供能、模組、使用理解等影響；他的**肉身**和**復歸能力**是另外的維度，死亡回來不等於這一擊打不死他。
- 艾莉維亞的個人規則與自有高階科技有獨立實戰價值；最終能達至少與男主完整原裝頂端武裝相稱的高度，但早期有效配置和精確原理尚未完全確認，不能先按本量尺硬填完整數值。
- 技術差距與戰力結果不是完全同義：高階科技有可能形成絕對壓倒；但戰場還依賴是否真的攜帶適合裝備、觀測情報、攻防相性、操作、環境、打擊能否觸及真正本體、後勤和是否自願交戰。

## 二、戰力「帶」：讓讀者感到差距的作者量尺，非全民共用戰鬥職級

此表依**當下實際可動用的完整戰鬥配置**劃分（角色＋此時攜帶武器＋防護＋可合法取得的協同），不是出生身分或個人肌肉等級。**由下往上是大致越來越能支配規模龐大的實戰，但相鄰間隔不固定、非一級壓一級、部分戰力帶可因作戰類型重疊**。

| 作者工作帶 | 讀者應有的實際威脅感 | 不是什麼 |
|---|---|---|
| **日常／普通武備** | 一般居民、普通野獸、基本守衛與能威脅個人生命的常見工具；槍械／刀具本來就能殺人 | 不等於所有普通人都弱到不能傷專業者 |
| **職業／精銳** | 長期實戰或專業遠征者，良好武器防具、戰術與組織，能處理一般人難以對抗的威脅 | 不等於精銳個體能徒手擋子彈 |
| **強化／異質精銳** | 顯著的強化肉體、高度訂製裝備、異常生理或高級作戰系統，在某些環境能壓過整支普通隊伍 | 不保證全身素質同樣強 |
| **超常／高階特化** | 超越常規軍警認知的機動、重破壞或防護；可對較大重要設施或高級戰鬥系統形成嚴重威脅 | 不保證對所有規則／環境危險免疫 |
| **戰略／跨域作戰** | 一人或一套配備足以改變局部勢力平衡、戰爭、巨大工程與跨層高端交鋒；可能操控大尺度場域／特殊空間 | 具「戰略作用」未必單挑比所有下方高，也不保證能安全跨所有世界層 |
| **前文明完整高端武備** | 真正由超十級原文明有效運作的專業高端軍工、特殊作戰體系與同級反制；對一般文明可能是不可比的降尺度威脅 | 並非所有原文明公民都具備此戰力，更不是前文明武器的上限 |
| **前文明自身頂端特殊體系** | **在前文明內部亦罕見且被頂級研究者／作戰者重視的終端成果**，可能與多層存在索引、超高等作用與完整專用能源網協同；仍可能有同級對手與相性限制 | 不是 Celeste／法月懷的同級，也不自動最強；不把此級壓縮成「普通前文明裝備＋1」 |

**關鍵的跨度**：前五帶本來就不是等距；從「戰略」到「前文明完整」有時相距若干文明世代都不能追及，而「完整前文明武備」與「其自身稀有頂級成果」也不只相差一件普通瞄具。可以有大量不同高階技術文明分佈其中，不得把以上七行當成世界只有七種力量的封閉天梯。具有專門條件的低帶武器可能傷害高帶生物，通常不代表低帶全面追上高帶。

**地域的生存威脅**另行記錄：高危世界層與真正隱藏 Path of Pain 可以輕易殺死普通人甚至高階探索者，但不能像怪物一樣賦予固定「戰鬥等級」；橋下未知黑霧帶來的主觀死亡恐懼，也不等於客觀能關閉諾亞復歸。

## 三、身體素質：至少六個獨立欄位，而非「整體身體五級」

每位重要角色按需要記錄：**力量／負載**、**爆發移速／長距離移動**、**反應與精細動作**、**耐久與抗傷**、**耐力／恢復與長時承受**、**感官／空間平衡／生理適性**。可再註記抗毒、耐壓、呼吸或異種生命特性；這些常是跨世界層探索的真正門檻。

為了有分寸，可給**每一項身體屬性獨立標註下列幅度帶（助手候選）**：

| 肉身幅度帶 | 有感的能力差距（因物種／環境與功能有所不同） |
|---|---|
| **生物常態** | 此種族正常的活動、承重與感官範圍；**絕非預設等於地球人類** |
| **長期訓練／極限** | 透過鍛鍊、長期工作或天賦接近該種生物的自然高端；力量、協調與耐力可分別精進 |
| **精密強化** | 生物增幅、一般優秀義體或精密輔助，能使某些素質明確超出其原生上限 |
| **重度強化／異質肉身** | 極顯著、超過普通身體範圍的力量、速度或抗傷；或某種生物原本就具異常高的自然素質 |
| **超常軀體** | 能夠直接與重裝武器或巨型機械相抗的某些實際生理素質；仍可因速度、感知／高級作用而落敗 |
| **高階非典型承載** | 身體本身可能具有分布式結構、非普通局部性或原文明級複合生命工程；**不代表每個原文明居民都有**，且要再看實際構造 |

**標注「來源」及「是否常駐」**：純肉身、生物改造、植入裝置、外骨骼、防護場與短時能力加成都應區分。穿著動力甲能扛重物，不等於脫甲後肌力已升級；持有不死復歸，不代表耐久高；擁有超高反應，也不代表跑速同樣快。

例：某位異種工坊技師可有「力量：重度強化幅度；移速：常態；耐壓：極高；精密操作：高」，不是整體一個數字。某頂尖狙擊者本身肌力普通，但反應、射擊技術和感測設備足以構成高致命性。某個高速角色非常快卻缺防護，被一擊命中仍會死。

## 四、技術／經驗：獨立於肌力與裝備

**作者層技術段位**可選用「入門／熟練／專精／大師／技藝極境」作工作詞，不要求全世界承認相同稱號。每項領域獨立：武器操作、格鬥、體術／攀爬、戰場感知、導航測繪、駕駛、機械維修、急救、隊伍指揮、高維計算／界面控制、規則作用的精確操控、談判情報等。

- 一名工坊宗師可以修造極難設備，未必是強戰鬥者。
- 一名肉體強大但缺乏戰鬥經驗者，可被有正確武器和情報的精銳對抗；**若科技／規則差距太大，技巧也不能無中生有製造可擊穿的防護**。
- 高位技術不等於資訊全知：熟悉某一座巨構城市的戰士，未必懂另一世界層無人遺跡。
- 這能呈現真正的人物成長：練會精準操作、正確選擇撤退時機、取得足以處理新世界層的行動技術，與取得新原裝模組並列，但不是「修煉後所有欄位＋1」。

## 五、武器／裝備／道具分類：先按用途、來源、可用性能，再談價值

### 使用功能類別（可重疊）

| 類別 | 具體可能物品／能力 | 對劇情的意義 |
|---|---|---|
| **近身／遠程殺傷** | 刀劍、槍械、實體彈、能量武器、定向場、特殊作用武裝、生體毒性與反制裝置 | 火力、射程、穿透、精度、接觸條件和殺傷對象不同 |
| **防具／防護** | 軟硬裝甲、重型義體、動力甲、場護盾、環境隔離、防規則干涉 | 防彈與防高維攻擊不是同義；對不同機制有防禦缺口 |
| **機動與跨層** | 鉤鎖、攀行具、飛行器、載具、牽引場、空間接駁設備 | 同一深井，普通人繞路三日，高階移動者可能幾秒越過（前提是知道可達） |
| **感測與情報** | 望遠觀測、材料掃描、導航、特殊目標索引、遠程通訊、紀錄探針 | 高攻擊者打不到「真正本體」時，這類設備比火力更重要 |
| **工程／開路** | 爆破、切割、運輸、起重、修橋、啟閉大型古機關、現場加工 | 巨構探索與路網社會後果，不一定是打怪用 |
| **能源與支援** | 高密度供能、冷卻／熱管理、彈藥補給、修復、計算、照護／醫療、行李儲存 | 決定性能能否持續發揮，改變遠征長度 |
| **特殊／規則／研究** | 空間界面、規則干涉設備、對特殊生態有效物件、未知原理遺物、條件式護符 | 特殊作用可能越過普通裝甲但受適格與反制限制 |
| **非戰鬥日用品** | 防寒服、照明、食物保存、貨幣憑證、語言器、樂器、紀念物 | 與角色生活同等重要，不能因「無攻擊力」就當垃圾 |

### 裝備「性能帶」候選

**民用實用 → 專業制式 → 頂尖訂製 → 高階異質／特殊作用 → 前文明原裝完整系統 → 前文明內部頂端特殊成果**。

這是**功能性能的工作標籤**，不是所有裝備都必須六級。各段中可有大量價差、性能重疊與地域差異。**普通前文明家用杯子不必比某軍用跨層護甲「高戰力」**；但前文明的真正作戰設備可能以遠超低位文明的高科技方式運作。

同一件物品至少從**五個獨立面向**判斷：
1. **來源／技術傳承**：當代工坊、本地頂尖文明、跨域研究、前文明原裝、未知遺跡、Celeste 親手創造等；來源不直接代表攻擊強度。
2. **實際性能／威脅對象**：能傷什麼、護住什麼、跨越什麼，作用對象與限制。
3. **稀有與可取得性**：量產品、昂貴、單一工坊定製、孤品、無法複製／來源失落。
4. **相容與維持成本**：誰能操作、是否需供能、是否接特定網絡、適合什麼環境與外界規則；不給高等前文明設備亂加俗套爛電池衰退。
5. **狀態／控制權**：完整、缺外部模組、被封、在別人手裡、使用者知識不足、真正由 Celeste 曾改變運作條件等。

## 六、遺物（Relics）不是直接等同「頂級神器」

**遺物是來源／年代／罕見特殊性的社會概念，不是統一的戰鬥高級別。**

可以有：
- **古工業與失落生活遺物**：古老機械儀表、醫療器材、民生測量器，有些仍能工作，戰力普通但對考古／維修極珍貴。
- **異質文化或生態遺物**：特定異種文明的有機器具、特殊個人生命材料、紀念物，可能只對某類環境有用。
- **高階科技遺物**：早已失去生產線的先進防護、空間工程、特別能源設備等；可很強，也可能只剩窄用途。
- **原初前文明原裝遺物**：真正完整者即使在無人遺跡中也仍可能有超規格作用，**不是因存放久就鏽成低級機器**；若因殞落損毀，應與 Celeste 的歷史及實際損害相容。
- **來自 Celeste 的特殊贈予／設置造物**：可以有復歸錨點等極高位作用，也可以只是普通情感紀念物；此來源不等於可供一般人複製或公開量產。

**避免憑「古董、神器、遺物、禁器」四個詞互相推高攻擊力**。一個能解開舊機關的低火力鑰匙，可能比一把能轟掉一座橋的武器更有探索價值。反過來，一件戰略級原裝遺物也真的可以讓持有者的戰力躍遷，不能為平衡強行弱化。

## 七、威脅記錄：同一個人不只一條強弱線

對重要角色／大敵／大型裝備可建立簡短作者檔：

- **載體：**力量、速度、反應、耐久、長時承受、感知、生理環境適應。標明裸身、義體、常駐規則與外裝來源。
- **技藝：**精通什麼武器、能否立體移動、是否有觀測／技術使用知識、戰場經驗與操作失誤。
- **現在可用的武備：**殺傷力、穿透／作用類型、射程／機動、場控、防護、對特殊規則的介入、續航、真正目標辨識。
- **情報／條件：**知道敵人哪部分是本體？是否先設陷阱？是否有隊友或設施支援？能否撤退？是否需保護其他人？
- **戰場威脅帶：**上述現用配置在何類戰鬥中大致落在哪裡，並明確寫出**對何種敵人可以壓倒／可能被克制**。

【全為推理示例，非正式人物定案】
- 諾亞：**武器來源**為前文明內部頂端特殊，但**目前可用配套**並不完整；自身裸身力量、速度、抗傷**尚未定案**；復歸是存活長線能力，**不是防彈／保護旅伴**。這使他可能一擊摧毀某地先進設施，卻在未能先手或未識別目標時被殺，再到錨點醒來。真正取得原裝模組能讓其現用戰力**發生巨大且真實的躍升**。
- 艾莉維亞：**規則與獨立高科技**足以形成自主高階戰力，不能只列為諾亞的護盾／開門輔助；她自己的肉體、常備武裝、實際作用範圍與精確核心原理仍待設計；最終上限對標頂端特殊原文明武備不是「每項肌力同高」。
- 某本地異質技師：原生力量、耐熱可以非常強，射擊技術卻一般；若身穿重型工程外骨骼可扛超大負荷，未必能反制遠方高階空間射擊。
- 某前文明平民：出身於最先進文明，但當時**沒有攜帶作戰體系**；不會僅因文明身分就擁有頂尖格鬥戰力。反過來，該文明的專業完整武備真的可能對另一個普通高科技文明的整支重裝部隊有碾壓性差距。

## 八、科技文明梯度不是人物軍階

「蒸汽、柴油、賽博、異質生命、空間工程」既可以是不同**技術線／產業鏈**，也可以是**建築美學和文化**，不能當成各種文明只有單方向科技樹。某地的農業、生體醫療、跨層導航與武器可能差距很大。

作者可按各項產業與技術分別記：材料與製造／能源／資訊計算／交通空間／生物與醫療／軍事武器／防護／文化和資源。例如某文明民用運輸成熟，但沒有真正前文明級作戰技術；另一社會住在鏽鐵社區，卻有從事空間觀測的頂尖研究者。

**原文明「超十級」是宏觀創作尺度用語，不是把本篇七個戰力帶數成第十一階，更非強制以現實卡爾達肖夫等級換算。**各文明可能各有自己的軍階、武器定級、遠征危險星數、工坊品質或遺物目錄，彼此標準甚至無法直接換算。

## 九、世界層與 Path of Pain 的力量印象

地理威脅不採固定「怪物等級」：
- 普通成熟商隊能長期利用的路線，可以依季節／經濟改變。
- 巨大層間斷層本身便使**成功穿越的生還者**相對少；能越過某路的人，不一定能在交戰時擊敗該層每個生命。
- Celeste 特意加重惡意的公開可知高危世界層以及隱藏 Path of Pain，更極度致命，普通人死了不能免費復歸；諾亞能在她特設錨點返回，但無法保證所有未知風險都安全。艾莉維亞的獨立能力不應被劇情硬封印。
- 越過某機關可能看重速度和控制，不需要比某怪物戰力更高；擊敗重裝敵人也不自動有能力穿越黑霧深淵。

## 十、正式建立此量尺前仍須使用者核可的設計細節

1. 宏觀七個「戰力帶」的名稱是否合適、需否進一步增加細層或減少？它們是作者層粗分類，未確認公開職級和固定門檻。
