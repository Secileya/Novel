## 依創作需求使用，而不是套模板

1. **微表情與關係**：用情境「動作／表演」與「情感／關係」及文字搜尋；例如 Q-195 是卷 41 的角色微動作。回看角色當時是否真會這樣說、如何看向對方、是否有旁人誤讀。
2. **荒誕冷幽默**：選 J 類的幽默／比喻標籤；如 J-015 卷1。研究笑點成立的職業與人際背景、前搖與落拍，別複製原著獨有用語。
3. **長線回響與群像**：篩「伏筆／回收」「群像／配角」，可看 Q-347、J-349（卷70）。先盤點《巨構世界》自己已建立的日常意象與人物經歷，絕不移植相同收官橋段。
4. **新章素材選用**：按當前創作需求選擇必要方法，不設固定技法配額，核對既有角色 DNA、世界制度、時間因果、候選正文版本與已確認作者決策，再決定用不用。沒有必要每章塞滿 T 技法。

## 索引與 QA 的界線

- 研究摘要優先取原條目明示分類；早期缺乏分類時改取原研究中的「借用領域／轉換機制」作**輔助摘要**，並在每筆註明來源等級。
- A–F 研究軸、T 技法只記載原條目可識別的明示標籤；未明示並非沒有該技巧。
- 十個「自動輔助情境標籤」用字詞規則整理，存在誤報／漏報；這不是原著定義，也不是 Gemini 的原始標籤。
- 696 條是精選素材，70 卷均有條目，**不代表全 1030 章每個可用句子都已摘錄**。
- 本輪可證明索引、標題編號與分卷完整；**不代表 ChatGPT 已獨立逐句重讀全書**。
