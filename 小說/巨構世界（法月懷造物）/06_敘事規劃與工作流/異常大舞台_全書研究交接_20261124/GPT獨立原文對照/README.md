# GPT獨立原著研究｜現行接手入口與五層工作規程 v1.1
> 作者2026-11-24明確要求：70卷分14輪，每輪五卷；文字、人物、創意、敘事、實作五層均須研究並永久保存；第1、2輪須補研後才進第3輪。研究非正史，Canon0／PREWRITE HOLD不變。

## 接手必讀順序
先讀上層[研究總入口](../README.md)、本文件及最新進度；再讀對應五卷原著TXT、逐卷台帳及五卷整合。原著目錄：小說/方九×莉雅（改寫線）/來源與校對/原著分卷_異常大舞台_1030章70卷/。章範圍以[實際分卷導航](../70卷完整研究文庫/README.md)為準。另按巨構現行作者決策與設定引擎規程核對要使用的原創素材；不得以研究取代正式設定。Gemini讀Drive鏡像，不要求直接讀GitHub；新增鏡像須另驗。

## 每輪必備五層（不是五個簡略標籤）
1. W文字：精讀正常敘述、動作、對話、轉場、環境、戰鬥、情感段落。逐項研究用詞、形容、動詞選擇、語序、長短句、停頓、擬聲、比喻、段落落點、視角與讀者感受；保留原著行錨及短辨識詞，另寫不同情境的原創句組、反例與限制。不能只分析名場面或只說「生動」「有反差」。
2. P人物：表情、目光、姿勢、動作、心理、個人語感、情緒的前後變化；研究人物欲望、主動選擇、失誤、日常習慣、同一人不同情境、關係網與配角自主性。區分旁白明示、人物猜測、研究者解讀；不把反差、吐槽、冷靜、微動作模板化。
3. C創意：採集生物、生態、種族、文明、生活用品、技術、能力玩法、場景奇觀、荒誕、幽默、恐怖、未知與事件構思；拆出組合原理、感官、限制、文化功能及因果。不限當前巨構章節，保留遠期可用素材；不可只換名詞複製原作，不要求每個創意連到主線。
4. N敘事：章內節奏與章間推進、視角切換、因果、訊息差、伏筆/回收、人物關係、冒險、戰鬥、群像、世界自運轉、張弛、收束與時間跳躍。建立跨卷鏈，分開事實與假說，記錄反例與適用邊界；不把後見之明當作者預先構思證明。
5. A實作：每輪保存可直接參考的原創文字小樣、場景/事件/生物或文明的不同構思、角色互動與演出、適用情境、反例、未核設定及相容性。至少有真正寫成的短段落，而非全部只寫概念。創意自由，正式使用前回查設定；不擅自固定諾亞、艾莉維亞、原槍色彩、地區或正式事件，不推進正式章。

## 證據與保存
- 每輪先定位五卷及章標頭，依來源逐段閱讀，記錄原著路徑、blob SHA、行錨與實際檢查範圍；不以全文已取得等同全文已讀。不因已有Gemini報告就只重述。對重要主張核對前後語境、反例、文體與作者/角色情報邊界。
- 五層均需有具體可追溯證據、功能拆解、原創轉化與限制；一組可跨層，但不可用同一句分析冒充五份獨立成果。每輪不設固定素材上限，不因聊天篇幅截斷研究。若未完成五層，標PARTIAL並列明缺口；若僅定向核對，標SOURCE_SPOT_CHECKED，不冒稱全卷精讀。全量逐句QA另計。
- 可用 W/P/C/N/A＋卷/章/行錨為檢索鍵；保留與既有R證據、Q/J及T技法的關聯（能查證才標）。新的候選不自動升正式T或Canon，原報告和原著不覆寫。
- 普通非破壞新增按作者既定規則直接main；讀回確認全文、標題、完整度與SHA後更新本入口。CI、Drive、全庫v2與696條逐筆核對各自記帳。聊天僅摘要，不得作為唯一研究記錄；實際已保存內容與未完成項須如實說明。
- 本研究與正文重構是獨立工作線，不更改正文最新停點。
