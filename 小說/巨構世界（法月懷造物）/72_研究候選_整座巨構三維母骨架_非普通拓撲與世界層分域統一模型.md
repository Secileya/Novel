# 研究候選 72｜整座巨構的三維實體母骨架、非普通拓撲與世界層分域：統一空間模型

> 2026-10-19。**本份研究結構，不先取新地名、不為每個位置配置文明、沒有故事事故，也不是正式世界結構定案。**此前使用者指出「不應是文明甲／隔絕／文明乙的一個個世界盒子」，並補充「文明由環境長出，文明也建自己的巨構，一些在衰落後成為後世地貌」；這兩項以及 B＋C 偏好、真正世界層巨大且一些邊界極難通行，均為優先約束。原始核對：[01 世界尺度](01_世界尺度與空間.md)、[03 交通路網](03_交通路徑與斷層.md)、[25 外殼三方案](25_討論續錄_頂尖武器重構_首次輾壓_女主不可復活_巨構外殼.md)、[26 B＋C 正式偏好](26_討論續錄_BC巨構_開篇雙主角_模組貨幣_空洞騎士路網與痛苦之路.md)、[39 多岔路網](39_討論續錄_開場群落外部路網_高危世界層與隱藏苦痛之路.md)、[40 宏觀大隔絕](40_討論續錄_世界層隔絕_人口空白尺度_苦痛之路終橋.md)、[70 巨構文明演替](70_研究候選_世界層交錯_巨構外形_環境文明巨構演替.md)、[71 多代地貌模擬](71_研究模擬_三類世界層交錯_文明巨構與多代地貌.md)。

## 一｜核心提議：厚骨架網＋巨型空域群＋少量異常接合，而非一顆空心球、幾塊文明板

**候選的整體母型**：巨構首先是一個含大量實際物質的**非均勻、非對稱、具有多重分枝與環路的厚骨架網**。其部分骨架寬到能容納山海與完整生態，部分形成大曲殼、承力脊、孔隙、斜板、巨型封閉艙群；之間既可能相互通氣，也可能用真實厚壁隔絕。整體有大量不承載居民的廣闊空域，不是填滿盒子。

**B 的作用**：實體結構真的佔據空間、支撐重量、損壞、傾斜、能量輸送、承接潮流、被工程師造修、被文明逐世代增築與遺棄；這些構成一切真地理的基本因果。

**C 的作用**：一小部分接點或空域，其**內部有效距離、容積或接合關係**不能完全由單張普通三維外觀圖推定。例如某殼外側有限而內側真空域極大、兩處普通圖上不貼合的邊界以特殊界面連在一起，或外部投影近而內部可達路途極長。**這是空間模型候選，不自動規定 C 等於穿越高維、四維空間法術或無限自由傳送。**

**禁止混淆**：外殼 ≠ 每片天空；可見巨大空腔 ≠ 新世界層；同一主承力骨 ≠ 一條可行走的跨層通道；跨城 ≠ 跨世界層；能看見對方 ≠ 兩地相鄰可走；技術先進程度 ≠ 層次高度。

## 二｜五份需要同時存在的「世界底圖」

| 底圖 | 記錄的客觀對象 | 如果缺了它，故事會出錯 |
|---|---|---|
| **S：實體物質骨架** | 主脊、曲殼、內壁、梁、孔隙、巨橋、自然岩體、後世工程與破碎面；真空間中的幾何形態與承載關係 | 巨大設施只剩無因果的背景貼圖，一射就倒或永遠倒不了 |
| **V：空域與環境** | 每個實際可存在的氣候／水域／光照／壓力／重力／熱／生態區、彼此連通或隔絕的表面 | 一個巨腔隨意有海洋藍天，卻沒有任何維持條件 |
| **J：接合、拓撲與度量** | 普通三維接壤、局部非普通邊界縫合、拉長的有效距離、有效內部容積、接合方向以及通過時物理如何轉換 | 看起來遠近與真正路徑任意改寫，靠「高維」一句無限作弊 |
| **T：實際移動／交通網** | 按足行、船、列車、機動飛行、特殊空間技術、體型／適性各自建立可走邊和旅時、能源、回程條件 | 忽略誰能到、要花多久；所有勢力因劇情需要瞬移 |
| **H：多代工程地貌史** | 哪些是原始承力件、誰建造次級工程、何時斷裂、沉積、倒落、被自然生態與後代社會覆蓋或維護 | 每座山、橋、湖都被誤當創世原件，文明沒有真實建造和年代積累 |

**作畫順序**可以先 S／V 再 J，之後按不同人物能力生成 T，最後用 H 反向改寫 S／V／T 的不同年代版本。這五份是作者層分析法，不是小說世界內居民共同使用的五種官方地圖。

## 三｜研究角度：物體形狀、空間拓撲、實際通路是三種不同關係

- **物理貼近**：A、B 兩面外觀相距一小段，但有完整抗壓厚殼隔開。外側一個觀景窗能看見彼岸，不表示能從附近鑿出通道；真正的旅行路也許在非常遠的接合節點。
- **結構連續**：同一根巨型主骨架穿過龐大空域 A、B，但其中是不可呼吸的實心承載材料、閉鎖內部腔體或工程危險段。沿著鋼梁外面攀爬不等於普通居民真能從 A 走進 B。
- **非普通接合**：兩個在普通三維外觀投影中不相接的真空域，只有在兩個特定介面建立穩定對接；穿過的是**一條物理空間上的可達路線**，而非點擊世界地圖自由瞬移。即使有接口也可能被設壓門、潮差、技術、建制或危險隔開。
- **有效空間展容**：某個封閉殼內部真實可生活的空間極大，當地日常測量可一致，外觀容積卻不足以用普通直覺容納；這是局部內在幾何／度量效應。**展容和非普通縫合是兩種不同機制，任何一種都不預設所有地方必備。**
- **視覺相鄰的不同原因**：也可能只是超大尺度曲殼上從窗孔看見遠方；這時完全不用 C，普通實體幾何就足夠。**能用 B 的具體實體構造說明，就不借 C 遮掩。**

**外部數學研究只提供建模類比**：拓撲學中的「沿邊界黏合／商空間」示範了在概念上可以先定義數塊空間，再決定其邊界如何識別；但不意味本小說中有物理通道就一定遵守某個教科書的流形構造，或某個邊界必須能任意雙向通行。真正旅行還得另外有 T 的運輸條件。參考 Stanford 數學交流：https://web.stanford.edu/~dkim04/blog/gluing-manifolds/ 與多倫多大學拓撲教材：https://www.math.toronto.edu/laithy/3272023/327ps3.pdf 。

## 四｜「世界層」更嚴格的工作判準：宏觀分域＋難以消除的界線，不是樓面

**候選定義**：在巨大尺度下，一片有一定內部結構與空域聯繫的宏觀分域，其內有**大量不同方式可以彼此探索、居住、貿易或從許多方向靠近**的次區域；通往另一宏觀分域的跨接則顯著集中於少數特殊地帶，或受到高風險、工程維護與特殊拓撲制約，形成真正可辨認的世界層隔絕。

**不能僅靠交通圖定義**：普通道路因戰爭或停工斷掉不自動產生新世界層；某少數高端交通幹線運作多年也不令兩個世界層失去宏觀結構差異。因此判斷需同時看 S 的分域骨架、V 的空域、J 的接合、T 的通行困難及長期歷史，不是任選一個數字或單一標誌。

**對不同通行技術可以有不同的 T**：普通旅團可能幾乎無法跨層，一條先進工程幹線可能正常運作，某位高等存在可能自由穿越特定空域。但這些例外需要具體技術與來源，不得無端縮短巨構尺度。真正大斷層的局部情況可以很不一樣，仍遵守第 03／40 的使用者原定。

**分類不強迫全球共識**：不同文明或測繪學派可把某兩片宏觀分域算作一個複合層，或分成兩個；這是**地圖分類的差異**，不意味世界客觀空間自相矛盾。作者可為重大分域先確立真實接合，角色卻不知道全貌。

## 六｜巨構外部形狀與內部並非逐層對應：可選的合成母型

**主模型優先候選（仍未選定）**：外部如果能完整看見，大致是一張非對稱的巨型**厚脊與環路網**，若干方向長出不同厚薄的曲殼、巨大封閉或半開放容器群、貫通空腔與有環的支承體；其中**局部**出現非普通空間展容／縫口。

- 外側看到的細頸部分，內部可能有極長真物流通道，也可能塞滿無法通行的實體材料；**細頸不直接等於跨層大門**。
- 某一片厚殼背後可能支撐完整的海盆與多年氣候系統，另一片薄殼背後有極其先進的可維護科研生活區；厚薄並不決定誰文明高低。
- 一根巨型「垂直」骨架上的人，可能在中途沿側向曲環繞行多年，才到達結構上更上游／更外端的部分；同層也可能有極高高差。
- 巨構外部若實際暴露真空，**內部就要處理密封、輻射、承力與供能**；若外部是另一封閉時空，物理環境另設。**外部究竟在哪裡仍未定**，本模型不擅自宣稱有銀河或恆星。
- 後起文明的建橋、築城、導光、造海盆與多代坍落，可在主模型表面生成新的次級支骨與地形；**原始巨大母骨架以外還有後代無數工程層，歷史會改變 S/V/T，而不必一直改寫所有世界層的 J**。

## 七｜「往上」不能靠所有地方一根世界向上箭頭

**作者層已存在真正的最上層**，Celeste 為絕對管理者，但她不必待在那裡。**居民掌握某些更高世界層的測量紀錄**合理；卻不代表對最上層有公共普遍證明。

這裡提出兩種**尚不能互相混用為同一硬規則**的候選方法：

1. **結構上行／主脊序列**：某些巨大骨架可建立由內部低位承接，到更高位支承／較外端的**區域級有向關係**。它提供旅人「確實向上」的方向感，但若遇到環路、分枝、特殊接合，則只能定義**局部偏序、部分地域難以比較**，不能拿全域地球式海拔直接排所有地方。
2. **實際遠征的上行譜系**：幾代測繪者確認若干上行路徑，記下它們實際進入更宏觀／更上端的分域；「向上」首先是有人走過、有人測過的局部關係。遙遠的終點可能仍未被外界證明，卻容許諾亞與艾莉維亞真心追求那個最高處。

**本輪推薦**：暫採「結構上行傾向＋已測上行線索」兩套描述協作，保持它們是**地方實際導引**而非全球絕對坐標；真最上層由作者層保留，但不宣布所有地理箭頭都唯一收束到 Celeste 所在位置。若真正的非普通接合造成繞圈，**不能從層級名詞推出任何人都能無限繞上去**。

## 八｜三個壓力測試：模型真的能用，而不是只聽起來漂亮

**測試 I，窗口看見另一片巨大世界**：
地面 A 是巨型承載梁上的安居帶，一段高處可望見遠方曲殼 B 的農田與天幕；對岸視距可短、到達要長途。**先嘗試普通厚殼＋缺少通行孔的 B 解釋**，不需要立即設 C。測量人可能已知道遠處有正常居民；主角第一次看到不等於世界第一次發現。

**測試 II，沿著幾乎沒有盡頭的同一根支架**：
物質上 S 真連續，越走越遠經過不同年代交通橋與各代文明重建、巨型殘骸與自然生態；交通 T 可能因耗材、無氣地段、封閉承載段中斷。**高度增加數千公里也可能仍在原本世界層內**。對真正探險者，它已足以撐一大段遠征，而不必造一個新的「第幾層」。

**測試 III，一處超出外形的有效容積**：
外側看似一塊厚重殼囊，內部經真局部測量有遠超外側容積想像的完整空間和大氣；如果採 C 的展容機制，需指定邊界與長期穩定性，普通居民可以有可靠道路、產業、交通和生活。從殼囊某個小洞鑽進來**不表示**立刻抵達其最遠端；幾十年歷史的居民也不會只有一個 NPC 來解釋。

## 九｜研究方法的外部支撐與限度

- **流形與邊界黏合**：從不同部分的局部空間建立整體接合的數學思路，參考 Stanford 數學文章 https://web.stanford.edu/~dkim04/blog/gluing-manifolds/ 和多倫多大學講義 https://www.math.toronto.edu/laithy/3272023/327ps3.pdf 。**它只能支持「可以分開研究局部空間和它們的接合」，不能證明現實具有傳送縫口。**
- **地理可達性／網路**：道路能否通與距離長短應分別建模，參考關於街道連通與地理資訊的研究 https://www.sciencedirect.com/science/article/pii/S0198971599000174 。把地貌當成實際移動的成本而非貼圖，屬從研究轉化的創作建議。
- **人工居地的重力與採光工程**：NASA 早期可居住環境研究 https://www.nss.org/settlement/nasa/75SummerStudy/Chapt.1.html 說明人工環境必須同時思考住居、通路、農業、重力與採光。**此範例量級與宇宙條件不等於小說的巨構；只借用工程問題意識。**

## 十｜仍未決定的根本選擇：不該被第72份假裝解決

1. 巨構客觀外部是在普通宇宙、另一獨立時空、部分投影，或其他情況？
2. 外界能否從某條路**走到**真外殼表面；若能看外部，又看見什麼？
3. 主脊環路是原始母骨架自身如此，還是多代文明將數套巨大骨架縫合；後者是否能動到宏觀世界層？
4. 局部非普通空間的 C 是「擴展容積」為主、「遠端邊界黏合」為主，還是不同區域兼有兩種？哪些地方真的需要 C？
5. 真世界層物理邊界應更依結構骨架、有效空間分域、還是其組合？分類是否需要對不同測繪學派保持彈性？
6. 層間極難跨越在某些路確實存在，如何與已有正常客貨運跨層幹線共存，而不讓全域變成「層間一律只有極少數神選者能穿」？
7. 「向上」究竟有哪些可驗證客觀結構指標，才能讓主角有真登頂目標但不提早揭露最頂端客觀位置？
8. 整座世界尺度、固定層數、總人口、全部路網、Celeste 真管理位置、前文明對原骨架建造的份量都**未定**。

> 研究結論（候選，不是正式選定）：**可以將巨構做成真實厚實、具有分枝與環路的多尺度物質母骨架；它支撐交錯的巨大空域，少數部位由非普通幾何另行接合，內部又被不同世代文明反覆建造、摧毀和再利用。世界層是宏觀結構與可達性分域，不是國界、地形類型或固定高度樓層。**
