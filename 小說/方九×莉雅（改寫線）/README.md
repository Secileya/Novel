## 分層規則

1. 原著資訊只記可指出來源的基線，並標明證據狀態。
2. 使用者指定改寫獨立列為 `REWRITE-USER-FIXED`。
3. 正文只記本線已實際發生的事件；人物分析與例句不會自動變成事件。
4. 正文是已整理的改寫，不得冒充使用者逐字原話。
5. **方九由使用者扮演，不得自行補出他沒說過的台詞。** 有疑義先按稽核表處理。
