## 監控應做、不能做

1. 在支援連接 GitHub 的排程環境中**實際讀** 05／JSON／02；只有看到來源才能說明現有狀態。
2. 找 `open/scheduled/rescheduled` 的真實待辦，`active` 的長期偏好，`last_raised` 是否剛提過，`completed` 是否應移出速覽；不要因時間久就把喜好標過期。
3. 對**可直接證實的資料錯誤**，在安全與權限允許時才修正 GitHub 並回讀；不能憑過去對話的未載入猜測改寫個人偏好、成約或正文。

5. 不在公開倉庫未經明確允許寫入私人健康、住址、真實財務或其他敏感內容。
6. 如果需要真正**跨排程、跨對話持續工作的代理**，可以考慮符合資格帳號的 ChatGPT dot：官方說明 https://help.openai.com/zh-hant/articles/20001530-getting-started-with-your-dot 。dot 仍需使用者親自建立、確認適用資格與權限；不是現在兩項排程已建立 dot。
