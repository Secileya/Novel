# 方九 × 莉雅（改寫線）維護規則

本檔適用於此目錄及其子目錄。

## 1. 先讀順序

任何新對話先讀：

1. `00_專案交接.md`
2. `人物設定/01_原著資訊與改寫線邊界.md`
3. `人物設定/02_方九與莉雅_性格與互動規則.md`
4. `人物設定/03_事件順序與目前狀態.md`
5. `來源與校對/01_對話來源與恢復缺口.md`
6. 最新正式正文

## 2. 狀態標記

- `ORIGINAL-USER-REPORTED`：使用者對原著的明確說明。
- `SOURCE-RESEARCH`：有 repo 內研究導航，但未在本輪直接核對原著全文。
- `REWRITE-USER-FIXED`：本線由使用者明確指定的改寫。
- `PROSE-ESTABLISHED`：本線正式正文已發生。
- `OPEN`：尚未決定。
- `SUPERSEDED`：已被後來修正覆蓋。

不得把 `SOURCE-RESEARCH` 或其他專案中的類比分析升格成原著確定事實；不得把 `REWRITE-USER-FIXED` 倒灌成原著。

## 3. 人物與親密互動

- 兩人都是成年人與自願親密伴侶。
- 本線雙方都更熱烈、更主動；方九的原著外在冷靜不能變成本線固定上限。
- 熱烈、主動、害羞、慌亂可同時存在。不可把害羞寫成自動拒絕，也不可把熟悉寫成毫無情緒。
- 主導可來回交換；不要固定攻受、逗弄者、吐槽者或收尾者。
- 莉雅會吐槽、惡作劇、罵髒話，但粗口和臉紅都按情境出現，不設每場配額。
- 莉雅可以直接承認想抱、想親、想靠近；羞澀不等於典型悶騷或只否認。
- 方九可以直白表愛、先抱先親、被反撩到耳紅或偶爾失控；不要寫成冷面霸總，也不要只剩被動接招。
- 玩笑之後保留真實情緒延續：人可以繼續惱、繼續笑、忽然安靜、認真坦白或自然依偎，不必強制進下一個反轉節拍。
- 現行正式線的親密尺度為非露骨；若使用者後續另行指定，先更新設定與交接，再寫新正文。

## 4. 續寫與同步

- 「繼續」必須從最新正式停點後寫，不重播第一篇事件。
- 新正文完成後同步：正文、事件順序與目前狀態、交接停點；若形成永久新規則，再改人物設定。
- 設定例句、可能性、笑話示例不等於已發生事件。
- 來源缺口要保留，不用新寫台詞假裝舊對話已逐字找回。
- 新增或修改正文後，以單一可核對提交同步到 GitHub；成功後回讀檔案與提交。
