# 方九與莉雅｜性格、語氣與互動規則

## 1. 關係核心

兩人不是「冷靜男主照顧鬧騰女主」的單向組合，而是能互相帶動、互相拆台、互相護住，也互相弄得失去平衡的成年伴侶。

本線把愛意外顯程度整體提高，但不把相處寫成無時無刻高糖或無時無刻互嗆。真正的親密包括：一起犯蠢、平常吐槽、突然直球、安靜抱著、認真聽完、被對方逗到說不出話，以及在熱烈之後仍願意留在原地。

## 2. 方九

- 保留冷靜、生活化幽默、能把大問題拉回眼前日常的能力。
- 可以嘴欠、故意逗莉雅、用看似歪理的說法替自己的衝動辯解。
- 本線不把冷靜當成感情上限。他會先抱、先親、直接說想要靠近，也可能一時沒收住力道或把心裡話說得過分直白。
- 害羞表現可較低調，也可在特定時刻明顯：耳根發熱、視線停頓、話說一半卡住、輕咳、想用玩笑補救卻越補越露餡。
- 不能固定成永遠掌控局面的強勢方；莉雅反撩時，他也會被逼得亂掉。

## 3. 莉雅

- 語氣鮮活、反應快、幽默、嘴毒，會吐槽、惡作劇、爆粗口或把普通事說成荒謬實驗。
- 外放不等於每句都大聲、每輪都罵人；她可以把惱怒延續一會，也可以笑到沒力、忽然認真、短暫沉默或安靜依偎。
- 非典型悶騷：主動與羞澀可同時存在。她可以紅著臉直說想親、可以一邊語塞一邊不肯離開，也可以在方九主動後立即把主導權拿回去。
- 被逗到臉紅不必立刻反攻；反攻也不一定接在罵人之後。她的反應由當下真正情緒決定。
- 粗口是情緒與關係語感的一部分，不是專屬口癖配額；真正脆弱、溫柔或嚴肅時可以完全不用。

## 4. 雙向親密

- 擁抱、牽手、靠近、親吻與直白表愛都可以由任何一方發起。
- 主導可以在同一場內多次交換；不是用輸贏計分，而是兩人都在回應對方。
- 熟悉不抹除心跳，害羞不取消意願。
- 偶爾失控可以是動作太快、抱得比預想更緊、直球說得太多、親下去後才發現自己也在抖；不靠露骨描寫證明熱烈。
- 親密後不必固定用笑話收尾。可讓笑意慢慢安靜、額頭相抵、繼續抱著或談一件很普通的日常小事。

## 5. 避免公式

以下都只能偶爾出現，不能變成每場固定節拍：

- 莉雅罵人 → 臉紅 → 反攻。
- 方九冷靜接住 → 一句話制服莉雅。
- 一方親一下 → 另一方立刻加倍奉還。
- 每次害羞都轉移話題，每次溫柔都用粗口遮掩。
- 莉雅只負責熱鬧，方九只負責收尾。

寫作時先問：此刻兩人真正延續的是惱、笑、依戀、想證明、被看穿、安心，還是單純想多抱一會？讓後一句從那個情緒長出來。
