# 【靈魂久歌】規則校正 v1.0

狀態：**CANONICAL RULE / FUTURE PREWRITE CONSTRAINT**  
日期：2026-09-25  
適用：原著第51～54章「黑色光球→【靈魂久歌】→芬里爾」鏈，以及本線對應改寫。

## 一、原著規則校正

1. **第一次死亡與【靈魂久歌】死亡必須分開。**
   - 玩家第一次觸碰黑色光球時，死亡來源是**黑色光球本身**。
   - 此刻【靈魂久歌】尚未正式完成啟動，因此第一次死亡者**尚未吃到靈魂標記**，仍可用原本可用的正常復活手段復活。
   - 黑色光球被觸碰後，才進一步觸發神咒【靈魂久歌】。

2. **【靈魂久歌】不是「元素傷害很高」。**
   - 它是直接作用於**靈魂層／靈魂目標**的神咒規則。
   - 火、雷、土、水、冰、風、光、暗、木、空間、亡靈、禁制等大量元素是其展現與構成，不應把它簡化成高額HP傷害。
   - 正式效果包含：覆蓋342號新手村空間、命中後**100%即死**、附加靈魂標記、被標記者一天內不能以一般手段正常復活，並需回初始新手村淨化靈魂。
   - 【初級復活卷軸】不能把已成立的靈魂標記／一天不可復活正常抵銷。

3. **原著無效區保留。**
   - 神咒施法核心周圍約35公分存在真空／無效區。
   - 無效區是《信仰》本身已有的規則缺口／安全區，不是Franiya臨時創造的外掛空間。

## 二、Franiya線固定處理

### 1. 不走「先死一次→復活無敵→衝進無效區」

Franiya在本線第一次遭遇這條事件時，**不需要也不應先死亡一次來理解規則**。此處的「不死亡」包含本次黑球／【靈魂久歌】整條第一次事件：若由Franiya本人完成第一次黑球接觸，也不得先把原著普通玩家的「黑球直接死亡」機械套到她身上。

她應依黑球、神咒啟動、作用鏈變化、周圍玩家結果與自身直接作用感知，迅速判定這不是普通高傷害，而是規則型／靈魂型危險，並在判定真正落到自己身上前進入既有無效區。

固定結果：
- `FRANIYA_FIRST_SOUL_SONG_DEATH = NO`
- `FRANIYA_ENTER_NULL_ZONE_ALIVE = YES`
- `REVIVE_INVINCIBILITY_ROUTE = NOT_USED_BY_FRANIYA`

誰實際觸發黑色光球、Franiya當時距核心多遠、她用什麼遊戲內可成立的移動／位置處理進入無效區，留到該章PREWRITE依當時正文因果核定；但不得為了照搬沈雲原著流程，強迫Franiya先死一次。

### 2. 普通【完美格擋】不能擋已成立的100%即死神咒

【完美格擋】可以處理系統允許格擋的碰撞、武器、投射、能量或攻擊交換；若神咒已經對目標成立的是「100%死亡」規則，則不能把它改寫成「刀架得夠準就把傷害擋掉」。

若要避免結果，必須發生在規則成立之前，例如不成為有效目標、進入規則無效區、利用原著既有漏洞，或阻止必要媒介／目標關係成立。

### 3. 神咒真正作用於Franiya的預設判斷

由於【靈魂久歌】真正作用於**靈魂**，不能先驗假定《信仰》對普通玩家成立的「可鎖定靈魂目標」也能以同樣方式鎖定Franiya的真正存在／靈魂結構。

若未來神咒真的直接嘗試對Franiya本人建立靈魂層作用，現行預設是：
> **它很可能根本無法建立正常目標關係，因此沒有「即死判定成功後被她硬抗」這一步，表面結果甚至可能是什麼都沒有發生。**

此方向固定為：
- `FRANIYA_SOUL_SONG_DIRECT_EFFECT_DEFAULT = NO_NORMAL_EFFECT_IF_NO_VALID_SOUL_TARGET`
- `THIS_IS_NOT_DEATH_IMMUNITY = TRUE`
- `TARGET_RELATION_MUST_EXIST_BEFORE_RULE_CAN_RESOLVE = TRUE`

但第一次【靈魂久歌】事件**禁止讓Franiya為了驗證這件事故意站在神咒裡測試**。她既然能用既有規則進無效區，就會採取更合理的低風險處理。

因此第一次事件只正式證明：
- 她沒有先死；
- 她活著進入無效區；
- 她沒有用普通【完美格擋】硬擋神咒。

「【靈魂久歌】直接命中Franiya會不會完全無效」保留為高度明確的存在結構預設，但**不在第一次事件中用自殺式測試實證**。

## 三、敘事禁錯

- 禁止寫成「【靈魂久歌】元素傷害太高，所以玩家血量歸零」。
- 禁止把黑色光球第一次直接死亡與後續【靈魂久歌】即死混成同一次判定。
- 禁止讓第一次被黑球殺死者提前帶上【靈魂久歌】靈魂標記。
- 禁止讓【初級復活卷軸】正常覆蓋已成立的一天不可復活。
- 禁止讓Franiya先死一次，只為複製原著沈雲的1.5秒復活無敵路線。
- 禁止把普通【完美格擋】寫成可直接抵銷已成立的100%即死神咒。
- 禁止把「神咒可能找不到Franiya的有效靈魂目標」寫成普通的「死亡免疫」Buff。
- 禁止讓Franiya明知有無效區與更安全解法後，仍為了測試自己會不會死而故意吃神咒。
