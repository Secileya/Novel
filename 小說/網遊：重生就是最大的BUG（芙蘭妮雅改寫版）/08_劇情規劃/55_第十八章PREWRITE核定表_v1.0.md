## 三、原著第39～40章因果正式回收

### 3.1 原著真正需要保留的功能

原著千人圍堵不只是沈雲與黑色暗流的私人仇恨結果。

本線要保留的核心世界因果：
1. 頂尖獨行玩家若不受大型公會控制，會直接改變高端資源、首殺、聲望與玩家流向。
2. 【影子】早年也是獨立高手，最後成長到可以靠個人聲勢與十大公會平起平坐。
3. 【夜色無邊】曾是18歲頂尖天才，被大型公會以長期野外封鎖壓掉成長窗口。
4. 原著【黑色童話】【四海聯盟】【百川書院】正是當年壓影子／圍夜色無邊的主要勢力之一，因此它們有「早期處理獨行天才」的既有組織記憶與工具。
5. Franiya目前同時具備：
   - 無大型公會歸屬；
   - Lv7；
   - 世界第一黃金Boss獨立首殺；
   - 公開姓名；
   - 高端戰鬥短片；
   - 黃金裝備流通能力；
   - 已拒絕正天招募；
   - 影子本人已公開接觸；
   - 現有技術仍未被大型公會摸清。
6. 因此她符合「可能長成第二個影子，甚至更麻煩」的風險模型。

### 3.2 黑色暗流前後態度不能重置

第15章黑色暗流曾明確判斷：
> Franiya沒有搶過他的東西、沒有殺黑色童話的人，硬造一個仇人很蠢。

這條**不能作廢**。

本章若讓黑色童話加入圍堵，必須呈現為：
- 黑色暗流仍不把事情理解成私人報復；
- 新增資訊與其他公會的共同決策讓問題從「要不要無故惹她」變成「三家是否共同維持既有高端競爭秩序」；
- 他可明確保留反對／不喜歡該做法的態度，但在四海／百川已準備出手、且歷史上三家本就共同做過類似事件的前提下，最終同意**有限參與五日封鎖方案**；
- 其理由應是組織競爭與共同風險，不是突然恨Franiya；
- 若他認為代價超過收益，也可只出部分資金／情報，不親自下場。

### 3.3 三家正式決策

本章核定優先採：
- 【黑色童話】
- 【四海聯盟】
- 【百川書院】

三家共同出資／協調，保留原著組合。

但本線動機重建為：
- 不在Franiya現在還能處理時出手，之後她若把連續世界首殺、黃金裝、獨立聲望與自由模式技術堆起來，處理成本只會更高；
- 目標優先不是「把她殺退遊」，而是**用五日封鎖切掉前期成長窗口**；
- 若Franiya願意加入大型勢力／接受某種約束，部分參與者甚至可能更偏向談判；但目前她已明確拒絕正天，且沒有加入任何公會的需求。

不得寫成：
- 三家所有人都嫉妒她；
- 三家因一條論壇帖子集體失智；
- 黑色暗流突然因私人仇恨暴怒；
- 「她是女人／長得特別」成為主要動機。

## 七、Franiya這一小時做什麼

這一小時不能全靠切鏡讓Franiya消失。

她自己的行動應保持簡單且符合章末停點：
- 在342村內看未去過的街區／功能區；
- 可順手處理普通生活性遊戲事項，例如查看修理、補給、一般NPC店鋪或整理背包；
- 不強迫開三個黑鐵寶箱；
- 不主動去刷怪升級；
- 不前往村口「等戰」；
- 她可以逐步察覺：
  - 村裡有人往出口方向聚；
  - 佣兵ID／團隊標記增加；
  - 市場有人高價收遠程消耗品／藥劑；
  - 工作室開始賣「342村口大事」情報。
- 她不需要因此緊張；目前只會把它當成正在形成的新事件。

本章讓一小時倒數接近或正式走完。

優先方案：
- 佣兵封鎖先在一小時內完成；
- 地獄使者在章末或接近章末完成「嘗試接觸」；
- 若使者先送出線索載體／訊息，Franiya可以**先取得但不立即展開閱讀**，讓原著「圍堵後才真正查看穆斯塔線索」的節奏仍大致成立；

可正式建立：
- 地獄使者確實出現／發出接觸；
- 暗金線索載體已可取得。

是否在本章公開【穆斯塔】名字，優先**不公開**，留到千人事件後閱讀；除非正文節奏自然需要。

- 也不應因自己很強就高調宣戰。
- 首先是確認：
  - 對方目標是不是自己；
  - 封鎖條件；
