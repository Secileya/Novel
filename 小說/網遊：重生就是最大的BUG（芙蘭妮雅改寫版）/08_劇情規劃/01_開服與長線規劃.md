# 開服與長線規劃

> 狀態：骨架規劃，不是已發生正文。

## 第一階段：正常新遊戲
功能：
1. 建立正常現代社會與全新遊戲開服。
2. 所有人對這款遊戲都是新人，但現實能力與組織資源不同。
3. 建立芙蘭妮雅與本地系統的特殊關係。
4. 只用小異常展示差距，不直接攤宇宙級尺度。
5. 讓普通玩家、高手、公會、資本形成不同認知。
6. 讓遊戲本身值得玩，不只是主角表演場。
7. 不進入現實異能／末日。

### 登入候選節奏
- 她第一次使用登入設備。
- 遊戲力量嘗試建立普通玩家式附著。
- 她感到力量想貼上來。
- 強制作用尚未成立便自然散掉。
- 她沒有拆系統，介面正常出現。
- 確認「能玩」後繼續建角。

這一幕應安靜，不用宇宙級特效。

### 建角
原著確定可捏臉。若後續確認 0% 調整，可利用「遊戲裡以為是捏的／現實見到才發現本人就長這樣」作長線反差。

### 第一批戰鬥展示
優先：
- 雙短刃技術。
- 無多餘步伐。
- 讀怪物／玩家動作。
- 投刀回收。
- 小幅軌跡／慣性調整。
- 快速理解自由操作。

避免：
- 黑洞。
- 改時間。
- 刪 Boss 因果。
- 造宇宙。

### 第一次系統矛盾候選
- 對手使用無敵判定。
- Franiya 尚不知道那段被遊戲定義為無敵。
- 她正常命中。
- 系統提示攻擊無效。
- 目標卻實際受到致命結果甚至死亡。
- 戰鬥紀錄同時留下「無效」與「死亡」。
- 她理解後，後續正常遊戲主動尊重無敵判定。

是否放在早期、對手身分與事件位置未定。

### 第一波反應
普通玩家：技能？裝備？Bug？捏臉？有人瞧不起，有人只想做自己的事。
技術玩家：慢放、比對自由操作、查角色數值、研究她到底預判還是反應。
公會：查 ID、查履歷、問組織、考慮招募／交易／觀察，逐步發現背景查不到。

### 不要重複的節奏
禁止 Boss → 首殺 → 全服公告 → 全員震驚 → 下一 Boss 無限循環。

混入任務、交易、生活職業、公會招募、直播、假攻略、裝備市場、現實工作／學校／公司反應與其他地區獨立事件。

## 第二階段：遊戲社會成熟
- 系統公會正式形成。
- 領地、交易、排行、職業分工增加重量。
- 早期資產開始有長期價值。
- Franiya 的名字在不同圈層有不同辨識度。
- 現實企業與政府把遊戲視為重要產業／社會基礎設施。

第一建會令／公會核心是高優先候選，但取得者未定。

## 第三階段：異常累積
異常最初仍可被懷疑為 Bug、設備問題、新技術、伺服器事件或隱藏機制，之後才累積到正常解釋不足。

候選：
- 遊戲物品與現實出現難解對應。
- 感官／身體回饋超出設備能力。
- 某些空間或訊息不再只是資料。
- 官方找不到合理技術來源。

## 第四階段：局部重疊
- 少量遊戲規則進入現實。
- 部分遊戲成果開始有現實效果。
- 公會、領地、裝備、技能與早期資產被重新估值。
- 政府、軍事、國際與大型企業才進入高強度介入。

## 第五階段：融合
- 遊戲不再只是能安全下線的娛樂。
- 死亡、領地、物品、技能的現實後果重新定義。
- 正常世界的人開始真正面對超常規則。

不得因此倒推「開局早就有異能者」。

## Franiya 的長線
她從一開始就遠超遊戲與本世界正常量尺，因此長線不是升級到足以活下來，而是：
- 她願意用多少。
- 何時還把事情當遊戲。
- 哪些規則值得尊重。
- 哪些威脅使她停止自我限制。
- 其他人如何逐步理解自己一直只看到極小一部分。

## 名字威懾
陌生 ID → 局部玩家認得 → 技術圈／公會／市場留下紀錄 → 大型事件進入高端資料庫 → 某些組織只聽 Franiya 就調整計畫。

不能直接跳到全民敬畏。

## 第一階段結束標誌候選
- Franiya 第一次成為跨區技術圈明確認得的 ID。
- 第一次大型唯一事件。
- 第一個真正頂尖玩家與她交手／分析。
- 第一塊具公會戰略價值的資產出現。
- 第一個官方無法簡單解釋的技術異常。

具體終點待後續確認。
