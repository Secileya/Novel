## 二、第26章功能判定

本章不再延長布魯斯事件，也不直接跳到第四日下午。

本章採「短現實降落 → 返回遊戲 → 舊情報線前進一步」三段式：

1. **短現實降落**：讓簡雨朧與Franiya真正把今天剩下的一小段行程走完，顯示兩人不因一次高壓事件就只剩危機功能。
2. **關係更新但不做家世說明會**：簡雨朧知道Franiya現在已見過簡文山；可以出現很短的祖孫／護衛／剛才事件對話，但不把簡家、正天、炎黃聯盟背景一次倒完。
3. **返回《信仰》**：傍晚前後Franiya自然結束外出、回家並重新登入。
4. **舊線前進**：張文君取得「NPC錄像原始拍攝者」的新進展；只把來源鏈從二手推到一手，不直接給出地獄骷髏城路徑。

本章必須有實際前進，不寫成整章吃飯／散步／聊天。

- 維持低振幅、自然、精準。

- 可確認原始檔確實存在，並能比對錄像時間／原始訊息／未經二手剪輯等基本真偽資訊。
- 拍攝者本人仍不需要知道地獄骷髏城，也不應因「是原拍攝者」就突然成為高級情報NPC。
