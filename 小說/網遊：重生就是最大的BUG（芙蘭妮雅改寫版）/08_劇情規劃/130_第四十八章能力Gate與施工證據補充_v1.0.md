## 二、Franiya Ability Gate

### 第48章預設

- `EVENT_HORIZON = OFF`
- `SPEED_LIMIT_RELEASE = OFF`，除非129號之外另有後續正式核定。
- `HIGH_LEVEL_BODY_ABILITY = OFF`，不以現實本體天體／黑洞級力量直接破壞《信仰》玩法。
- `WEAPON_RECONSTRUCTION = LEGAL`，沿用既有重構邊界，不複製武器面板／技能／彈藥／冷卻。
- `GAME_SHELL_OUTPUT = PASS`：角色殼數值差距、地形、裝備耐久與系統規則必須持續有意義。
- `KNOWLEDGE_GAIN = LEGAL`：不得由作者知識提前得知貝克位置、芬里爾身份／本體位置、斯芬克斯、星辰樹或其他未取得資訊。

### EVENT_HORIZON = OFF 的理由

- Lv17～18暗影魔獸本身只是高於角色殼的現場戰鬥壓力，不等於因果／存在層問題。
- 貝克的異常狀態需要先觀察與取得證據，不能用事件視界當偵查能力。
- 芬里爾分身即使層次高，也不能因「強者出現」自動開視界；先依既定分身辨識、劍柄共鳴與對話因果處理。
- 本章重點是角色殼差距下的技術／裝備／判斷、劍柄因果回收、人物知情與世界規則落地，不是高階本體能力展示。

若正文施工中真的出現原PREWRITE未包含、且涉及「普通作用結果無法成立、因果逃逸、跨重生／再生／傳送等機制必須封鎖」的新硬證據，必須先回到PREWRITE層重算，不得直接在正文臨時開視界。

## 三、事件視界固定視覺備忘

若未來章節正式開啟，不得誤寫顏色：

- 核心／刃緣內側：近乎吞光的深黑／無光區。
- 外側：熾白、白金、金黃、橙金、橙紅至深紅的吸積盤式高亮環帶／弧帶／流線。
- 最高能局部：可少量藍白。
- 高辨識遠觀：深黑核心＋金橙吸積環。
- 非固定紫黑特效；芙蘭妮雅藍紫瞳色不得機械套入事件視界。
