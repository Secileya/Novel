## 三、本章核心因果選擇：B分支正式成立

### 3.1 不是被腳印「導航」到Boss

第13章右側腳印只提供：有人進去過、回來痕跡較少、有人曾較急地退回。它不能直接被解讀成「Boss就在右邊」。

本章Franiya進右側深區的原因固定為：
- 已完成附近一輪正常採集；
- 右側玩家流量較低，代表資源競爭可能較少、未知路線資訊價值較高；
- 她本來就需要眼珠、礦石、藍心草，探索新區域與任務目標自然一致；
- 她不因未知就停步，也不因知道讀者／作者有Boss就直線找Boss。

因此：RESOURCE_AND_EXPLORATION_CAUSE → RIGHT_BRANCH → DEEPER_AREA → BOSS_CONTACT。
不是：FOOTPRINTS = BOSS_HINT → DIRECT_BOSS_ROUTE。

### 3.2 正式遭遇方式

- Franiya進入更深礦道後，先依正常探索節奏前進。
- 她不會先看到「黃金Boss房」或系統箭頭。
- 【暗黑魚人刺客】先以刺客AI／活動邏輯主動選擇她作為攻擊目標。
- 第一個真正Boss證據就是攻擊本身＋之後的【探查術】結果。
- Franiya在第一次短暫可確認窗口使用【探查術】，取得Lv8、黃金與五技能資訊；部分高屬性仍可因探查條件不足無法完整讀取。
- 不直接得到約4500HP、強隱約1分鐘等沈雲實戰估算／觀察值。

## 四、Franiya對Boss的戰力基準

### 4.1 人物能力不能被下修

- Franiya的**實戰經驗、戰鬥技巧、感知能力遠高於《信仰》現階段所有玩家**。
- 不是「比普通玩家高」，也不是「和世界級高手差不多」。
- 她不靠背招式表反應，而是直接讀取作用、重心、慣性、軌跡、能量、武器受力與攻擊形成。
- 未知技能不自動造成第一次吃招。
- 【潛行／強隱】不等於目標從作用關係、地面、空氣、武器、能量與空間中真正不存在。

### 4.2 與原著等級基準交叉

原著更低等級沈雲已能防守、周旋、累積Boss傷害並最終完成擊殺。

本線Franiya現在Lv7、敏捷15、等級差只有1級，且技巧／感知／實戰經驗遠高於所有玩家。因此本章固定：
- Boss第一擊**不是「能不能防住」的主懸念**；
- 普通近身攻擊、【背刺】、【疾馳】與重新現身後的攻擊，常態自限下都應能穩定防守／拆招／反制；
- 不得為了凸顯黃金Boss而憑空把Franiya的角色殼寫慢到比原著更低等級沈雲還差；
- Boss仍然客觀危險，只是危險性不能靠削弱Franiya本人來成立。

## 五、本章戰鬥解法

### 5.1 第一輪：Boss主動近身

- Boss由【潛行】／刺客切入發起攻擊。
- Franiya在攻擊真正成立前讀到作用變化，正常完成偏轉／格擋／讓位。
- 副手短刃可作物理阻擋、改線、卡腕／卡刃與控制攻擊路線；不偷渡完整副武器攻擊收益。
- Franiya不需要解除速度限制，也不需要事件視界。
- 不因【淬毒】存在就預設中毒；Boss武器未命中即可不成立。

### 5.2 反擊方式

Franiya的普通裝備輸出較低，因此她不靠胡亂多砍，而是：
- 優先打高價值命中位置；
- 利用命中部位影響傷害的既有遊戲規則；
- 每次Boss主動靠近，都把它的進攻窗口轉為自己的反擊窗口；
- 動作以最短路徑、最少多餘修正完成，不浪費Lv7角色殼可以提供的速度。

### 5.3 【強隱】不是失去Boss

- 視覺／系統隱身效果正常成立，不寫成技能失效；
- Franiya不需要「看見透明模型」；
- 她從地面受力、空氣／空間作用、能量建立、武器與移動造成的連續變化追蹤其行動；
- 她不因第一次見【強隱】就失去判斷。

### 5.4 真正難題：脫戰與回血

Boss若判斷正面交換不利，會嘗試：強隱 → 拉開 → 脫離安全距離 → 回血 → 再襲。

本章正式採：
- Franiya**不開速度限制解除**；
- **不開事件視界**；
- 她先用現行Lv7角色殼直接處理。

理由：
1. 她和Boss只差1級，不先假定角色速度已完全無法追擊。
2. 她的移動沒有普通玩家的猶豫、過度轉向與修正損耗。
3. 她能在Boss真正開始撤退時就讀出路線，而不是等看見背影才追。
4. 礦道是有限地形；她可以切最短路徑、卡轉角／出口方向，而不是跟著Boss屁股直線追。
5. 她只需要不讓Boss真正脫離到能安全完成戰鬥重置／恢復的狀態，不需要在純直線極速上永久比Boss快。

### 5.5 不使用兩張升規格牌

- SPEED_LIMIT_RELEASE = NOT_USED
- EVENT_HORIZON = NOT_USED

兩者不是因為不能用，而是**沒有必要**。若常態Lv7角色殼已能防守、反擊、跟住／截住Boss撤退並持續累積傷害，Franiya沒有理由為一場已可處理的戰鬥主動破壞自己保留的遊戲尺度。

### 5.6 收尾

- 不使用【高等血符】或等價憑空爆發道具。
- 不使用事件視界永久破壞／再生封鎖。
- 不使用速度限制解除。
- 不讓Boss完整回血重置。
- 經過數輪「Boss靠近 → Franiya防守／拆招 → 精準反擊 → Boss嘗試拉開 → Franiya提前截線」後，Boss血量被普通武器穩定壓低。
- 最後由Franiya以**普通主手短刃＋精準弱點／高價值命中**完成正常角色層擊殺。
- 戰鬥不需要把她寫成苦戰到失誤連發；客觀難點主要來自Boss機制與低階裝備輸出效率，而不是她本人技巧不足。

## 十、世界反應的章級邊界

黃金首殺是世界級遊戲事件，不能一句「論壇炸了」帶過。但第14章主體是探索 → 遭遇 → 戰鬥 → 擊殺 → 公告。

因此本章只做第一層即時反應：
- 礦洞／342附近玩家聽到匿名世界公告後短暫停頓；
- 因玩家名與Boss名均隱藏，普通人不能直接知道是Franiya，也不能直接知道在拉爾斯湖畔礦洞；
- 少數恰好知道342有人正在深入礦洞的工作室／玩家可以產生「可能和這裡有關」的低可信猜測，但不能立刻確證。
