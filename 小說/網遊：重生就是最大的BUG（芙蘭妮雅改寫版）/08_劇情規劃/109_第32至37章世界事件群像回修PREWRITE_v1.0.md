# 第32至37章世界事件群像回修 PREWRITE v1.0

> 狀態：PASS
> 正式回修：ALLOWED
> 目的：修正【靈魂久歌／芬里爾世界主線】→系統更新→全球怪物攻村→342特殊第11波→93%結算爭議這一整段的群像覆蓋不足。

## 一、問題確認

現行第32～37章主因果有效，不推翻：
- Franiya於342狼王殿觸發黑球／【靈魂久歌】／芬里爾世界主線。
- 在線新手村玩家受到世界級死亡／掉級後果；Franiya本身未被正常死亡判定結束。
- 次日更新後全球進入8小時怪物攻村。
- 342第11波因赫爾墨斯徽章NPC身份引出亞當斯／達倫不可抗力事件。
- 芬里爾關係重分類使亞當斯／達倫撤離，342提前守村成功。
- Franiya升Lv9、93%貢獻、取得【貪狼之爪】。
- 第37章約1.5億人次申訴及智能核心公開核驗成立。

缺口不是主因果，而是：世界級事件發生時，鏡頭過度集中342與少數觀察者；此前正式建立的243【細雨朦朧大魔王】、452【大夢初曉】／錦繡、刺殺者公會、其他具名玩家／公會等沒有留下相稱的事件後效。

## 二、回修原則

1. **世界級事件沿既有角色網路傳播。**
   - 不要求每名角色同章出場。
   - 但已建立、合理受事件影響的人物不能像被世界暫停。
   - 至少留下「當下反應／行動改變／後續記憶」之一。

2. **反應必須依角色位置與能力不同。**
   - 普通玩家：死亡、掉級、抱怨、錄影、改排時間、守城恐慌／適應。
   - 小隊高手：先處理當前戰場，再從實際樣本修正打法。
   - 公會核心：重排人員、資源、輪值、遠程比例、情報優先級。
   - 情報／刺殺組織：更新Franiya檔案與跟蹤／接觸規則。
   - 與Franiya有私人因果者：反應必須建立在「她們知道現實Franiya＝遊戲Franiya」這個既有資訊上。

3. **不做打卡式切鏡。**
   - 不為每個名字安排一句「震驚」。
   - 只切能展示不同後果、不同決策或後續關係的節點。

4. **資訊邊界不變。**
   - Franiya仍不知道簡雨朧＝243【細雨朦朧大魔王】。
   - Franiya仍不知道唐曉煙＝452【大夢初曉】。
   - 簡雨朧、唐曉煙知道現實Franiya與342玩家Franiya是同一人。
   - 她們不知道黑球、芬里爾劍柄、林中談話等未公開資訊。

5. **不改章末與時間線。**
   - 第38章〈石縫裡的銀線〉及108號第39章PREWRITE仍有效。
   - 回修只增加世界運作與角色後效，不改Franiya等級、裝備、任務與主要事件結果。

## 三、正式回修位置

### A. 第33章〈八點零五分〉
加入世界事件／更新前夜與攻村第一波的具名群像：
- 243【細雨朦朧大魔王】：若在【靈魂久歌】發生時在線，親歷死亡＋掉級；她認得世界公告上的Franiya，對此反應與陌生玩家不同，但不因此知道觸發細節。
- 452【大夢初曉】／錦繡：以公會管理視角處理成員掉級差、次日8小時守城與遠程／補給配置；唐曉煙知道Franiya本人，私人認知與公會決策分開。
- 刺殺者公會／極限速度流：把「Franiya觸發世界主線」加入既有觀察檔，但不能推導黑球機制。
- 次日第一波同步短切243／452實際守村，使兩條線不是更新夜說完就消失。

### B. 第34章〈第十波沒有怪〉
在第6～7波與第10波附近加入跨村進展：
- 243：飛行怪波讓法師價值上升，簡雨朧以自身法術時機與小隊協作處理，不寫成全村主角。
- 452：錦繡早前形成的「主線組＋近距離探路／任務組＋可回援距離」在攻村中自然演化成輪值／預備隊，證明既有自主線有後果。
- 至少一個未具名／海外村落顯示同波次可以因人員配置不同而失守或重創，避免所有村都跟342同節奏。

### C. 第37章〈一億五千萬次申訴〉
加入公開核驗後的已建立角色後效：
- 簡雨朧：以現實私人聯絡對Franiya的93%做符合她性格的短反應；不暴露其243遊戲ID。
- 唐曉煙／錦繡：更新公會接觸規則；私人救援／認識不拿來壓價，亦不主動把Franiya現實身份散給公會。
- 黑夜傳說／極限速度流：從「技術異常觀察」提升到「世界事件＋NPC事件處理模型不足」，並調整尾隨規則。
- 其他公會維持差異：招募、買情報、避戰、質疑仍可並存。

## 四、角色反應連續性

回修後固定：
- 簡雨朧若因【靈魂久歌】親歷掉級，後續記得是Franiya觸發的世界事件，不會記憶重置。
- 唐曉煙／錦繡因本次世界事件形成的守城配置、情報優先級與Franiya風險模型，後續持續有效。
- 極限速度流／刺殺者公會對Franiya的觀察由單純技術樣本升級；再遇Franiya不得像只看過第3／8章。
- 世界事件不是Franiya一個人的舞台；其他角色在鏡頭外仍持續升級、組隊、守村、失敗、取得裝備與建立自己的遊戲經驗。

## 五、禁止事項

- 禁止為了群像讓每章切十幾個名字。
- 禁止把所有角色都寫成Franiya粉絲／黑粉／研究員。
- 禁止讓簡雨朧或唐曉煙提前知道芬里爾、黑球核心或第11波私密談話。
- 禁止把243／452直接寫成必然守村成功或必然失守，除非後續正式因果需要；現階段只建立過程與可追蹤後效。
- 禁止改動第32～37章既有硬結算。
- 禁止回修造成第38章白色遺跡入口失效。
