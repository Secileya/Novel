# 一、狀態分類

- **KEEP_NOW**：在目前1～7章時間內本來就應成立，已發生或可視為世界同時運作。
- **DELAY**：事件本身仍可存在，但必須等本分支真正到達相應時間／等級／地點／條件。
- **RECALCULATE**：原著結果高度依賴沈雲操作、前世攻略、私人敵意或排名操盤，不能直接搬；需按Franiya世界重算。
- **CONDITIONAL**：只有特定前置事件在本分支真正發生才會觸發；前置不存在就不發生。
- **CANCEL_OR_REBUILD**：原著因沈雲穿越／黃博士／夢境戀愛／私人仇恨等專屬因果，本分支不照搬，若未來需要功能只能另建新因果。
- **UNRESOLVED_HIGH_IMPACT**：來源足以證明它重要，但目前沒有足夠因果安全地鎖死結果；在下一次依賴它前必須先解決。
