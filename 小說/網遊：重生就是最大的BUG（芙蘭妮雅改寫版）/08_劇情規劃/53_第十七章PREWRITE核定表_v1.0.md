## 四、本章核心事件

### A段｜三件Lv8黃金裝備的處理

Franiya不需要把所有剛得到的裝備永久留在背包。

她會做最簡單的用途判斷：
- 【火狐炎刀】無等級限制、黃金、可成長，且已重構為她最順手的成對雙短刃 → 現階段主武器。
- 【藍銀匕首】需求Lv8，且作為單純武器用途與【火狐炎刀】高度重疊 → **可出售**。
- 【靈動之靴】Lv8後可提供敏捷與【疾馳】 → 暫留。
- 【白骨戒指】Lv8後有感知與黑暗視野 → 暫留。
- 三個黑鐵級隨機寶箱不因「正好在市場」就強迫開；本章仍可保持未開。

Franiya選擇賣【藍銀匕首】的理由只有：
> 自己目前不需要，而且黃金裝在第二日市場有極高交換價值。

不是缺錢，不是炫耀，也不是刻意釣大公會。

### B段｜Franiya再次進342市場

- 她已在第10章看過市場，因此本章不重新教學市場規則。
- 她一進市場就會被直接認出；不再需要「是不是首殺者」的猜測。
- 世界首殺者本人拿出黃金匕首，可信度極高，會自然吸引高資本／高階玩家。
- 普通玩家反應可存在，但不要整章只剩圍觀尖叫；市場仍持續正常交易。

交易方式優先：
- Franiya不熟悉第二日黃金裝的精確極限價格，採**公開競價／價高者得，只收金幣**比自己亂猜一個固定價格更合理。
- 原著30,000金掛價→50,000金成交可作市場尺度參考。
- **本PREWRITE核定：若競價無新反證，最終由張文君／香檳怪盜以50,000金取得【藍銀匕首】。**
- 允許使用系統契約延後部分金幣到帳，前提與原著市場規則一致。
- Franiya不會因對方是首富之女就改變語氣，也不會故意壓價／抬價逗人。

### C段｜雨天決行正式載入

此前第10章因「Franiya尚無黃金匕首」而沒有載入【雨天決行】／【影子】交易線；現在條件成立。

雨天決行：
- 保留原著核心DNA：年輕、有名、影子系人物、帶自信與一定傲氣，不是笨蛋。
- 不照搬原著「先說現階段不可能有人賣黃金裝→當場打臉」的完整笑話，因本線世界已公開知道Franiya剛拿黃金Boss首殺；他若還堅稱不可能有黃金裝，會變成降智。
- 他可以因身份／市場自信顯得高傲，也可以代表影子表達對【藍銀匕首】的興趣。
- 不與Franiya發生無理由衝突。

### D段｜影子第一次正式進入Franiya主線

- 影子不是突然為Franiya本人而來；**直接入口是黃金【藍銀匕首】交易**，與原著一致。
- 影子可以透過雨天決行／通訊器遠端出聲，不要求本人出現在342。
- 他目前對Franiya的理解來源：
  - 世界第一黃金Boss實名首殺；
  - 少量既有公開錄像；
  - 第16章流出的短片；
  - 342市場與公會情報。
- **他現在仍看不懂Franiya完整技術。**
- 他能做的是比普通人更快確認：
  - 她絕對不是普通高端玩家；
  - 她的公開戰績與現有錄像之間存在大量缺口；
  - 值得正式記住。
- 影子可提出：
  - 原著式「標價＋一個人情」；
  - 或「價格不抬到張文君的純金幣競價，但附帶人情」。
- Franiya對影子人情本身沒有既定市場價值，也沒有崇拜心理。她可以非常平靜地問：
  > 「人情能換多少金幣？」
  或直接表明自己這次只按交易價值處理。
- 這不是侮辱影子，只是她真的不把名聲本身當貨幣。
- 影子不得因此惱羞成怒；他可以覺得有趣、重新評估她，保留真正頂級玩家的從容。

### E段｜張文君／香檳怪盜的交易與招募

- 第10章兩人已有自然短接觸，因此本章不是陌生人第一次見面。
- 張文君作為高資本盜賊玩家，對Lv8黃金匕首有直接用途；她最後競價成功合理。
- 交易成功後可自然建立**遊戲好友／商業聯絡**，理由限於：
  - 以後Franiya有刺客／盜賊裝備可直接詢價；
  - 張文君可提供高價收購。
- 不自動變成親密朋友。
- 正天已在第10章公開進駐，因此本章**不再重播「正天宣布進駐」**。
- 但Franiya現在已多出「世界第一黃金Boss獨立首殺」這個重大履歷，張文君重新提出正天招募是合理的新條件。
- Franiya可簡短拒絕，核心理由不是「討厭正天」，而是她沒有加入大型公會、被組織管理的需求。
- 張文君可以接受，並保留後續交易關係。

### F段｜暗金任務線索的提供渠道開始回收，但不提前拿到內容

原著第36章在神殿拒絕後建立：
- 神殿方不提供暗金線索；
- 地獄側因此接手；
- 一小時後由地獄使者提供。

本線Franiya已正式成立：
- 月神神殿敵對；
- 十二主神神殿拒絕進入；
- 暗金線索獎勵已存在但無內容。

因此本章可以讓系統／世界機制第一次明確補上：
- **神殿方不會提供這份線索；**
- **將由地獄側使者提供；**
- **仍需等待實際使者接觸。**

為避免把原著章號機械壓縮：
- 本章只建立「提供渠道／等待接觸」即可；
- **不得在本章直接把第43章的地獄骷髏城／死靈法師穆斯塔法內容塞給Franiya。**
- 是否明示「一小時後」可直接沿用原著；若採用，時間必須成為後續真正流逝的時鐘，不可下一段立刻跳到使者抵達。

## 五、Franiya人物反應

本章Franiya不需要因：
- 影子；
- 張文君；
- 50,000金；
- 世界首殺餘波；
- 正天招募

而突然變得興奮或社交化。

主要反應：
- 東西不用 → 賣。
- 價格高 → 知道很值錢。
- 影子很有名 → 記住名字，但不自動產生崇拜。
- 正天邀請 → 沒需求就拒絕。
- 地獄側接暗金線索 → 知道後續會有人來，等即可。

可有很淡的好奇：
- 影子的人情為什麼在這個市場值這麼多；
- 大型公會／資本如何把名聲與關係直接變成交易籌碼。

但她不需要長篇內心分析。
