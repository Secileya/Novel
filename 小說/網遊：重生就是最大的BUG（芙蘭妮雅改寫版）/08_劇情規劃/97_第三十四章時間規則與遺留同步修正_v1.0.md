# 第三十四章時間規則與遺留同步修正 v1.0

> 建立日期：2026-09-26  
> 性質：96號PREWRITE後修／同步稽核紀錄  
> 現行施工仍以更新後的`96_第三十四章PREWRITE核定表_v1.0.md`（內文v1.1）為直接Gate。

## 一、修正原因

遺留稽核發現兩類問題：

1. 第34章PREWRITE把【神隱】章初「仍在3日冷卻」寫得過於靜態，可能誤導成整章都不可用；但第19章實際使用到第34章後半可能已跨過72小時。
2. 「每日登入8小時」與「怪物攻村8小時」曾被誤讀成08:00登入、08:05開戰後必須打到16:05，形成表面5分鐘衝突，需要回原著時間口徑核對。

## 二、原著時間重新核對

依repo內原著TXT既有直接切讀結果（第55章後段＋第62～66章）：

- 系統更新到次日08:00。
- 玩家08:00可以重新登入。
- 約5分鐘後，新手村前方空間劇烈波動，怪物攻村正式啟動。
- 原著公告怪物攻村為8小時活動。
- 第63章說明約30分鐘一波，8小時共16波。
- 原著342在特殊第11波高階NPC事件處理完後就進入守村成功與貢獻結算。

因此：

- 第33章08:05左右開戰是相容原著的，不回修成08:00。
- 「8小時」是名義活動／完整波次窗口，不能推成342必須固定戰到16:05。
- 第34章只施工到第10波，沒有每日登入上限的即時衝突。
- 342特殊第11波後究竟如何結算，仍必須依本線神使／徽章因果重算，不能直接照搬原著。

## 三、【神隱】冷卻修正

正式規則：

- 第19章使用【神隱】，技能明示冷卻3日。
- 3日按實際72小時計。
- 第19章只把使用時點錨在「開服第二日中午前後」，沒有精確分鐘。
- 第34章開場第五日08:29仍在冷卻。
- 第34章後半若故事時間已超過「第19章實際使用時點＋72小時」，技能自然解除冷卻。
- 若正好處於未建立精確分鐘的臨界區，正文以Franiya查看技能UI作合法判定，不由作者補造分鐘錨。
- 冷卻解除＝恢復可用，不等於必須立即使用。
- 【神隱】是否READY不會自動解開第11波【亞當斯】／【達倫】／神使身分判定Gate。
