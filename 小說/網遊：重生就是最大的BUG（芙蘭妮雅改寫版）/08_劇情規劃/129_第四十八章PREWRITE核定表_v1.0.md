# 第四十八章 PREWRITE 核定表 v1.0

> 前置：第47章〈深淵下面有一片森林〉＋128號POSTWRITE＋127號85～94專項Gate。  
> 世界時間：開服第10日，承接第47章同一登入時段。  
> 地點：星辰深淵下層污染森林。  
> 候選章名：**〈劍柄先醒了〉**。  
> 結論：**PASS／正式施工ALLOWED。**

## 一、本章事件引擎

Franiya活著落入星辰深淵下層後，不再把「走路」本身當章節內容；本章直接由Lv17～18暗影魔獸的現場壓力推動，沿任務／污染環境找到失聯者與更深層高階存在，最終讓既有【芬里爾劍柄】第一次在芬里爾分身面前產生完整因果回收。

一句話：

> **她本來是來找貝克，卻先被一個她早就帶在身上的劍柄認出了路。**

## 二、開場硬狀態

- Franiya：Lv10、人族游俠、自由模式；初級游俠轉職未完成。
- 力量23／敏捷17；10點未分配。
- 火狐炎刀因第47章墜落減速已明顯消耗耐久，但未歸零、未損毀。
- 【探索星辰深淵】ACTIVE。
- 【芬里爾劍柄】持有；此前已在亞當斯事件中自行震動／共鳴，證明其氣息可被高階NPC辨識。
- 【芬里爾的呼喚】未使用。
- 【千幻之心】未建第二身份；本章原則上不需要。
- 常規傳送受限已由系統提示確認。
- 目前視野內至少有三頭Lv18【暗影魔狼】；原著另有Lv17【暗影雄獅】等下層魔獸。
- Franiya仍不知道貝克位置、芬里爾分身、斯芬克斯與星辰果／能量。

## 三、場景鏈A｜暗影魔獸不是玩家PVP

本章先完成第47章末壓力，不可一開章直接切對話。

固定：
- 高8級的暗影魔狼／其他魔獸可以靠面板速度、力量、生命與傷害對Lv10角色殼形成真實風險。
- 但若局部存在可執行技術解，Franiya仍不因操作／判斷失誤受傷。
- 戰鬥目標優先是脫離、取得空間與路線，不為經驗值追殺整群。
- 可使用環境、樹根、高低差、重構長兵器／短刃／弓與軌跡控制；彈藥仍需合法箭矢。
- 火狐炎刀墜落後耐久已下降，正文應讓她控制使用強度，而不是剛磨完岩壁又當無限耐久工具。

若出現高階魔獸因更深處存在而不敢追，應先讓Franiya觀察到行為變化，再追索原因；不能因作者知道芬里爾在前面就直接前往。

## 四、場景鏈B｜貝克

原著功能：
- 宙斯神使【貝克】在下層以失神／異常狀態出現。

本線必須承接第41章任務：
- 羅蒙交給Franiya的公開理由之一就是「貝克進入星辰深淵後失聯」。
- Franiya若找到他，第一反應應是確認身份、生命／行動狀態、周邊威脅與能否對話。
- 不自動知道他為何失神；可從裝備、神使標誌、系統名牌或任務反應確認他就是目標人物。
- 貝克不是單純任務物件。若能說話，至少要有殘存目的／恐懼／執念或警告；若當下無法正常對話，也要讓其狀態對後續選擇產生作用。

資訊邊界：
- Franiya知道「找到人」不等於「任務完成」，尤其下層傳送受限且貝克狀態異常。
- 不提前知道芬里爾與貝克之間原著完整事件原因。

## 五、場景鏈C｜芬里爾劍柄先於名字發生

這是本章最重要的本線差分。

推薦因果順序：
1. Franiya接近某一區域時，背包內【芬里爾劍柄】先出現比亞當斯事件更清楚的震動／熱度／方向性共鳴。
2. 她只能確定「與劍柄來源高度相關的東西就在附近」，不能因此直接知道是芬里爾分身。
3. 周圍Lv17～18魔獸的追擊／活動範圍同步出現明顯退避，建立第二條獨立證據。
4. 真正看到高階存在後，Franiya可依既定分身感知能力直接辨識：**眼前並非完整本體，而是與外部本體保持真實連接的分身／化身類存在。**
5. 正式名字／身份由NPC、系統可見資訊、劍柄反應或對話落地，不由作者知識直接倒灌。

禁止：
- 芬里爾分身像第一次見普通冒險者一樣完全忽略劍柄。
- Franiya明明已有劍柄／解救芬里爾／亞當斯共鳴前置，正文卻照抄沈雲原著陌生對話。
- 把【芬里爾的呼喚】自動觸發；它目前仍未使用，除非正文出現明確必要性。

## 六、芬里爾分身人物與對話功能

本章至少完成以下內容中的大部分：
- 芬里爾先處理「妳為什麼帶著我的東西／這件東西怎麼到妳手上」。
- Franiya能回答自己實際知道的來源與【解救芬里爾】任務，不補她不知道的歷史。
- 芬里爾可對她先前遇到亞當斯、劍柄已被辨識產生符合自身世界關係的反應。
- 原著功能「羅蒙隱瞞關鍵任務情報」可保留，但必須讓Franiya先知道**具體被隱瞞的是什麼層級的風險／限制**，再讓芬里爾或系統談規則責任。
- 原著【依創世神規則三倍獎勵】可作本章重大規則資訊，但不要變成百科講解。
- 芬里爾分身是高階智慧存在，不因Franiya只有Lv10就以普通低階NPC口吻對待她；劍柄、她活著下來、她對分身的直接辨識都足以讓他重新評估。

## 七、斯芬克斯是否同章進入

本章允許斯芬克斯登場，但不強制完成全部謎題。

優先順序：
1. 暗影魔獸壓力。
2. 貝克。
3. 芬里爾分身與劍柄回收。
4. 羅蒙隱瞞／三倍獎勵／出口限制。
5. 若容量仍自然，再讓【斯芬克斯】作為「離開條件」正式被召來／出現。

若斯芬克斯登場：
- 保留原著5題、兩次機會、答錯有致命後果、成功可強化兩件裝備的高重量規則。
- 禁止為了章末鉤子只寫「斯芬克斯來了」就斷章；至少讓規則與人物性格真正落地。
- 若開始答題，Franiya多數一般邏輯題應快速處理；真正可形成摩擦的是本地文化、語義雙關、只有《信仰》社會常識才能回答的題型。
- 不機械建立第二身份，不自動找【細雨朦朧大魔王】。

## 八、本章可自然吸收的原著功能

預期主要吸收：
- 第86章後半：下層污染森林與高級怪物。
- 第87章：貝克、芬里爾分身、傳送限制、羅蒙隱瞞／三倍獎勵、斯芬克斯出口條件。
- 第88章前段：斯芬克斯人物／規則，視章容量決定是否開始正式五題。

正常情況約2～3章原著功能→1章本線正文，符合最新章容量規則。

不應在本章硬吃：
- 第89章第二身份建立。
- 第90章完整魔法開發。
- 第91～94章全部強化／星辰能量／回城回報。

這些需依本章結果再Gate。

## 九、人物最小卡

### 貝克
- 當前角色功能：失聯神使／任務追尋目標。
- 當前欲望：至少活著離開／擺脫異常狀態，具體依原著證據窗口施工前再核。
- 知識優勢：知道自己為何進深淵的一部分資訊。
- 弱點：當前失神／異常，未必能完整交流。
- 禁止：只當躺地上的任務標記。

### 芬里爾分身
- 當前角色功能：高階世界存在、劍柄來源、深淵規則與羅蒙隱瞞的揭露節點。
- 欲望：處理自身被封印／痛苦與星辰相關問題；同時必然在意自己的劍柄為何落在Franiya手中。
- 知識優勢：遠高於Franiya，知道深淵、羅蒙、創世神規則與自身本體處境。
- 對Franiya初始立場：不是固定友軍；但劍柄與既有【解救芬里爾】形成特殊接觸基礎。
- 情緒外漏：對自己物件／封印／被隱瞞因果可有明確反應，不寫成全知平板解說器。

### 斯芬克斯（若登場）
- 當前欲望：遵守自身契約／遊戲規則，同時享受題目把人難住的過程。
- 社交方式：高位、帶玩味、不必對低等級冒險者客氣。
- 不能只當五題UI。
