# 第八章原著差分 v1.0

> 對應：第八章〈穿不了，就賣掉〉
>
> 核對重點：原著第11～12章白銀交易、第150～152章哥布林秘境後續、第153～154章江海異動起點。

## 一、白銀裝備交易

### 原著
- 開服早期白銀裝備極度稀缺，會直接引來多個大公會代表報價。
- 裝備屬性可設定給陌生人查看。
- 高品質、無等級限制【精靈秘銀劍】曾以15000金幣成交。
- 交易介面需要雙方放入物品／金幣，各自確認；任一方變更交易內容後需重新確認。
- 沈雲該段另帶故意操控、交易後反殺並搶回裝備等事件。

### 本線
- 不重演精靈秘銀劍交易與反殺。
- 第七章掉落、Franiya本人無法使用的戰士系白銀重甲承擔「第一筆正式高價交易」功能。
- 不虛構該重甲正式專名、完整屬性與未核技能。
- 本章以20000金幣成交；只代表當時供需，不定義全服白銀裝固定價格。

## 二、第一次正式大公會接觸

### 原著
- 白銀裝備與異常戰績很早就會讓職業玩家、公會與資本線介入。
- 沈雲因自身前世情報、操作與衝突迅速與多個公會產生交易／敵對因果。

### 本線
- 前七章不讓十大公會集體追著Franiya跑。
- 世界首通＋可售白銀重甲讓第一次正式接觸條件自然成熟。
- 使用已正式載入且與Franiya有現實私人因果的唐曉煙／錦繡完成第一個公會接觸。
- 唐曉煙必須區分私人救援與公會公事，不拿人情砍價、不索取地下入口。
- Franiya拒絕加入錦繡，但保留正常交易關係。
