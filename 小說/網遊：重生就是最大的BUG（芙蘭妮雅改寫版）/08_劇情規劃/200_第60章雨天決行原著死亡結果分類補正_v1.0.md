# 第60章雨天決行原著死亡結果分類補正 v1.0

> 日期：2026-09-30  
> 狀態：`RETRO_APPLIED / PROSE_UNCHANGED`

## 一、補正原因

第60章正文中，雨天決行先手轉紅後被【折光】以8階【海潮】擊殺回城。

此前部分PREWRITE／交易語句把「雨天決行被擊殺」整體寫成 `REBUILD`，容易產生錯誤印象：彷彿「雨天決行死亡」本身是芙蘭妮雅改寫版新增結果。

正式補正：

- **原著第113章本身已經存在雨天決行死亡／回城結果。**
- 因此：`RAINY_DAY_DEATH_OUTCOME = PRESERVED`。
- 第60章只是在Franiya／折光現行因果下，重新建立導向同一客觀死亡／回城結果的合法實作。

固定：

`PRESERVED_OBJECTIVE_OUTCOME_CAN_COEXIST_WITH_RECALCULATED_CAUSAL_IMPLEMENTATION`

`REWRITE_RESULT != DIVERGENCE_BY_DEFAULT`

## 二、精確拆分

### A｜死亡／回城結果

- `ORIGINAL_EVENT`：原著113雨天決行死亡／回城。
- `PRESERVATION_DELTA = PRESERVED`
- `REWRITE_DISPOSITION`：保留客觀結果，依本線角色與戰鬥因果重新實作。
- `REWRITE_RESULT`：第60章雨天決行先手紅名後，被8階【海潮】擊殺回城。
- `RESIDUAL_STATUS = NONE`

### B｜精確死亡手段

目前現行SOURCE捕捉足以確認原著死亡／回城結果，但沒有鎖死原著最後一擊、完整攻防步驟與精確死亡方法。

因此：

`ORIGINAL_EXACT_DEATH_METHOD = SOURCE_DETAIL_NOT_LOCKED`

`METHOD_SAME_OR_DIFFERENT = NOT_ASSERTABLE_WITH_CURRENT_SOURCE_EVIDENCE`

不得因第60章使用【海潮】就自行宣稱「原著也是海潮擊殺」，也不得反向宣稱「原著不是海潮，所以本線手段不同」。SOURCE沒有證據時不補判。

### C｜死亡後第二身份ID知情

這一項才是真正的結果差異：

- 原著：雨天決行只記得第二身份的臉，不知道其ID。
- 本線：第59章已有旁觀者在可聽範圍公開喊出【折光】，第60章雨天決行本人亦已確認該ID；匿名死亡提示只隱藏提示欄姓名，不會刪除既有記憶。

因此：

`POST_DEATH_ID_KNOWLEDGE = RECALCULATED_DIFFERENT_RESULT`

### D｜第二身份再次改臉

- 原著沈雲後續因錦繡選秀與曝光問題再次調整第二身份外貌。
- 本線折光與主身份僅五官底子相同，帳號、種族、職業、髮色、瞳色、耳型、氣質、氣息都不同，現階段無充分因果再次改臉。

`SECOND_IDENTITY_REFACE = RECALCULATED_DIFFERENT_DECISION`
