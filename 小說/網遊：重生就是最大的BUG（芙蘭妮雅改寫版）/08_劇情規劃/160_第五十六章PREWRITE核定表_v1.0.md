## 三、本章事件順序

### Scene 1｜還沒出城，世界11先落地
- Franiya仍在主城內移動。
- 系統公布【香檳怪盜】／張文君成為世界第11、華夏第10離村玩家。
- 公告延續「前100仍公告」世界規則；公開獎勵只寫已知層：華夏特殊道具＋世界黃金裝，不替未命名物命名。
- Franiya只獲得公開順位資訊，不自動知道張文君現實身分／正天集團完整責任。

### Scene 2｜先還第55章的債
- 額外月神石批次通知：契約鎖定名單的指定件已完成公證集中。
- Franiya折返中央驛站／既有封閉處理室。
- 不改正常批次，不插隊，不追加名單。
- 完成整批啟用處理、逐件公證返件；若原契約未明示總件數，正文不杜撰數字。
- 系統把`EXTRA_BATCH_SERVICE_BARTER_CONTRACT`標記為FULFILLED／CLOSED。

### Scene 3｜五階主城守護者不是一個數字
- Franiya在真正離城前回皇宮使用寶庫資格。
- 皇宮行政端先完成尚未正式落地的五階守護者編制交接。
- 49名金甲衛兵＋統領【馬修】；等級上限不得高於Franiya。
- 交代馬修是羅蒙基於星辰深淵任務／後續星辰果責任配置的優質統領，而非隨機普通隊長。
- 【抄家】：充足理由→封鎖光明主城任一玩家產業1小時→每日1次。Franiya本章不使用。

### Scene 4｜皇家寶庫第四層
- 由皇宮正式入口進入【聖光秘境】。
- 皇家寶庫是七層高塔；Franiya資格只進第四層；1小時選取倒數。
- 守護者不報真名。引導者／規則自然提醒不要對高階守護者亂用探查。
- 第四層以特殊卷軸、技能書、傳送／儲存／功能性道具為主。

### Scene 5｜先選到一件不能拿的
- Franiya看中【毀天滅地卷軸】。
- 只顯示表面：獻祭生命與裝備力量、嘗試激發神咒、方圓萬米、生效後3日不可復活。
- Franiya準備把它列入3件選取時，守護者阻止。
- 守護者這時才說：真正啟動尚需獻祭兩件傳說級裝備。
- 因是守護者阻止她完成已合法選擇，而非Franiya自己改選，按規則補償：選取容量3→4。
- 守護者可補充未來資格：完成星辰果任務＋持有兩件傳說級裝備後可再談帶走【毀天滅地】。

### Scene 6｜四件真正進手
Franiya依自身當前需求選：
1. 超大型空間戒指：約20個標準足球場容量，直接對應2000顆星辰果物流。
2. 【定位傳送機器】：華夏戰區任意坐標定位傳送，CD3個月；解決第一次回返，但非固定往返。
3. 【賦能之書】：只先知道能提升其他道具效果。
4. 【未知圖紙】：只保留未命名／未知用途，不補後文答案。

四件必須在出庫前完成合法保管鏈。

### Scene 7｜賦能後才知道答案
- 出庫後Franiya以【賦能之書】對既有【職業試煉卷軸】使用。
- 【賦能之書】消耗／狀態依原著機制處理為已使用，不重複使用。
- 只有賦能完成後才顯示強化卷軸：1日試煉結束時可匹配2個最高適配隱藏職業，並各轉化為職業卷軸。
- Franiya本章不啟動1日職業試煉；初級游俠任務仍ACTIVE。

### Scene 8｜路線只解了一半
- 【定位傳送機器】已取得，第一次回星辰深淵地下森林已有合法工具。
- 固定星辰果物流仍未完成；【傳送珠】尚未取得，不能把一次性／3月CD定位機寫成固定路線。
- 本章不因作者知道持有人為黑色暗流就讓Franiya追查。
- Franiya重新朝日光森林前進；【採集彩虹鳥的羽毛】仍0／200，下一章進實戰。

### 世界側短鏡頭｜不讓世界只跟著Franiya轉
- 星羽公會正式存在；霓裳羽衣可對「世界11／華夏10＋主城服務熱點」作公開流量判斷，但不得照搬原著追沈雲劇情。
