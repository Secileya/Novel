## 三、從「稽核文」改回「小說」

### 3.1 先寫發生了什麼

正文的先後順序應優先是：

> 人物看見／聽見／想要什麼 → 做了一件事 → 世界回應 → 她／他改了下一步

不是：

> 先解釋這不是什麼 → 排除三種誤解 → 聲明角色不知道什麼 → 最後才做動作

設定防錯應留在PREWRITE、角色知識矩陣與POSTWRITE。正文只在誤解本身會影響當下閱讀時才澄清。

### 3.2 段落要承載完整動作或完整念頭

- 一個敘事段通常承載二至五個相互關聯的句子：動作、觀察、結果與立即判斷可以放在一起。
- 真正要加重的短句可以單獨成段，但稀缺才有力量。
- 若一章過半非空段落都在10字以下，或中位段長低於18字，視為**機械碎段警報**，必須人工重讀；不因對話多就自動判定失敗。
- 禁止把物品名、一個數字、一個動作拆成連續數個獨立段，除非當下真的在刻意營造極端停頓。

### 3.3 降低否定句的比例

優先用正面事實呈現邊界。

- 不要寫「她不是忘了，也不是沒有想到，只是現在不需要」；直接寫她把五點留到轉職後再配。
- 不要連續聲明「不是讀心／不是未來視／不是攻略」；寫出她實際讀到的石縫、力向、聲音、NPC用詞或玩家行為。
- 若一項禁錯已在工作檔寫清楚，正文不再用作者口吻重複。

### 3.4 解題與戰鬥也要有當下壓力

- 每一輪推理都要有新證據、誤判風險、時間／資源成本、現場變化或角色欲望，不只是候選項一直縮小。
- 好奇、期待、不耐、小心、成功後的滿足都可以在Franiya的低振幅下存在。
- 戰鬥不只是「她讀到→正確回應」；對手會記得、會改招、會犯錯，環境、角色殼與任務目標也應提供摩擦。

## 四、原著筆風真正需要保留的東西

1. **快速的事件入口。**開場盡早讓人物遇到具體問題，不先寫長篇無衝突設定。
2. **明確的當下欲望。**升級、賺錢、損回面子、贏過某人、拿任務、救人、收集證據或只是吃一樣東西都可以。
3. **規則與利益直接說清楚。**數值、物價、技能、掉落、時間成本不需要文學化。
4. **輕快但不乾淨的人性。**路人會買瓜、眼紅、負氣申訴、說錯話、追價、裝懂；高手也會狂、會不服、會主觀。
5. **旁白可以有笑點和立場。**不需要每段都像無菌技術說明。
6. **世界在主角之外繼續運作。**但鏡頭要有當事人自己的事，不是只為Franiya做反應報告。
7. **章末鉤子來自利益、危機、新人或新規則。**不只是Franiya「準備去看下一件事」。

## 五、群像反應的鏡頭控制

- 世界級事件當章通常只完整寫一至三個最有戲的節點。
- 其他已建立人物不是被忘記；將他們的後效記入知識矩陣／未完成因果，在下一個有行動價值的場景呈現。
- 同一章若連續出現三次以上「看完資料／沉默／更新檔案」結構，視為**打卡式群像警報**。
- 每個鏡頭開始前要先回答：這個人原本正在做什麼？這條消息打斷、幫助或破壞了他什麼？
- 人物語氣與欲望依`02_角色設定/05_原著人物DNA與立體反應基準.md`；任何未列入十人範例表的新人物，依`02_角色設定/07_全角色動態建模與聲線生成基準.md`即時建模，不能退回通用NPC口吻。

## 六、全角色聲線不是固定名單

- 十名既有人物卡只是一批已建好的高頻樣本，不是角色白名單。未來出現的原著人物、原創人物、只出場一章的重要NPC與後來升格的路人，都必須在第一次承擔劇情功能前建立最小人物卡。
- 原著命名人物至少讀三個證據窗口：首次完整登場、當前事件的連續前後文、後續最能暴露性格或關係的一場戲。不能只抄職業、身份與一句口頭禪。
- 對話前先固定：他現在想從對方手上得到什麼、怕暴露或失去什麼、知道／誤會／不知道什麼、如何看待對方、句子長短與詞彙領域、習慣用哪種社交手段、情緒從哪裡漏出來。
- 同一人物可以因對象、地位、疲勞、利益與秘密而改變語氣；這叫有因果的變化，不叫聲線漂移。禁止把「每個人永遠同一口頭禪」當成立體化。
- 每場重要對話至少同時有雙方目的、資訊落差或理解衝突，以及談完之後的一項實際改變。只有問答功能、系統說明或主角正確結論的對話，視為未完成。

## 七、章容量與事件密度

第40、41章暴露的新問題不是刪減太多字，而是把一個自然長章切成「離村」「皇宮」「清紅／接任務」等單節點章。第40章經月神石公開回修後約四千四百中文字，第41章約三千三百中文字；兩章都仍是事件正典，但不再作章容量範本。第41章另有大量一句一段，不能因事件正確就判定筆風已修好。

### 2026-09-30新硬規則

- 正常長章改為**九千至一萬四千中文字**基本施工帶；若完整事件鏈自然需要，可超過一萬四千，不為字數硬截。舊`8000～12000`從本次更新起全部視為歷史數值，不再作新章施工依據。
- **每一個正式改寫章原則上至少消耗原著連續三章的事件責任，視因果密度可以消耗四章、五章乃至更多。**這裡的「消耗三章」指原著三個章號中具有敘事責任的事件已獲得正式去向，不是只讀到三章，也不是把三章摘要成幾段。
- 若其中某原著章主要是`WORLD_BACKGROUND_LOCKED / SOURCE_RULE_ONLY / VOID_WITH_CAUSE`，只要其功能經正式分類、正文必要後果與POSTWRITE同步已完成，可計入該原著章事件責任的消耗；`READY / DEFERRED / TOUCHED_NOT_CONSUMED`不能計入已消耗最低三章。
- 第59章起PREWRITE必須明列`MIN_ORIGINAL_CHAPTERS_TO_CONSUME = 3`與預計SOURCE範圍；POSTWRITE必須回報實際完整消耗了哪些原著章號，以及哪些只被觸及、不得灌入最低數。

其餘固定規則：

- 一章通常承載四至六個有結果的場景單元，必要時更多，組成一條完整小弧線；每個單元要有進入、摩擦／選擇、結果與餘波。不能完成一項系統操作、見到一名NPC或接到一個任務便收章。
- 原著章號不是我方斷章點。PREWRITE先抓連續因果功能；**最低從三章起算**，自然相連時可完整吸收更多原著章事件。
- **增加承載量不等於壓縮。**篇幅來自更多完整場景、人物欲望、具體對話、規則摩擦、世界細節、行動結果與後效；不得把原著數章摘要成一段，也不得用重複心理、走路、吃飯或系統欄位灌水。
- **長距離旅行保留時間成本，不按日切章。**原著若明確需要數日、長距離或實際物理路程，Franiya線必須保留這段耗時與距離；但途中若沒有足夠事件重量，應使用場景跳接、概括性時間推進、少量關鍵摩擦與資源變化承載，不把「又走了一天／又走一段路」本身擴成獨立一章。
- **旅行只有在本身發生不可替代事件時才完整展開。**例如重要人物相遇、真正危機、重大情報、關係變化、特殊戰鬥、世界規則揭露或會改變後續的選擇。單純路程、常規繞路、重複補給與無新增資訊的安全登出，不構成獨立章理由。
- **Franiya解題更快，不以旅行灌回篇幅。**她若因能力、技術或判斷而比沈雲更快解決某段原著流程，可以直接讓該事件縮短；應把容量交給後續自然相連的原著事件，而不是額外走路、重複偵察或日常操作。
- 第43～46章既有正文不因此規則回修；其事件正典保留，但「逐日展開長距離行程」不得作為未來節奏模板。
- PREWRITE必須列出「主事件弧＋次事件弧＋人物／世界後效＋章末局勢變化＋至少三章原著事件消耗計畫」，並回答本章還能自然吃下哪些後續節點。除非使用者明確另行要求，禁止只消耗一至兩個原著章便收章。
- 原著研究應在寫前一次讀足本章整條事件鏈與關鍵人物證據窗口，再一次交付完整章；不得每處理一個小節點便停下等待下一輪。
- POSTWRITE容量稽核：中文字數、完整場景單元數、本章實際完整消耗的原著章號／事件功能、只觸及未消耗的章號、章末是自然局勢變化還是任意切斷。只報總字數而不查事件密度，不算通過。

例外：只有使用者明確指定短章／間章／單一場景章時，才可低於九千字或低於三個原著章事件消耗；不能由模型自行把「高重量場景」當成少消耗原著章的例外。

## 八、寫前與寫後快速閥門

### 寫前

- 本章的一句事件引擎是什麼？
- 除Franiya外，至少一名角色自己想要什麼？
- 原著同功能場景的節奏、笑點、利益與第一層後果是什麼？
- 因Franiya取代沈雲而失效的只是哪些專屬因果？哪些人物欲望與世界行為仍應存在？
- 本章有哪些完整場景單元？如果只列出一到兩個小功能，為什麼不把後續自然節點一併寫入？
- 本章預計完整消耗哪至少三個原著章號？每章責任如何落地？
- 本章新出場人物的最小人物卡與三個原著證據窗口是否已建立？
- 若本章跨越數日或長距離，哪些段落真的有事件重量？其餘路程是否應以時間跳接或概括推進，而不是按天切章？

### 寫後

- 搜尋連續的「不是」「沒有」「不知道」「不需要」；能否改成現場事實？
- 搜尋獨立「——」與過密的十字以下段落。
- 拿掉人名，主要角色的對話是否還能分辨？
- 是否出現兩個以上只會查資料與更新標籤的鏡頭？
- 是否用作者解釋代替了笑點、尷尬、衝突、風險或行動後果？
- 是否誤把「尊重知情邊界」寫成所有人都比現實更理性、更有禮？
- 本章是否達到九千至一萬四千字正常施工帶，或有使用者明確例外？
- 本章是否完整消耗至少三個原著章事件責任，而不是把`TOUCHED_NOT_CONSUMED`灌成完成？
- 本章是否達到足夠的自然事件承載量，而不是在「接任務／準備出發」任意斷開？
- 拿掉人名與身份標籤後，新人物的欲望、說話節奏與社交手段是否仍可分辨？
- 若本章存在長距離旅行，是否保留了真實耗時與資源成本，同時避免把無事件的行程切成多章？
