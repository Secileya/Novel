# 原著改寫長期循環 v1.0

> 狀態：本專案固定工作流程。
>
> 用途：讓任何新對話／新模型都能持續研究《网游：重生就是最大的BUG》、重算芙蘭妮雅版因果、規劃篇章、寫正式正文並完成 GitHub 交接，而不依賴聊天記憶。
>
> 上位流程：`小說/00_總索引與交接/NOVEL_WORKFLOW_PROTOCOL.md`。若本檔與上位流程衝突，以上位流程為準；本檔負責補充本專案特有的「原著母本 → 差分 → 芙蘭妮雅版正文」循環。

## 0. 一句話流程

**恢復專案狀態 → 定義本輪目標 → 查原著連續前後文 → 拆原著功能與人物知情 → 對照芙蘭妮雅／本線設定重算因果 → 標記保留／改寫／作廢 → 同步設定 → 做篇章／章節核定 → 寫正文 → 更新連續性與原著差分 → commit。**

這個循環可以重複使用到全文結束。

# P1｜先定義本輪問題，不無界限讀原著

每一輪先寫出一個明確研究單位，例如：
- 原著第1～15章開服篇；
- 切爾文與精靈語；
- 第一塊高價裝備；
- 清酒牧歌第一次重要登場；
- 現實異能界第一次介入；
- 某場公會衝突是否仍會發生。

不得以「把1822章全部重新讀一次」作為每輪前置。

## 本輪研究單位至少要有

- 原著章節範圍／事件名稱。
- 為什麼現在需要研究它。
- 它可能影響哪個本線設定／篇章。
- 是否會直接進下一章。

# P2｜原著證據稽核

## 2.1 找位置

優先使用全文搜尋定位：
- 章名。
- 人物名。
- 裝備／技能／公會名。
- 關鍵台詞或事件詞。

## 2.2 不能只看搜尋片段

定位後必須讀**連續前後文**。

最低要求不是固定章數，而是讀到能回答：
1. 事件怎麼開始；
2. 人物當時知道什麼；
3. 為什麼作出這個決定；
4. 事件直接結果；
5. 後面至少第一層後果。

一般事件可讀前後 1～3 章；跨章大事件要擴大，直到因果完整。若篇章很長，不以章數硬切。

## 2.3 每個原著節點固定抽六項

1. **原著事實**：實際發生什麼。
2. **人物知情**：當事人當時知道／不知道什麼。
3. **觸發條件**：事件為何會發生。
4. **敘事功能**：作者用它完成什麼。
5. **直接後果**：人物、物件、聲望、勢力、經濟有什麼變化。
6. **後續依賴**：哪些後面事件依賴它。

## 2.4 原文來源不足

若完整 TXT 在當前對話不可取得：
- 先看 GitHub 是否已有原文或研究摘錄；
- 沒有就明確標「原著全文不可核對」；
- 不得用模型印象補細節；
- 可以做不依賴原文的設定整理，但不能宣稱完成原著差分。

# P3｜差分重算

核心公式：

**芙蘭妮雅版現況 = 原著尚可成立的基線 + 芙蘭妮雅／本線已固定條件 − 依賴沈雲特有前提的部分 + 新因果自然導出的後果。**

每個原著節點只能進以下狀態之一：

- **保留**：原條件在本線仍成立。
- **改寫保留**：事件類型仍成立，但人物動機／結果重算。
- **功能保留、事件換掉**：只保留敘事功能。
- **延後／重排**：仍可發生，但時點改變。
- **作廢**：成立前提已消失。
- **待核對**：證據不足。

## 差分時必查的芙蘭妮雅固定條件

- 她不是沈雲，不繼承重生攻略。
- 她有自己的漫長人生、傭兵／暗殺／滲透／組織經驗。
- 她的反應、感知、思考、身體控制不是普通人量級。
- 她對各種語言都能在實際接觸後極快理解、反推並完整掌握；精靈語只是案例。
- 她不屬於本地異能體系。
- 遊戲系統不能天然支配她本體。
- 無敵幀、強制位移等正常成立，主要因她願意按照遊戲規則玩。
- 正常遊戲時她主動壓低高尺度能力，不等於能力被封印。
- 世界級玩家與異能強者必須保留真正專業性，不能當墊腳石。
- 世界會自行運轉，Franiya 不包辦所有首殺、事件與榜單。

## 反應重算

每個重要事件至少檢查：
- 普通玩家會怎麼理解；
- 真正懂技術的人會怎麼理解；
- 大公會／工作室會怎麼評估；
- 資本／媒體是否有利益；
- 異能圈是否已經有合理理由注意；
- 哪些人根本不在乎。

禁止把所有反應合併成「全服震驚」。

# P5｜篇章與章節規劃

## 長章制固定規則

本專案採**長章制**，不追求傳統網文每章數千字的切法。

固定原則：
- 一章可以承載大量內容；數萬字完全可以接受。
- 不設定「我方1章＝原著1章」或任何固定換算比例。
- 一章可以吸收原著數章、十數章，甚至更多事件，只要本線因果仍連續、閱讀節奏仍清楚。
- 不因字數已長就機械斷章；優先在一個完整的小弧線、關係轉折、事件階段或明確局勢變化完成後再斷。
- 可以在同一章內使用多個場景、小節、時間推進、論壇／公會／其他玩家視角，使章內資訊量變大而不混亂。
- 若某段原著內容在 Franiya 版沒有新價值，可壓縮成幾段；若某個原著小事件因她介入產生大量新後果，也可以在一章內充分展開。
- 「章很長」不是拖戲理由。每一大段都必須增加角色、因果、規則、情報、世界反應或情緒價值。
- 後續 PREWRITE 不再以「這章只能完成一個小功能」為預設，而是先問：**這一章自然能完整吃下多少個連續事件節點？**

篇幅只作方向，不作硬門檻：
- 常態可落在約一萬至數萬中文字。
- 若事件密度與因果需要，超過數萬字仍可繼續，不必為了章長硬拆。
- 反之，真正需要短章時也可以短，但不能把短章當預設格式。

目前第一章〈少一層〉篇幅較短，只代表開篇初版已落地，**不得把它當成本線後續章長範本**。後續章節按長章制處理。


## 5.1 篇章級先做事件鏈

每個小篇章至少列：
- 起點。
- 終點。
- 中間 3～8 個必要因果節點。
- 哪些原著事件被保留／替換。
- Franiya 的選擇如何讓後續偏離原著。
- 同期其他玩家／公會／異能圈在做什麼。
- 篇章結束後世界留下什麼不可逆變化。

不要一開始把幾十章逐章鎖死；先鎖因果骨架。

## 5.2 單章核定表

正式寫一章以前，固定回答：

- **時間／地點／POV**
- **章首狀態**
- **本章核心看點**
- **本章原著錨點**
- **哪些地方已經因差分失效**
- **Franiya 本章知道／不知道什麼**
- **其他關鍵人物知道／不知道什麼**
- **Franiya 本章願意使用到哪個力量尺度**
- **本章至少一條世界自主運作線**
- **本章結束時改變什麼**
- **下一章自然入口**

「世界自主運作線」不代表每章都要切 POV，只要求作者先知道鏡頭外的世界沒有停止。

只有以下全部成立才能寫正文：

1. 相關穩定設定已讀。
2. 本章涉及原著時，原著前後文已完成 P2。
3. 相關事件已完成 P3 差分。
4. 沒有未處理的高影響設定衝突。
5. 單章核定表已完成。
6. 最新正文斷點已確認。
7. 本章不會偷偷把候選寫成既成事實。

判定：

**PROJECT_PREWRITE = PASS**

未 PASS 時只做研究／規劃，不輸出正式正文。

# P7｜正式正文

## 寫作時固定原則

- 原著是母本，不逐句、不逐章換名重播。
- 保留原著人物人格時，仍要讓本線既成因果真正影響他們。
- 不用作者旁白提前公開 Franiya 全能力。
- 她能做到 ≠ 她每次都會做。
- 她不知道玩家黑話名稱時可以問，但不得因此被寫成看不懂底層現象。
- 她能快速學各種語言，但語言能力不等於知道攻略、歷史秘聞或地方文化全部答案。
- 頂尖玩家可以讓她第一次看見新的遊戲規則，但不應靠普通人的反應速度／假動作長期壓住她。
- 遊戲判定與她的真實作用可能矛盾；是否配合由她選擇。
- 外貌反應、技術反應、勢力反應分散。
- 每章至少有一個刪掉後會真正失去的角色／因果／資訊／情緒／世界價值。

# P9｜週期性總檢查

觸發：
- 一個小篇章結束；
- 或連續約 5～10 章沒有做總盤點；
- 或重大原著分歧成立；
- 或遊戲／現實融合階段切換。

固定檢查：

### 因果
- 有沒有仍沿用其成立前提已被刪掉的原著事件？
- 有沒有因 Franiya 的選擇應該提早／延後／消失的事件？

### 人物
- 原著人物是否被寫成只為 Franiya 服務？
- 頂尖高手是否仍有自己的成長與成果？
- 誰和 Franiya 的關係已經實際改變？

### 情報
- 公開資訊、圈內資訊、異能組織機密是否混在一起？
- 論壇傳聞有沒有被作者誤當事實？

### 社會
- 裝備、首殺、公會、貨幣、異能與現實資本是否留下後果？
- 鏡頭外的公會、玩家、異能者是否仍在行動？

### Franiya
- 有沒有不小心把她降成普通玩家？
- 有沒有反過來每場都用高階力量破壞遊戲感？
- 有沒有把「不知道術語」寫成「不理解現象」？
- 有沒有把通用語言學習誤縮成只會精靈語？

完成後把需要修正的項目直接落盤。

# 10. 研究進度的唯一記錄方式

長篇原著不能靠聊天記憶記「讀到哪」。

唯一長期記錄放在：

`04_連續性與索引/05_研究與改寫進度.md`

每次原著研究後至少更新：
- 已完整連續核對範圍；
- 只做過關鍵詞／片段核對的範圍；
- 尚未核對；
- 已建立差分的事件；
- 下一個研究目標。

**「片段核對」不得寫成「完整讀完」。**

# 11. 固定停止條件

一輪工作做到以下條件就停，不無限擴張：

### 研究輪
- 本輪問題已有足夠原文證據；
- 已完成差分；
- 已同步 GitHub；
- 下一個研究問題已記錄。

### 規劃輪
- 小篇章骨架能支撐下一章；
- 不需要先把後面數十章全部決定。

### 正文輪
- 正式章節完成；
- POSTWRITE／設定同步完成；
- 下一個自然入口已留下。

這個停止條件用來避免每次為寫一章都重新研究整本原著。

# 12. 最終目標

本流程不是要讓改寫「越來越不像原著」，也不是要強迫它「照原著走」。

目標是：

> **每次都先知道原著為什麼會那樣發生，再根據芙蘭妮雅與本線已成立的世界條件，推導現在還會不會那樣發生。**

只要這個因果鏈一直維持，本線即使後期與原著產生巨大分歧，也仍然是有來源、有承接、有世界重量的長篇改寫。
