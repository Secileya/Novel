# P0.5｜有效性、過時與矛盾稽核

每次接手、使用者修正設定、正式章節完成後都要執行；不等到5～10章總檢查才處理。

## 固定檢查

1. 以 `01_章節` 最高正式章號與正文實際章末為起點，不先相信交接或摘要。
2. 比對交接、當前狀態、未完成因果、角色知識矩陣、研究進度、章節索引與總索引中的：最新章號／標題／停點／下一個PREWRITE。
3. 搜尋仍在有效文件中的舊章號、「待定但正文已固定」、「尚未完成但正文已完成」、「下一章卻指向已完成章」、已被後修推翻的規則。
4. 分清：正式正文、有效工作檔、候選規劃、歷史施工紀錄、已作廢版本。
5. 有效工作檔與最新正式正文衝突時，以最新正式正文與後期明確修正為準，回頭改工作檔；不得拿舊工作檔覆蓋正文。
6. 不能只在檔尾追加新說法。舊說法若已失效，直接刪除、改寫或在原處標成歷史／已取代，避免全文搜尋再次撈到它。
7. 歷史PREWRITE／章綱可以保留當時狀態，但檔首必須說明適用章節與是否已被正式正文取代。
8. 若發現正文級矛盾或已確認的修文債，先修正文與下游摘要，再開始下一章。
9. 原著來源先過完整性／連續性檢查；章號缺失、重複或不在現有TXT時，不得假稱已核對。

## P0.5 PASS

- 已被推翻的舊資訊不再以有效語氣殘留。

# P2｜原著證據稽核

## 2.1 找位置

優先使用全文搜尋定位：
- 章名。
- 人物名。
- 裝備／技能／公會名。
- 關鍵台詞或事件詞。

## 2.2 不能只看搜尋片段

定位後必須讀**連續前後文**。

最低要求不是固定章數，而是讀到能回答：
1. 事件怎麼開始；
2. 人物當時知道什麼；
3. 為什麼作出這個決定；
4. 事件直接結果；
5. 後面至少第一層後果。

一般事件可讀前後 1～3 章；跨章大事件要擴大，直到因果完整。若篇章很長，不以章數硬切。

## 2.3 每個原著節點固定抽六項

1. **原著事實**：實際發生什麼。
2. **人物知情**：當事人當時知道／不知道什麼。
3. **觸發條件**：事件為何會發生。
4. **敘事功能**：作者用它完成什麼。
5. **直接後果**：人物、物件、聲望、勢力、經濟有什麼變化。
6. **後續依賴**：哪些後面事件依賴它。

## 2.4 原文來源不足

若本輪所需的原著章節在現有TXT中不可取得、章標不連續或來源完整性不足：
- 先看 GitHub 是否已有原文或研究摘錄；
- 沒有就明確標「原著全文不可核對」；
- 不得用模型印象補細節；
- 可以做不依賴原文的設定整理，但不能宣稱完成原著差分。

# P3｜差分重算

核心公式：

**芙蘭妮雅版現況 = 原著尚可成立的基線 + 芙蘭妮雅／本線已固定條件 − 依賴沈雲特有前提的部分 + 新因果自然導出的後果。**

## 3.0 原著事件時間錨點＋因果重建優先原則

**核心：原著主角實際經歷過的重要事件，原則上先視為「應在相近世界內時間重新評估並盡量保留」，而不是因Franiya不是沈雲就先刪。章號只用來定位來源；真正決定本線何時發生的是原著事件的遊戲日／現實日／時段與前置條件。**

差分順序固定為：
1. 先找出原著事件的**世界內時間錨點**。
2. 拆出事件的**核心世界因果／制度因果**，與沈雲專屬包裝分開。
3. 只移除真正不能轉移的沈雲專屬部分（重生情報、專屬舊仇、只能由其戀愛關係成立的選擇、未來物資等）。
4. 對其餘部分，主動尋找Franiya線已存在的人物、勢力、利益、公開戰績、任務、地點或社會規則，建立新的自然觸發理由。
5. 只要新因果成立，事件本體／人物／世界反應應優先在接近原著時間窗落地；人物反應、關係、結果可完全不同。

**兩位原著女主是標準例子：**Franiya不會照沈雲原線與她們發展同樣的戀愛，因此「只能靠戀愛本身成立」的橋段不照搬；但只要某次相遇、襲擊、家族事件、任務、合作、救援、遊戲交叉、公會／異能組織事件並非百分之百依賴戀愛關係，它就不應因戀愛結果不同而整段消失，而應改用Franiya自己的關係與動機重建。

**千人圍堵是另一個標準例子：**沈雲與黑色暗流的私人仇怨只是原著動機的一部分；更深的世界因果還包括「大型公會不希望出現第二個影子」、影子曾由獨立高手成長到可與超級公會平起平坐、以及黑色童話／四海聯盟／百川書院曾參與壓制影子崛起並圍殺夜色無邊的歷史慣性。當Franiya以無大型公會歸屬的獨立玩家身分公開拿下世界第一黃金Boss、迅速累積高端技術與名聲後，她同樣會進入這套既有風險模型。因此不能只因「她沒有沈雲那份私人仇恨」就把圍堵事件整體刪掉；應重算發起者、參與者、規模、成本、方式與Franiya反應，並優先在原著相近時間窗評估落地。

只有當一個事件的**全部成立理由**都依賴沈雲不可轉移的專屬條件，且不存在世界規則／人物利益／新因果可重新建立時，才真正作廢。

## 3.1 主角差距放大原則

原著沈雲的長線本身就是「與同期玩家／公會高手逐步拉開差距」；移植到Franiya時，這個趨勢不能被壓平，正常情況下只會**更早、更穩、更明顯**。

固定判斷：
- 原著沈雲的同期優勢可作為參考下限，不是Franiya必須被壓回去的目標值。
- Franiya沒有重生攻略，但她本人的戰鬥經驗、感知、控制、即時建模、完美時機與武器／戰術理解遠高於原著同期玩家；一旦遊戲角色的等級、屬性、技能、武器與資格逐步解鎖，她能把更多真實能力轉譯進《信仰》，因此**技術差距會隨系統承載能力提升而放大**。
- 差距不只看等級。還包括：單刷上限、擊殺效率、**零無效動作**、資源利用、對未知機制的理解速度、多線戰鬥密度、裝備／技能轉化效率、穩定性、公開戰績與高端圈評價。
- 她主動自限只用來保留遊戲體驗，不等於主動把自己調成「和世界頂尖玩家差不多」。若正常規則內已足以遠超同期，就應讓差距真實成立。
- 其他世界級玩家仍須保持專業與成長；**差距變大靠Franiya更強，不靠把別人寫笨。**
- 若原著事件的壓力來源只是「沈雲當時還不夠強／操作仍有人類上限」，不能直接套給Franiya；必須改由真正的系統硬限制、資格、等級／裝備輸出門檻、資訊黑箱、組織規模、法律／社會後果或她自己的選擇建立壓力。
- 反過來，原著「第二個影子」「獨立高手威脅大公會」等社會反應，在Franiya線通常只會更早、更強，除非她刻意隱匿且外界缺乏證據。她現在已公開黃金Boss首殺，因此此類風險評估應上調而不是下調。

## 3.1.1 世界級玩家也不等於Franiya的同層對手

- 世界級玩家保留真實專業性、歷史戰績與弱勝強能力；不能因Franiya存在就把他們寫成普通玩家。
- 但Franiya過去本來就能在真實生死環境中靠技術／經驗弱勝強；進入《信仰》後又屬更高層存在落入較低層規則框架。**她被限制的是角色輸出端，不是戰鬥理解端。**
- 因此只要角色殼滿足有效輸出條件，世界級／頂級玩家的純技術層面不構成真正難題；相對處理難度可以低於「切菜」。
- 寫作時必須同時成立兩件事：對手確實很強、對其他玩家有充分重量；Franiya仍能用零無效動作與最短解快速拆掉。
- 若事件仍需保持壓力，改用角色硬限制、等級／裝備／資格、群體規模、封鎖面、地形、情報黑箱與後果，而不是虛構一個能靠同層操作把Franiya拖入苦戰的人類玩家。

## 3.1.2 原著事件節點保留，不保留原著數字上限

- 原著重要事件要優先保留的是**時間窗、事件功能、世界因果與社會後果**，不是沈雲當時的精確擊殺數、耗時、受傷量、技能使用次數或「剛好做到哪裡就離開」。
- 當Franiya在同一節點具備更高效率、更大相對差距與零無效動作時，結果可以自然放大：更快、更乾淨、殺得更多、受傷更少、封鎖瓦解得更徹底，外界反應也應同步更大。
- 例如原著千人圍堵中，沈雲以【神隱】反殺142人後突破，包圍圈已被敘述為名存實亡。Franiya版若依她當時性格、紅名／掉落規則、時間成本與最佳解判斷選擇直接清場，**殺數百人乃至把約千人全部擊殺都屬合法改寫方向**；不能因原著只殺142人就把142當上限。
- 「全殺」目前屬**允許且高度相容的結果候選，不在尚未建立正式PREWRITE前鎖死**。正式落地時仍要核對Franiya當時是否有理由停手、是否存在逃跑／撤退成功者、紅名與後續成本，以及她認為最快最乾淨的解是否就是清空全場。
- 若Franiya真的近乎全滅／全滅千人，敘事尺度也必須跟著升級：不應只沿用原著「包圍圈名存實亡」同等反應，而要讓直播、媒體、公會高層、世界級玩家、普通玩家與幕後發起者出現更大、更分層的重新評估。
- 放大結果不能靠把對手寫笨；必須建立在Franiya本身的高維理解、零無效動作、角色當時可用的有效輸出與她自己的決策上。

## 3.1.3 「同一事件節點＋Franiya版本」只是通用改寫方法，不是千人圍堵特例

使用者補充：「千人圍堵可能從原著142殺放大成數百乃至約千人全滅」只是**符合原著事件經歷節點、但由Franiya形成自己版本**的一個示例；同一方法要普遍套用到其他原著主角節點。

可參考的非封閉例子：
- **赫爾墨斯黃金寶箱／神使邀請**：事件節點保留；Franiya仍可遇到同一套神明關聯，但她拒絕／接受的理由、武器使用方式、後續神殿關係都按她自己的人格與能力重算。
- **智腦提前接管**：原著章號在後，但世界內時間是第一夜，因此Franiya線可更早在本線章序落地；保留的是時間錨與世界事件，不是原著章號。
- **簡雨朧／神恩守護項鏈**：Franiya不走沈雲同款戀愛，但任務情報交換、平行任務交叉、後續合作仍可保留並重建。
- **千人圍堵／公開PvP**：保留大公會壓制獨立天才、華夏觀察者直播與技術分析節點；發起理由、擊殺數、打法、碾壓程度與後續震動按Franiya放大。
- **疾風狼／芬里爾節點**：若Franiya在對應時間與路線自然抵達，世界級／神級任務、芬里爾認可、神器線可作原著節點保留；但她沒有沈雲的前世知識，辨識、選擇、對話、任務接受理由與處理方式必須重算。
- **兩位原著女主的非純戀愛事件**：襲擊、任務、家族／公會／異能事件、合作與救援，只要不是百分之百靠戀愛關係本身成立，就優先找Franiya自己的理由落地。

固定提醒：**例子不是清單上限。**未來重讀每一段原著，都要主動尋找「事件核心功能／時間窗／世界因果」可否保留，再做Franiya版，而不是只在已列出的幾個事件上使用此方法。

## 3.1.4 Lv8是最後一個既有硬等級時間錨；其後改按實際經驗自然成長

- 現行「開服第四日下午才到Lv8」保留，因這是此前為修復第7～8章過度壓縮、替原著第二～第四日重要事件留出世界時間而建立的**既有硬時間錨**。
- **不回頭修改已完成正文。**第7～16章中Franiya在Lv7期間已擊殺大量Lv8變異魚人、包含Lv8黃金Boss卻仍未升級，與早期少量擊殺就快速升級相比確實存在數值觀感差；此處視為既成正典／歷史施工痕跡，不再倒灌重算經驗。
- 但從今後施工開始，必須恢復經驗與等級的一致性：大量越級擊殺、Boss、任務或其他明確給經驗的行為若持續發生，等級應自然推進；不能再只為了等原著事件而無理由卡級。
- **Lv8達成後，不再自動繼承「某天必須是Lv9／Lv10」等固定時間表。**後續等級由本線實際經驗獲取、任務、怪物等級、擊殺密度與已確認系統公式自然決定；若未有明確EXP數值，至少按前後相對量保持自洽。
- 原著事件仍按世界時間錨保留，但**事件時間與Franiya等級解耦**：到某原著節點時，她可以比沈雲原線等級更高；此時重算敵我數值、任務條件、裝備資格與事件結果，不得再把她壓回原著等級。
- 若未來確實需要新的等級硬錨，必須有新的明確理由（例如系統等級上限、轉職門檻、經驗封鎖、使用者另行核定），不能僅因「原著當時幾級」就建立。
- 後續若出現「短時間殺了大量高等怪仍完全不升級」，必須有正文／設定可支持的原因；否則視為連續性問題。

## 3.2 技術公開≠技術被摸清

- 公開錄像、首殺與高手關注只能證明「外界開始看見異常」，不能自動等於職業圈已理解Franiya的技術。
- 第14～16章屬於**關注／素材累積期**：可以提高觀察優先級、收集錄像、提出錯誤或部分正確猜測，但不得建立完整技術模型。
- 第一個適合讓華夏觀察者、天痕等真正開始拆出Franiya可觀測技術輪廓的時間點，優先放在**千人圍堵／大規模公開PvP之後**；高壓、多目標、多人職業配合、較長戰鬥時長與多角度慢放素材才足以支撐專業分析。
- 即使到該節點也只是「開始摸到輪廓」，不是看穿她的真實能力。
- 千人圍堵中的敵方仍須保持專業性；但相對Franiya而言，**個體與小隊層面的直接處理難度仍很低，接近切菜**。數量主要增加的是路線、封鎖、時間與組織成本，不應被寫成一千個人各自都能讓她苦戰。

每個原著節點只能進以下狀態之一：

- **保留**：原條件在本線仍成立。
- **改寫保留**：事件類型仍成立，但人物動機／結果重算。
- **功能保留、事件換掉**：只保留敘事功能。
- **延後／重排**：仍可發生，但時點改變。
- **作廢**：成立前提已消失。
- **待核對**：證據不足。

## 差分時必查的芙蘭妮雅固定條件

- 她不是沈雲，不繼承重生攻略。
- 她有自己的漫長人生、傭兵／暗殺／滲透／組織經驗。
- 她的反應、感知、思考、身體控制不是普通人量級。
- 她對各種語言都能在實際接觸後極快理解、反推並完整掌握；精靈語只是案例。
- 她不屬於本地異能體系。
- 遊戲系統不能天然支配她本體。
- 無敵幀、強制位移等正常成立，主要因她願意按照遊戲規則玩。
- 正常遊戲時她主動壓低高尺度能力，不等於能力被封印。
- 世界級玩家與異能強者必須保留真正專業性，不能當墊腳石。
- 世界會自行運轉，Franiya 不包辦所有首殺、事件與榜單。

## 原著人物／事件的時間窗與延後登場

原著人物在原本時點沒有足夠理由出場，**不等於人物永久作廢**。正式差分時必須區分：

- **時點失效**：原著當下的登場理由因本線前提改變而消失。
- **事件改寫／作廢**：原事件本身不能照搬，但人物仍可能保留。
- **人物永久作廢**：只有明確核定該人物本線不採用時才成立，不能由「這次沒出場」自行推導。

只要重要原著人物仍具有長線人物、關係、勢力或事件重量，就要放入**延後登場追蹤**。後續每次 PREWRITE 重新檢查第一個自然窗口，例如Boss／掉落／裝備／交易、論壇與職業圈情報、公會利益、現實外出／求救／工作／組織事件、既有人際關係、地點與任務交會。

「盡快登場」是指**在第一個符合人物動機、情報邊界、地點與因果的窗口優先載入**，不是為補名單硬塞巧遇。

另固定採**遊戲／現實雙時間軸對位**。如果原著主角在某個現實時段會登出、外出或進入現實事件，本線不能只因目前遊戲線寫得順就無限把 Franiya 留在線上；必須判斷她是否有自己的合理理由離開遊戲。反之，沒有合理理由時也不能只為對齊原著強迫她下線。

典型案例：原著「極限速度流」相關人物原本因野豬王／白銀裝備等利益鏈在現場出現；本線未觸發同一前提，因此原時點不硬搬，但人物線改列延後追蹤，之後在白銀裝備、Boss、交易、論壇熱度或職業圈情報真正形成交集時重新評估。

## 反應重算

每個重要事件至少檢查：
- 普通玩家會怎麼理解；
- 真正懂技術的人會怎麼理解；
- 大公會／工作室會怎麼評估；
- 資本／媒體是否有利益；
- 異能圈是否已經有合理理由注意；
- 哪些人根本不在乎。

禁止把所有反應合併成「全服震驚」。

# P5｜篇章與章節規劃

## 長章制固定規則

本專案採**長章制**，不追求傳統網文每章數千字的切法。

固定原則：
- 一章可以承載大量內容；數萬字完全可以接受。
- 不設定「我方1章＝原著1章」或任何固定換算比例。
- 一章可以吸收原著數章、十數章，甚至更多事件，只要本線因果仍連續、閱讀節奏仍清楚。
- 不因字數已長就機械斷章；優先在一個完整的小弧線、關係轉折、事件階段或明確局勢變化完成後再斷。
- 可以在同一章內使用多個場景、小節、時間推進、論壇／公會／其他玩家視角，使章內資訊量變大而不混亂。
- 若某段原著內容在 Franiya 版沒有新價值，可壓縮成幾段；若某個原著小事件因她介入產生大量新後果，也可以在一章內充分展開。
- 「章很長」不是拖戲理由。每一大段都必須增加角色、因果、規則、情報、世界反應或情緒價值。
- 後續 PREWRITE 不再以「這章只能完成一個小功能」為預設，而是先問：**這一章自然能完整吃下多少個連續事件節點？**

篇幅只作方向，不作硬門檻：
- 常態可落在約一萬至數萬中文字。
- 若事件密度與因果需要，超過數萬字仍可繼續，不必為了章長硬拆。
- 反之，真正需要短章時也可以短，但不能把短章當預設格式。

目前第一章〈少一層〉篇幅較短，只代表開篇初版已落地，**不得把它當成本線後續章長範本**。後續章節按長章制處理。


## 5.1 篇章級先做事件鏈

每個小篇章至少列：
- 起點。
- 終點。
- 中間 3～8 個必要因果節點。
- 哪些原著事件被保留／替換。
- Franiya 的選擇如何讓後續偏離原著。
- 同期其他玩家／公會／異能圈在做什麼。
- 篇章結束後世界留下什麼不可逆變化。

不要一開始把幾十章逐章鎖死；先鎖因果骨架。

## 5.2 單章核定表

正式寫一章以前，固定回答：

- **時間／地點／POV**
- **章首狀態**
- **本章核心看點**
- **本章原著錨點**
- **遊戲內／現實時間對位**：本章開始與結束時兩條時間各在哪；是否有原著重要現實事件已進入合理窗口。
- **原著人物延後登場檢查**：尚未自然進場的重要人物中，本章是否出現第一個足夠合理的載入條件。
- **哪些地方已經因差分失效**
- **Franiya 本章知道／不知道什麼**
- **其他關鍵人物知道／不知道什麼**
- **Franiya 本章願意使用到哪個力量尺度**
- **本章至少一條世界自主運作線**
- **本章結束時改變什麼**
- **下一章自然入口**

「世界自主運作線」不代表每章都要切 POV，只要求作者先知道鏡頭外的世界沒有停止。

# P7｜正式正文

## 原著重要人物／事件的敘事重量

本線不逐章重播原著，但**重要原著人物與重要原著事件一旦正式載入，不得因此被降格成概要、幾句旁白或只剩功能性替代**。

正式使用前要有足夠原著證據覆蓋人物核心性格與行為邏輯、當時知情、重要關係網與立場、事件起因與觸發條件、作出決定的理由、直接結果與至少第一層後果。

正文篇幅按人物／事件本身的敘事重量決定。可以改寫經歷、地點、相遇方式與結果，但不能把重要人物只留下名字、公告、報告或一句「之後認識了」。如果本章只適合建立遠景痕跡，則明確視為**尚未正式登場**，後續仍須在合理窗口給足場景。

## 寫作時固定原則

- 原著是母本，不逐句、不逐章換名重播。
- 保留原著人物人格時，仍要讓本線既成因果真正影響他們。
- 不用作者旁白提前公開 Franiya 全能力。
- 她能做到 ≠ 她每次都會做。
- 她不知道玩家黑話名稱時可以問，但不得因此被寫成看不懂底層現象。
- 她能快速學各種語言，但語言能力不等於知道攻略、歷史秘聞或地方文化全部答案。
- 頂尖玩家可以讓她第一次看見新的遊戲規則，但不應靠普通人的反應速度／假動作長期壓住她。
- 遊戲判定與她的真實作用可能矛盾；是否配合由她選擇。
- 外貌反應、技術反應、勢力反應分散。
- 每章至少有一個刪掉後會真正失去的角色／因果／資訊／情緒／世界價值。

# P9｜週期性總檢查

P0.5 是每輪必做的輕量一致性稽核；P9則是篇章級深度總盤點，兩者不可互相取代。

觸發：
- 一個小篇章結束；
- 或連續約 5～10 章沒有做總盤點；
- 或重大原著分歧成立；
- 或遊戲／現實融合階段切換。

固定檢查：

### 因果
- 有沒有仍沿用其成立前提已被刪掉的原著事件？
- 有沒有因 Franiya 的選擇應該提早／延後／消失的事件？

### 人物
- 原著人物是否被寫成只為 Franiya 服務？
- 有沒有把「原時點缺乏觸發條件」誤判成「人物永久刪除」？
- 延後登場的重要人物是否已出現第一個合理窗口卻仍被無限拖延？
- 重要原著人物／事件正式載入後，是否被不合理壓成概要、報告或一句帶過？
- 頂尖高手是否仍有自己的成長與成果？
- 誰和 Franiya 的關係已經實際改變？

### 情報
- 公開資訊、圈內資訊、異能組織機密是否混在一起？
- 論壇傳聞有沒有被作者誤當事實？

### 社會
- 裝備、首殺、公會、貨幣、異能與現實資本是否留下後果？
- 鏡頭外的公會、玩家、異能者是否仍在行動？

### Franiya
- 有沒有不小心把她降成普通玩家？
- 有沒有反過來每場都用高階力量破壞遊戲感？
- 有沒有把「不知道術語」寫成「不理解現象」？
- 有沒有把通用語言學習誤縮成只會精靈語？

完成後把需要修正的項目直接落盤。

# 10. 研究進度的唯一記錄方式

長篇原著不能靠聊天記憶記「讀到哪」。

唯一長期記錄放在：

`04_連續性與索引/05_研究與改寫進度.md`

每次原著研究後至少更新：
- 已完整連續核對範圍；
- 只做過關鍵詞／片段核對的範圍；
- 尚未核對；
- 已建立差分的事件；
- 下一個研究目標。

**「片段核對」不得寫成「完整讀完」。**

---

# 11. 固定停止條件

一輪工作做到以下條件就停，不無限擴張：

### 研究輪
- 本輪問題已有足夠原文證據；
- 已完成差分；
- 已同步 GitHub；
- 下一個研究問題已記錄。

### 規劃輪
- 小篇章骨架能支撐下一章；
- 不需要先把後面數十章全部決定。

### 正文輪
- 正式章節完成；
- POSTWRITE／設定同步完成；
- 下一個自然入口已留下。

這個停止條件用來避免每次為寫一章都重新研究整本原著。

---

# 12. 最終目標

本流程不是要讓改寫「越來越不像原著」，也不是要強迫它「照原著走」。

目標是：

> **每次都先知道原著為什麼會那樣發生，再根據芙蘭妮雅與本線已成立的世界條件，推導現在還會不會那樣發生。**

只要這個因果鏈一直維持，本線即使後期與原著產生巨大分歧，也仍然是有來源、有承接、有世界重量的長篇改寫。
