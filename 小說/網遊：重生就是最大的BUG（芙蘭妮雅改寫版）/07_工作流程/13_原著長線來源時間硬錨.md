# 原著長線來源時間硬錨

> 建立：2026-09-30  
> 狀態：FIXED / MANDATORY  
> 適用：所有在早期只被提及、但於後期原著來源窗才正式啟動的長線人物／寵物／地區／任務／資產／關係。

## 一、問題來源

第57章PREWRITE曾將115-F【四翼黑龍】簡化為一般 `DEFERRED_WITH_TRIGGER`。這會留下兩個錯誤空間：

1. 因為早期已知四翼黑龍存在，就提前數百章去找；
2. 因為不是當前章節主線，就一路DEFER到原著正式啟動窗之後才想起來。

兩者都違反「原著什麼時候正式去建立，改寫正文就在同一來源時間窗建立」的既定原則。

## 二、硬錨欄位

凡屬長線事件，SOURCE disposition 必須額外標記：

- `EARLY_WORLD_MENTION_POINT`
- `SOURCE_ACTIVATION_WINDOW_START`
- `SOURCE_CORE_CONTACT_DEADLINE`
- `NO_EARLY_BUILD_BEFORE`
- `MUST_ACTIVATE_AT`
- `NO_LATE_DRIFT_AFTER`
- `REWRITE_CAUSALITY_REBUILT_FOR_FRIANIYA`

普通 `DEFERRED_WITH_TRIGGER` 不足以取代上述欄位。

## 三、時間硬錨原則

固定：

`EARLY_MENTION != EARLY_BUILD_PERMISSION`

`DEFERRED != UNBOUNDED_DELAY`

`SOURCE_ACTIVATION_WINDOW_REACHED => REWRITE_ROUTE_MUST_ACTIVATE`

`SOURCE_CORE_DEADLINE_REACHED && CORE_CONTACT_NOT_BUILT => SOURCE_TIMELINE_DRIFT_FAIL`

角色可以改變：
- 動機；
- 取得方式；
- 接觸方式；
- 關係結果；
- 戰鬥結果；
- 是否馴服／結盟／敵對。

但不能無理由改變：
- 原著長線正式啟動的大時間窗；
- 原著核心接觸應發生的最晚窗口；
- 中間必要來源節點的相對順序。

## 四、標準案例：四翼黑龍

115-F只負責登記：
- 四翼黑龍作為世界實體存在；
- 龍寵／龍族相關規則存在；
- 沈雲前世曾擁有四翼黑龍的私人所有權歷史不移植給Franiya。

真正尋找／進入龍族區域／建立Franiya自己的黑龍關係，綁定原著後期正式龍族來源窗：

`NO_EARLY_BUILD_BEFORE_CH744_EQUIVALENT = TRUE`

`MUST_ACTIVATE_AT_CH744_EQUIVALENT = TRUE`

`CORE_CONTACT_NO_LATER_THAN_CH752_EQUIVALENT = TRUE`

其中原著744等價節點為龍族區域／龍之大陸長線正式啟動窗口；744～751為龍族接觸與前置；752等價節點進入四翼黑龍核心接觸。

因此：
- 第115章等價窗口不得提前讓Franiya去找黑龍；
- 到第744章等價來源節點時，黑龍長線必須正式啟動；
- 不得跨過第752章等價節點仍只維持模糊DEFERRED；
- Franiya是否最終取得／馴服四翼黑龍，必須由她自己的因果、能力、選擇與實際互動決定，不能直接繼承沈雲前世所有權。

## 五、PREWRITE Gate

每次PREWRITE掃描長線事件時新增：

- `SOURCE_LONG_ARC_TIME_ANCHOR_CHECK`
- `EARLY_BUILD_PROHIBITION_CHECK`
- `ACTIVATION_WINDOW_DUE_CHECK`
- `CORE_CONTACT_DEADLINE_CHECK`

任一FAIL：

`PREWRITE_GATE = FAIL`
`BODY_BUILD = BLOCKED`

直到時間錨與正文安排一致。

## 六、與VOID規則的關係

「沈雲前世已擁有某物／某角色」可以作為私人歷史被VOID，但不得因此VOID該世界實體及原著後續正式接觸時間。

固定：

`PRIVATE_PAST_OWNERSHIP_VOID != WORLD_ENTITY_VOID`

`PRIVATE_PAST_OWNERSHIP_VOID != SOURCE_TIMELINE_VOID`

如果世界實體後續在原著有正式登場／尋找／建立關係窗口，必須保留該時間錨並為Franiya重建自己的因果。
