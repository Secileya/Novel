# 原著可借鑑機制與反面素材

## 值得長期抽取

### 高擬真帶來的身體技術
原著不是所有操作都簡化成按技能鍵。高擬真使角色身體磨合、自由模式、格擋與控制變得重要。

本線改寫：
- 普通玩家需要磨合。
- 職業高手適應更快。
- 芙蘭妮雅不應有普通人的身體控制難題。
- 她真正需要學的是「這個遊戲把哪些動作判成什麼」。

### 玩家資訊錯誤擴散
原著早期把「被野豬追」與「拿到白銀裝備」錯誤拼成隱藏任務攻略。

可借鑑的是：
局部目擊 → 錯誤歸因 → 論壇現身說法 → 自媒體加工 → 大量模仿 → 專業圈重驗。

不必照搬野豬。

### 大公會不只會殺人搶裝
原著稀有裝備出現後，大公會會考慮購買、接觸、招募、名聲與時間成本。

本線強化：
- 交易比無理由追殺更常見。
- 不同幹部有不同意見。
- 公會也要衝級，不會為陌生人無限浪費資源。

### 職業玩家、轉會與身價
這讓頂尖高手在 Franiya 出現以前就具有社會重量。可以保留職業化，但避免排行榜變成絕對戰力數字。

### 遊戲與現實經濟
高階裝備、材料、情報、公會資產能被現實資本定價，使遊戲在尚未入侵現實前就對社會有重量。

## 芙蘭妮雅版特別適合的反差
- 她不懂術語，高手以為她是新人。
- 她已完成那個術語描述的高階行為。
- 她不知道未展示 Boss 技能，但第一次看到後迅速建立模型。
- 她不熟 UI 小技巧，不代表自由戰鬥會輸給熟 UI 的人。
- 她的操作不一定華麗，卻幾乎沒有無效動作。
- 真正懂行的人可能比普通觀眾更沉默，因為他們知道正常人需要多少修正。

## 目前確定不要
- 把沈雲的重生攻略直接搬給 Franiya。
- 系統天然高於 Franiya。
- 黃博士作為穿越／記憶／未來因果核心的主線。
- 無止境論壇震驚循環。
- 為打臉製造假高手。
- 所有男性因外貌失智。
- 大公會固定「不加入就殺」。

## 現實異能後修
- 本線**保留**原著式現實異能者與異能組織，不再把「現實異能」列入反面素材。
- 真正需要改造的是：不能讓異能線在開服早期無理由吞掉網遊主線，也不能把 Franiya 當成某個本地高階異能者來解釋。
- 異能相關橋段是否保留，依其人物、組織、情報邊界與本線因果逐段判定。

## 尚待使用者逐項指出的不喜歡部分
使用者已明確表示原著還有很多地方不喜歡，但除現實異能與目前已修正項目外，其他尚未逐項鎖定。

研究原著時可以標「疑似需改造」，但不能自行把某橋段升格成永久禁用；後續由使用者確認再補入修正檔。
