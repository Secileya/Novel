## 二、SOURCE DEDUCIBLE｜可反向鎖定的歸屬範圍

此前版本把9件全部降成「第6～10群體資產池」過於粗糙。跨讀第97章職業、第98章死亡、第99～100章掉落後，可以進一步鎖定：

### 1. 兩件法師暗金

來源玩家必定是：
- 【糖度過高】
- 【四海縱橫】

對應原物必定是：
- 【深海水晶球】
- 【火焰法杖】

因兩人皆為法師，而原著明示五件暗金按職業匹配，兩件法師裝正好一人一件。

因此：

`MAGE_DARKGOLD_OWNER_POOL = {糖度過高, 四海縱橫}`

`MAGE_DARKGOLD_ITEM_POOL = {深海水晶球, 火焰法杖}`

`ONE_ITEM_PER_PLAYER = TRUE`

但原著目前沒有寫出「糖度過高一定是哪一件／四海縱橫一定是哪一件」，所以二者間的**最後一對一配對仍不可硬填**。

### 2. 三件戰士暗金

來源玩家必定是：
- 【西江月】
- 【青絲縛劍】
- 【半夢半醒】

對應原物必定是：
- 【貪狼鎧甲】
- 【貪狼戰盔】
- 【貪狼腿甲】

因三人皆為戰士，而原著明示三件戰士暗金正好對應三名戰士，一人一件。

因此：

`WARRIOR_DARKGOLD_OWNER_POOL = {西江月, 青絲縛劍, 半夢半醒}`

`WARRIOR_DARKGOLD_ITEM_POOL = {貪狼鎧甲, 貪狼戰盔, 貪狼腿甲}`

`ONE_ITEM_PER_PLAYER = TRUE`

但三件裝備在三人之間的**最後逐件配對仍未被原著點名**。

### 3. 四顆環境珠

原著明說：
- 五人被擊殺後，道具只少一件；
- 【青絲縛劍】運氣好，沒有爆出自己的系統獎勵道具；
- 沈雲最後拿到四顆環境珠。

因此可反向鎖定四珠的掉落者集合為：
- 【糖度過高】
- 【西江月】
- 【四海縱橫】
- 【半夢半醒】

【青絲縛劍】的系統獎勵道具**沒有掉落給沈雲**。

因此：

`ELEMENT_ORB_DROPPER_POOL = {糖度過高, 西江月, 四海縱橫, 半夢半醒}`

`ELEMENT_ORB_ITEM_POOL = {避風珠, 避雷珠, 避水珠, 避火珠}`

`QINGSI_SPECIAL_REWARD_DID_NOT_DROP = TRUE`

四珠在四名玩家之間的最後一對一映射仍未明示。

## 三、SOURCE UNSTATED｜只剩最後一層不能亂補

真正仍屬SOURCE_UNSTATED的，不是「9件到底屬於誰這整件事」，而只有：

1. 【糖度過高】與【四海縱橫】誰持【深海水晶球】、誰持【火焰法杖】。
2. 【西江月】【青絲縛劍】【半夢半醒】三人各自對應哪一件【貪狼鎧甲／戰盔／腿甲】。
3. 【糖度過高】【西江月】【四海縱橫】【半夢半醒】各自掉落哪一顆【避風／避雷／避水／避火珠】。
4. 【青絲縛劍】沒有掉出的那件「系統獎勵道具」究竟是何物，第99～100章本段沒有命名。

因此舊標記：

`EXACT_ORIGINAL_PLAYER_TO_ITEM_MAP = SOURCE_UNSTATED`

修正為：

`EXACT_ORIGINAL_PLAYER_TO_ITEM_MAP = PARTIALLY_DEDUCIBLE`

`EXACT_PAIRWISE_ASSIGNMENT_WITHIN_CLASS_POOL = SOURCE_UNSTATED`

`DO_NOT_ERASE_DEDUCIBLE_OWNER_POOLS = TRUE`

研究檔不得再把已能反推的職業／掉落者範圍全部降成無資訊的群體池。
