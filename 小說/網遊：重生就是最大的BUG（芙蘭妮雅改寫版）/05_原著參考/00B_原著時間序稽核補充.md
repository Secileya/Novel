# 原著時間序稽核補充

> 建立日期：2026-09-29  
> 性質：SOURCE_CAPTURE_WORKFLOW_OVERLAY / MANDATORY  
> 上位流程：`00A_原著事件捕捉與反向歸屬流程.md`  
> 施工Gate：`07_工作流程/05_事件時間序與回補Gate.md`

本檔將「世界內時間順序」正式加入原著捕捉必要流程。若與舊捕捉習慣衝突，以本檔與最新時間序Gate為準。

## 一、每個事件新增四欄

每個需要進入改寫佇列的原著事件，除章號外必須同時標：

- `SOURCE_CHAPTER_ORDER`：原著章號／敘事出現位置。
- `SOURCE_IN_WORLD_ORDER`：原著世界內真正發生順序。
- `NARRATIVE_MODE`：PRESENT / FLASHBACK / PARALLEL / MEMORY_EXPOSITION / LATE_DISCOVERED_HISTORY。
- `FRANIYA_IN_WORLD_ORDER`：Franiya正式線應落在哪個世界時間位置。

任何事件不得只靠章號決定前後。

## 二、章內時間切換必須記到切換句

若同一章前半與後半屬不同時間層，不得整章只標一種時間。

例如原著第95章：
- 前半仍在補完兩天前的星辰深淵結算；
- 簡雨朧外部通訊再次響起後，旁白明寫「思緒一下子被拉了回來」；
- 緊接著再說「在殺死黑色暗流後」，才正式回到第84章後現在時。

所以必須記：

`CH95_PART_A = FLASHBACK`

`CH95_PART_B = PRESENT`

## 三、平行事件不能強行串成前後

只要原著使用跨視角剪輯，同一自然日內的不同地點事件必須標 `PARALLEL`。

已確認例：
- 第81～82外界月神石爭議，與第85～94後來補寫的星辰深淵個人經歷存在時間重疊。
- 第137～144沈雲職業試煉內部，與外界永恆長眠跨境／華夏玩家反應平行。
- 第193～201永恆長眠個人競技場，與沈雲德沃夫卡姆／星雲礦行程平行。
- 第211～213郵輪普通乘客層與27層簡雨朧／炎黃聯盟線平行。

## 四、發布時間禁止作為故事時間

原著標示的「章節更新時間」只是作者發布元資料。

禁止用它判斷：
- 是否過了一天；
- 角色是否已下線／重新上線；
- 任務剩餘時間；
- 同一戰鬥是否被拆成兩天。

典型例：第169章約定15分鐘後原初之地見，第170章雖發布日期變化，故事內仍是同一場15分鐘後約戰。

`CHAPTER_PUBLISH_TIMESTAMP_AS_WORLD_TIME = FORBIDDEN`

## 五、回憶／前世塊不得當現在時事件

看到「回想」「思緒拉回」「曾經」「前世」「遊戲現實融合後第X月」等訊號時，要判斷是否為背景記憶。

已確認：
- 第154章核心是前世戰爭年代回憶。
- 第157章含前世源義清關係回憶。
- 第217～222部分Zero／納塔麗內容是沈雲前世臥底記憶。

如果Franiya沒有同一份人生，不能把這些回憶按事件表直接搬進她的現在時。

## 六、跨章停止點

30章區段結束前必須多讀下一章，確認事件是否真的結束。

已確認：
- 120→121：蒂姬勝負與第二環任務。
- 150→151：神恩守護項鏈只是暫借，真正所有權仍是任務獎勵。
- 180→181：原初之地對局真正收束。
- 240→241：薩拉【毀滅法則－崩壞】與【魔力補給】才完成伏擊解法。

## 七、既有正式正文的時間債

使用者已明確要求：目前不為早期時間錯位做大規模拆章重寫。

既有問題標為：

`TIMELINE_DEBT`

處理原則：
- 不自動重寫已完成正文；
- 後續不再產生新的「較晚事件先寫、再把較早事件當現在時補回」；
- 晚發現的舊事件改分類為 `ALREADY_OCCURRED_OFFSCREEN`、`LATE_DISCOVERED_HISTORY`、`FLASHBACK` 或狀態補丁；
- 若舊事件會改變當前持有物／知情／關係，施工前先補狀態，不重新演一遍。
