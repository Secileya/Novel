# 一、091～095｜斯芬克斯強化不是抽象升級，而是完整素材鏈

## 1. 【靈動之靴】→【靈動祝福之靴】

原件：
- 黃金；
- 敏捷+16；
- 【疾馳】移速+20%，5秒，CD1分鐘；
- 【踢擊】必定擊倒；完全輔助／半輔助額外+50%傷害，自由模式按完成度計傷害，CD45秒。

斯芬克斯以半神力量強化後：
- 升為暗金【靈動祝福之靴】；
- 敏捷+24、防禦+13；
- 【疾馳】提升至30%；
- 【踢擊】CD縮短至20秒；
- 自由模式的「完成度計傷害」規則不變。

這是後面第116章踢擊92%完成度的直接前置來源，不能只記「靴子升暗金」。

## 2. 【火狐炎刀】強化有不可替代的指定素材

原件是黃金可升級武器，已融合【十二階魔獸聖火靈狐十分之一晶核】。

斯芬克斯不能憑空把它升級；原文明確說：
- 要提升火狐炎刀，必須繼續增加【聖火靈狐晶核】含量；
- 斯芬克斯剛好持有另外十分之一；
- 她把這份晶核實際融入火狐炎刀，含量由十分之一變成十分之二；
- 火狐炎刀才正式升為暗金。

暗金後關鍵變化：
- 攻擊145-163；
- 力量+37、精神+17；
- 每擊附加80火傷；
- 【火焰刀】範圍增至前方5米、灼燒150/秒×10秒、準備2.5秒、CD90秒；
- 新增【解放】：解除晶核對裝備本體的壓制，大幅強化裝備；代價是使用後整件火狐炎刀3天不能使用。

`FIREFOX_BLADE_UPGRADE_MATERIAL = HOLY_FIRE_FOX_CORE_1_OF_10`

不得改寫成「斯芬克斯用神力直接升級」。

## 3. 斯芬克斯契約本身有成本

斯芬克斯透過答題契約吞噬失敗者獲得能量；若她輸，就必須依契約替對方強化裝備。

強化高階裝備對她不是零成本。火狐炎刀甚至迫使她付出珍藏的聖火靈狐晶核。

創世神契約一旦成立不能任意改掉，連芬里爾也不能直接替她反悔。

# 二、093～095｜芬里爾、星辰與星辰能量鏈

## 1. 星辰深淵名稱來源與芬里爾真正目的

星辰深淵曾墜落一顆巨大星辰，星辰力量改變周圍土地，並使星辰樹／星辰果實形成特殊效果。

芬里爾分身留在地下森林，真正目的之一是煉化這顆星辰，緩解本體長期封鎖與痛苦。

煉化時間約一年以上。

因此【關鍵時刻】任務成立：
- 難度：傳奇；
- 時間：1年；
- 目標：在芬里爾煉化星辰最後無法分心的時刻，找到能幫助他的神明；
- 失敗：降5級；
- 獎勵：芬里爾煉化星辰後，取得打造神器材料之一。

這不是「打敗來犯神明」任務，而是「找盟友／找神明支援」。

## 2. 雙重吟唱與精靈語必須分兩層記

沈雲以撥雲見月身份第一次正式展示法師能力時：
- 小火球＝一階；
- 閃電鏈＝三階；
- 自由模式下可用魔法符文平衡元素，進行【雙重吟唱】；
- 兩個低階魔法可在約3秒內共同完成；
- 高階魔法因元素更多、更混亂，不能直接照搬同一技巧。

另外，精靈以【精靈語】排列魔法元素，因元素親和可用更小代價組合更多元素；原著在此直接給出：

`ELVEN_LANGUAGE_MAGIC_DAMAGE = ×2`

這和雙重吟唱是兩個不同機制，不得混成「雙重吟唱所以雙倍傷害」。

## 3. 【星辰能量】是一次性個體屬性資源

第94章首次明示：
- 【星辰能量·力】：使用後力量+5；
- 每名玩家限用一次。

正文同時推斷並實際取得：
- 力、體、敏、神、防五類。

沈雲先替自己的三身份使用／預留，再另有大量剩餘；此處要保留原文的「三身份預留」概念，不要把不同身份誤當成完全共享所有一次性使用紀錄。

## 4. 芬里爾傳送陣附帶清紅名結果

沈雲離開地下森林、經芬里爾留下的六芒星回到光明主城外時，發現紅名一併消失。

這是實際事件結果，但原著沒有把它寫成所有芬里爾傳送陣的通用公開規則。

標記：
`FENRIR_TELEPORT_REDNAME_CLEAR = OBSERVED_CASE, NOT UNIVERSALIZED`

# 三、094～107｜星辰深淵任務獎勵與交通鏈必須串成一條

## 1. 羅蒙隱瞞貝克情報 → 三倍補償

羅蒙大帝承認自己事前隱瞞【宙斯神使貝克已前往星辰深淵】的重大情報。

依創世神規則，他必須給沈雲三倍獎勵。

原本【探索星辰深淵】只寫：
- 伯爵；
- 五階主城守護者；
- 皇家寶庫挑1件。

結算後：
- 任務判定為傳奇級；
- 皇家寶庫改成可挑3件。

## 2. 【運送星辰果實】不是探索任務的原始獎勵，而是後續長任務

羅蒙需要：
- 每5天2000顆；
- 果實離樹不得超過10天；
- 任務持續60天；
- 失敗會讓羅蒙強烈不滿，並撤銷官職與爵位；
- 原始獎勵是大幅提高在光明帝國的地位。

第95章沈雲只先交出自己原本採到的100顆。污染果實離開芬里爾魔力肆虐區後會恢復正常，正常【星辰果實】可治病、緩解疼痛；玩家使用可立刻清除當前所有負面狀態，CD1小時。

## 3. 皇家寶庫：1件→3件→4件＋延後取得毀天滅地

順序必須鎖死：

1. 探索星辰深淵原始獎勵：寶庫1件；
2. 羅蒙因隱瞞情報，按三倍補償：改成3件；
3. 沈雲在寶庫想拿【毀天滅地卷軸】；
4. 守護者阻止，因為真正啟動還需要獻祭兩件傳說裝備，沈雲當時一件傳說裝都沒有；
5. 為補償不能取走該卷軸，守護者再把當次可帶走數量提高到4件；
6. 同時更新【運送星辰果實】任務：若完成，且未來擁有兩件傳說裝備，可回來取得【毀天滅地卷軸】。

實際拿走：
- ①大型空間戒指：容量約20個標準足球場；
- ②【賦能之書】：立刻用在職業試煉卷軸，將「最佳隱藏職業1個」升成「最佳隱藏職業2個」；
- ③【定位傳送機器】：華夏戰區任意坐標，3個月1次；
- ④一張圖紙。

全文反查仍沒有可靠證據把第④張寶庫圖紙與後面任何命名圖紙一對一對上。

因此：
`ROYAL_TREASURY_FOURTH_BLUEPRINT_EXACT_ID = SOURCE_UNSTATED`

這才是可以使用 SOURCE_UNSTATED 的案例。

## 4. 定位傳送機器不是單獨用一次就結束，而是拿來建立永久交通節點

第106～107章完整鏈：

- 沈雲用【定位傳送機器】直接輸入「星辰深淵地下森林」坐標；
- 這次消耗掉該機器3個月一次的傳送窗口；
- 到達後立刻用從黑色暗流身上爆出的【傳送珠】把地下森林設為標記點；
- 傳送珠共可記3個地點，可刪除／更改，每日可使用1次；
- 因此他把「三個月一次的定位機器」轉換成「已知目的地後可用傳送珠每日回訪」的長期交通鏈。

之後又在日光森林建立另一個傳送珠標記。

`ONE_SHOT_LONG_RANGE_LOCATOR -> PERMANENT_MARK -> DAILY_TELEPORT_ROUTE`

這是典型跨物件組合利用，不能把定位傳送機器、傳送珠分開摘要。

## 5. 60天星辰果實任務在107章只完成一期供貨，不是整體完結

第107章明寫沈雲回到地下森林採果，回城後「上交了這五天的星辰果實數額」。

全文後段仍再次出現【運送星辰果實】任務，並在很久以後才正式說任務完成。

因此091～120時間窗內只能標：
`STARFRUIT_60_DAY_MISSION = ACTIVE / FIRST_QUOTA_DELIVERED`

不得在107章寫成整個任務完成。

所以千幻之心不是單純「外觀／ID偽裝器」。

`THOUSAND_ILLUSION_IDENTITY = APPEARANCE + ID + NPC_AURA_IDENTITY_SEPARATION`

## 5. 跨身份技能效果保留有方向性

第112章明示：
- 先用游俠身份啟動【貪狼之魂】；
- 再切換成法師身份，已存在的貪狼之魂仍保留；
- 但法師身份不能重新施放這個近戰裝備技能。

所以：
`ACTIVE_EFFECT_CAN_PERSIST_ACROSS_ID_SWITCH`
不等於
`NEW_ID_CAN_CAST_SOURCE_EQUIPMENT_SKILL`

## 6. 血脈覺醒時間點

第112章補充：

- 人類可分戰鬥／魔法／敏捷／體質等，也可後續換巨人、矮人等強力血脈；

## 7. 第113章再度回證法師輸出鏈

# 七、114～116｜外界推理與操作模式補細

## 1. 左谷風／清酒牧歌開始反推沈雲軟肋

外界看到：
- 世界4、5的大夢初曉與細雨朦朧大魔王沒有被殺；
- 其他光明主城前十玩家被沈雲截殺；
- 沈雲又連續殺高人氣女性玩家。

左谷風與清酒牧歌因此提出假說：
- 大夢初曉與細雨朦朧大魔王可能是沈雲在意的人；
- 細雨朦朧與張文君關係緊，不宜直接碰；
- 錦繡當時只是中等公會，可用公會摩擦去測試大夢初曉與沈雲是否有關係。

這裡要區分：
`EXTERNAL_HYPOTHESIS != CONFIRMED_TRUTH`

角色是在用有限情報推測，不是已知沈雲前世關係。

## 2. 「華夏美女收割機」是論壇／輿論外號，不是系統稱號

因連續擊殺高人氣女性玩家，論壇形成「華夏美女收割機」稱呼。

沈雲本人後來才因霓裳羽衣事件破例去看熱搜。

他在華夏觀察者「我們到底需要怎樣的偶像」貼文下回覆：

> 信仰里，我就是規則。

智腦立即置頂並做世界推廣，短時間內形成世界趨勢第一。

這是一次主動公共形象操作，但不是系統正式稱號。

## 3. 第116章自由模式弓箭使用不能簡化成「高手都自由」
