# 一、本輪結論

061～090第一輪稽核已補回「月神石先公開完整屬性再引爆全球搜索」等高優先級漏項；新流程再掃後，仍確認有幾條必須獨立建立Ledger的資產鏈：

1. 【貪狼之爪】不是普通掉落，而是342怪物攻村93%貢獻第一名的系統暗金獎勵，先公布、隔日發放，之後成為第99章貪狼套裝回收鏈的第一件。
2. 世界第一離村的兩項獎勵來源必須拆開：華夏第一→【千幻之心】；世界第一→【職業試煉卷軸】。

4. 第二顆月神石的精確買家是張文君，成交25萬金，而且原文明寫金幣到帳、月神石從沈雲背包消失、張文君實際取出石頭。
5. 【三三卷軸】在第84章不是突然出現，它是第3章【找回神恩守護項鏈】的前置獎勵，直到黑色暗流剛出村才第一次消耗；這次消耗直接提高【魔·陽炎腰帶】【傳送珠】等掉落率。
6. 【魔·陽炎腰帶】【傳送珠】可以精確鎖死「系統剛發給黑色暗流→沈雲擊殺黑色暗流→掉落→沈雲撿取」，不存在來源模糊。
7. 【驚雷骨架】不是雷鳥普通掉落，而是沈雲低等級擊殺符合進化條件雷鳥後，以採集術從其中一具屍體採出，再與832根雷鳥羽毛／310根殘破羽毛自動組裝為【驚雷羽翼】。
8. 第84章其實已站在「星辰深淵任務完成後」的現在時；第85～90章是沈雲聽到簡雨朧通訊後回想「兩天前」的倒敘。若按章號當時間順序，會把整段星辰深淵因果寫亂。
9. 【探索星辰深淵】的任務完成機制不是「看見芬里爾就立刻結算」；芬里爾先判斷正常情況要以死亡離場才能徹底結束，後用斯芬克斯答題給沈雲另一條離開路線。真正回城交任務、伯爵到手在第84章現在時已確認。
10. 斯芬克斯五題契約在第90章勝出，獎勵是「兩件暗金及以下裝備強化」；真正被挑中的【靈動之靴】【火狐炎刀】及強化成本要跨窗讀第91～92章才能閉環。

# 五、第73～75章｜拍賣不是論壇口嗨，報價有實際支付上限

沈雲只接受：
- 金幣；
- 且系統限制玩家報價不得高於自己實際持有金幣。

所以：
- 春江水暖／黑色暗流報40萬，代表代理鏈確實能支付40萬；
- 張文君報25萬，也代表她當時實際持有足額金幣。

此規則對判斷大型公會前期資金實力很重要。

# 六、第80章｜【驚雷骨架】→【驚雷羽翼】素材鏈

第一輪抓到了面板，但新流程要保存它不是普通裝備掉落。

## 前置戰鬥

沈雲以【牛戰士】幻化形態在5分鐘內全滅93隻雷鳥。

普通戰利品：
- 沒有裝備；
- 掉出法師技能書【閃電鏈】。

## 【驚雷骨架】取得 `SOURCE_EXPLICIT`

沈雲對最近一具雷鳥屍體使用【採集術】：

> 「你獲得驚雷骨架。」

原著補充取得條件：
- 約上億隻雷鳥才可能有一隻攜帶；
- 必須是雷屬性能量接近頂峰、將進階【雷鵬】的雷鳥；
- 玩家必須在**低於雷鳥等級**時殺死牠，才可能採集到；
- 即使條件成立仍有採集成功率問題。

因此：

`SOURCE = SPECIAL_HARVEST_FROM_QUALIFIED_THUNDERBIRD_CORPSE`

不是：
`NORMAL_EQUIPMENT_DROP`

## 同場採集總量
- 雷鳥晶核×90；
- 完整雷鳥羽毛×832；
- 殘破雷鳥羽毛×310。

## 自動組裝

沈雲把羽毛丟向【驚雷骨架】後，羽毛受到骨架力量牽引自動排列，直接形成：

【驚雷羽翼】（白銀）
- 防禦+5；敏捷+8；精神+3；感知+15；
- 【雷電磁場】：500米探測，包括隱身單位；準備10秒；CD10分鐘。

後續第107章會再補出持續30秒，因此061～090只記到本章版面時必須保留「後文補欄位」。

### Ledger

`93雷鳥擊殺 → 對特殊雷鳥屍體採集 → 驚雷骨架 → 採集832完整羽毛＋310殘羽 → 自動裝配 → 驚雷羽翼`

# 七、第83～84章｜【三三卷軸】真正來源與第一次消耗

# 十、第86～90章｜【探索星辰深淵】完成條件不是看到芬里爾就即時結算

- 每組10顆；

- 宙斯神使【貝克】，已失去意識；

- 這個任務正常要以沈雲「死亡離場」為終結；

`ABYSS_TRUTH_DISCOVERED ≠ IMMEDIATE_TASK_SETTLEMENT`

- 沈雲最後成功離開；

# 十一、第88→92章｜斯芬克斯契約跨窗閉環

## 普通斯芬克斯規則
- 隨機出現在世界各地；
- 問3題；

- 3題全對可強化1件裝備；

## 芬里爾特例

芬里爾要求：
- 問沈雲5題；
- 給2次挑戰機會。
