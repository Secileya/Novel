# 二、153～160｜現實異能線：能力來源、人物債與108種異能正式校正

## 1. T型屏障是既有異能界技術，不是沈雲能力

江海附近出現T型屏障：
- 可使普通人忽略／看不見屏障內異常；
- 同時壓低異能波動對外界儀器的可探測性；
- 現場屬較舊型號；
- 紅可以直接偵測並定位，代表紅的偵察能力高於當代常規異能機構監測水平。

這條要歸入：
`WORLD_TECH / ABILITY_CONCEALMENT_INFRASTRUCTURE`

不能誤記為沈雲自帶隱匿領域。

## 2. 簡文山伏擊局與三名高重量戰力

事件核心人物：
- 簡文山：炎黃聯盟創始人之一，S級重力異能者；
- 法蘭特：M國頂級火焰異能者，黑色火焰；
- 源義清：R國第一戰士級人物，沒有異能，靠肉身／戰鬥能力抵達S級戰力層；
- 沈雲：先旁觀，後介入。

M、R方面合作伏擊簡文山的重要原因之一，是簡文山的重力訓練可以顯著提高炎黃聯盟年輕異能者的成長效率。

所以此事件不是單純私人仇殺。

## 3. 沈雲救下小女孩【溫柔】不是臨時善心支線

沈雲認出小女孩後，回想起未來：
- 自己曾在逃亡中被長大後的她藏匿／救過；
- 她後來為保護沈雲死在追兵手中；
- 她死亡時，沈雲曾看到純白火焰一閃而逝。

本次療傷時，沈雲發現：
- 女孩體內力量與自己的火焰出現【異能共振】；
- 兩種力量很可能同源／同屬性；
- 她可能正在痛苦與生死刺激中逐步覺醒具備療癒效果的火焰異能。

沈雲因此重新評估她對自己未來身體問題的價值。

這條線同時包含：
`OLD_LIFE_DEBT + FUTURE_HEALING_POTENTIAL + PERSONAL_REGRET`

不能只縮成「沈雲救了一個小女孩」。

## 4. 簡文山金色身份牌：沈雲拒收，真正持有人轉移給溫柔

簡文山原本要把個人金色身份令牌交給沈雲：
- 炎黃字樣＋雙龍；
- 正面「簡」字；
- 在華夏異能圈具極高通行／求助效力。

沈雲沒有收。

他要求：
- 把令牌交給溫柔；
- 由簡文山親自照顧、撫養她；
- 不要按炎黃聯盟慣常方式對她洗腦／塑形；
- 若下次見她快樂健康，沈雲可欠炎黃聯盟一次出手機會；
- 若她受到傷害，則可能站到炎黃聯盟對立面。

資產歸屬：

`JIAN_WENSHAN_GOLD_TOKEN: OFFERED_TO_SHEN -> REFUSED -> ASSIGNED_TO_WENROU`

不得列入沈雲持有物。

## 5. 真夏千雪：雙S級不是推測成雙能力後才成立，而是正文直接用戰鬥表現確認

真夏千雪當前已展示：
- 雷電異能；
- 念動力異能；
- 兩者都達S級層面。

念動力還可：
- 少量使用時難被儀器偵測；
- 隔絕自身存在感；
- 使她能悄無聲息靠近沈雲。

沈雲之所以直接逃：
- 不想和她建立更深交集；
- 前世她長期纏著沈雲學異能精細控制；
- 後來沈雲仍教過她一些；
- 在未來沈雲死後，她被沈雲認知為「人類第一高手」；
- 現在她精細控制差，但可用極高總量壓制，甚至能以念動力拉隕石。

這條關係是【前世麻煩人物／後來的學習關係】，不是當前敵人。

## 6. 重大校正：原著支持的是108種，不是「108 vs 110」矛盾

第160章明確交代：

1. 博士把其他異能者細胞逐步植入沈雲體內；
2. 先從低階異能開始；
3. 植入到72種後，開始加入S級異能細胞；
4. **總數達108種後，博士判定到達臨界點，不再繼續；**
5. 後期原著再次明寫：108種異能齊聚；
6. 其中最後形成／成長到S級強度的異能有72種。

所以應鎖：

`TOTAL_IMPLANTED_ABILITIES = 108`

`S_GRADE_ABILITIES_LATER_PRESENT = 72`

目前第一手TXT全文精確搜尋沒有找到「110種異能／一百一十種異能」的原著支持。

因此先前若研究檔把「110 vs 108」列為原著內部矛盾，應視為：

`OLD_RESEARCH_ERROR, NOT_SOURCE_CONTRADICTION`

## 7. 108種異能不是當前108種都可自由使用

第160章的身體限制：
- 【聖焰】是核心壓制與修復力量；
- 其他異能彼此衝突、破壞身體；
- 聖焰平時負責壓制它們並修復損傷；
- 一旦戰鬥大量抽離聖焰，體內異能就會加劇失控；
- 當下其他異能基本無法正常使用；
- 本次逃離真夏千雪前後，紅甚至限制聖焰只能再短時間使用約30秒。

當前重生後：
- 72種S級強度異能受到某種奇特力量部分壓制；
- 失控速度比前世慢；
- 紅推估約四年多後仍可能壓不住。

因此：

`108_ABILITIES != 108_CURRENTLY_USABLE_SKILLS`

這是角色戰力邊界，不可用「有108種」直接當成108個隨選技能槽。

# 六、171～180｜原初之地職業規則、操作模式與「五人圍剿」真正結果

## 1. 場內職業不是外界現職照搬

備戰階段玩家可選轉職後職業。

例：
- 騎士可選聖騎士等分支；
- 法師可選單系／多系；
- 生命、靈魂、亡靈等特殊系不是普通第一次轉職分支，而更偏隱藏職業；
- 弓箭手、格鬥家第一次轉職沒有普通分支。

原初之地會隨現實遊戲進度逐步更新可選職業。

## 2. 約戰慣例為5v5，不是單純1v1

華夏高玩圈約戰常用5v5原初之地：
- 先看一路單挑；
- 再看團戰；
- 同時測PVP、PVE、抗壓、決斷、大局觀、團隊協作。

這是左谷風過去推廣後形成的圈內慣例。

## 3. 場內外通訊是單向資訊邊界

原初之地中：
- 裡面資訊可以往外送；
- 外界資訊不能傳入場內。
