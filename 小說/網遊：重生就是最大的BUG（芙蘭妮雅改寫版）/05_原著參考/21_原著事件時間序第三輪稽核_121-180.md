## 一、最高優先規則：章節發布時間 ≠ 世界內時間

原著每章標示的「章節更新時間」是作者發布元資料，不得拿來推導故事經過幾天。

典型案例：
- 第169章末，天痕－七星與沈雲約定「十五分鐘後」在光明主城原初之地入口見。
- 第170章雖然章節發布日期已經變成下一個現實日，但故事內直接承接這次十五分鐘後的約戰。

因此：

`CHAPTER_PUBLISH_TIMESTAMP != SOURCE_IN_WORLD_TIME`

後續所有時間稽核只能採正文中的「第二天／今天／昨天／幾分鐘後／遊戲時間耗盡／下線再上線／回憶」等敘事證據。

# 二、121～135｜蒂姬第二環 → 雅典娜神殿 → 魚人寶庫，同一主線逐步推進

## 121～122｜第120章的真正結算

第121章開頭緊接120章：
- 蒂姬承認自己為掙脫裸絞而解除同屬性壓制，違反公平戰約定，因此判自己輸。
- 沈雲取得的只是【學習真我流格鬥術的資格】。
- 隨後【尋找蒂姬】任務立即變更為第二環【蒂姬的幫手】：30天內協助蒂姬擊殺傳奇級暗夜精靈迦娜。

所以：

`CH120_BATTLE_RESULT = CH121_OPENING`

`TRUE_SELF_STYLE_QUALIFICATION != TRUE_SELF_STYLE_ACQUIRED`

第121章章名「擊殺暗夜精靈迦娜」不可按章名理解成當章已殺死迦娜。

## 123～125｜智慧之城／雅典娜神殿與翡翠湖事件

- 沈雲傳送到智慧之城，進雅典娜神殿處理信仰／神殿相關線。
- 第123章末查看直播情報時，正文明說翡翠湖衝突「大概發生在十分鐘之前」。
- 第124～125章承接同一事件，不存在另過一天的敘事證據。
- 沈雲現身、擊殺魚人守護者後，現實身體異常警告連續出現。

## 125→126｜強制下線不是時間跳躍

- 第125章末：系統連續警告現實身體異常。
- 第126章開頭：五秒倒數後被強制踢下線。
- 現實中沈雲短暫承受劇烈頭痛與記憶／身體異常。
- **同章很快明寫「重新進入到遊戲後」**，他仍回到翡翠湖畔北側。

因此這裡是：

`GAME -> FORCED_OFFLINE_REALITY_EPISODE -> SAME_DAY_RELOGIN`

不能把126章錯算成自然跨日。

## 126～135｜魚人寶庫連續事件

- 魚人寶庫鑰匙與75顆疾風狼優質晶核被正式消耗／啟動。
- 其他玩家蜂擁、沈雲混隊、魚人王子迪亞斯、寶庫戰、火狐炎刀【解放】、亞特蘭蒂斯線索與戰利品清點連續發生。
- 第134～135章讀取迪亞斯日記時出現「試煉空間」時間資訊，這是迪亞斯自身經驗／系統現象的敘述，不是當前世界真的又經過十年。
- 第135章沈雲明確決定「今天」剩餘時間練級，等「第二天」再開職業試煉。
- 同章末明寫遊戲時間耗盡，下線休息；當晚準備大量奶茶，為翌日試煉做準備。

這是本區第一個清楚自然日邊界。

# 三、136～145｜職業試煉與外界事件是平行時間，不是先後兩條獨立日程

## 136｜第二天上線，正式進職業試煉

- 第136章開頭明示「第二天一大早」。
- 沈雲回光明主城住宅啟動職業試煉。
- 系統沒有提供一個所有玩家通用的固定「試煉時間倍率」。
- 原文反而指出：不同參與者對試煉內時間的感知可能不同，智腦如何做到未解。

因此不得把迪亞斯「現實一小時、主觀至少十年」直接套成沈雲職業試煉的固定倍率。

`TRIAL_TIME_RATIO = NOT_UNIVERSALLY_FIXED`

## 137～144｜試煉內／外界並行

沈雲人在封閉試煉空間時，外界並沒有停止：

- 第137章：永恆長眠跨越國界線進入華夏戰區，觸發世界公告。
- 原文明示：世界所有玩家都收到公告，**唯獨處於封閉空間的沈雲沒有聽到**。
- 外界冰霜舞步、北落師門、天痕等開始對永恆長眠的來意與約戰做反應。
- 同時間沈雲仍在【戰鬥之道】裡輪換不同職業、對抗高階NPC投影／試煉內容。

所以：

`CH137_144 = PARALLEL_TIMELINES`

A線：沈雲職業試煉內部。  
B線：華夏戰區外部，永恆長眠跨國、高手與公會反應、哥布林秘境攻略等。

### 知情邊界

沈雲不能在試煉內因作者旁白而知道永恆長眠已跨境；必須等離開封閉空間後透過可用情報取得。

`SHEN_KNOWS_ETERNAL_CROSS_BORDER_DURING_TRIAL = FALSE`

## 141～144｜神明／試煉內容不是外界同步事件

宙斯、堤豐、智慧之書、時空控制等高階畫面屬於試煉內部／投影／特殊空間，不可因章號與外界公告交錯就當成外界同地發生。

## 145｜試煉後返回正常世界

第145章起，沈雲已離開職業試煉，將注意力轉向地獄級哥布林秘境與神恩守護項鏈線。

# 四、145～152｜哥布林秘境 → 神恩守護項鏈 → 當日遊戲結束

## 145～150｜同一登入日內的哥布林秘境主線

- 沈雲回342新手村。
- 處理論俠行道／青絲縛劍等玩家遭遇。
- 進地獄級哥布林秘境。
- 依原著隱藏路線處理啸月銀狼。
- 第150章離開副本時，玩家甚至因「進去時間太短」誤以為他死亡退出。
- 第150章正式得到【月爆】技能書與【神恩守護項鏈】。

### 月爆時間規則

- 夜晚才能吸收月之能量。
- 充滿3000需要1小時。
- 每次啟動消耗1500，可用兩次；每次30秒，CD30分鐘。

這裡的「一小時」是技能充能條件，不代表正文直接跳過一個故事小時。

## 151｜神恩守護項鏈只是暫借

- 第151章續接第150章。
- 第二環任務【尋找地獄惡魔賈斯坦】成立。
- 時限3年。
- 失敗懲罰：收回神恩守護項鏈。
- 任務完成獎勵：取得神恩守護項鏈真正所有權。

所以150～151當下狀態是：

`NECKLACE_POSSESSION = TEMPORARY_LOAN`

不是永久入手。

## 152｜同日遊戲時間耗盡

- 沈雲先使用當日剩餘遊戲時間練級。
- 使用傳送珠到星辰深淵。
- 明寫「用完了遊戲時間後便下線休息」。
- 等級升至12。
- 下線後開始翻論壇，等待夜晚。

這裡是第二個明確遊戲日邊界。

# 七、170～180｜發布日期跨日，但故事內是同一場15分鐘後約戰

## 170｜不能因章節更新日期而另算一天

第170章內容就是第169章所約的原初之地對戰準備：
- 系統匹配；

`CH169_TO_CH170_GAP = ~15 MINUTES IN_WORLD`

不是「隔了一天」。

## 171～180｜同一場5v5比賽連續戰鬥

- 對戰開始後所有角色、裝備、地圖經濟、兵線、塔與交戰都屬同一場原初之地對局。
- 第176章甚至明確給出遊戲時間「第四分鐘」。
- 第180章末沈雲瞬殺冰霜舞步，但比賽仍未正式結束。

## 必須跨讀181章

第181章開頭緊接180章：
- 沈雲繼續近身北落師門；
- 北落師門拿出七箭同射；

`ORIGINAL_LAND_MATCH_RESULT_REQUIRES_CH181_CROSS_WINDOW = TRUE`

不得以180章「冰霜舞步死亡」當成整場戰鬥結算。

# 八、本段對Franiya施工的時間序Gate

## 1. 回憶塊不得當新事件補寫

尤其：
- 154章＝前世戰爭年代記憶。
- 157章＝前世源義清人物關係記憶。

若Franiya沒有對等前史，這些只能拆其功能重新設計，不能因掃描到它們就排進下一章現在時。

## 2. 平行外界事件需保留知情差

137～144：永恆長眠跨境、外界公會動作與沈雲職業試煉同時發生。

Franiya若處於封閉副本／試煉，也不得作者全知同步取得外界公告以外的資訊；是否收到公告依實際系統規則重算。

## 3. 強制下線不等於跨日

125→126的現實身體異常是短時中斷，原文同章已重新登入。

## 4. 發布時間禁止進入時間推算

後續掃描與PREWRITE不得把 `章节更新时间` 當世界日曆使用。

## 5. 跨章結算必須讀到真正停止點

本段至少：
- 120→121：蒂姬勝負與第二環任務。
- 150→151：神恩守護項鏈「暫借」與第二環。
- 180→181：原初之地整場真正結算。
