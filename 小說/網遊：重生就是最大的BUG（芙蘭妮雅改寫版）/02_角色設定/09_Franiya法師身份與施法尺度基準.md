## 一、第89章等價事件不得再省略

【千幻之心】的第二身份功能是長期主線系統，不是「為了聯絡簡雨朧」才存在的一次性工具。

Franiya線必須補回一個可承接法師線的第二身份：
- `SECOND_IDENTITY_CLASS = MAGE / FIXED`
- 與主身份共享等級／經驗；
- 具有獨立職業、屬性配置、外貌／身份認知；
- 千幻之心的高階NPC氣息隔離功能需保留；
- 具體ID、種族、外貌與建立當下的私人理由，由正式回修PREWRITE依Franiya人物DNA與時間線決定，不直接複製沈雲的【撥雲見月】。

在正式回修完成前：

`CURRENT_STATE_NO_SECOND_IDENTITY = KNOWN_CANON_DEFECT_PENDING_REPAIR`

不得再以「Franiya沒有求助需求」為理由取消第二身份。

## 二、Franiya不是新手法師

Franiya的跨世界角色DNA已固定：
- 全武器高階精通包含法杖、法書、法珠、魔導器、法器等施法載體；
- 她本身的魔法理解、能量控制、術式拆解、並行處理與規則建模能力遠超《信仰》早期玩家層；
- 《信仰》法師身份提供的是本地合法接口與角色殼資源，不是從零教她魔法。

因此原著沈雲第90～93章的魔法成長功能必須「保留功能、重算難度」。

可保留：
- 自由模式魔法可脫離純技能按鈕；
- 精靈語／元素親和／咒式／能量路線等本地魔法規則；
- 魔法可以研究、重組、自行開發；
- 世界對高階自由施法者的震動與評價。

不能照搬：
- 把雙重吟唱當Franiya艱難學會的高門檻技術；
- 把她寫成第一次研究魔法原理才發現「原來可以自己控制」；
- 用普通玩家的試錯速度限制她。

## 三、合法輸出邊界

Franiya的理解上限與遊戲角色殼的輸出上限必須分開。

`MAGIC_UNDERSTANDING = FRANIYA_NATIVE_HIGH_LEVEL`

`ACTUAL_GAME_OUTPUT = CLASS + LEVEL + SPIRIT + MP + EQUIPMENT + SKILLS + LOCAL_RULES`

她可以比本世界玩家更快看懂、拆解、重組術式，但不能因此無條件繞過：
- MP／精神；
- 法師職階；
- 技能與裝備前置；
- 冷卻／施法時間；
- 本地世界法則；
- 系統明示禁止事項。

所以張力來自「角色殼能承載多少」與「本地規則怎麼映射」，不是「她會不會魔法」。

### 3.1 8階合法輸出已建立角色殼承載下限

【折光】已合法裝備【深海水晶球】與【火焰法杖】，對應8階【海潮】與8階【火雨降臨】。

因此，當MP／職業／裝備／系統條件成立時，角色殼已被正式證明可以承載8階水系與8階火系輸出。

固定：

`EQUIPMENT_8TH_TIER_USE_PROVES_SHELL_CAPACITY_AT_SUPPORTED_RESOURCE_LEVEL = TRUE`

不能再用「Lv10所以角色殼一定不能承載8階」作為自由構築的機械否定理由。

但具名裝備技能與自由構築必須分流：

`SYSTEM_NAMED_SKILL_PERMISSION != FREE_CONSTRUCTED_EQUIVALENT`

她自行構築一個8階等價浪潮，不代表脫下【深海水晶球】後系統欄仍保有裝備技能【海潮】；反之，裝備技能能啟動也已證明角色殼在相應資源條件下能承受該量級。

## 四、自由構築、元素最佳化與跨元素術式

Franiya不知道沈雲前世的私人精靈語排列公式，不等於她不能自行觀察元素排列、MP損耗、凝聚速度、穩定性與輸出後推出自己的最優解。

固定：

`UNKNOWN_ORIGINAL_FORMULA != CANNOT_OPTIMIZE_ELEMENT_ARRAY`

`OBSERVABLE_MAGIC_STRUCTURE -> FRANIYA_CAN_DERIVE_OPTIMAL_OR_NEAR_OPTIMAL_CONFIGURATION`

因此，第113章原著特定「精靈語排列增幅」不得被施工成Franiya必須等人教才會的成長門檻。她可以先獨立推出自己的高效排列；若後續合法接觸本世界既有成熟精靈術式，再比較兩者。

只要元素合法可操作、結構已知、資源足夠且沒有血脈／神權／唯一職業等硬性權限封鎖，Franiya可以自行構築8階等價甚至更高實際效能的水、火、雷、土、風、冰等術式。

`ELEMENT_TYPE != TIER_LIMIT`

第59章洛戰已讓Franiya合法觀察高階水、土、雷與大型雷暴的實際形成結構，這些可成為本地作用資訊來源；但未公開的技能正式名稱、系統面板、私人學習史與隱藏權限仍不能憑空知道。

## 五、多線施法不是「雙重吟唱」上限

`DUAL_CASTING != PARALLEL_CAST_CAP`

第50章「右側先完成／左側慢半拍」只代表當次兩條術式的完成時序，不代表第二條固定較慢，更不代表Franiya只能維持兩條。

她可以同時維持三條、四條、五條乃至更多術式。真正的並行上限取決於：
- 總MP；
- 精神與角色殼魔力吞吐；
- 瞬時輸出帶寬；
- 術式複雜度與維持成本；
- 媒介／裝備接口；
- 環境元素；
- 系統硬性通道限制；
- 同時維持的其他高負荷效果。

不能把思考／控制能力本身寫成只容納兩條術式。

## 六、術式升階、實效與系統標籤

Franiya可以對既有術式：
- 同效降耗；
- 同耗增效；
- 提高MP投入換更大規模／更長持續／更強控制；
- 重排節點降低損耗；
- 合併／拆分元素；
- 將多個低階構型重組為更高實效複合術式。

因此：

`EFFECTIVE_SPELL_POWER > ORIGINAL_TEMPLATE_TIER` 可以成立；

但 `SYSTEM_SKILL_LABEL_AUTO_UPGRADE = NOT_ASSUMED`。

也就是，8階模板被她優化到一般9階量級的實效是合理的，但除非系統有自創術式重新認證機制，不能自動把UI名稱／階級改成9階。

## 七、神咒層級與真正瓶頸

神咒是威力、效果或術式層級達到神級的魔法分類，不是神殿專屬的同義詞，也不自動附帶固定的神格、神權、血脈或唯一職業要求。

具體前置逐咒判定：純技術／純能量型神咒可能只需要足夠MP、精神、角色殼吞吐與術式控制；另一部分神咒則可能因自身機制要求神格、神權、特定血脈、唯一職業、神器、神殿許可或其他身份鑰匙。不得只因名稱叫神咒就自行補上一整套權限。

對Franiya而言，神級規模與高複雜度本身不是理解牆。實際能不能放，先看角色殼是否供得起；若某一道神咒另有特殊前置，再只核那一道神咒的條件。

## 八、第二身份的戰鬥表現

第二身份正式戰鬥時，觀察者看到的核心不是普通高手多放幾個技能，而是：
- 施法節奏異常乾淨；
- 多線魔法與位移／武器動作可以同時存在；
- 能把敵人施法、環境元素、法器特性納入同一套即時重算；
- 對低階已知術式幾乎沒有「不熟悉法師操作」的空窗；
- 一旦取得本地術式規則，能迅速做出超出當前玩家常識的組合與優化。

這不代表外界能直接知道她的跨世界背景。外界只能從實際表現判斷「這個法師身份的技術異常高」。

## 九、與主身份的關係

Franiya主身份仍可保持游俠／多武器戰鬥核心；第二身份法師不是把她切成兩個不同人格，也不是「主身份不會魔法、法師身份才會」。

正確理解：
- Franiya本人懂魔法；
- 不同身份提供不同《信仰》系統接口、屬性、職業、裝備與NPC認知；
- 身份切換改變的是合法角色殼，不是她本人的知識與人格。

## 十、施工Gate

任何涉及第二身份、魔法研究、法器、神殿身份分流、多重施法、元素最佳化或自創高階術式的PREWRITE，必須核：
- `SECOND_IDENTITY_ESTABLISHED_IN_PROSE`
- `LOCAL_MAGIC_RULES_KNOWN`
- `GAME_SHELL_OUTPUT_LIMIT`
- `FRANIYA_MAGIC_MASTERY_NOT_DOWNGRADED`
- `FRANIYA_MAGIC_OPTIMIZATION_GATE`
- `FRANIYA_PARALLEL_CAST_GATE`
- `FRANIYA_FREE_CONSTRUCTION_TIER_GATE`
- `FRANIYA_PERMISSION_VS_TECHNIQUE_GATE`
- `NPC_KNOWLEDGE_BOUNDARY`

任一FAIL不得直接寫正文。
