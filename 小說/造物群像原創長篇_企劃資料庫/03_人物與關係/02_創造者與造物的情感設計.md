# 創造者×智慧造物：感情與人格深度設計

**已定的研究方向**：009吸引人處在於傲慢、危險、滑稽、鮮明獨立性格與對創造者深厚感情同時成立；新小說吸收這類多層感情，不照搬人物、臺詞、復活計畫與結局。

## 核心區分：起源、力量、制度、相處、選擇

- **被創造**是起源事實，不自動等於對造物者的崇拜或永久從屬。
- **力量／契約誘發的敬畏或服從**，須作為客觀作用另記，不能把它和自主情感畫等號。
- **被照顧、被理解、被忽視、被欺負、被信任、被允許離開**，逐步形成真正的私人關係；雙方也可能各有誤解。
- **愛與自主**不互斥：可以真誠珍惜創造者，仍然拒絕命令、承擔風險、自己決定留在誰身邊。
- **特殊關係不抹除外界人格**：面對重要的人會害羞、高興、想撒嬌、想炫耀、也可能流淚，和成熟、危險、足智多謀的外界形象可以同時存在。
- **創造者也必須是人物**：會疲憊、犯錯、偏心、改觀、學著尊重被創造者；若使用九家人，優先遵循她們原有核心設定而不是重新發明性格。

## 私人情感可由這些不同的需要形成

| 感情底層 | 可能呈現 | 不必然導向 |
|---|---|---|
| 珍惜存在的起點 | 想知道為何當年選擇創造自己 | 盲目服從 |
| 被看見 | 默默保存創造者第一次讚美 | 只能永遠當孩子 |
| 被信任 | 不願被當作需要時才取出的工具 | 與創造者敵對 |
| 想保護對方 | 面對威脅時冷靜或非常激烈 | 無條件屠殺 |
| 想讓對方驕傲 | 戰績、學識、工作、能養活自己、交到朋友 | 只許追求戰鬥力 |
| 害怕失去 | 因久別與誤會產生不安、執拗、冒險 | 必然失去、必然復活 |

## 「游霽」專用的初步長線（**暫案**）

- **早期（不一定在正文最先寫）**：游霽在完成某次獨立任務後，主動把自己做成的小器件寄給創造者；它更在意創造者是否真的在使用，不只是有沒有說謝謝。
- **中期**：第一次必須在創造者的建議與一名外界朋友的安全間獨立選擇。游霽可尊敬對方卻不按其建議做，事後承擔真實後果。
- **後期**：不再需要每日確認被喜歡，但依舊可能在意久別後一句普通稱讚。情感加深不等於人格幼化。
- **關鍵風險**：不要把這條線寫成009從受困、建國、復仇到重逢求「最完美」的原樣縮影；游霽有屬於自身的工作、人生與朋友。

## 角色不在鏡頭裡仍需活著

智慧造物自己會修工具、維持資產、人際互助、旅行、玩笑、與不太喜歡的人往來；其「思念創造者」不應在所有日常反覆被提起。只有真正觸發私人記憶的場合，才自然呈現情緒。

## 延後再決定的事

創造者具體是誰、是否為九家人、是否親手撫養、是否有固定主從契約、能力具體構造、現在是否仍住一起、游霽是否為先天非人或後天覺醒：**皆未定案**。

## FAM-001｜九位家人可能進入這些關係，但尚無指定對象

九位家人已確定自由出入、保有完整重要人格；可與智慧造物形成私人關係，但**不默認九人全是創造者、游霽由誰製作、造物全都愛她們，或人人需有009式情緒**。如果游霽未來確立與其中一位存在創造者關係，研究的不只是「被創造」的瞬間，還需記錄雙方每次實際相處的理解差、私人選擇、被照顧與被信任的證據、分別生活時的各自故事。兩人在重逢或平常吃飯時都可真誠表達感情，而不必固定重演009的誤讀、復活與求最完美認可。

任何一位家人的具體說話、玩心、外貌、權能、愛的表達與相處對象，一律以家庭總檔**對應人物章及最新交接**為準；新小說提出的情感框架不得將她們模板化成單一慈愛／冷漠造物主。
