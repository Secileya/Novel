## 研究方法：真正寫出伏筆而不靠改稿作弊

1. **SEED**：設定一個當時就有合理生活意義的細節（紀錄、感情、制度流程、道具用法），讓人物能按當下情報行動。
2. **ECHO**：隔一段足夠的生活／政治／技術時間，讓相同細節帶來另一種衝突，而非每隔兩章就提醒讀者「這是伏筆」。
3. **REINTERPRET**：新情報使讀者能重新理解舊行為，但不得否定舊篇的客觀事件和私人情感。
4. **PAYOFF**：回收應改變人物承諾、組織策略、受害者命運和社會關係；不能只是解說答案。
5. **AFTERMATH**：即使秘密揭曉、勝負已分，倖存者仍會生活、追責、交易、哀悼及重建。
6. **OPEN**：敘事資料庫敢寫尚未知道，不以AI推定填答案；每條加下一次該去哪章補證據。

**本檔創作方法是從原著抽象所得，不構成新小說固定世界法則。**

# SRC-37｜原著「七階登神」：發現、命名、質變、限制及後期驗證

**身份：SOURCE-BASED RESEARCH；非本小說世界規則。** 依使用者 TXT 章號核查 CH077–078、CH130、CH178、CH183–185、CH190、CH223、CH270、CH336、CH399–402、CH650–651、CH716–718、CH723；不是抄成單一終極官方定理。原著至少有（A）陳燁提出的生命階位、（B）079遊戲的易懂等級名稱、（C）九尾狐參照另一世界建立的精神／物質修煉階級、（D）後期六階內五個過程，彼此聯繫但絕非同一張精確的戰鬥力量換算表。

## 1. 正文最早形成分級與後續公開的不同層次

- **CH077–078**：079的關卡與商店先使用「普通、優秀、精英、史詩、傳奇、聖域、神話」七種遊戲化稱謂；來源於陳燁未來提出的「七步登神長階」理論。079當時最多只能製造三階怪物與獎勵，**不能把介面有七階寫成遊戲實際能獎勵七階**。
- **CH130**：陳燁因002與025出現所伴生的世界變化，思考生命與世界本質互相影響，**自行推導**七階：零階常態；一階高於常人／常態生物；二階具固有或次級特性；三階具有絕對特性或生命本質接近改變世界門檻；四階真正可以改變世界；五階以肉身自由穿行宇宙星海；六階聖域，生命形式超越生命本身的存在性質變；七階神話，當時仍不知成神基礎而是推論上限。當時的「可改變世界」「神話」不可寫成已完全掌握的公式。
- **CH183**：陳燁按「生命本質階位」核算越級獵殺獎勵；序列本身常用的「能打幾階」是**實戰戰力**，兩者不等同。三階能殺四階仍未必升成四階生命。
- **CH223**：後續經驗總結：能力初型決定多數序列進化主幹（冰系延冰、變身系沿變身等）；四階是生命與能力開始整體躍遷的重要門檻；低階也可能單獨某方面極強、肉身脆弱，**不是階低＝不起眼**。此處是當時的角色／旁白歸納，不宜把所有日後例外抹去。
- **CH336**：九尾狐公開的修煉體系針對人類、藉異界修煉法建立一至四階標準：一階覺醒、二三階突破精神或物質閾值、四階要求精神和物質雙修。該章另述異界五階化神、六階仙分五境、七階的傳說。這是**修煉路徑特有的模型**，不等於每位序列都靠雙修進階；相同階位的鯨魚和人也不會同樣強。
- **CH399**：陳燁回顧六階聖域內「五個過程」與神性累積的關係，設定更深入；不能把「六階＝瞬間完成全部神性」寫成既定。
- **CH716—718、CH723**：009借無限篇章與相關布局真正進到七階層級；此為晚期故事已發生的事，證明CH130的「第七階仍是推測」只是早期知識邊界，不可永久凍結在舊模型。

## 2. 便於故事設計的七階原著整理（審慎簡表）

| 級 | CH130時的陳燁理論／後續質感 | 不是什麼 |
|---|---|---|
| 零階 | 地球常態生命基準；各物種基礎身體差異很大（參CH336） | 不是「所有零階同戰力」 |
| 一階／普通 | 超出常態生物門檻；修煉者可從覺醒能量起算 | 不是只能打小怪，更不是設定上必須弱 |
| 二階／優秀 | 固有或次級特性；某項獨特能力可對常人構成絕對性災害 | 不是戰力只能是二倍人類 |
| 三階／精英 | 絕對特性、或逼近世界改變門檻；可高度偏科 | 不是一身全能；能力特性相性要看 |
| 四階／史詩 | 生命與世界間的規則接點，對世界本質產生改變；能力與生命全面躍進是常見現象 | 不是只因為炸毀城市就升四階 |
| 五階／傳奇 | 肉身在宇宙星海自主生存／遠行的生命尺度，且可具有不同專業方向 | 不是全員同一招式／同一體型 |
| 六階／聖域 | 生命存在形式超越常規，另有五境或五個過程（依不同系統敘述）；神性與人格成為重要命題 | 不是五境細節在CH130就定稿 |
| 七階／神話 | CH130時概念上限，晚期有實例；涉及篇章與更高層級權柄 | 不是一般人現今能測得精確全部能力 |

**比對原著實力時須再辨認**：序列生命位階、某戰鬥能力有效性、絕對特性、物品戰力、眷屬、組織社會重量、地形與情報。CH078當時將002李淵列二階，後期李淵升階，不能抹除其早期弱項和後期進化，也不能拿後期李淵倒寫前期必然五階。

## 3. 新小說應借鑑什麼？

1. **多重尺度**：生命本質、能力可怖程度、實際戰力、制度影響分開；小物可在低「生命階」而令高階者忌憚。
2. **由角色探索而建立理論**：早期階級定義有未知與修正，不是作者頒一張永恆真理表。
3. **進化的形態連續**：能力後期深化沿著初始核心，不從速度忽然變成任意因果操控。
4. **具備存在性質變**：四階、五階、六階、七階的敘事重量不只是加大破壞半徑；社會結構、物種、親情、目標和自我理解可受影響，但不必機械失去人性。
5. **不可照抄原著**：原創能力、階級名和長期事件要重新有其世界內歷史。是否採七段、如何登記序列都還是原創提案。

# SRC-38｜進化競爭並非一場：兩類機制、時間與人物後果

**身份：SOURCE-BASED RESEARCH，參CH060、CH078、CH183–185、CH190、CH193–197、CH399–402、CH480、CH508、CH636、CH650–651。**

## 競逐A｜早期同階／越階獵殺的進化獎勵

- CH060：秦棱與陳燁的「新生／舊生競逐」有意識形態與政治後果；人類可抵抗怪物，**不等於人類已被納入同階獎勵的簡單等級賽**。
- CH183：陳燁獎勵殺死同生命階位或越階取勝的序列；不獎勵三階獵殺二階。當局者往往按實戰強度估算，陳燁卻依生命位階，造成計畫與資訊差。
- CH185：范夜在被操控下殺死015進化，進化能力與本身夢魘特性發生聯合變化；**獲獎不等於人格認可，更不代表死者無重量**。
- CH190、CH193—197：019、002等將獵殺同階變成制度性博弈；李淵精確利用對手的親屬、符咒、敵我情報與情緒安排殺局，說明競逐會鼓勵不止單挑的算計與悲劇。

## 競逐B｜千年神權之戰（CH399–402開設，CH651收束）

- **目的**：陳燁讓長期稱王的序列參與新的文明競逐，形式上爭取成神資格；CH400明示他另有推動序列合作、迎接熵的動機。當事序列對此的理解不相同。
- **舞台**：以未來篇章參與建成的星球與時間域，世界內1,000年、地球約10年（時間約100:1）。他開始製造智慧生命，不是「把既有某國搬到新地圖」。
- **基本規則**：一名序列對應文明的神、選授王冠。王冠被奪可淘汰，王冠亦可交易藥劑、天災、聯盟；結盟可共享勝利資格。前三百年不許真身直接介入，其後三／四／五階分別於300／600／900年後解禁，六階不能下場。勝利為期限到時王冠優勢或只剩一個聯盟。
- **隱藏深度**：CH401李淵測出可轉化眷屬但不能直接操控其忠誠；國王、人口與文明的自主選擇因此無法全由神控制。CH402他反著設計篩選，得到意料中的仁慈領袖；其他神的制度結果不同。
- **長期轉化**：CH480林楓／千喉一段把「競賽以殺人求生」轉成臨敵互救；CH508李淵發現王冠應優先用於結盟，不該只砸在升階；CH636複雜的結盟使血神可連通陣營。**不同人可反過來發現規則鼓勵的真正最優解不是持續殺光別人。**
- **收束**：CH651完成，聯盟內死者也因勝利資格而有相應回歸；未聯盟者沒有同樣保障，陳燁另依六階下場違規進行處置。前後不是同一件常態低階淘汰賽。

## 可借鑑但不移植

- **競爭機制必須有動機**：提出者想驗證／篩選／加速／阻止什麼；制度獎勵什麼行為；誰能鑽規則；弱勢者如何結盟；非參賽者的生存受何影響。
- **勝利要允許合作、非預設策略**：當人發現更有效／更善良／更殘酷的辦法，機制必須尊重其行為後果。
- **不能長篇全靠賽事推動**：家族、經濟、救援、創造者與造物感情、人類普通人生，須能不受競賽控制而繼續。
- **原創提案**：中期可有跨城公開試證／共同防災資源爭取，不以獵殺同類強制進化，也不複製千年王冠。

## 二、原著的「創造」至少五種目的：不要只照能力列表
1. **研究自保／準備自己飲用藥劑**：CH001明言希望能理解人體後果、最後讓自己參與實驗；同一能力會先在別的生命測試。
2. **獲取難以取得的材料**：CH001提出沒有超凡材料就自己造；CH025的生物工廠想能穩定生產實驗素材。生成物之後會自發活動，不只是原料。
3. **達成抽象長目標「神需要哪些能力」**：CH075有不死、支配生死、未知特性等逐項條件；每個新創造是對舊缺口的下一步，不是隨機掉寶。
4. **測試「能力如何影響世界」**：CH110與130關於古遺物和生命與世界互相質變，是陳燁的**假說**，當時並非客觀鐵律；研究問題本身推動新實驗。
5. **設計競賽觀察人性／給予機會**：CH399—402的競賽兼具發獎機會、文明實驗、個人觀察；要把主辦方目的和參賽者真正目的分開。

## 三、原著對「競爭」的使用不是一套固定升級程式
- **資源／素材競爭**：前期序列爭奪實驗物、古遺物、研究能力和組織支持；其中不少競爭不是陳燁直接主持。
- **獵殺換進化**：CH183對同階與更高階的有效獎賞有區分，生命階位不等同絕對戰力；個別人物的親仇會和獎勵機制抵觸。
- **組織政爭**：CH160、167、233等包含收容機構更名、奪取研究資源、十天干共用序列、秘密投靠等；組織不是純練功資源販賣處。
- **文明神權競逐**：CH399—402重新設置千年規則與王冠；CH508李淵分析「贏得競賽」不等於全部殺光，CH651以聯盟方式收束。早、中、後期的競賽雖有同一創造者，**目的與規模不同**。
- **拒絕競爭亦是選擇**：許多序列有家庭、職業、愛情、自由與保護他人的願望，不應把每個人的終極目標寫成升神。

## 四、原著常用的六步「因果接力」
1. **出場以前**：人物已有職業、家庭、債務、舊仇或技術；組織已有制度。
2. **事件觸媒**：新造物／稀缺材料／一樁傷害／一句不能公開的情報。
3. **互相誤讀**：創造者、造物、政府及旁觀者掌握資訊不同，不自動共享作者所知。
4. **各自決策**：合作、收容、研究、逃避、獵殺、隱瞞、出走或不參加。
5. **可量後果**：死亡、救援、資產流向、仇恨、技術、關係、名聲和組織制度；即使英雄離場仍繼續。
6. **長期重估**：新的章節揭露舊行動另一層意義，並令人物再決策，不以「真相公開」作終點。
