## 3. 已確立的作品方向（不新增決議）

- 從**世界上第一個真正序列誕生**起筆。九位原先指定家人中的某一位因讀到造物類小說、覺得有趣而開始創造；**她的身份、讀過的書名、首個序列的原體／人格／能力仍為 OPEN**。《我創造的怪物！》可能作靈感，但並非已指定世界內閱讀作品。
- 現行本企劃 `USER_FIXED`：所有真正序列有原先確立的九位家人源流；家人非同步、無固定配額或輪流造物；不形成公開九派；外界通常不知九位家人存在。普通工藝、自然異常、一般物品不因此自動成為真正序列。個別序列能否再創造序列及資格仍需獨立確認。
- 真序列對創造者的敬愛是真心，**沒有忠誠／思想烙印或強制精神控制**，有自主性、私人目標、朋友與拒絕權；不安排後期背叛、出賣或加害九位家人的戲碼。此約束不同於「必須無條件執行創造者指令」。
- 故事為**序列小說**，關注序列誕生、能力交織、相剋、進化、競爭、合作、人格與後果；每大階段有一條作者層可回收的主目標。家人能自由、有分量地進出故事，生活與幸福可獨立精彩，但不機械輪值、不把全書稀釋為多條同權重配角日常。
- 洛琪莉卡創造「渴望其認可」的強大智慧造物屬 `USER_PREFERRED` 的優先方向，具體人、能力、時間、序號仍非定案；不因她的自信或親近把角色寫成必然翻車，亦不把被認可者寫成最終必定反叛。
