# SRC-50｜原著739章章節內容與節奏：可驗數據、抽核章次、推進規律

**類別 SOURCE_RESEARCH＋標示INFERENCE的敘事判讀。** 真正的「逐章」材料是配套CSV 739行的**章名、章字元數、標題及正文詞彙線索**；其中**47章指定篇章經本輪定向核查**，並在CSV有經核對的人物事件摘要；其餘692章只作機械索引，**不冒稱已完成739章逐章人工內容摘要**。機械詞語觸及與語義主旨嚴格區分：戰鬥詞出現≠該章是戰鬥章，角色名出現≠該角色是主視角。原文持續含「章节更新时间」欄位；740章包括主篇外的安寧片段、番外與試讀，長度統計不可當純主篇均值。

## 1. 概況：短而密、章節字元相當一致

- 標準章標739個（001—740，缺標準714章），**每章字元中位數2321、平均約2374**，10—90百分位大約 **2232—2573字元**（含標點及原文件章內附註，不是平台詞數）。
- **660/739（約89.3%）章名含「！」／「!」**。這是作者選取強烈事件標題的客觀特徵，不證明每章都有真正懸念，更不應機械要求本作每章都用驚嘆號。
- 各個大段平均未出現倍增：早期001—050中位數2342，晚期652—740及附加內容所屬章節仍約同一量級；**世界愈大，不等於每章就愈長**。
- 章內可同時含能力、戰鬥、組織、私人情感，不必假定一章只能做一件事，也不要把詞頻當準確的章級內容占比。

## 3. 原著一章往往包含多個動作，而不是一章一種職能

**以實查的CH511（約2339字元）為例**：它先交代後位能力是如何沿舊能力衍生；隨即切到舞娘與天使，通過舞蹈干擾強敵的片段驗證能力效應；最終讓天使按自身性格作出選擇，令局面轉危。**同一章可以一邊說明力量系譜，一邊展示能力相性與角色立場，尾端再造成下回衝突。**

**以CH401—402為例**：400章宣告限制，401李淵立刻用眷屬轉化測試有無可操作餘地，402再翻轉選王標準。這是「設定服務事件」，不是「先談20章神權哲學，再去進行選王」。

**以CH036—041為例**：009才登場，短期內就出現錯誤解讀、其他序列處置、009分裂物獨特效果、半成品藥劑爭奪與GOC回應，情節同時改變數個陣營。這些變化共同服務「造物突破會怎麼讓世界失衡」的階段主目標。

## 4. 全書739章機械詞彙索引結果的正確用途

配套CSV `01_全739章節奏與內容線索_機械索引.csv` 每章列出：**章號／原著章名／研究分期／字元數／題名及正文詞彙線索／抽核與否／如有則重要章節核對摘要**。

另 `02_階段篇幅與題材詞彙訊號統計.csv` 列出每個階段的長度與文本詞彙觸及。例如每章出現「战斗／击杀／攻击」一類詞，**只能說該章涉及這些語詞**，不能據此宣告該章「大部分都在打架」，也不能從文本表面認定某人物獲勝。這套量化只能輔助挑出值得回讀的章節，不能代替真正逐章閱讀。

## 5. 作者長期目標如何讓大世界收束（INFERENCE）

- **期初定一件吸引人的事情**：新造物能力的後果、009式人物誤讀、009出逃、某次組織收容失效、神權目標等。
- **每幾章就有真變化**：出現新的主力序列／能力限制／戰鬥結果／資訊轉折／結盟改變，不必每章都全新，但不能連續大量章節只追蹤旁枝人物日常。
- **配角有前史，卻未必擁有等量鏡頭**：CH059千喉仍要保留本人害怕失控殺人的人格，並不等於作者立刻連寫二十章其草原生活；回到主爭奪時才讓他的心性改變選擇。
- **能力展示與衝突要黏在一起**：讓讀者在對抗、交易、救援、誤判中認識力量，而非每人首登場要寫百科全書。
- **階段回收→下一階段加大目標**：前期試藥與收容、序列集團、異界與階位、神權之戰、星海外敵之間承接具體因果；本作不必複製原有競賽或神系。

## 6. 這輪尚未完成的部分

**47章指定重要章次人工抽核，692章仍是由原文的章題＋正文詞彙建立的粗索引。** 如要研究「每一章主要事件、人物視角、轉折、伏筆、懸念、章末鉤子」，下一輪須按50章／100章分批真正逐章閱讀、覆核每章主內容並寫章級一至兩句人工紀錄。不要把詞彙索引自動升格為人手精讀成果。來源較舊 SRC-43、SRC-44 同樣遵守其註明的實際覆蓋。
