# SRC-37｜原著「七階登神」：發現、命名、質變、限制及後期驗證

**身份：SOURCE-BASED RESEARCH；非本小說世界規則。** 依使用者 TXT 章號核查 CH077–078、CH130、CH178、CH183–185、CH190、CH223、CH270、CH336、CH399–402、CH650–651、CH716–718、CH723；不是抄成單一終極官方定理。原著至少有（A）陳燁提出的生命階位、（B）079遊戲的易懂等級名稱、（C）九尾狐參照另一世界建立的精神／物質修煉階級、（D）後期六階內五個過程，彼此聯繫但絕非同一張精確的戰鬥力量換算表。

## 1. 正文最早形成分級與後續公開的不同層次

- **CH077–078**：079的關卡與商店先使用「普通、優秀、精英、史詩、傳奇、聖域、神話」七種遊戲化稱謂；來源於陳燁未來提出的「七步登神長階」理論。079當時最多只能製造三階怪物與獎勵，**不能把介面有七階寫成遊戲實際能獎勵七階**。
- **CH130**：陳燁因002與025出現所伴生的世界變化，思考生命與世界本質互相影響，**自行推導**七階：零階常態；一階高於常人／常態生物；二階具固有或次級特性；三階具有絕對特性或生命本質接近改變世界門檻；四階真正可以改變世界；五階以肉身自由穿行宇宙星海；六階聖域，生命形式超越生命本身的存在性質變；七階神話，當時仍不知成神基礎而是推論上限。當時的「可改變世界」「神話」不可寫成已完全掌握的公式。
- **CH183**：陳燁按「生命本質階位」核算越級獵殺獎勵；序列本身常用的「能打幾階」是**實戰戰力**，兩者不等同。三階能殺四階仍未必升成四階生命。
- **CH223**：後續經驗總結：能力初型決定多數序列進化主幹（冰系延冰、變身系沿變身等）；四階是生命與能力開始整體躍遷的重要門檻；低階也可能單獨某方面極強、肉身脆弱，**不是階低＝不起眼**。此處是當時的角色／旁白歸納，不宜把所有日後例外抹去。
- **CH336**：九尾狐公開的修煉體系針對人類、藉異界修煉法建立一至四階標準：一階覺醒、二三階突破精神或物質閾值、四階要求精神和物質雙修。該章另述異界五階化神、六階仙分五境、七階的傳說。這是**修煉路徑特有的模型**，不等於每位序列都靠雙修進階；相同階位的鯨魚和人也不會同樣強。
- **CH399**：陳燁回顧六階聖域內「五個過程」與神性累積的關係，設定更深入；不能把「六階＝瞬間完成全部神性」寫成既定。
- **CH716—718、CH723**：009借無限篇章與相關布局真正進到七階層級；此為晚期故事已發生的事，證明CH130的「第七階仍是推測」只是早期知識邊界，不可永久凍結在舊模型。

## 2. 便於故事設計的七階原著整理（審慎簡表）

| 級 | CH130時的陳燁理論／後續質感 | 不是什麼 |
|---|---|---|
| 零階 | 地球常態生命基準；各物種基礎身體差異很大（參CH336） | 不是「所有零階同戰力」 |
| 一階／普通 | 超出常態生物門檻；修煉者可從覺醒能量起算 | 不是只能打小怪，更不是設定上必須弱 |
| 二階／優秀 | 固有或次級特性；某項獨特能力可對常人構成絕對性災害 | 不是戰力只能是二倍人類 |
| 三階／精英 | 絕對特性、或逼近世界改變門檻；可高度偏科 | 不是一身全能；能力特性相性要看 |
| 四階／史詩 | 生命與世界間的規則接點，對世界本質產生改變；能力與生命全面躍進是常見現象 | 不是只因為炸毀城市就升四階 |
| 五階／傳奇 | 肉身在宇宙星海自主生存／遠行的生命尺度，且可具有不同專業方向 | 不是全員同一招式／同一體型 |
| 六階／聖域 | 生命存在形式超越常規，另有五境或五個過程（依不同系統敘述）；神性與人格成為重要命題 | 不是五境細節在CH130就定稿 |
| 七階／神話 | CH130時概念上限，晚期有實例；涉及篇章與更高層級權柄 | 不是一般人現今能測得精確全部能力 |

**比對原著實力時須再辨認**：序列生命位階、某戰鬥能力有效性、絕對特性、物品戰力、眷屬、組織社會重量、地形與情報。CH078當時將002李淵列二階，後期李淵升階，不能抹除其早期弱項和後期進化，也不能拿後期李淵倒寫前期必然五階。

## 3. 新小說應借鑑什麼？

1. **多重尺度**：生命本質、能力可怖程度、實際戰力、制度影響分開；小物可在低「生命階」而令高階者忌憚。
2. **由角色探索而建立理論**：早期階級定義有未知與修正，不是作者頒一張永恆真理表。
3. **進化的形態連續**：能力後期深化沿著初始核心，不從速度忽然變成任意因果操控。
4. **具備存在性質變**：四階、五階、六階、七階的敘事重量不只是加大破壞半徑；社會結構、物種、親情、目標和自我理解可受影響，但不必機械失去人性。
5. **不可照抄原著**：原創能力、階級名和長期事件要重新有其世界內歷史。是否採七段、如何登記序列都還是原創提案。
