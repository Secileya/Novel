# FAM-002｜九位家人的可見度、節奏與介入因果

**性質：依使用者於2026-10-17進一步確認之正式敘事規約；情境示例皆為候選，沒有任何正式正文已發生。**

## 已確立的最高原則

1. 九位家人：**法月懷、塞希莉雅、朔凜月、洛琪莉卡、絲蒂莉雅、薇絲莉雅、璃安、芙蘭妮雅、小曦**，使用 GitHub `小說/家庭總檔/01_家庭完整角色設定總檔.md` 與最新 `00_總檔交接.md` 為權威。新作無權自行改寫其力量、人格、重要感情、稱呼或人物歷史。原有九人可自由出入，不必每卷當中心。
2. **不能長時間完全隱居幕後到像是不存在**：允許家庭生活、旅行、創造和與外界朋友真實往來；她們可以在場且只做當時真心想做的事，不必都隱藏身份。
3. **不能為了讓鏡頭熱鬧而到處亂竄、隨意搞事**：動機應能追溯到當時旅遊目的、正在做的家事、早有的關係、真實興趣或被嚴重觸及的底線；不是異物一出現就被旁白硬派過去。
4. **不強制每章、每卷出場定額，也不強制留空配額**。正式規劃每一段長時間跳躍時，需詢問她們其間正在生活什麼；若鏡頭長久未及，可以用有內容的家庭篇、旅行篇或關係更新自然接上，非硬塞一則「大家過得很好」敷衍。
5. **不因九人強大而軟化她們、製造假無能**；不因她們能解決問題便讓地方制度與普通人世界自動消失。她們可直接介入真實觸及自己的人與事；其他事件根本未與她們交叉時自然依本地人物解決。
6. 家庭感情不是單一「溫暖模板」：洛琪莉卡真可靠而非每次翻車；璃安能主動快樂親近；法月懷可以主動撒嬌；九人全部可主動照顧與受照顧。依**最新版家庭總檔**核實個別細節，不直接靠本檔重建原角色。

## 真正可運作的四種鏡頭

| 模式 | 意義 | 不能犯的錯 |
|---|---|---|
| **家庭完整日常** | 一頓飯、逗弄、做東西、一起休息或一場自己的出遊，可以是完整章節，純享受家庭情感 | 把每次笑談都安排成世界主線伏筆，或把家庭凝縮成固定撒嬌台詞循環 |
| **一家人裡一至幾位外出** | 某人因自然興趣在港口、市集、他國短暫／長時間逗留，建立自己的普通朋友與熟人 | 故意每次九人全部到齊，或把強大者裝成連普通事情都不懂 |
| **已累積的人際交會** | 她們曾認識某位工匠、孩子或研究者，因交易／約定／個人感情再見面 | 角色剛遇到危險，九人便無理由從遠方即刻現身 |
| **真正重大的主動行動** | 某位家人的重要物、人與底線遭威脅，或她自願參與有趣／危險／有重量的事情 | 為拖戰力而讓她只能旁觀，或強制每卷都發生宇宙危機 |

## 出場密度不是數學配額，而是追蹤失聯理由

- **每個卷／主要篇章 PREWRITE** 記：九人目前各自可能在做什麼、跟哪條事件有真實關係、是否有值得直接寫的家庭故事。答案可以是某幾人出場，也可以是外界獨立敘事。
- **跨月、跨年或長期外界大篇章**：不能讓九人在世界內莫名定格；建立私人生活的獨立事件時鐘。適當在讀者需要恢復親近感時，安排一段完整且不敷衍的家庭相處；這屬**節奏要求**，不是規定每十章一場抱抱。
- **九人有正當理由真正涉入**：允許行動果斷，並承擔合理社會後果；某次她們順手解決極難事件並不表示所有案件都須用同一方式處理。
- **若長期未出場**：交接檔註明「上次真正出場、此後世界內經過多久、當時她們在做什麼、是否欠缺情感承接」。不能讓下一個AI因長篇換對話忘記她們。

## 家庭與世界時鐘（候選例子，尚未鎖死）

- 家庭自身：朔凜月與洛琪莉卡的相處、璃安和芙蘭妮雅親近、兩位館主／長輩角色自己的興趣、小曦與家人日常等等；依主總檔核對。
- 旅行時鐘：其中一人某段時間在海港做手工買賣，之後離開，留下真朋友與交易紀錄；**不等於必然是該異物的創造者**。
- 智慧造物時鐘：它也有想主動回家的理由，而不只是等待創造者「召回」；與九人的連線要合法且帶私人歷史。
- 世界時鐘：其他人照樣工作、結婚、組織衝突、逃難、研究、死亡。創造者與家庭永遠不是唯一歷史驅動力。

## 統一否決的六種寫法

「九人集體失蹤數百章僅靠後台交代」／「每一件小事故全家都現身」／「九人為證明世界危險而突然被削弱」／「智慧造物在外界什麼都不會做，只等主人」／「每卷結尾突然出現一位家人替地方人物解決所有矛盾」／「以客串頻率替代真實的人物關係與生活」。
