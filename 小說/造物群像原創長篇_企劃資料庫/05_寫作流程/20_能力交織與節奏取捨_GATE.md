# GATE-20｜能力不為差異而扭曲，群像不為完整而失焦

## 能力設計
- [ ] 允許兩名不同序列都戰鬥、都獸化、都蟲化或都治療；沒有硬逼一個改成高抽象概念能力？
- [ ] 同型能力是否在表現、附帶作用、環境、戰術決策或成長方向上有**必要且自然**的區別？不用發明十種多餘規則。
- [ ] 有沒有把好用且已成立的能力只為追新奇而一直重寫？若沒有劇情／因果必要，優先保留。
- [ ] 既有序列配合、對抗與相性是否足以創造新戲？有沒有先使用舊人物而非無端新增十位？
- [ ] 沒有直接把原著獨特的序列整組換名字、換一小部分就當新作原創？

## 章節節奏
- [ ] 每個階段有一個作者層長期目標，讀者知道正在追逐什麼？
- [ ] 章節是否實際推進能力、戰局、人物抉擇、情報或情感？純家庭日常是否本身真的有趣，而不只為配額？
- [ ] 新增配角是否有舞台功能；不需要人人各自完整連載的日常、職涯、政治支線？
- [ ] 不把原著詞彙自動分類當作「每章已精讀」；從739章機械索引挑章人工回查？
- [ ] 本書的源流隱密、九家人非九派、真心忠誠無烙印、不背叛家人等設定是否保持？

## 文件信度
原著TXT統計739章數據是真的；同名術語命中或章題索引只是**研究線索**；已人工核對的47個章節只代表被抽核的章節，不等於全部739章被逐行理解。
