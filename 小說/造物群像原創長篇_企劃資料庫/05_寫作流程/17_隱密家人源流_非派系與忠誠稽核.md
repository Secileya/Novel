# GATE-17｜九位家人低可見度、序列非派系、忠誠與私密稱呼寫作前稽核

本檔需與 `../00_總索引/12_隱密源流_非派系_忠誠與出場原則.md` 一同使用；非新小說正文。

## 每章必問
- [ ] 本章家人是否真的需要直接出場？若非，能否讓外界人物在自身人生中完成？不是限制家人不能出場，而是防隨手召喚。
- [ ] 家人若出場，她本人的理由、情感、選擇是否真實？是否符合最新 `小說/家庭總檔`？她沒有因此被當成官府／派系首領？
- [ ] 本章有角色提及家人的名字或尊稱嗎？是否明確交代該人如何得知？避免旁白把來源信息偷塞入公共知識。
- [ ] 序列的組織是否有獨立目標、供應鏈、成員、理念、財務與歷史？沒有把出生來源當政治陣營嗎？
- [ ] 洛琪莉卡的主力序列是否在外界也實際很強、聰明、有能耐？沒有只剩狂熱／蠢萌，也沒有創造者一嫌棄就怨恨或自卑？
- [ ] 稱呼是否建立於它與洛琪莉卡的私人關係？沒有把「主人」做成公開家徽、陣營頭銜或受控烙印證據？
- [ ] 忠誠是否表現為長期核心信念與行動，沒有強行安排戲劇性背叛九位家人？烙印是否保留 OPEN，未假裝已敲定？
- [ ] 誤解創造者的話是否符合人物性格與當時情報？誤解後的後果由行動者承擔，沒有把洛琪莉卡變成真正下達危害命令？
- [ ] 同源序列是否可能敵對、異源序列是否可能友好？沒有用九位家人名字把九大派別一口氣劃分世界？
- [ ] 世界外部知情有合理路徑嗎？不因一次大戰／研究就突然得知九人完整起源？
- [ ] 家人即使很久沒有直接出鏡，序列／人物／城市發展也能留下她們曾創造生命的間接因果，但不需要一直念其名嗎？

## 不寫的快餐公式
九家人排名榜；九大神軍；洛琪莉卡的王國對薇絲莉雅王國；所有序列自報由誰創造；主人不誇就認為自己被拋棄；所有家庭日常都會觸發外界大事件；凡研究異物者自動知道九位家人。
