# GATE-18｜序列主軸與分期長期目標：刪除失焦支線的寫作稽核

**USER_FIXED 方法論 + PROPOSAL 檢查步驟**。配套 `../04_劇情與伏筆/26_序列主軸_非同步創造與作者分期長期目標.md`。適用新卷設計、章節規劃及新增重要人物。

## 篇章建立前
- [ ] 一句話說清這個階段**作者想要完成**的序列主線目標，而不是列出十種各自都重要的社會問題。
- [ ] 核心焦點及主要阻力是否清楚？讀者追的主要變化是不是序列的創造、進化、競爭、抉擇或後果？
- [ ] 本階段終點／實際回收是什麼？是否為下一階段新的主要目標留出因果？
- [ ] 是否誤把九位家人安排成同時創造、輪流創造、每人固定一個序列派系或年度主持競賽？
- [ ] 現有舊港務五卷／百章表是否已只作素材庫，不是壓倒現行正典的時間表？

## 每新增角色或支線前
- [ ] 這名角色是主角、核心對手、推動主目標的關鍵人物，還是只需要一次有趣／有溫度的出場？
- [ ] 這條私生活場景是否足夠精彩或帶有必要情緒節奏？若兩者皆否，是否可留於人物履歷而不另開章？
- [ ] **每個人都有自己的人生**是否被誤讀成**每個人都要另開完整長篇**？
- [ ] 這場衝突最終會改變什麼序列相關狀態？若只補社會細節，是否應縮短、合併或延後？
- [ ] 家庭的真實溫暖和獨立生活是否得到尊重，但沒有成為九人固定輪班的日常副小說？

## 例外
真實有趣的獨立家庭日常、角色相處、小型幽默或休息篇章都可以存在，不要求每句話埋伏筆，也不把每一段溫柔改寫成主線任務。檢查的是**整個階段是否失焦**，不是一刀切掉所有非主線內容。
