# GATE-16｜v1.3群像百章草案寫作前檢驗

本檔是寫作編輯流程，不是要求把情緒劇情變成報告。每五至十章校對一次，長伏筆發生變更時隨時追蹤。

## A. 每次預寫所需
- 鏡頭主人在這之前的工作、住處、家庭、朋友與私人壓力；若本章沒有異序，他今天本來要做什麼？
- 本章因何真的會發生：委託、保管契約、債務、熟人求助、地形、舊案、勢力策略，不能說「剛好」。
- 本章衝突是否由不同人的合理但不相容選擇產生；是否有每個人各自能接受的勝利？
- 本章能力是否在建立的客觀物理與概念邊界內使用；「技巧進步」是否未偷換成「境界質變」？
- 伏筆必須記載先前已被讀者實際看見的訊息，不得把作者待寫計畫記為已埋。

## B. 需要禁用的捷徑
- 不能因建立十段節奏便把每章寫成整齊的單一流水帳；百章CSV是可挪動候選節點。
- 同一個雇主、溫伏川、洪陸笙、容閔、鐘瓷各有不同利益；不要最後揭露原來所有風暴／小事都是某人單手設計。
- 沒有異常能力的何映荻、老技師、工友和演職人員有自己的專業；關鍵成果不能自動由序列代做。
- 顏家姊妹與何家兄妹的喜悅、成功、親密可以長久留存，不預設死亡、背叛作劇情燃料。
- 九位家人面對真正因果可以主動介入，但不可為了保護已排定劇情而被迫降智、不出手、失去既有力量；亦不可每逢港口危機都自動被請來。

## C. 伏筆的基本資料欄
`伏筆ID / 首見實際章 / 早期所見 / 見證角色 / 知情與誤讀邊界 / 中段更新 / 回收事實 / 改變哪些決策與關係 / 仍待回答 / 已寫或僅提案`。

## D. 卷末核驗
- 第一卷主要事故至少有一部分責任、實際賠付和家戶成果結案；可保留後續後果，但不准永遠藏所有答案。
- 卷內至少兩個彼此獨立的故事經歷局部開始、變化、結束，不要求所有人被同一計畫收編。
- 強者可以在必要時實際強勢解決事件；後續張力可由利益、信任、知情差與不可替代的私人選擇延續，不必強行再造更高戰力阻止他們。
- 顏家、何家或其他幸福人物可真正迎來好結局，並繼續活得有事情可做。
