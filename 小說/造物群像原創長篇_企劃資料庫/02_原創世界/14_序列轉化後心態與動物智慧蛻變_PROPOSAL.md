# WORLD-14｜序列轉化後的人格、給藥者關係與動物智慧蛻變（USER_FIXED方向＋PROPOSAL實作）

## 權威界線
**使用者本輪重點／USER_FIXED方向**：從原著實例研究**給藥後人物真實反應**（對自己能力、身體、情緒、未來目標及給藥者），尤其**動物接受魔藥後應真正蛻變出高度智慧、情感與自主性**，不能只變大、變強、會聽話；不要把所有人寫成「看到別人有超能力，所以想報名喝藥」。新作已定：九位家人是序列唯一根源；真心敬愛、沒有忠誠烙印且不背叛家人；魔藥體系的具體媒介、首個序列與原體仍OPEN。**此檔描述的方法是準則，具體反應場景、能力、時程與創造者仍是PROPOSAL。**

## 1. 真正值得先想的不是「職業」，而是他失去了／得到了什麼
人類原體應具有一個**故事在魔藥出現前就存在的生活狀態**：有可能正在工作、逃亡、思念、委屈、追求某種事、甚至只是普通過日子；不必每個人都瀕死或深陷創傷。創造者與原體的相遇應有自然因果，而不是到處問誰想要進化。若角色**可以選擇**，要寫清楚他當時**知道多少、不知道多少、為什麼仍要作出決定**；在威迫下答應與知情自願不是同一件事。沒有使用魔藥的初始決定（如動物、特殊非人生命）則依當時意識狀態與創造者個性寫，不偽造不存在的知情同意。

角色轉化後可同時有驚嚇與興奮、痛苦與重生感、感激與不信任、想再見給藥者與希望趕快離開、力量自豪與對自己怪物外形的羞恥。**允許反應互相衝突、會變**，但不規定每個角色都要將所有反應輪流演一次。

## 2. 給藥者與真正創造者需要區分
- 若**家人親自給藥且也是序列創造者**：序列可以在受到幫助後真誠感謝、被嚇到而質問、想知道對方為何選自己、因很強大而敬畏、又因實際相處感到被接納／喜愛。**由此自然形成或表達對創造者的真心敬愛**；親近不排斥一開始害怕、迷惑或不喜歡自己的新外貌，但不能靠藥劑自動植入服從。
- 若**只是拿藥來的人／傳遞媒介的第三方**：這人未必就是九位根源創造者。序列可以對他感激、戒心、愧疚、討厭、交易或無特別感情，**不自動向交瓶者表達對創造者的愛**。真正源流仍追到九位家人或未來有合法衍生資格的序列，但不需要即時公開。
- 對方**是給藥者，也是製作者／研究者嗎？是救命者、交易者、旁觀者或無意傳遞者？**角色的主觀理解也可能與真相不同；這個差別可直接推動劇情，卻不必做成一套全都市調查機構。

## 3. 能力第一次使用後，可以直接改變人物想做的事
- **第一反應**：身體是否痛？感官有沒有改變？是否還有舊傷？能否以原本方式生活？這些都是值得描寫的具體小事。
- **第一次自主能力測試**：因人格而非作者數值表選一件事做：想確認不會傷及家人、忍不住想奔跑、想報復過去的敵人、想再唱歌、想試著飛、想隱藏新身分等。
- **對給藥者的反應**：可以主動找對方求助或問清楚，也可以先努力解決眼前難題。**真心敬愛不等於當場只有感動落淚、跪拜或宣誓效忠**。
- **新目標**：不必人人「幫創造者征服世界」；有人要過原本日常，有人想追逐力量、愛情、自由、財富、復仇、守護、知識或玩樂。其具體新目標常是原本人生願望在新能力作用下**第一次變得可行**。
- **長期再看**：魔藥會帶來新的人際風險與能力相性；個性仍會成長。一次能力展示可在數章內導致對手、事件、關係變化，保持序列小說主線，不將每名角色獨立列成長篇日常。

## 4. 動物轉化必須蛻變出真實智慧——不是「會說話的戰寵」
- **蛻變的本質**：原本的生物本能、記憶、熟悉的人／味道、依附或警戒仍可能在；魔藥使它取得足以思考自己、理解對方、學習知識與語言、長期記住承諾、理解利害並作出有責任的選擇的真正智慧。**不是只讓狗說話、烏鴉變人、昆蟲軍團服從而稱為高智慧序列**。
- **原著001的分層（SRC-58 CH001）**：先聰明、再用教學學會語言、後來才偶然擬態。**對本作可取的是學習與自我形成真正發生過；不能硬套原著7天＋5天的時程，也不要求動物最終擁有固定人形。**
- **新智慧與舊本性互不抹殺**：可以仍喜歡以前的棲息地／食物、對熟悉照顧者有信任、對人類處事覺得可笑，甚至不喜歡穿鞋或討厭城市；但它能**反省本能、克制衝動、欣賞他人、決定自己的生活**。不預設動物一瞬間接受人類道德、價值或完整社會知識。
- **情感的深化**：原本就有的安全感、親近、恐懼、快樂可能轉化成「我知道你曾照顧我」「我還想留在你身邊，也想看看外面」「我不希望別人受傷」等有自覺的情感。**不能把對創造者的真誠敬愛寫成魔藥附帶的寵物忠誠烙印**。
- **別套單一時間流程**：某序列剛轉化便具有成熟語言和抽象理解也可成立，但需依家人實際創造意圖與能力解釋；另一個則需要相處／學習。兩者都能成為真正完整人格。智慧≠人形，人形≠智慧；動物從此是人生的主體，不只是九人高興時逗玩的寵物。
- **動物是否原本就有完整人類式選擇能力**要按物種與個體具體寫；在尚未蛻變前，不強行安排一套「我願意成為序列」的成人對話。

## 5. 比角色能力表更有用的「序列出生場景」核對
當作者準備寫第一序列或其他重要誕生時，先問：
1. **遇到魔藥前**它正在做什麼？當時要的是什麼？
2. **得到魔藥／遭轉化時**它真正知道、以為自己知道的又是什麼？創造者為何此時出手？
3. **醒來／蛻變後**它第一個想確認什麼？對舊身體、舊關係、新能力的情緒各是什麼？
4. **它認為給藥者是誰**，這與真正創造者有何不同？它的敬愛／疑問如何自然表現？
5. **它第一次實際主動採取的行動**是什麼？能否不用增加一堆旁枝人物，就讓該決定形成下一章衝突？

這些是挑最有戲的提問，**不是五題都要各寫一章，也不是生前每個關係都要追出獨立長篇**。

## 6. 可撤換的簡短敘事微例（全PROPOSAL）
- **人類**：一名原本追求某事的人在生存壓力下拿到選擇，他喝下後先摸向舊傷、發現自己能站穩，卻又發現手指長出陌生構造。他不必立刻道謝；也許先問「這能變回去嗎？」隔天才去找給藥者，而第一個真正行動仍是先前未完成的私人目標。
- **動物**：曾經能認出熟悉聲音的鳥，轉化後先發現自己開始**理解句子背後的意思**，甚至理解那人為何停頓、何謂「明天」；牠可能第一次想知道自己能否選擇不回籠子，又真心想陪伴原本照顧牠的人。後來牠學會語言，第一次提出的是自己的問題，而不是覆述主人交代。此例並非暗示001必須仍是烏鴉或變成擬態者。

**待確認**：第一序列具體原體、家人身份、魔藥成分與出生主場景仍然OPEN；此前「折骸／劇團武師」的創造和報名流程不准默默升格為已定。本檔是情感／認知設計的優先參考，非不可變更的人物角色表。
