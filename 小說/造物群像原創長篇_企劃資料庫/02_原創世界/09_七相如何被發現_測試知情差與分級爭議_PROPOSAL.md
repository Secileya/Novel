# WORLD-09｜本作『七相』分級如何形成並被社會知道（PROPOSAL）

**核心創作原則已定：強起點、生命質變、社會知情差；名稱『七相』與本作世界史仍為提案。** 不能把原著079介面、陳燁石碑或九尾狐修行標準複製過來。

## 1. 沒有萬能偵測面板
- 一名剛得到能力的人**通常不會自帶『我是一相』訊息**，也不自動知道能力完整邊界。
- 調查者依三種可區別的實驗：**現象試驗**（是否重現、何種介質）、**生命試驗**（肉身／人格／自我延續形式是否改變）、**公共風險試驗**（失控風險、擴散、產業與制度影響）。
- 地方暫定稱呼可採『初型／穩式／跨域』等描述；七相是多年比較後的研究術語，不是主角開篇向大家宣布的固定表。
- 許多異序**無法可靠判相**；智慧造物可拒絕侵入性測試，拒測不等於未開化。非生命異物的『生命相位』可以直接註記**不適用**；仍可能比高相生命更危險。

## 2. 誰能知道什麼？
| 身分 | 通常能知道 | 不能因此知道 |
|---|---|---|
| 第一次持有者 | 感受與試用、自己的實際代價 | 全部邊界、生命相位、高階物件本質 |
| 工班／普通目擊者 | 『起重機失衡』『整段路重現』『一片街區被擋雨』 | 異序代碼和科學解釋、絕對級別 |
| 工坊／商會 | 工藝參數、局部失效案例、用戶需求 | 他人獨有材料與長年私人遭遇 |
| 地方鑑定所 | 受控實測、重大不確定性、暫定物件分級 | 無證據的大陸級上限、完整個人心靈 |
| 級別研究共同體 | 數年積累後形成的共同命名、概率範圍 | 尚未經歷的存在質變完整機制 |
| 九位家人 | 依原有極高理解力與各自興趣，可看出更深原理 | 不代表她們會免費向所有地方機構宣傳或替其撰寫分級 |

## 3. 大眾語言先於學術標準
- 同一『晴簷』現象在市場報紙叫『遮雨者』，工坊稱『降水軌跡改寫』，研究院稱『降水矢量偏移類』。各自有效但不可抹除資訊差。
- 地區可能引用彼此報告，也可出於商業利益故意誇大等級。**官方公示是社會產物，不是宇宙認證。**
- **所有首次大場面的描寫先展示物理與生活後果，後面才逐步由角色命名。** 不要『某三相啟動某某技』的遊戲語感。

## 4. 能力進步與質變有三套不同證據
A. 熟練／聰明：相同法則，因幾何、時序、材料與搭檔而表現不同。B. 裝備／組織：能力本體未變，外部文明讓它更可怕。C. 生命／存在質變：觀察到前後可重現的新本質，才有理由升相。**單次打贏高相、名聲大、創造者稱讚不自動升相。**

## 5. 第一卷可操作的逐步揭露
1. 郝知遙先看到起重機不可解的載重數字，並不講『HX-003三相』。
2. 顏晴沅／顏秋禾的公共雨棚事故（候選）：居民只知道雨水像被一片看不見的簷沿分開，有人獲救、也有人要求鑑定排水去處。
3. 葉舫依法取得鑑定書，當中區分**確認／推測／沒有測試**，由此引發保險責任爭議。
4. 第二卷，各地鑑定所對同一現象發生稱呼不一，形成共同標準競爭；也有人拒絕公開配方。
5. 第二卷中後期才可出現『七相』的研究性比較，其定義仍可被下一個實例修正。

**硬限制：** 不可為了讓普通居民懂劇情而突然把每人排到精確的第N相。表面輕巧的造物仍能造成城市級危害，不能因『無生命相位』而寫弱。
