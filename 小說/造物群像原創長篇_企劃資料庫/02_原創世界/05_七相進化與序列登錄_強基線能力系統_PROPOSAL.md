# WORLD-05｜原創能力系統：強基線的「異序」與七相深化（PROPOSAL）

**本檔全為原創提案，僅「初始可很強、保留進化空間、能力脈絡一致」是已獲使用者確認的創作原則。** 舊案「新世界不使用原著式統一序列號」仍合理；這裡提出一種**可選的社會登錄編碼**滿足讀者追蹤大量能力的便利，不照搬陳燁實驗先後順序。

## 一、四種必須區分的數據

- **異序號**：檔案事件的登錄編號（例如 `HX-014`），可重編、異名、多人共享一次事件的登錄，不是創造順序，也不是升階序列。登錄者只是某地協作的紀錄機構，無權替所有地區命名。
- **生命相位**：一個生命的存續、感知與對環境規則的作用深度。非生命造物可標「非適用」，卻仍有致命影響。
- **規則強度與有效範圍**：能力作用的是什麼、可否跨遮蔽物與介質、同時作用數量、是否帶概念優先權、可以持續多久。這與相位不一一換算。
- **現實危險／社會重量**：面對的敵人、資訊、軍械、地點、政治權利、技術影響、家族與人情等。九位家人的尺度完全獨立於這套地方分類，不能硬塞為「第七相」。

## 二、「七相」研究模型（可定名、改為非七級，先用於劇情設計）

| 暫稱 | 存在／能力質變，不是爆炸當量 | 示範與盲區 |
|---|---|---|
| Ⅰ「顯型」 | 生命／造物第一次有穩定、可辨認的異常本質；單一能力**已可強到摧毀港口主吊架、遠距移動或制壓大量普通武裝** | 非戰鬥型可改變醫療或證據法；不要求出場弱小 |
| Ⅱ「成式」 | 行動從直覺變成可反覆驗證的穩定規則，有效條件與失效條件可被掌握；精確、可靠性改變 | 不是單純功率翻倍，強使用者與弱研究者均可到達 |
| Ⅲ「並序」 | 同一來源的多次作用可穩定協同／跨對象連鎖，形成可設計的技術體系；協同仍沿既有能力核心 | 不等於憑空獲得全新元素能力 |
| Ⅳ「留界」 | 生命或能力與一定環境建立持續關係，在離開現場後仍留下可驗證的異常結構／痕跡 | 不自動意味可毀滅世界；對自然與制度有長時段影響 |
| Ⅴ「越岸」 | 不再完全依賴原所在地、材料與單一地理條件，能沿已建立的介質／法則跨遠域續存與運用 | 沒有先前連通條件者不能突然任意跨世界 |
| Ⅵ「自證」 | 身分與存在不完全靠原容器／單一肉身維繫；生命及其能力的延續方式實質改變 | 不等於無敵不死、不等於放棄情感與人格 |
| Ⅶ「立源」 | 可成為一種新現象可持續自我運作的源點，改寫一定領域對該現象的可能性邊界 | 只作遠期研究假說；世界內尚不能可靠核驗，也不是九家人能力上限 |

**限制／開放問題：**七相是一套跨機制的比較語言，不保證每件物品必能升相或需要走完七相。常見物件出場可以已有Ⅱ或Ⅲ的效果；人也可能一生維持Ⅰ卻憑絕佳能力和戰術對高相構成危險。各地可能拒絕此分類。

## 三、進化不靠殺怪經驗值

- **起源強度不低**：每份能力首次登場先寫它在現實中何其可怕，並列足以推動大事件的直接作用。只用「打不過新人」支撐升級欲望的設計需退回修改。
- **第一層增長：理解**：測試、數據、失敗、同伴的異質專業，令既有能力組合出新戰術；不必升相。
- **第二層增長：相位質變**：人物自身長期心理、存在結構、環境實際改變；能力表現出可觀測且與主幹一致的轉變，不是先定賞金再換新技能。
- **第三層增長：外物與文明**：儀器、工程、軍事、法律、後勤、宗教與信任網把原有能力運用至新的尺度；**人變強也不等於其本質一定進化**。
- **外來能量與獻祭**：可作個別故事的特殊事件，但不要機械地設成每個人的必經修練門檻。
- **難度梯度**：初期可怕→理解更精準→協同更加致命／有用→存在方式真正質變。錯誤理解可導致巨大意外但不要求新使用者降智；另一方反制成功須有情報來源。

## 四、各角色的量化測試（非最後戰力）

每位人物／非生命造物個別記：初始最大確認規模、能改變的客觀條件、反制的實際手段、開發與社會利用路徑、使用者的人生動機、是否可質變及哪一段劇情才可能發生。**不把九位家人填入這張階梯競爭表**。
