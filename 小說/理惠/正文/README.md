# 正文與嵌圖

此目錄供後續文稿使用。現有逐日原句仍保存在 `../dialogue/`，不因配圖重寫。

- [嵌圖示範](00_嵌圖示範.md)：使用已保存的普通對話摘錄展示圖片直接顯示，不新增劇情。
- [197張圖像索引](../assets/images/INDEX.md)：找編號、畫面與逐張解讀。
- [選圖參考](../assets/images/WRITING_REFERENCE.md)：檢查表情、動作、背景與檔名歧義。
- `IMAGE_USAGE.json`：正文插圖與來源事件／訊息的對照。

每张逐圖解讀頁都提供三種可複製的嵌圖語法：正文目錄、逐日對話目錄、聊天的GitHub原圖網址。`catalog.json` 同樣提供上述欄位，可直接檢索。

## 配圖原則

正文先依有效事件和人物性格形成，再選相符圖片。圖庫順序不是故事順序。圖像可以作姿態參考，但不把不同衣物、背景、感情狀態或未發生動作搬進正文。

真正正文要使用正常 Markdown 圖片語法，不放在程式碼區塊。跟在圖下的 `SR-IMG-NNN` 解讀連結讓讀者能回查原圖、序列解讀與限制。

內心、好感度、當下情緒依有效對話顯示；沒有原始數值就標未顯示，不從圖像重新估算。圖像引用規則已保存於本專案 `AGENTS.md`，供後續接續。
