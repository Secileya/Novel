## 來源與正典

- 先讀 `整理進度.md`、`人物設定/目前人物狀態.md`、相關最新有效事件與 `人物設定/說話方式與性格.md`。
- 修正優先序：使用者明確撤回／作廢 > 後期明確修正 > 後期相容補充 > 早期相容設定。
- `原始對話/` 是原來源，`分日對話/` 保存分日來源及當時採用段，`人物設定/` 是整理；`正文/事件閱讀順序.json` 指向38個最新有效完整事件，另有兩個舊路徑導讀。同事件合併後不要把舊分日檔再演一遍；不得把示範或圖像資料反向當成原始對話。
- 故事日與撰寫順序分開。後來回補第一天的段落放回第一天，保留取代關係。
- 保留原有內心、好感度、情緒及狀態；來源未顯示的欄位不偽造。
- 平台拒絕、中斷、重試不是人物記憶。

## 每次正文與模擬對話配圖

使用者已指定：之後正文要在相應段落穿插圖像索引引用，圖片直接顯示，不只給編號或超連結。

1. 查 `圖庫/圖片資料索引.json` 或 `圖片索引.md` 選圖；確認表情、動作、場景與衣物，不能只看原檔名。
2. 在對應敘事節點後輸出 Markdown 圖片 `![理惠｜SR-IMG-NNN](圖片路徑)`，並附相同 ID 的解讀索引連結。不要把嵌圖語法放在程式碼區塊內，否則正文只會顯示文字。
3. `正文/` 文稿使用每張的 `markdown_embed_from_prose`；`分日對話/第幾天/` 使用 `markdown_embed_from_dialogue`；聊天使用 `markdown_embed_for_chat`。更深目錄重新計算相對路徑。
4. 程式碼區塊只用於「如何引用」教學；真正正文中的圖片必須是正常 Markdown。
5. 有相符圖才插入。僅表情或姿態相符時標示「表情／姿態參考」，不要改正文去迎合不符衣物或背景。不符就略過，不假造缺號或事件。
6. 不把197張全部塞進一章；按當前情節節點配圖，並記錄於 `正文/正文配圖紀錄.json`。
7. 圖像不是同意、高潮、內心、好感度或已發生事件的獨立證據。婚禮、懷孕、育兒素材不自動改動關係狀態。
8. 151／152依146–150的口交連續圖解讀為口內射精／其後。158／159主要是乳交；161／162未清楚呈現舔肛。其他歧義見逐張解讀。

角色回話仍維持既有自尊、挑釁、嘴硬與選擇權；高好感度不抹除性格、不同意或真正拒絕。圖片只補充表達，不決定台詞。
