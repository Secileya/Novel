# 《Backrooms：無盡層級》重寫底稿

> 狀態：重寫前統整稿
>
> 原對話寫到第四十章，但第一至四十章的正文、章名與具體事件順序均不視為定稿。它們只是一批試寫素材。正式版本將在目前工作資料夾內從頭重寫。

## 一、作品核心

這是一部以「掉入後室、求生、探索大量層級並逐漸成長」為主體的長篇小說，預計總量可控制在五百章以內，但不先用固定章數限制故事。

後室必須是一個遠比主角、神器和兩名旅行者更大的世界。它有自己的層級、生態、實體、人類聚落、組織、交易、歷史與無法解釋之物。故事不能變成每到一層便破解一條規則，也不能讓所有異常都服務於主角的心理或身世。

作品的主要魅力應由四部分共同構成：

- 真正會致命的環境與實體。
- 現實世界不存在的景色與旅行感。
- 人類在後室建立的社會，以及利益、信任、背叛和互助。
- 零散而低頻的長線謎團。

## 二、主角：沈曜

沈曜進入後室前，已經厭倦日復一日的現實生活，對原本的人生缺少興趣與留戀。他不是一心求死，也不是無所畏懼；遇到危險時仍會恐懼，本能地想活下去。

他願意向未知前進，不是因為任務或救世使命，而是因為後室存在現實中永遠看不到、甚至可能從未有人看過的風景。這種好奇心與厭倦感是他的探索動機，但不能抹去普通人的恐懼、錯判、疲憊與求生反應。

性格與行動邊界：

- 不是天才解謎者，也不是冷靜到沒有情緒的攻略機器。
- 不以善良救世主為預設人格，救人與否要依當時關係、代價和選擇成立。
- 能觀察、記錄和學習，但不會知道作者才知道的答案。
- 逐漸學會區分哪些情報可以分享、哪些底牌需要隱藏。
- 探索動機必須多樣：好奇、求生、尋找物資、救人、交易、被迫逃亡、個人選擇或偶發事件；不能每次都是接任務。
- 成長不是單純戰力上升，而是生存能力、判斷、人際關係、裝備運用和對後室尺度的理解同步增長。

結局暫不決定。如果最後逃回現實，現實中必須先建立足以支撐他堅持回去的人或事；如果最後選擇留在後室探索，則要逐步寫出他對現實已無足夠留戀，而不是結尾臨時決定。

## 三、雙翼短杖／可展開鐮刀

### 定位

這是一件早期取得、接近神器級但並非萬能的異常物。它能讓沈曜與其他探索者有所區別，但不能替他自動解題、一路殺穿層級或免除真正的危險。

它不是命定主角獎勵。沈曜是在 Level 0 經歷長時間求生與 Bacteria 追殺後，意外切入一個未知空間，通過三段極端檢測，才取得這件物品。取得代表他達成了某種條件，不代表宇宙選中了他。

### 外觀

- 收納時是一根約三十五至四十五公分的黑色短杖，可攜帶，也可作為普通探路與防身工具。
- 材質介於金屬、石質與骨質之間，表面幾乎不受磨損。
- 上面有兩組很小的翼形印記：藍紫色惡魔翼與紅黑色蝙蝠翼。不仔細看只會當成紋路。
- 展開時結構延伸並形成戰鬥鐮刀，但正式重寫時不必沿用舊稿的每個機械細節。

### 已確定能力方向

1. 異常切割：可傷害部分普通武器難以作用的實體或異常物，也能切斷部分異常結構。
2. 規則／空間干涉：在符合條件時，能切開某些不合理連結、穩定即將消失的出口或製造一次賭命切出；不能任意選擇目的地，也不能把它當傳送門。
3. 情緒感知：可感受到附近人類或實體的情緒狀態，但不能讀心、判斷善惡、測謊或直接知道來源與原因。
4. 少數實體的認知反應：只有真正接觸過相關痕跡的極少數實體，才可能對翼形印記產生停頓、觀察、等待、悲傷、希冀等反應。這不是控制，也不等於友善。

寫作規則：

- 能力可以較早變得實用，不必為了拖成長而長期只寫「沒有反應」。
- 沈曜會主動研究、測試、記錄並逐步信賴它，不會在它有反應時無視。
- 真正感知到情緒時直接寫出情緒，例如「恐懼」「敵意」「等待」；不要用「不是熟悉、不是悲傷」的排除句式。
- 人類情緒較清晰；普通實體更多是飢餓、領域性、狂躁、捕食衝動或難以整理的混亂。
- 短杖是穩定可用的探索與戰鬥工具，不是每章突然失靈的抽獎道具；高階干涉仍可有體力消耗、短暫無法再次展開等可觀察限制。
- 限制必須由沈曜實際測試或遭遇後得知，不能直接用作者口吻宣布「冷卻」「失效」或完整能力表。

## 四、Stiliya 與 Versiliya 的痕跡

完整角色核心、Backrooms 旅行規則、實體關係與 Level Fun 事件史，另見同資料夾的《Stiliya／Versiliya 與 Backrooms 設定統整》。本節只記錄沈曜主線必須遵守的呈現規則。

她們是超脫單一世界與時間線、曾在後室旅行並留下物品或回憶的兩名旅行者。這不代表她們創造或管理 Backrooms，也不代表後室以她們為中心。沈曜前期不知道她們的名字與身分。

她們的痕跡應像彩蛋，混在後室無數組織標記、探索者塗鴉、實體作品、自然紋路和異常物品之中。不能看到翅膀就指向她們，也不能讓每一層都有相關痕跡。

頻率原則：十幾章到幾十章才可能出現一次；不是集中在某一篇大量投放。出現頻率不因暗線升級而增加。

發展方式：

- 前期：偶然彩蛋。可能只是一句俏皮留言、`ya`、顏文字、小物件或背景畫面，主角未必注意。
- 中期：低頻暗支線。不同人物曾看過相似印記，少數高層開始調查，某些實體產生反常反應，但仍無法拼出完整身分。
- 後期：已有線索開始互相連接，揭露她們曾經旅行和留下影響的事實；不把整個後室收束成她們的故事。

重要區分：她們親自接觸過的實體可以對她們形成深刻且只屬於她們的感情；沈曜旅途中遇到的絕大多數實體則從未見過她們，也不會對短杖產生特殊反應。

## 五、世界與敘事硬規則

- Level 0 通常沒有其他人，不能為了煽情隨便塞倖存者。
- 從 Level 0 切出並不是令所有基地人員震驚的奇蹟；真正值得注意的是未知空間、特殊經歷或異常物。
- 沒有人掌握全部層級。角色只能依自己的經歷、組織資料和可靠傳聞判斷。
- 其他探索者也會擁有特殊物品；沈曜不是唯一能接觸異常裝備的人。
- 後室危險不能總是複製人、幻覺或內心投射。要有實際會殺人的實體、環境災害、錯誤空間、生態規律和人類衝突。
- 並非每個層級都有完整謎底、筆記、控制室和規則說明。很多景象與事件可以永遠沒有答案。
- 不按 Level 0、1、2、3 逐層打卡；入口、意外切出、組織路線和賭命逃亡可把故事帶到數字很大的層級或無編號區域。
- 重要篇章細寫，普通旅程可跳時或濃縮，避免流水帳，也避免每章重複「第一次」「不知道」「沒有回答」等固定節拍。
- 文字恢復正常小說段落，不沿用舊稿一句一段、段段分隔線的形式。

## 六、可回收的事件原型

### 1. Level 0 → 未知空間 → Level 1

Level 0 必須是一段有份量的孤獨求生篇，而不是三小時走完。沈曜缺乏裝備，在飢餓、疲憊、方向錯亂與 Bacteria 的真實追殺中逐漸學會生存。最後全身是血、被逼到死路時，他抱著可能死亡的準備撞牆切出。

未知空間不是一般層級攻略，而是一處帶有血族哥德建築、庭園、高塔、石橋和柔和光線的廣大地域，風格中混合 Stiliya 與 Versiliya 的色彩，但不直接標示主人。三段檢測概念可保留：

- 絕對靜止：在追殺者逼近時壓住呼吸、動作與心跳。
- 概念剝奪：感官、文字、記憶與自我概念被逐層抽走，只能抓住「活」這個最原始執念。
- 自我重置／死生判定：以矛盾條件逼迫沈曜做出極端選擇；具體破解方式重寫時再設計，舊稿不直接沿用。

通過後取得短杖，再切入 Level 1。沈曜可以描述未知空間的環境，但會隱藏短杖以及真正需要保留的細節。

### 2. Level 1 的社會化階段

Level 1 用來讓沈曜第一次接觸後室人類社會：基地、物資、交易、情報、組織、獨行者與其他異常物。這不是永久基地日常，也不是連續接任務，而是讓他學會在「人比實體更難判斷」的環境裡生活。

可保留人物名：林澤、陳默。兩人的完整定位與是否保留到正式版，重寫角色表時再確認。

### 3. Level 6 與 Level 6.1

原本目標是前往 Level 6.1，途中卻誤入極危險的 Level 6。這一篇應造成真實損失，迫使隊伍失散，在黑暗、聲音誤導與實體威脅中求生，最後由倖存者在危急時切入 Level 6.1。

Level 6.1 不只是休息站。可保留無盡餐飲空間、黑市、人類聚落，以及「溫室巨嬰／前廳模仿者」式群體：有人在安全區複製排隊、炒作貨幣、消費與抱怨等前廳儀式，藉此假裝正常生活仍然存在。不能把所有人都寫成單純蠢人；這些行為背後應有否認、懷念、階級和利益。

### 4. Level Fun：F-214 事件原型

這是目前最值得獨立保留的單篇素材。

完整版本須同時包含「兩名旅行者當年的真實派對」與「多年後 M.E.G. 小隊觸犯保留物的探索事故」，不能只保留後者的恐怖橋段。

- 採 M.E.G. 探索紀錄或第一人稱倖存報告，可與主線保持距離。
- 小隊進入 Level Fun 回收失聯隊伍資料，發現一扇過度普通的木門。
- 門後是 Partygoers 長期維護的特殊派對房間：派對桌、蛋糕、兩個保留座位、動漫風共同畫作，以及雙方交換的禮物；花圈只是其中一件。
- 畫裡是兩名曾參與派對的旅行者，一人帶藍紫色惡魔翼意象，一人帶紅黑色蝙蝠翼意象；她們不是神祇或英雄，只像曾在此自然停留過。
- Partygoers 是蜂巢意識，但蜂巢意識不等於每具身體機械式同步。它們可共享目標、記憶與反應，同時採取不同分工。
- Partygoers 對普通人依然欺騙、感染、捕獵；它們卻把兩人視為真正參加過派對的朋友，並留下非人但豐富的情感性行為：兩個保留座位、照顧雙方禮物、重現特別日子的布置、等待、希冀、失去、佔有與專注的暴怒。
- 一旦有人帶著明確意圖碰觸花圈，事件不可逆。物品即使不可損壞，整個 Level Fun 仍會透過蜂巢意識同時知道「那個東西被侵犯了」，追獵集中到觸碰者；此人無論如何掙扎都必死。
- 短杖／鐮刀上的印記日後可讓所有 Partygoers 短暫停頓並傳來「等待」，但只足以讓沈曜逃過一次，不構成永久豁免、控制或友善關係。

### 5. 玻璃森林、荒地與觀測站

舊稿第三十四至四十章的具體正文不保留，但可回收三個概念：

- 玻璃森林有自身生態與模仿、適應型存在，不與兩名旅行者暗線相連。
- 荒地中存在具有領域性、遷徙規律或群體行動的巨大生物；它們不是專程等待主角的關卡。
- 廢棄觀測站曾由某個未知人類組織使用，而觀測者也可能是被觀測的一方。

正式重寫時，三者可以拆成不同篇章，也可以全部放棄；不繼承原稿的錄影、警告文字、控制台解答和事件順序。

## 七、明確放棄的舊稿傾向

- 第一至四十章的現有正文、章序和句式。
- 一句一段、每段插入分隔線的排版。
- 每個層級都是房間、筆記、規則、控制台、錄影和出口的同一套流程。
- 危險總在映照沈曜內心，或頻繁使用複製人與心理幻象。
- 每次遇到特殊實體都讓短杖反應，並強行連回 Stiliya／Versiliya。
- 角色明明不知道，敘事卻先宣布物品機制、層級真相或「這是最後的考驗」。
- 為了強調伏筆而反覆寫翅膀、熟悉、悲傷、沒有反應。
- 只做設定展示而沒有具體代價、選擇與後續影響的章節。

## 八、正式重寫的建議起步

正式版先只鎖定前四個篇章節點，不急著排到五百章：

1. 現實生活與墜入：用具體日常建立沈曜的厭倦，以及他仍會害怕死亡的矛盾。
2. Level 0 長期求生：真正的孤獨、資源壓力、錯判與 Bacteria 追殺，讓他在沒有神器時先具備可信的生存底子。
3. 未知空間與取得短杖：三段檢測必須是高潮，也要留下未解之處。
4. Level 1：讓沈曜知道後室不只是迷宮與怪物，而是一個有人類秩序、利益和無數道路的世界。

之後再依角色關係與事件後果決定先走普通探索、Level 6／6.1，或插入第一篇獨立探索紀錄。每一個新篇章開始前，只需確認四件事：進入動機、核心景色、真正危險、離開後造成的改變。

## 九、暫時保留、尚未定案

- 故事最終是回到現實，還是留在後室。
- 短杖／鐮刀的正式名稱、能力上限和第三段檢測的精確破解方式。
- 林澤、陳默及舊稿其他配角是否沿用，以及誰會在 Level 6 事件中存活。
- 公開 Wiki 層級設定與原創改編的比例；正式寫到特定層級時再逐層確認，不一次鎖死。
- Stiliya 與 Versiliya 的真相在正文中揭露到什麼程度。

這些空白不是漏洞，而是重寫時仍可調整的設計位；未確認前不能由正文擅自定案。
