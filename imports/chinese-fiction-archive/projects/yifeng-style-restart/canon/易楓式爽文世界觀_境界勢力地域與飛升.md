# 易楓式爽文世界觀：境界、勢力、地域與飛升

## 一、世界總體結構

這條世界線採用「下界一座完整大世界—九大仙域—諸天道域—界海」的階層結構。

故事開局所在的下界名為**蒼玄界**。蒼玄界不是隨時可以被上界隨手摧毀的假世界，也不是只為襯托仙界而存在的新手村；它有自己的歷史、王朝、宗門、妖族、商路、海域與飛升傳承。當人物升往更高世界後，下界既有勢力仍會生活、改變、結盟與產生新的故事。

完整空間順序如下：

**無名谷 → 青河郡 → 雲州 → 東陵 → 天衡大陸五方地域 → 蒼玄界 → 青冥仙域 → 九大仙域 → 諸天道域 → 界海。**

六位主角不受這套境界表準確衡量。境界只用來建立當地人的認知、勢力秩序與迪化升級層次，不能反過來限制絲蒂莉雅、薇絲莉雅、塞希莉雅、法月懷、璃安與小曦。

## 二、下界修煉境界

蒼玄界採十個主要境界，每境分初期、中期、後期、圓滿。功法本身的「第幾重」與修煉境界分開計算；例如顧行舟的《歸雲心典》第三重，不等於他處於第三個修煉境界。

| 境界 | 核心變化 | 通常影響範圍 |
|---|---|---|
| 淬體境 | 淬鍊皮肉、筋骨與氣血，能正式承受靈氣 | 村鎮武者、宗門雜役與外門起點 |
| 引氣境 | 感知並引導天地靈氣入體 | 小城修士、宗門外門主力 |
| 築基境 | 建立穩定道基，開始使用完整術法與法器 | 可在一縣之地立足 |
| 靈臺境 | 識海成臺，神識外放，可短距離御空 | 郡城強者、小宗長老 |
| 金丹境 | 靈力凝丹，壽元與力量大幅增長 | 一郡頂尖、七品宗門根基 |
| 元嬰境 | 元嬰離體，遠距御空，肉身受損仍可能存續 | 一州主要勢力的鎮宗人物 |
| 化神境 | 神魂與天地法則初步相合，可改變大範圍天象 | 一州霸主、跨州強者 |
| 洞虛境 | 洞察空間與法則縫隙，可開小型洞天 | 一方地域的重要巨頭 |
| 合道境 | 自身之道與天地規則相合，一念可影響山河秩序 | 皇朝、古宗與聖地核心 |
| 渡劫境 | 經歷天劫洗鍊，逐步將凡軀與靈力轉化為仙基 | 蒼玄界明面最高層；圓滿後可叩開天門 |

### 下界戰力使用原則

- 一般小宗弟子多在淬體、引氣；真傳弟子多在築基至靈臺。
- 金丹足以在青河郡稱雄，元嬰能左右雲州局勢，化神以上不會無理由集中在開局小城。
- 洞虛、合道與渡劫各有真正地位，不可剛登場便被下一境界大量取代。
- 六位主角的日常物件可能讓人跨越瓶頸，但不保證任何得到東西的人當場連破十境；機緣首先補全道路，真正走多遠仍與接受者自己的選擇和承受能力有關。

## 三、仙域境界

渡劫圓滿者經天門飛升後，凡靈會逐步轉成仙元，進入仙域十境：

| 境界 | 核心定位 |
|---|---|
| 人仙 | 剛完成仙元轉化，正式脫離凡軀限制 |
| 地仙 | 能與仙域地脈共鳴，建立穩定仙基 |
| 天仙 | 可調動較完整的天地仙則 |
| 真仙 | 真靈穩固，普通形神毀傷難以真正殺死 |
| 玄仙 | 開始掌握多重仙則與深層空間 |
| 金仙 | 金性不朽，能承受跨域遠行與界壁侵蝕 |
| 仙君 | 可統御一方仙州、建立大型仙門 |
| 仙王 | 能開闢或長期維持獨立仙界碎片 |
| 仙尊 | 足以左右一大仙域的秩序與興衰 |
| 仙帝 | 九大仙域明面頂點，可使自身大道烙印跨越多座仙域 |

璃安的正式設定已明確遠遠超過仙帝，因此仙帝不能被知情旁白當成她的準確境界。其他五人同樣不能被本表封頂或硬塞進某一境。

## 四、仙帝之上的諸天境界

仙帝走到自身仙道盡頭後，不再稱為飛升，而稱為**證道**。證道成功者離開九大仙域，進入諸天道域。

| 境界 | 說明 |
|---|---|
| 道君 | 能把自身大道化成獨立規則領域 |
| 道尊 | 一道可貫穿多座世界，門人能沿其道修行 |
| 道主 | 可成為一座完整道域的秩序核心 |
| 道祖 | 能追溯並改寫一類大道的源流，但仍不等於全知全能 |
| 超脫者 | 離開既有道域生滅循環，開始接觸界海 |

「超脫者」仍只是本地宇宙體系對極高存在的稱呼，不是六位主角的最終力量定義。即使道祖看見小院，也可能只敢把她們判斷為「不可理解的超脫者」；這仍然只是新的低估。

## 五、勢力等級

蒼玄界通行九品制，九品最低、一品最高。評級不只看最強者，也看傳承、資源、護山大陣、附屬地域與能否穩定培養下一代。

| 勢力級別 | 最低常見支柱 | 通常統治尺度 |
|---|---|---|
| 九品 | 築基境 | 鄉鎮、小型山門 |
| 八品 | 靈臺境 | 一縣或數座城鎮 |
| 七品 | 金丹境 | 一郡重要勢力 |
| 六品 | 元嬰境 | 一州大型宗門 |
| 五品 | 化神境 | 數州聯盟或皇朝重臣級勢力 |
| 四品 | 洞虛境 | 東陵、南嶺等一方地域的霸主 |
| 三品 | 合道境 | 跨地域古宗、上古世家與強大神朝 |
| 二品 | 渡劫境 | 大陸頂尖勢力 |
| 一品 | 多位渡劫、完整飛升傳承 | 聖地、祖庭與中央神朝 |

達到一品門檻後，勢力通常不再以數字品級自稱，世人多直接稱其為聖地、神朝、祖庭或禁區。禁區不一定是邪惡勢力，也可能是無法被現代修士理解的古代遺存、特殊生靈領地或破碎世界入口。

仙域勢力則分為仙門、仙宗、仙宮、帝統四階。帝統代表曾誕生或仍有仙帝坐鎮，不表示其所有弟子都凌駕下級勢力。

## 六、地域劃分

### 6.1 青河郡：開局地域

青河郡位於雲州南側，山多、雨多，靈氣在東陵只能算中下。凡人城鎮、修仙宗門與山中妖族彼此交錯，消息通常要數日至數月才會傳到州府。

已出場地點：

- **無名谷：**六人居住的舊院所在。原本在地方地圖上只是一處亂石枯木遍布、靈氣稀薄的普通山谷。六人入住後，外界地圖、靈脈與因果並未立刻自動公開改名；當地人仍只知道它叫無名谷。
- **青河城：**距無名谷百餘里，是郡內最大的交易與消息集散地。城主府、百珍樓分樓及數個修仙家族共同維持秩序。
- **歸雲山：**歸雲宗山門所在，目前護山陣已破，宗門危局尚未解除。
- **斷岳嶺：**斷岳門根基所在，掌握青河郡多座礦山與法器工坊。
- **落雁山脈：**人族與妖族勢力交界，可提供前期靈材、妖族視角與非宗門型角色。

### 6.2 雲州

雲州下轄十二郡。最高常見力量為元嬰，化神通常只在重大事件中現身。州府設有皇朝巡察使、問星樓州閣與跨州傳送陣。

青河郡的消息必須先經歷當地證實、商旅傳播與州閣複核，才能形成「無名谷隱居著前輩」的第一版傳聞，不能第一天便全州皆知。

### 6.3 東陵

東陵由三十六州構成，受**大晟神朝**東境朝廷名義統轄。此地宗門、世家、皇朝與妖族互相牽制，洞虛境才有資格成為一方真正巨頭。

### 6.4 天衡大陸

天衡大陸分為五方地域：

- **東陵：**宗門與皇朝並立，故事起點所在。
- **南嶺：**妖族、靈植與古老山靈眾多。
- **西荒：**古戰場、佛門、苦修者與失落城邦並存。
- **北原：**冰原、遊牧王庭、器道宗門與遠古巨獸活動區。
- **中州：**聖地、神朝中央與跨域傳送核心集中之處。

大陸之外有四大海域、群島仙門與海族祖庭。海域不是單純番外地圖，而能從商路、天象與飛升古史持續影響陸地。

### 6.5 蒼玄界

蒼玄界以天衡大陸為最大已知陸地，另有海外大洲、懸空洞天與尚未完全探索的界外裂域。中州強者口中的「天下」通常只是已知文明圈，不代表他們真正掌握整個世界。

## 七、開局主要勢力

### 7.1 青河郡勢力

- **歸雲宗：**顧行舟所屬宗門。曾是七品宗門，因根本心法與問雲碑長期殘缺、強者凋零，如今實際只剩九品底蘊。其核心不是報仇工具，而是一群仍想守住傳承與山門的人。
- **斷岳門：**目前追殺顧行舟並進攻歸雲宗的七品勢力。表面目的是吞併山門與靈脈，真正看重的是問雲碑可能指向的上古傳承。行事強硬，但門內不同人物可以有利益、恐懼、野心與服從命令等不同動機。
- **青河城主府：**八品官方勢力，優先維持城池與商路，不會無條件替歸雲宗或斷岳門站隊。
- **百珍樓青河分樓：**跨地域商盟的地方分支，負責買賣、拍賣與消息流通。它會是最早把小院日常物件送到更大地域的渠道之一。
- **問星樓青河暗樁：**不公開立門，只收集異象、強者與遺跡情報。它是迪化傳聞的重要放大器，但每次判斷都必須有情報證據，也可能作出合理卻錯誤的結論。
- **落雁山妖族：**由數個妖族族群構成，不統一服從單一妖王。它們對靈脈與自然異動的感知早於人族，可能比青河城更早注意到無名谷正在改變。

### 7.2 東陵級勢力

- **大晟神朝：**名義統轄東陵三十六州，以官府、軍鎮、學宮與封王共同治理，不是只會派人挑釁主角的空殼皇朝。
- **太微劍宗：**東陵四品宗門，以劍道與跨州除妖聞名。初期可能把問雲碑的變化理解為失傳劍道或洞虛遺府。
- **問星樓：**跨越五方地域的情報勢力，擅長榜單、天象與因果推演。它會反覆修正對無名谷的評級，構成「每次以為終於看懂，實際又低估」的長線笑點。
- **萬寶商盟：**百珍樓所屬商盟。重視可交易價值、契約與商路安全，能把六人的日常物件帶進拍賣、皇朝與聖地視野。

### 7.3 大陸頂尖勢力

- **太初聖地：**蒼玄界最古老的人族聖地之一，保存飛升史與部分上界記錄。
- **大晟中央神朝：**大晟神朝核心，與東陵地方朝廷並非同一層級。
- **萬妖祖庭：**統合部分大妖血脈與妖族古地，但不能代表所有妖族。
- **滄海龍庭：**四海最強勢力之一，掌握海域航路、潮汐與多座海底古陣。
- **葬星淵：**位於中州之外的禁區，傳說能看見不屬於蒼玄界的星辰。它將在飛升篇以前提供第一批「這座小院或許根本不屬於本界」的證據。

## 八、飛升後去哪裡

### 8.1 蒼玄界的固定飛升目的地

蒼玄界的渡劫圓滿修士叩開天門後，正常情況下會飛升至九大仙域之一的**青冥仙域**。

具體落點是：

**青冥仙域—東極仙州—接引古城。**

接引古城設有三十六座接引臺。新飛升者會先完成仙元轉化、登記來處，再自行選擇加入仙門、接受原宗門上界祖庭接引，或以散仙身分進入仙域。沒有上界靠山不等於一定被抓走或奴役，但會面臨資源、身分、語言與仙域規則上的現實壓力。

### 8.2 飛升路徑規則

- 飛升目的地主要由下界坐標決定；蒼玄界通常只能通往青冥仙域。
- 擁有完整上界仙印的宗門，可以把本宗飛升者引向特定接引臺。歸雲宗原有的仙印早已失落，因此歷代無人知道其上界傳承是否仍存在。
- 上界仙人若以真身強行降臨蒼玄界，會受到界壁壓制，力量最多只能穩定維持在渡劫層次；投影、化身與隔界法器則能繞過一部分限制，但無法完整承載本體。
- 下界修士飛升是單向成本極高的遷移，不是想回便能立刻回。仙域勢力因此不會每遇見一點異象便派無數仙王下凡。
- 六位主角不受飛升通道限制。她們若前往仙域，是因為旅行、好奇、陪伴某人或想看看某件東西，而不是境界到了、被天劫逼走或下界容不下她們。

### 8.3 上界劇情的第一個鉤子

小曦補全問雲碑後，碑中失落的上界印記也已恢復，只是顧行舟與歸雲宗尚未察覺。

青冥仙域某處早已衰敗的**歸雲仙宗**會逐漸感應到斷絕多年的下界道統重新亮起。上界人物最初會以為是祖師遺留的後手，之後以為有下界渡劫高人修復傳承，再之後才發現完成此事的只是一名覺得石頭在哭的兔耳女孩。

這條線能讓上界提前產生反應，卻不讓上界人物立刻降臨並搶走下界篇的敘事位置。

## 九、仙域與更高地域

### 9.1 九大仙域

九大仙域彼此並列，每一域都包含大量仙州、洞天、仙城與附屬小世界。青冥仙域只是蒼玄界飛升者的第一站，不是九域中心。

九域中央存在一片不直接歸屬任何仙域的區域，稱為**太初天**。仙帝議事、跨域交易、帝統爭端與通往諸天道域的證道臺皆在此匯聚。

其他八大仙域的名稱暫不一次固定，等實際進入相應劇情再依文化與主題命名，避免現在製造大量永遠用不到的空殼設定。

### 9.2 諸天道域

道域不是一層更大的普通大陸，而是由不同大道秩序形成的世界群。某些道域以劍、夢、輪迴、生命或機關為根本，也有多種大道共存的開放道域。

仙帝要進入道域，必須在太初天證道成功。失敗者不一定死亡，也可能大道崩解、退回仙尊或成為失去前路的殘道者。

### 9.3 界海

界海位於已知道域之外。不同宇宙、破碎世界與未成形可能性如島嶼般浮沉其中。當地超脫者只能有限航行，不能宣稱掌握全部界海。

界海是本世界力量體系的最高已知地域，但仍不是六位主角的來源答案，也不負責把法月杏、法月懷或塞希莉雅的本質重新解釋成當地體系產物。

## 十、迪化認知升級梯度

不同地域必須依自己掌握的證據推斷六人，不能所有人一開始就喊出最高境界。

| 觀察層 | 初步判斷 | 為何合理 | 後續如何被推翻 |
|---|---|---|---|
| 青河郡 | 隱居的金丹或元嬰前輩 | 問雲碑修復、山谷隔絕追兵 | 金丹無法使殘缺本身失去成立理由 |
| 雲州 | 化神至洞虛高人遊戲人間 | 機緣能改造宗門傳承與地脈 | 洞虛造物開始影響跨州天象與飛升印記 |
| 東陵 | 渡劫老祖或上界謫仙 | 無名谷物件超出下界煉器極限 | 天劫與界壁反而主動避開小院的日常痕跡 |
| 蒼玄界聖地 | 仙君、仙王的下界化身 | 上界古籍只能找到這個最接近的解釋 | 小曦隨手修復的東西在青冥仙域也被當成無上道源 |
| 青冥仙域 | 仙尊或仙帝隱遊 | 下界物件跨界後仍能改寫仙則 | 仙帝無法看懂風箏上一筆最普通的線 |
| 九大仙域 | 道君、道尊投影 | 仙帝體系已無法衡量 | 諸天道域發現她們的日常先於本域大道成立 |
| 諸天道域 | 道祖或超脫者 | 已知最高分類只剩這些稱呼 | 即使道祖也只能看到她們願意讓其看見的部分 |

旁人的推論必須一層層更合理，而不是一層層更會吹捧。有人敬畏、有人懷疑、有人想交易、有人只想研究、有人擔心既有秩序被改變，也有人得到機緣後選擇隱瞞。迪化的樂趣來自不同人以有限資訊拼出不同答案。

## 十一、建議篇幅與地域曝光順序

以下章數只作節奏參考，不是不可修改的硬限制：

1. **青河郡篇（約第1—60章）：**歸雲宗危局、問雲碑、顧行舟第一次回報、小院需要日用品、青河城與地方勢力建立各自判斷。
2. **雲州篇（約第61—160章）：**問星樓第一次正式評級，多宗爭取機緣，六人的日常創造開始改變一州修行方式。
3. **東陵篇（約第161—300章）：**皇朝、四品大宗與妖族巨頭介入；不同勢力不再只求寶物，而是開始爭論小院究竟想讓世界變成什麼。
4. **蒼玄界篇（約第301—500章）：**聖地與飛升傳承出現，上界印記甦醒，第一件小院日常物品意外進入青冥仙域。
5. **青冥仙域篇（約第501章後）：**歸雲仙宗、接引古城與帝統勢力從上界重新解讀下界異象；六人可選擇前往，而不是被迫飛升。
6. **九域與道域篇：**只有當仙域人物與既有矛盾真正完成後再開啟，不以連續換地圖取代人物關係和配角成長。

## 十二、不得破壞的世界觀原則

- 境界高不等於人物更聰明、更高貴或在家庭中更有地位。
- 低階人物也能憑證據作出比高階人物更接近真相的判斷。
- 新地域的人不會自動知道舊地域發生的一切；消息需要傳播、驗證與失真。
- 六人知道自己強大，不能為了迪化把她們寫成連普通修煉常識都不懂。
- 小曦的懵懂在於沒有外界力量尺度，不是完全沒有知識、記憶與判斷。
- 飛升不是力量重置；顧行舟等配角在下界建立的人生與成果不因進入仙域便失去價值。
- 上界不是所有人的終極答案。每一層人物都只能依自己的認知為小院命名，而讀者會知道他們仍只看見其中一部分。
