# 末世莉月｜統一專案交接

本目錄是「莉月超市」相關創作的統一容器，但不是把所有版本合成同一條時間線。

## 閱讀入口

1. 先讀 `source-research/末世重生無敵商店爽文_研究與創作轉化.md`，理解最初參考框架及不可直接照搬的部分。
2. 要續寫正式末世正線，讀 `mainline/canon/末世莉月正線_世界與創作基準.md`、`mainline/continuity/末世莉月正線_章節索引.md`，再讀第 175 章。
3. 要續寫七十二年後分支，讀 `branches/late-era-72-years/canon/末世莉月七十二年後高武分支總檔.md` 與該線連續性說明。
4. 要續寫全民覺醒重置線，讀 `branches/high-martial-reset/canon/全民覺醒重置線_世界基準.md` 與該線連續性說明。
5. 四位 OC 的跨世界權威設定位於 `../../shared/four-oc-dossier/`，本專案只保存世界線內的變體與事件。

## 世界線隔離

- `mainline/`：大夏末世、秦昭重生、莉月超市正線；正文第 1–175 章。
- `branches/late-era-72-years/`：末世正線七十二年後的非正史高武分支；正文第 1–4 章。
- `branches/high-martial-reset/`：完全重置的現代全民覺醒世界；不是末世後續；正文第 1–7 章。
- `source-research/`：題材研究、參考作品骨架與創作轉化記錄；只提供靈感，不能凌駕正文與後期總檔。

## 優先順序

明確作廢／撤回 ＞ 後期明確修正 ＞ 後期較完整補充 ＞ 早期仍相容設定。各線正文與索引只在本線內生效，除非使用者明確要求合併。
